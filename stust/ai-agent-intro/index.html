以商管情境為起點，認識如何與 AI Agent 協作，將需求整理成可檢查的小型網頁作品。

課程設計與學習目標

本工作坊不要求學生先會寫程式，而是從熟悉的商管問題出發，練習說明使用者、目標、限制與完成條件，再與 AI Agent 協作完成可檢查的成果。

  • 建立 AI Agent 的基本觀念，了解工具可以協助的範圍與限制。
  • 從商管情境練習整理需求，避免只得到零散的 AI 回覆。
  • 完成可在瀏覽器開啟的小型作品，並練習檢查與修正。
  • 將個資、未公開資料、來源與人為判斷納入日常使用原則。

兩種工作坊設計

兩種設計都會建立 AI Agent 基礎、需求整理、作品檢查與修正的能力；詳細活動安排將於上課時說明。

上午流程

  • 第一節：建立共同觀念，從商管問題整理需求與完成條件。
  • 第二節：與 AI Agent 協作完成小型作品，進行檢查、修正與分享。

各班會使用相同的學習主軸；案例與討論會依課程特色調整。詳細操作流程與教材將於上課時說明。

課程重點

  • 認識生成式 AI、聊天工具與 AI Agent 的差異。
  • 練習把商管問題整理成清楚的需求與完成條件。
  • 以 AI Agent 協作完成一個可在瀏覽器開啟的小型作品。
  • 學習檢查、修正與負責任使用 AI 的基本原則。

課堂會依各班的學習情況調整示範與實作內容；詳細操作流程與教材將於上課時說明。

課前準備

  • 筆記型電腦、電源與穩定網路。
  • 依課堂通知準備可使用的 AI 工具帳號。
  • 請勿準備或輸入個人資料、公司機密或未公開資料。
