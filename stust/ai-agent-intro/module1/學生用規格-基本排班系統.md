# 迷你賣場排班系統規格

## 系統目標

建立一個供迷你會員制賣場主管使用的基本排班數位工具。系統提供一週的排班建議，依職員的主要職務、技能及可工作時間安排人力，並顯示尚未補足的人力需求。

本系統是教學用範例，情境參考大型倉儲賣場，但不是好市多的官方系統，也不代表任何真實企業的營運規定。系統使用的職員、資料及排班規則皆為虛構。排班結果為待主管確認的建議草稿。

## 使用者與工作角色

系統使用者為賣場主管，可檢視職員資料、產生班表、重新產生班表及查看人力缺額。賣場包含以下六種工作角色：

| 工作角色 | 工作內容 |
|---|---|
| 主管 | 現場管理、班表確認及工作協調 |
| 收銀人員 | 收銀及結帳服務 |
| 賣場服務人員 | 顧客引導、商品介紹及賣場整理 |
| 倉儲理貨人員 | 收貨、補貨及庫存整理 |
| 清潔人員 | 賣場清潔及環境維護 |
| 保全人員 | 出入口秩序、現場巡查及安全通報 |

## 職員資料

系統使用同一資料夾中的「虛構職員資料庫.json」作為職員資料來源。該檔包含 27 名小說虛構角色，並提供姓名、主要職務、技能、可排班日及可排時段。資料中的賣場職務與技能是本範例設定，不代表角色在原著中的職業。職員姓名、職務與技能須依 JSON 原始資料呈現，技能須與所屬職務相符；不得加入真實員工或其他個人資料。

系統須在畫面上提供職員名單檢視，顯示姓名、主要職務、技能及可排班時間。若採用單一網頁檔案，須將 JSON 中相同的虛構資料放入網頁程式，確保本機直接開啟時仍可操作，不需架設伺服器。

## 排班範圍與人力需求

排班範圍為星期一至星期日，每天分為三個時段：

| 時段 | 時間 |
|---|---|
| 早班 | 08:00–12:00 |
| 中班 | 12:00–16:00 |
| 晚班 | 16:00–20:00 |

每個時段各職務的基本需求如下：

| 工作角色 | 每時段需求人數 |
|---|---:|
| 主管 | 1 |
| 收銀人員 | 2 |
| 賣場服務人員 | 1 |
| 倉儲理貨人員 | 1 |
| 清潔人員 | 1 |
| 保全人員 | 1 |

系統須呈現每個日期、時段及職務的需求人數與實際排班人數。

## 排班規則

1. 只能安排在該日期及時段有空的職員。
2. 職員只能排入其主要職務；安排前須確認其技能符合該職務需求。
3. 同一職員每天最多安排一個時段，同一時段不得重複安排該職員。
4. 同一職員每週最多安排六個時段，以保留每週至少一個休息日。
5. 排班時依職員目前已排的時段數由少至多選擇，盡量平均分配工作；時段數相同時，依固定順序選擇，讓相同資料可重現相同結果。
6. 每個職務盡量達到指定需求。若沒有合格且有空的職員，須保留缺額，不得安排不合格人員或隱藏缺額。
7. 產生班表時，依星期、時段及工作角色逐項安排；每次選擇符合可工作時間、職務資格、未撞班及每週時段上限的職員。無合適人員時，記錄該日期、時段、職務及缺少人數。
8. 每次重新產生班表，都須依目前職員資料及需求重新計算班表與缺額。
9. 系統只需使用上述簡單規則，不需進階最佳化演算法，也不得宣稱班表為最佳或唯一正確結果。

## 介面與功能

系統須提供繁體中文介面，包含以下內容與操作：

- 系統名稱：「迷你賣場排班系統」。
- 說明此系統使用虛構資料，產生的班表須由主管確認。
- 「產生班表」及「重新產生班表」操作。
- 一週班表檢視，顯示日期、時段、工作角色、需求人數、實際人數及職員姓名。
- 職員資料檢視，顯示姓名、主要職務、技能及可排班日與時段。
- 缺額提示，逐項顯示日期、時段、工作角色及尚缺人數。
- 依日期或時段篩選班表；若整週檢視仍清楚易讀，可不提供篩選。
- 資料錯誤或格式無法讀取時，顯示清楚的繁體中文提示。
- 版面適合一般桌上型電腦及手機寬度閱讀。
- 班表狀態明確標示為「待主管確認的建議草稿」。

## 系統範圍

- 系統須能在本機以瀏覽器開啟及操作。
- 使用簡單網頁檔案及瀏覽器內建功能，不需安裝額外套件。
- 不需帳號登入、伺服器、資料庫或雲端服務。
- 不包含薪資計算、績效評量、員工管理或工作申請流程。
- 不包含臨時請假、代班安排或其他進階排班功能。
- 不使用真實員工、顧客、企業內部或敏感資料。

## 驗收條件

1. 系統可在本機瀏覽器開啟，主要介面使用繁體中文。
2. 系統使用「虛構職員資料庫.json」所列的 27 名職員資料，不需使用者先建立名單。
3. 使用者可產生並重新產生星期一至星期日、每天三個時段的班表。
4. 排班只會使用可於該日期及時段工作的合格職員。
5. 不會將同一職員安排在同一天的兩個時段，也不會讓職員每週超過六個時段。
6. 未達人力需求時，會清楚顯示日期、時段、職務及缺少人數。
7. 職員名單及班表均能清楚閱讀；班表標示為待主管確認的建議草稿。
