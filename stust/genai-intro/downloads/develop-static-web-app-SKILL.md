# 靜態網頁小工具製作流程

以臺灣繁體中文說明，英文名詞補充。學生完全沒有寫程式經驗；提供給學生複製的提示必須用一般用語描述目的、畫面、操作與預期結果，不要求學生指定程式語法、CSS、色碼、像素或套件。技術實作由 Agent 處理，交付時用編號步驟帶學生找檔案、開啟與驗收。先確認實際專案位置，讀取使用者需求與指定素材；詳細六步驟見 [workflow.md](references/workflow.md)。

1. **說清楚需求（Brief）**：列使用者、輸入、操作、輸出、限制與可人工核對的預期答案。來源缺字或規則不清楚時記錄疑問，不從圖片猜出未提供的規則。
2. **建立專案（Project）**：建立本機資料夾，保存 brief.md、prompt.md、素材與 notes.md。空白起點不得讀取或沿用其他範例的 CSS、配色、範本或布局；不要把後階段的完整規格偷加到 Basic 提示。
3. **做最小版本（Build）**：使用本機 HTML/CSS/JavaScript。需要離線時，不使用 CDN、網路字體、外部 API 或框架依賴。先完成一條可操作流程。
4. **親自測試（Check）**：開啟實際網頁，對照正常、邊界、錯填及精度案例，檢查鍵盤、手機寬度與離線開啟。依題目選適用項目；使用瀏覽器截圖，不用示意圖代替執行證據。未執行項目明列「未測」。
5. **具體修改（Refine）**：保存可獨立開啟的 01-short、02-full、03-improved。Basic 使用瀏覽器預設外觀；Minor 白底、藍色按鈕、單欄且重新寫 CSS；Detailed 在完整版副本上保留功能，重新依學生描述的配色、區塊位置、文字大小與手機排列。不得把外觀修改混入算法修改；計算與顯示四捨五入分開處理。修改後重跑原案例。
6. **保存交付（Deliver）**：保存每階段的提示詞、README、實際截圖、預期／實際／通過／待修的驗收表，列出假設、未測項目與開啟方法。若有圖片，複製完整素材資料夾。只在使用者要求時發布。

## 教學圖轉工具

先由使用者確認教學圖的輸入、規則、單位與限制。醫事案例只用虛構教學數值，不加入個案資料、診斷或臨床建議。專業規則由來源與人工驗收決定，不能以畫面漂亮或沒有程式錯誤代替正確性。

本工作坊示範：視光 Detailed 使用青綠左右工作台；醫檢 Detailed 使用琥珀工作紙。新題目可自行指定風格，不預設沿用這兩套 CSS。不可把已保存的驗收報告說成新一輪 AI 生成已通過。
