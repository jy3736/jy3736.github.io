# AI 基礎與 AI Agent 實作：完成一個最小可行的專業數位工具

中華醫事科技大學短期課程設計（重建版）

## 課程定位

本課程面向以視光系、醫檢系為主的學生，以「理解 AI、操作 AI Agent、完成一個最小可行的專業數位工具」為主軸。它不要求學生先具備程式基礎；第一單元建立從辨別式 AI、生成式 AI、Chatbot、推理模型到 AI Agent 的基本脈絡；第二單元聚焦 AI Agent 與 Vibe Coding 的專案操作，練習建立、管理、加入與修改專案資源；第三單元則以視光或醫檢的簡單情境，完成一個可立即操作的專業數位工具。

當程式實作能由 AI Agent 協助時，人更需要說清楚想解決的問題、需要哪些資料、規則如何運作，以及結果是否合理。課程刻意不追求複雜功能，而是讓學生在有限時間內完成一次「從專業問題到可運作成果」的完整體驗；程式實作的門檻雖可由 AI Agent 降低，但專業知識、需求定義、規則說明、結果驗證與責任判斷，正是學生需要帶走的核心能力。

## 單元一：從機器學習到 AI Agent

### 目的

為學生建立一個簡單但正確的 AI 脈絡，而不是急著操作工具。

### 內容

- 辨別式 AI／早期機器學習：依既有資料進行辨識、分類或預測。
- 生成式 AI：產生文字、圖像或其他內容。
- Chatbot：以對話方式回應、協助查詢與產生內容。
- 推理模型：適合需要多步分析、規劃或檢索的任務。
- AI Agent：在授權範圍內結合任務、上下文與工具，分步完成工作。

### 學習重點

學生能分辨不同 AI 使用方式，並理解專業判斷、資料確認與最終責任不能交給 AI 取代。

## 單元二：AI Agent 與 Vibe Coding 的專案操作

### 目的

讓學生真正知道「專案」是什麼，以及如何透過 AI Agent 在專案內完成、修改與延伸工作。

### 操作內容

1. 建立專案資料夾，確認儲存位置與重新開啟方式。
2. 認識並新增檔案，例如 `index.html`、`notes.md` 與 `assets/`。
3. 加入額外的公開素材或教學資料，請 AI Agent 讀取、整理或修改內容。
4. 用清楚的需求引導 AI Agent 產生或修改程式、文件、網頁文字與素材規劃。
5. 直接開啟網頁，確認產出結果並進行小幅修正。

```text
my-first-agent-project/
├── index.html      # 可直接在瀏覽器開啟的頁面
├── notes.md        # 需求、規則與測試紀錄
└── assets/         # 額外加入的公開素材或教學資料
```

### Vibe Coding 的課堂定義

Vibe Coding 不等於不思考地讓 AI 寫程式。學生需要說清楚目標、限制、資料、規則與驗收方式；AI Agent 協助實作，學生再檢查、測試與調整結果。

## 單元三：用 AI Agent 做出專業 MVP

### 目的

讓學生體驗：即使不熟悉程式，也可以將一個清楚、簡單的專業問題做成可操作的網頁工具。

### MVP 範圍

- 一個靜態網頁。
- 少量輸入欄位。
- 一段明確、可驗證的規則或公式。
- 一個按鈕與立即可見的結果。
- 對空白、非數字、負值或不合理輸入的提示。
- 以至少兩到三組虛構資料進行測試。

### 視光系範例：處方轉換器

輸入虛構的球面度數、柱面度數、軸度等處方資料，依課堂設定的轉換規則顯示結果。工具目標是練習欄位設計、規則實作與輸入檢查，不提供處方建議。

### 醫檢系範例：稀釋換算器

輸入虛構的原液濃度、目標濃度與目標體積，依課堂公式計算所需原液與稀釋液體積。工具目標是練習單位、公式、結果呈現與輸入檢查，不提供檢驗判讀或實務決策。

## 課程完成指標

課程結束時，學生能展示一個最小但可運作的網頁工具：輸入少量虛構資料、按下按鈕、看見依規則產生的結果，並知道如何請 AI Agent 協助修改它。

完成比複雜更重要。學生要帶走的是一個可延伸到未來專題的流程：用專業知識定義問題，讓 AI Agent 協助製作，最後由人檢查與負責。

## 課堂界線與準備

- 不輸入真實個資、病歷、檢驗資料或其他敏感資料。
- 所有案例均使用虛構教學資料與課堂規則。
- 學生準備筆記型電腦、電源、穩定網路與可用 AI Agent 帳號。
- 依主辦單位事前確認可用工具、登入方式與額度。
