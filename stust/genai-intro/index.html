中華醫事科技大學 × AI Agent 實作講義

從專業問題出發，說清楚規則，完成能在自己電腦上操作並驗收的小工具。不需要先會寫程式。

  • 認識 AI Agent
  • 保存工作方法
  • 學會製作流程
  • 自主練習：視光或醫檢實作

課程單元

  1. 單元一

    從機器學習到 AI Agent

    從 ChatGPT 之前的機器學習與辨別式 AI 談起，認識辨別、生成、對話、推理與工具操作，比較 Chat、Work、Codex 各自交付什麼。再用讀書計畫、小組會議紀錄與準備清單練習清楚交辦、核對來源，最後寫出自己的五欄需求表。

    進入單元 →
  2. 單元二

    從 Gems、GPTs 到自己的第一個 Skill

    比較一般聊天、Gems／GPTs 與 Skill 各保存了什麼。以活動通知整理完成五個操作：先做一次、指定做法、使用保存的技能、換一份有缺漏與矛盾的資料再用、修改一條規則並重跑；最後把自己常做的整理工作保存成技能。

    進入單元 →
  3. 單元三

    AI Agent 與靜態網頁製作流程

    認識網頁 APP 的檔案與用途，再把服飾門市的兩層折扣做成促銷購物車結帳試算器：檢查 60 項商品資料、建立試算器、親自驗算折扣金額，接著調整畫面並整理成商品型錄。範例可以不同，提示要求的功能一項都不能少。

    進入單元 →

  4. 自主練習：依科系從單元四、單元五擇一

  5. 單元四 · 自主練習

    視光教學圖：處方轉換

    依課堂規則把負柱鏡處方轉換為正柱鏡。先手算虛構案例，抓出軸度 90° 與 91° 的邊界，再以 Basic、Minor、Detailed 三階段提示製作、測試與改進，比較三個版本的差異。

    進入單元 →
  6. 單元五 · 自主練習

    醫檢教學圖：稀釋換算

    依 C₁V₁ = C₂V₂ 計算原液與稀釋液體積。先分清最終體積與稀釋液、確認共同單位與顯示精度，處理濃度相同等邊界，再以三階段提示製作並逐項驗收。
