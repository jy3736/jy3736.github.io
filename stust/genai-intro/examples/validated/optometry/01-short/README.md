# 負柱鏡轉正柱鏡小工具

## 怎麼打開

1. 在這個資料夾找到 `index.html`。
2. 用滑鼠雙擊 `index.html`，網頁就會在電腦的瀏覽器中開啟。
3. 如果雙擊沒有開啟瀏覽器，請在檔案上按滑鼠右鍵，選擇「打開檔案的應用程式」或「開啟方式」，再選你的瀏覽器。

不用安裝軟體，也不用連網路。`README.md` 是這份使用說明，`prompt.md` 是本階段的學生提示。

## 怎麼使用

1. 輸入球面度數，例如 `-2.00`。
2. 輸入柱面度數，例如 `-1.00`。這個工具是負柱鏡轉正柱鏡，所以柱面請填負數或 `0`。
3. 輸入軸度，例如 `180`。請填 `1` 到 `180` 的整數。
4. 按「轉換處方」，下方會出現新球面度數、新柱面度數和新軸度。

上面的例子會得到球面 `-3.00 D`、柱面 `+1.00 D`、軸度 `90°`。

度數欄只要輸入數字，不要加上 `D`；軸度欄不要加上 `°`。如果漏填或輸入超出範圍，瀏覽器會提醒你修改。

要算另一組處方，直接修改欄位，再按一次「轉換處方」。修改輸入後，上一組結果會先隱藏，避免把它當成新結果。

## 計算方式

- 新球面度數 = 原球面度數 + 原柱面度數。
- 新柱面度數 = 原柱面度數變號。
- 新軸度 = 原軸度 + 90；超過 180 就減 180。

結果的度數顯示到小數點後兩位；計算使用你輸入的數值。柱面為 `0` 時，工具仍依上面的公式計算軸度。
