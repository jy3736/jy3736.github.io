# 第二步：完整版提示詞（另開資料夾重做一次）

完整版提示詞內容與講義〈給 AI Agent 的 MVP 提示詞・第二步〉相同，這裡不重複抄錄，重點是它補上了短版沒講的那些決定：

- 明講五個輸入欄位，**包含兩個單位下拉選單**（濃度：mg/mL、µg/mL、%（w/v）；體積：mL、µL）
- 明講兩個濃度共用一個濃度單位、所有體積共用一個體積單位，而且**不要自動換算**
- 明講合理範圍：C1 > 0、V2 > 0、0 < C2 ≤ C1，並說明 C2 ＝ C1 是合理的（不需稀釋）
- 明講錯誤處理：空白、非數字、超出範圍、大到算不出來，都不要計算
- 明講顯示到小數點後三位、過程用完整數值、畫面要註明是四捨五入、不可出現 -0.000
- 明講畫面要印出三個式子、要有警語、要能用鍵盤操作

## 跟短版比，差在哪裡

| 項目 | 短版 | 完整版 |
|---|---|---|
| 單位 | AI 寫死 mg/mL 和 mL | 兩個下拉選單，選了就同步到所有相關欄位與答案 |
| 3 / 1 / 10 | 3.3333333333333335 mL | 3.333 mL（並註明是四捨五入） |
| C2 > C1 | 照算，給 -100 mL 稀釋液 | 擋下來，說明「稀釋只會把溶液變稀」 |
| C1 = 0 | Infinity | 擋下來，說明濃度必須大於 0 |
| C1 或 V2 負值 | 照算 | 擋下來 |
| V2 = 0 | 給 0 / 0 | 擋下來 |
| 三格留空 | 顯示 NaN | 三格各給一句提醒 |
| 超大數字（1e400） | 顯示 Infinity | 擋下來，說「大到電腦算不出來」 |
| 畫面說明 | 只有一行公式 | 三個式子＋四捨五入說明＋為什麼 C2 不能大於 C1＋僅供練習警語 |
| 鍵盤操作 | 沒特別處理 | Tab 移動、Enter 送出、焦點看得見 |

## 關於單位的一個重點

工具**不會**幫我換算單位。兩個濃度都用同一個單位、兩個體積都用同一個單位，代入 C1V1 = C2V2 的時候單位會在等號兩邊上下消掉，真正參與計算的只有數字。我實際試過：把 10 / 2 / 25 那組的單位改成 µg/mL 和 µL，答案還是 5.000 µL 和 20.000 µL——數字一樣，只有標示跟著換。這是對的行為，不是 bug。
