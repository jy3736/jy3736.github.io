# 第二步：完整版提示詞（另開資料夾重做一次）

完整版提示詞內容與講義〈給 AI Agent 的 MVP 提示詞・第二步〉相同，這裡不重複抄錄，重點是它補上了短版沒講的那些決定：

- 明講第 3 條「**只有在大於 180 時**才減」，並舉出軸度 90 的反例
- 明講合理範圍：球面 -20～+20、柱面 -20 到小於 0、軸度 1–180 整數
- 明講柱面填 0 和填正值要提醒，不要硬算
- 明講錯誤處理、兩位小數、不可出現 -0.00、轉換後球面可能低於 -20 是正常的
- 明講畫面要放三條規則、正負柱鏡說明、僅供練習的警語
- 明講不要加的東西（個案紀錄、診斷建議、需要連網的功能）

## 跟短版比，差在哪裡

| 項目 | 短版 | 完整版 |
|---|---|---|
| 軸度 90 那組 | 給 0 度（錯） | 給 180 度（對） |
| 柱面填 0 | 照算 | 提醒「沒有散光，不需要轉換」 |
| 柱面填 +1.00 | 照算 | 提醒「本來就是正柱鏡了」 |
| 軸度 3.5 / 200 / 0 | 照算 | 分別提醒小數、超出範圍 |
| 球面 +30 | 照算 | 提醒超出合理範圍 |
| 三格留空 | 顯示 NaN | 三格各給一句提醒 |
| 柱面度數顯示 | `1.00 D` | `+1.00 D`（正常帶正號） |
| 畫面說明 | 沒有 | 三條規則＋正負柱鏡說明＋僅供練習警語 |
| 鍵盤操作 | 沒特別處理 | Tab 移動、Enter 送出、焦點看得見 |

## 我實際跑過的五組核對（全部相符）

| 輸入 | 工具給的答案 | 我手算的答案 |
|---|---|---|
| -2.00 / -1.00 / 180 | -3.00 D / +1.00 D × 90° | 相同 |
| +1.50 / -2.25 / 100 | -0.75 D / +2.25 D × 10° | 相同 |
| -4.00 / -0.50 / 1 | -4.50 D / +0.50 D × 91° | 相同 |
| +0.25 / -0.75 / 90 | -0.50 D / +0.75 D × 180° | 相同（邊界，不必減） |
| -1.00 / -0.50 / 91 | -1.50 D / +0.50 D × 1° | 相同（邊界，要減） |

另外試了 -20.00 / -2.00 / 45，得到 -22.00 D / +2.00 D × 135°。轉換後球面低於 -20 是兩個度數相加的正常結果，工具沒有當成錯誤，這點是對的。
