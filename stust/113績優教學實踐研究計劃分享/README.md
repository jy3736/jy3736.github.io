## 預覽與操作

可直接用瀏覽器開啟 `index.html`，或在專案根目錄執行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory 簡報開發/docs
```

開啟 `http://127.0.0.1:8765/`。這只提供本機預覽，不會發布網站。

- 左右箭頭、←／→、PageUp／PageDown：換頁。
- 目錄：跳至指定頁；點空白遮罩或 Esc 關閉。
- 講稿／N：切換目前頁面的詳細講稿；換頁時跟著更新。
- 滿版／Ctrl+F／⌘F：切換放大呈現，Esc 退出。這是網頁版面切換，不會強制瀏覽器進入系統全螢幕。
- Home／End：第一頁／最後一頁。
