大家好，歡迎來到「AI Agent 實作：從 Vibe Coding 到可重現的商管應用」。

這是一門為商管學院大學生設計的兩週短期課程，共四堂課、十二小時。不需要程式背景；只要帶著筆記型電腦、願意動手嘗試，就可以開始。

這門課不只是教大家如何向 AI 下指令，而是帶大家學習：如何把真實的商管問題，整理成清楚的目標、資料、限制與完成標準，再和 AI Agent 一起完成可用的數位作品。

課程中，我們會認識 Codex、Claude Code、GitHub Copilot 與 Antigravity 等 AI Agent 工具，也會了解生成式 AI、AI Agent、Vibe Coding 與 VS Code 的基本概念。更重要的是，學生會練習檢查 AI 的成果，修正問題，而不是直接相信第一個答案。

接著，我們會用 Vibe Coding 製作商管情境的靜態網頁，例如活動行銷、產品介紹、成本試算或 KPI 儀表板。第三堂課則會進一步建立智慧網頁資料蒐集 Skill，讓 AI Agent 協助整理公開且可合理使用的資訊，並在網頁版面改變後重新驗證結果。

最後，我們會完成一個公司任務派工與人力排班系統。假設公司當天有五項任務，每項任務需要不同的人數與專業技能，例如電子工程、機械工程或業務支援。系統會根據人員的可上班時段與專長，產生一份每日派工與排班建議表。

學生將從中理解前端操作介面、網頁伺服端、簡易資料庫與 AI Agent 協作開發之間的關係。課程的目標不是立刻做出完美系統，而是完成一個真正能運作、能測試，也能持續改進的最小樣本。

讓我們一起把 AI，從聊天工具，變成能協助解決商管問題的實作夥伴。
