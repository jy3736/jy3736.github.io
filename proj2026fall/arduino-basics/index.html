怎麼使用這份講義？

  1. 先看「看一看」，再動手：每一節都先用生活中的例子說明原理，看懂了再接線，比較不會接錯。
  2. 接線照步驟一條一條來：每接完一條就對照電路圖，確認插在正確的孔位。
  3. 程式可以複製，但最好自己打一次：程式框右上角有「複製」按鈕。親手打過，才會發現大小寫、分號這些細節。
  4. 先猜再看答案：有「先猜猜看」的地方，點開之前先在心裡想一想，猜錯的地方最值得記住。
  5. 「改一改」一定要做：改一個數字、觀察板子的變化，是理解程式最快的方法。練習的參考解答請先自己試過再點開。
  6. 打勾追蹤進度：每個單元開頭的學習目標可以打勾，會記在你這台電腦的瀏覽器裡。

Arduino IDE 基本操作

每個單元都會用到下面這幾個動作，先熟悉位置。

動作在哪裡做什麼
選擇開發板與連接埠「工具」選單，或視窗上方的開發板下拉選單選「Arduino UNO」，以及接上 USB 後出現的連接埠
驗證左上角的打勾圖示檢查程式有沒有寫錯，但不上傳
上傳左上角的向右箭頭圖示把程式編譯後送進板子，板子會立刻開始執行
序列埠監控視窗右上角的放大鏡圖示看板子用 Serial.println() 送回來的文字與數字
序列埠繪圖家「工具」選單把板子送回來的數字畫成曲線

每次上傳前的三個確認

① USB 線有接好　② 開發板選的是 Arduino UNO　③ 連接埠選對了。上傳失敗時，九成都是這三項其中一項的問題。

接線的安全習慣

  • 改接線之前，先拔掉 USB 線，接好、檢查過再插回去。
  • LED 一定要串聯電阻（本課程用 220 歐姆），電阻會限制電流，保護 LED 與板子。
  • 5V 和 GND 不可以直接接在一起，這樣會短路。
  • 元件發燙、有焦味時，立刻拔掉 USB 線，再檢查接線。

麵包板怎麼通？

麵包板上的洞，有些內部是連在一起的。弄懂哪些洞相通，接線才不會出錯。

不同品牌的麵包板，電源軌可能在中間斷開。如果某一段沒電，用杜邦線把兩段接起來即可。
