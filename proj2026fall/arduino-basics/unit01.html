1. 從程式到板子：開發的流程

Arduino UNO 是一塊小小的電腦板。它沒有螢幕、沒有鍵盤，要讓它做事，必須先在電腦上把「要做的事」寫成程式，再透過 USB 線送進板子。每一次開發都是同樣的四個步驟：

① 在 Arduino IDE 寫程式→② 驗證：檢查有沒有寫錯→③ 上傳：送進板子→④ 觀察板子的反應

程式一旦上傳成功，就存在板子裡。即使拔掉 USB 線、改用其他電源供電，板子一通電就會再執行同一個程式，直到你上傳新的程式把它蓋掉。

認識板子上的腳位

UNO 板子邊緣一排一排的小孔叫做腳位，是板子和外面元件連接的地方。這學期會用到的有下面幾種：

腳位板子上的標示用途
數位腳位0 到 13輸出或讀取「有電、沒電」兩種狀態，例如控制 LED、讀取按鈕
類比輸入腳位A0 到 A5讀取連續變化的電壓，例如旋鈕、光線（第 3 單元）
5V5V提供 5 伏特的電源給元件
GNDGND接地，也就是電路的 0 伏特。每個電路最後都要回到 GND

2. Arduino 程式的基本架構

看一看兩個一定要有的區塊

每一個 Arduino 程式都至少要有兩個區塊，缺一個就無法編譯：

區塊什麼時候執行通常放什麼
setup()板子通電或按下重置後，只執行一次設定腳位用途、開始序列通訊等準備工作
loop()setup() 結束後，一直重複執行板子要持續做的事情

可以把它想成上課：setup() 是上課前把課本、文具擺好（只做一次）；loop() 是上課時一直重複的「聽講、寫筆記」。

動手做最小的 Arduino 程式

在 Arduino IDE 開一個新檔，你會看到下面這個樣子。它什麼事都不做，但可以成功編譯，這就是最小的 Arduino 程式。

  1. 用 USB 線把 UNO 接到電腦。
  2. 在 Arduino IDE 選擇開發板「Arduino UNO」與對應的連接埠。
  3. 按下「驗證」（打勾圖示），確認下方沒有出現紅色錯誤訊息。

看懂程式的每個符號

這幾行程式雖然短，卻包含了之後每個單元都會用到的寫法規則：

符號意思
void寫在區塊名稱前面，表示這個區塊做完事情後不需要交回任何結果。setup() 和 loop() 前面都要寫。
() 小括號緊接在名稱後面。之後會看到 delay(1000) 這種寫法，小括號裡放的是要交給它的數值。
{ } 大括號把屬於同一個區塊的程式包起來。{ 和 } 一定要成對。
; 分號每一行指令的結尾。就像中文句子結尾的句號，少了就會出錯。
// 註解後面的文字是寫給人看的說明，板子會直接忽略。

認識註解

// 後面的文字叫做註解。寫註解的好處是：下次打開程式，或同學要看你的程式時，能很快看懂每一行在做什麼。註解不會被送進板子，寫多少都不會讓程式變慢。

Arduino 程式區分大小寫

setup 不能寫成 Setup，digitalWrite 不能寫成 digitalwrite。大小寫只要錯一個字母，IDE 就會說它不認識這個名稱。

3. 範例 Blink：讓板上 LED 閃爍

看一看板上的 LED 在哪裡

UNO 板子上有一顆內建 LED，接在第 13 號數位腳位，旁邊通常印著字母 L。程式裡可以直接寫 LED_BUILTIN 代表這顆 LED 的腳位，不必自己記編號。

要讓 LED 亮，程式要做兩件事：

  1. 先告訴板子：第 13 號腳位是用來「送出」訊號的（輸出）。這件事只要做一次，所以放在 setup()。
  2. 再控制腳位：送出高電位（有電）LED 就亮，送出低電位（沒電）LED 就滅。這件事要一直重複，所以放在 loop()。

動手做上傳 Blink

  1. 把上面的程式輸入 Arduino IDE。
  2. 按「上傳」（向右箭頭圖示）。
  3. 觀察板上 LED 是否每秒亮一次、滅一次。

逐行說明

指令作用
pinMode(腳位, OUTPUT)告訴板子：這個腳位要用來「送出」訊號
digitalWrite(腳位, HIGH)讓腳位輸出高電位，LED 亮起
digitalWrite(腳位, LOW)讓腳位輸出低電位，LED 熄滅
delay(毫秒)讓程式暫停指定的時間，1000 毫秒等於 1 秒。暫停的時候，腳位維持原本的狀態

一步一步追蹤：板子到底做了什麼？

把程式想像成一張待辦清單，板子從上到下一行一行照做。下表是上傳後前 4 秒發生的事：

時間正在執行LED
0 秒setup()：pinMode(LED_BUILTIN, OUTPUT)滅
0 秒第 1 輪 loop()：digitalWrite(LED_BUILTIN, HIGH)亮
0 到 1 秒delay(1000)：等待亮
1 秒digitalWrite(LED_BUILTIN, LOW)滅
1 到 2 秒delay(1000)：等待滅
2 秒loop() 最後一行做完，回到開頭，開始第 2 輪：HIGH亮
2 到 4 秒重複同樣的四行亮 1 秒、滅 1 秒

畫成時間圖，就是一個整齊的「亮、滅、亮、滅」：

為什麼一定要有第二個 delay()？

如果把 LOW 後面那個 delay(1000) 刪掉，LED 熄滅之後，程式會馬上回到 loop() 開頭把它點亮。熄滅的時間短到眼睛看不出來，LED 看起來就像一直亮著。

改一改動手修改，觀察變化

  1. 把兩個 delay(1000) 都改成 delay(200)，LED 會變怎樣？
  2. 只改第一個 delay() 為 100，第二個維持 1000，亮與滅的時間有什麼不同？
  3. 試著讓 LED 做出「快閃兩下、停一秒」的節奏。
  4. 在每一行後面，用 // 寫下你自己的中文說明。
第 1、2 題：看看你猜得對不對

第 1 題：LED 亮 0.2 秒、滅 0.2 秒，閃得快很多，每秒大約閃 2.5 次（1000 ÷ 400 = 2.5）。

第 2 題：亮的時間變成 0.1 秒，滅的時間還是 1 秒，看起來像「短短地閃一下，停很久」。第一個 delay() 管的是「亮多久」，第二個管的是「滅多久」。

第 3 題的想法：「快閃兩下」就是把「亮、等、滅、等」寫兩次，最後再加一個比較長的 delay(1000) 當作停頓。

常見錯誤

狀況可能原因解決方式
上傳失敗開發板或連接埠沒選對重新確認「工具」選單中的開發板與連接埠
出現紅字錯誤少了分號 ; 或大括號 {} 沒成對對照範例，檢查每行結尾與括號

看懂錯誤訊息：少了分號

如果把 delay(1000) 後面的 ; 刪掉，按下驗證會出現類似 expected ';' before 'digitalWrite' 的訊息。意思是「在 digitalWrite 前面，應該要有一個分號」。錯誤訊息指出的位置，常常是出錯那一行的下一行，所以要往上一行找。

4. 延伸：外接一顆 LED

看一看為什麼要加電阻

外接 LED 時一定要串聯一顆電阻。電阻會限制流過 LED 的電流，保護 LED 與板子不被損壞。可以把電流想成水流，電阻就像水管上的一段細管，讓水不會一下子衝太大。

LED 有分正負腳，接反了不會亮：

LED 的腳怎麼認接到哪裡
正極長腳經過電阻接到腳位（送出訊號的那一邊）
負極短腳GND

電流的路線是：第 13 號腳位 → 電阻 → LED 長腳 → LED 短腳 → GND。整條路要接成一個圈，LED 才會亮。

動手做接線

  1. 拔掉 USB 線。
  2. 電阻一端接到 UNO 的第 13 號腳位。
  3. 電阻另一端接 LED 的長腳（正極）。
  4. LED 的短腳（負極）接到 UNO 的 GND。
  5. 檢查一次，再插回 USB 線。

接好後不必改程式，外接 LED 會和板上 LED 一起閃爍，因為兩顆 LED 都由第 13 號腳位控制。

改一改換一個腳位

把電阻改接到第 12 號腳位，並把程式中的 LED_BUILTIN 改成 12。外接 LED 還會閃嗎？板上 LED 呢？

看參考解答
看說明：板上 LED 為什麼不閃了？

外接 LED 會繼續閃，因為程式現在控制的是第 12 號腳位，而它正好接著外接 LED。板上 LED 固定接在第 13 號腳位，程式已經不再控制第 13 號腳位，所以板上 LED 不會跟著閃。

記住：程式裡寫的腳位編號，必須和實際接線的腳位一致，這是之後每個單元都要檢查的事。

5. 加碼範例

只用 pinMode()、digitalWrite()、delay() 三個指令，就能做出很多種燈號。下面兩個範例都值得上傳試試看。

範例 A：平交道警示燈

平交道的紅燈是兩顆輪流亮。做法是：一顆亮的時候，另一顆一定要滅，然後交換。請把外接 LED 接在第 12 號腳位（接法和第 4 節相同，只是換腳位），搭配板上第 13 號腳位的 LED。

注意 setup() 裡有兩行 pinMode()：每一個要當作輸出的腳位，都要各自設定一次。

範例 B：SOS 求救燈號

摩斯電碼的 SOS 是「短短短、長長長、短短短」。這個範例用亮 200 毫秒代表短、亮 600 毫秒代表長。

  • 一行裡寫了兩個指令（例如 digitalWrite(LED_BUILTIN, HIGH); delay(200);），這是允許的，因為每個指令都用分號結尾。這樣寫可以讓「亮多久」一眼就看得出來。
  • 程式很長、很重複。第 6 單元學了 for 迴圈之後，可以把「閃三次」縮短成三行。

7. 自我檢核與重點回顧

自我檢核

  1. 我能說出 setup() 和 loop() 的差別嗎？
  2. 我能說出 delay(500) 代表暫停幾秒嗎？
  3. 我能不看範例，自己打出讓 LED 閃爍的程式嗎？
  4. 外接 LED 時，我知道長腳要接哪一邊、為什麼要加電阻嗎？
看參考答案
  1. setup() 在通電或重置後只執行一次，放準備工作；loop() 在 setup() 結束後一直重複執行，放要持續做的事。
  2. 0.5 秒。delay() 的單位是毫秒，500 ÷ 1000 = 0.5。
  3. 寫完後對照第 3 節的 Blink 範例，檢查大小寫、分號、大括號。
  4. 長腳是正極，經電阻接到腳位；短腳接 GND。電阻用來限制電流，保護 LED 與板子。

本單元重點回顧

  • Arduino 程式一定有 setup()（執行一次）與 loop()（一直重複）。
  • pinMode() 設定腳位用途，digitalWrite() 控制輸出高低電位。
  • delay() 的單位是毫秒，1000 毫秒等於 1 秒。
  • 註解 // 是寫給人看的說明；程式區分大小寫，每個指令以分號結尾。
  • 外接 LED 要串聯電阻，長腳接腳位那一側，短腳接 GND。
