第 3 單元：可變電阻與類比讀值

按鈕只有兩種狀態，但真實世界的很多東西是「連續變化」的，例如音量旋鈕、光線強弱。這個單元用可變電阻（旋鈕）產生連續變化的電壓，讓 UNO 讀成 0 到 1023 之間的數字，並學會用變數把數字存起來、換算成電壓。

本單元你會學到（學會了就打勾）

材料數量說明

1. 暖身：數位與類比

種類可能的值生活中的例子讀取指令腳位
數位只有兩種：HIGH 或 LOW電燈開關：開或關digitalRead()0 到 13
類比一整段範圍內的任何值音量旋鈕：可以轉到任何位置analogRead()A0 到 A5

2. 範例 Analog Read Serial：讀取旋鈕的數值

看一看可變電阻怎麼產生不同電壓

可變電阻有三隻腳。兩側的腳分別接 5V 和 GND，中間的腳會隨著旋轉，輸出 0 伏特到 5 伏特之間的電壓。

可以想像成一條溜滑梯：頂端是 5V，底部是 GND（0V），中間的腳是站在溜滑梯上的人。旋鈕轉動，就是讓這個人往上或往下移，他所在位置的「高度」就是中間腳的電壓。

看一看板子怎麼把電壓變成數字

UNO 內部有一個類比數位轉換器（簡稱 ADC），會把 0 到 5 伏特的電壓轉成 0 到 1023 的整數：

旋鈕位置中間腳電壓讀到的數字
轉到一端0 伏特0
中間位置約 2.5 伏特約 511
轉到另一端5 伏特1023

UNO 上標示 A0 到 A5 的腳位就是類比輸入腳位。

動手做接線

  1. 可變電阻一側的腳接 GND。
  2. 另一側的腳接 5V。
  3. 中間的腳接 A0。

動手做程式

  1. 上傳程式，打開序列埠監控視窗（速度 9600）。
  2. 慢慢轉動旋鈕，觀察數字變化。
  3. 關掉監控視窗，改開「工具」選單中的「序列埠繪圖家」，數字會變成一條曲線。

3. 認識變數、int 與 float

看一看變數是貼了標籤的盒子

int sensorValue = analogRead(A0); 這一行做了兩件事：

  1. 建立一個名叫 sensorValue 的變數，它就像一個貼了標籤的盒子，用來裝數字。
  2. 把 analogRead(A0) 讀到的數字放進盒子裡。
int：盒子的種類（裝整數）sensorValue：標籤上的名字=：放進去analogRead(A0)：要放進去的東西

之後在程式裡寫 sensorValue，就等於「打開這個盒子，拿出裡面的數字」。盒子裡的數字可以被換掉，所以叫做「變」數。

兩種常用的盒子

型態裝什麼例子適合用在
int整數（沒有小數點）0、512、-3腳位編號、讀值、次數
float有小數點的數2.5、0.0049電壓、溫度等需要小數的量

int 是 Arduino 程式最常用來存數字的型態。0 到 1023 都是整數，剛好適合用 int 存放。在 UNO R3 上，int 能存的範圍是 -32768 到 32767。

變數名字的規則

  • 可以用英文字母、數字、底線 _，但不能用數字開頭：led2 可以，2led 不行。
  • 不能有空格：想用兩個英文字，習慣寫成 sensorValue（第二個字開頭大寫）。
  • 區分大小寫：sensorValue 和 sensorvalue 是兩個不同的盒子。
  • 名字要有意義：sensorValue 比 a 好懂得多。

建立一次，之後直接使用

型態只在建立變數時寫一次。之後要換掉盒子裡的值，直接寫 sensorValue = 100;，前面不要再加 int。

改一改回到第 2 節的程式動手修改

  1. 把旋鈕轉到最左和最右，記錄你看到的最小值與最大值，是不是剛好 0 和 1023？
  2. 把 delay(1) 改成 delay(500)，數字更新的速度有什麼改變？
  3. 把中間腳改接到 A1，程式要改哪裡才能繼續讀到數值？
看說明

第 1 題：通常很接近 0 和 1023，有時會差一兩個數字，這是元件的小誤差，不影響使用。

第 2 題：每 0.5 秒才印一行，畫面變慢、比較好讀；但轉動旋鈕時，數字要等一下才跟上。

第 3 題：把 analogRead(A0) 改成 analogRead(A1)。程式裡的腳位要和實際接線一致。

4. 範例 Read Analog Voltage：換算成電壓

看一看從數字換回電壓

讀到的 0 到 1023 是「數字」，不是「伏特」。要換回電壓，可以用比例計算：

電壓 = 讀值 × (5.0 ÷ 1023.0)

意思是：把 5 伏特平均分成 1023 份，讀值是幾，就有幾份。

讀值計算電壓（取到小數點後 2 位）
00 × 5.0 ÷ 1023.00.00 V
256256 × 5.0 ÷ 1023.01.25 V
512512 × 5.0 ÷ 1023.02.50 V
767767 × 5.0 ÷ 1023.03.75 V
10231023 × 5.0 ÷ 1023.05.00 V

因為電壓會有小數點，所以要用可以存小數的型態 float，而不是只能存整數的 int。

小心整數相除

在 Arduino 程式裡，整數除以整數，結果還是整數，小數部分會直接捨去。只要其中一個數寫成有小數點的樣子（例如 5.0），就會用小數計算。下面這個範例把幾種算法印出來比較：

5. 加碼範例：旋鈕儀表

用同樣的比例算法，把讀值同時換算成電壓和「旋轉了百分之多少」，並用 Serial.print(值, 位數) 控制小數位數。"\t" 是跳格，可以讓每一欄對齊。

先猜猜看：讀值分別是 0、512、1023 時，會印出什麼？
序列埠監控視窗
讀值：0	電壓：0.000 V	旋轉：0.0 %
讀值：512	電壓：2.502 V	旋轉：50.0 %
讀值：1023	電壓：5.000 V	旋轉：100.0 %

512 × 5.0 ÷ 1023.0 = 2.50244…，印到 3 位小數是 2.502；512 × 100.0 ÷ 1023.0 = 50.048…，印到 1 位小數是 50.0。

為什麼百分比不寫成 sensorValue * 100 / 1023？

這樣寫全部都是整數計算。讀值 1023 乘以 100 會得到 102300，超過 UNO R3 上 int 能存的最大值 32767，算出來的結果會是錯的。寫成 100.0 / 1023.0 用小數計算，就沒有這個問題。

6. 補充：UNO R3 與 UNO R4 的差異

不同版本的 UNO，類比讀值的解析度不同：

板子類比腳位預設讀值解析度
UNO R3A0 到 A510 位元（0 到 1023）
UNO R4（Minima、WiFi）A0 到 A5最高可到 14 位元

本課程的程式以 0 到 1023 的範圍撰寫。如果你手上的是 UNO R4，請先向老師確認板子的設定。

練習 1：模擬溫度計

假設旋鈕代表 0 到 50 度的溫度：讀值 0 是 0.0 度，讀值 1023 是 50.0 度。每 0.5 秒印出一行「模擬溫度：25.0 度」，印到小數點後 1 位。

練習 2：還差多少？

每 0.5 秒印出目前讀值，以及距離最大值 1023 還差多少，例如「讀值 800，還差 223」。這一題需要用 float 嗎？

看參考解答
看說明：需要 float 嗎？

不需要。1023 減掉一個整數，結果一定還是整數，用 int 就可以。只有結果可能出現小數時，才需要 float。

8. 常見錯誤

狀況可能原因解決方式
讀值一直在 0 附近中間腳沒接到 A0，或 5V 沒接好檢查三條線的位置
讀值一直是 1023中間腳接到了 5V 那一排中間腳要單獨接到 A0
轉動方向和數字變化相反5V 與 GND 兩側接反這不是錯，交換兩側的線即可反轉
讀值亂跳中間腳鬆脫，A0 浮接把線插緊
電壓一直是 0用整數相除 5 / 1023 得到 0改寫成 5.0 / 1023.0
出現 'voltage' was not declared變數還沒建立就使用，或名字大小寫打錯確認有 float voltage = ...，名字前後一致

9. 自我檢核與重點回顧

自我檢核

  1. 可變電阻的三隻腳分別要接到哪裡？
  2. analogRead() 讀到的數字範圍是多少？
  3. 我能說出「變數」是什麼，以及 int 和 float 的差別嗎？
  4. 讀值是 512 時，大約是幾伏特？
  5. 9 / 2 和 9.0 / 2 的結果分別是多少？
看參考答案
  1. 兩側分別接 5V 和 GND，中間腳接類比腳位（例如 A0）。
  2. 在 UNO R3 上是 0 到 1023。
  3. 變數是有名字、用來存放資料的盒子。int 存整數，float 存有小數點的數。
  4. 512 × 5.0 ÷ 1023.0 ≈ 2.50 伏特。
  5. 9 / 2 是 4（小數被捨去）；9.0 / 2 是 4.5。

本單元重點回顧

  • 類比輸入腳位是 A0 到 A5，analogRead() 把電壓轉成 0 到 1023 的數字。
  • 變數用來存放資料，int 存整數，float 存小數。
  • 用「讀值 × 5.0 ÷ 1023.0」可以把讀值換算成電壓。
  • 整數除以整數會捨去小數；需要小數時，要把數字寫成 5.0 這種形式。
