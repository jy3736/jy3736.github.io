01 下列哪些工作，通常放在 Arduino 程式的 setup() 區塊中？

  1. 設定腳位的用途
  2. 讓 LED 持續一亮一滅
  3. 反覆讀取按鈕的狀態
  4. 不停把讀值印到電腦上

02 關於下面這個 Arduino 程式，下列哪些敘述正確？

void setup() {
}

void loop() {
}
  1. 因為沒有 pinMode()，所以無法編譯
  2. 它可以成功編譯
  3. 上傳後，板子不會做任何事
  4. loop() 的內容只會執行一次

03 關於 Arduino IDE 工具列上的圖示，下列哪些敘述正確？

  1. 打勾圖示是「驗證」
  2. 打勾圖示是「上傳」
  3. 向右箭頭圖示是「驗證」
  4. 向右箭頭圖示是「上傳」

04 某個數位腳位已設為輸出，並接著一顆 LED（LED 另一端接 GND）。執行 digitalWrite(腳位, LOW) 會發生什麼事？

  1. 讀取腳位目前的狀態
  2. 腳位輸出低電位
  3. LED 熄滅
  4. 讓程式暫停一段時間

05 執行 delay(250); 時，程式會暫停多久？

  1. 250 秒
  2. 2.5 秒
  3. 25 秒
  4. 0.25 秒

06 已在 setup() 把板上 LED 的腳位設為輸出，loop() 內容如下。LED 會呈現哪一種節奏？

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(200);
  digitalWrite(LED_BUILTIN, LOW);
  delay(200);
  digitalWrite(LED_BUILTIN, HIGH);
  delay(200);
  digitalWrite(LED_BUILTIN, LOW);
  delay(1000);
}
  1. 快閃兩下，接著熄滅一段較長的時間，然後重複
  2. 每次亮與滅的時間都一樣長
  3. 慢慢亮起後保持長亮
  4. 亮一段較長的時間後，熄滅並快閃兩下

07 按下「驗證」後出現紅字錯誤訊息。下列哪些是可能的原因？

  1. 「工具」選單中的連接埠沒選對
  2. 某一行結尾少了分號 ;
  3. 大括號 {} 沒有成對
  4. 外接 LED 的長短腳接反

08 要把一顆 LED 外接到 UNO 的數位腳位，下列哪些敘述正確？

  1. LED 的長腳是正極
  2. LED 短腳接數位腳位、長腳接 GND
  3. LED 直接接腳位即可，不需要電阻
  4. 電阻串聯在數位腳位與 LED 之間

09 板子上已在執行控制板上內建 LED 的 Blink 程式。不修改程式，把一顆外接 LED 電路正確接到第 13 號腳位與 GND 之後，會看到什麼？

  1. 只有外接 LED 閃爍，板上 LED 不再亮
  2. 外接 LED 和板上 LED 一起閃爍
  3. 必須先改程式，外接 LED 才會閃爍
  4. 外接 LED 和板上 LED 輪流閃爍

10 在程式中用 // 寫註解，有哪些好處？

  1. 讓板子執行程式的速度變快
  2. 註解內容會顯示在序列埠監控視窗
  3. 下次打開程式時，能很快看懂每一行在做什麼
  4. 同學看你的程式時，能較快理解內容

11 程式上傳後，要打開 Arduino IDE 的序列埠監控視窗，應該怎麼做？

  1. 點選 Arduino IDE 右上角的放大鏡圖示
  2. 點選「工具」選單中的連接埠
  3. 按下板子上的重置按鈕
  4. 把 USB 線拔掉再重新插上

12 用 digitalRead() 讀取數位腳位，讀取結果有哪幾種可能？

  1. 0 到 1023 之間的任意整數
  2. 只有 HIGH 或 LOW 兩種
  3. 0 到 9600 之間的任意整數
  4. 只有 HIGH 一種

13 按鈕的一隻腳接第 2 號腳位（設為 INPUT）。希望按鈕沒按時穩定讀到 LOW、按下時讀到 HIGH，下列哪些接法正確？

  1. 第 2 號腳位經過 10k 歐姆電阻接到 5V
  2. 按鈕的另一隻腳接到 GND
  3. 第 2 號腳位經過 10k 歐姆電阻接到 GND
  4. 按鈕的另一隻腳接到 5V

14 序列埠監控視窗可以幫助我們做哪些事？

  1. 把板子內部的數值顯示在電腦螢幕上
  2. 確認按鈕有沒有接好
  3. 提供板子運作所需的電源
  4. 取代「上傳」，直接把程式送到板子

15 在反覆讀取按鈕並印出讀值的 loop() 最後，加上 delay(10); 的目的是什麼？

  1. 讓 LED 閃爍一次
  2. 設定序列通訊的速度
  3. 稍微等一下，讓讀值穩定
  4. 讓 setup() 再執行一次

16 以 pinMode(2, INPUT_PULLUP); 讀取按鈕，而且不外接任何電阻。下列哪些接法正確？

  1. 第 2 號腳位接到按鈕的一隻腳
  2. 第 2 號腳位直接接到 5V
  3. 按鈕與腳位之間再串聯一顆 LED
  4. 按鈕剩下的那隻腳接到 GND

17 第 2 號腳位以 INPUT_PULLUP 設定並接一顆按鈕，第 13 號腳位接一顆 LED 並設為輸出，已執行 Serial.begin(9600)。loop() 內容如下，下列哪些敘述正確？

void loop() {
  int sensorVal = digitalRead(2);
  Serial.println(sensorVal);

  if (sensorVal == HIGH) {
    digitalWrite(13, LOW);
  } else {
    digitalWrite(13, HIGH);
  }
}
  1. 沒按按鈕時 LED 亮
  2. 按下按鈕時 LED 亮
  3. 每執行一次 loop()，就把讀值印到序列埠監控視窗一次
  4. 第 13 號腳位被用來讀取按鈕

18 序列埠監控視窗中，按鈕讀值一直亂跳。下列哪些是合適的解決方式？

  1. 檢查輸入腳位的下拉電阻是否接好
  2. 把監控視窗的速度改成 115200
  3. 把程式中的 Serial.println() 刪掉
  4. 改用 INPUT_PULLUP 啟用內建上拉電阻

19 關於 Serial.begin(9600); 這一行，下列哪些敘述正確？

  1. 它把第 9600 號腳位設為輸出
  2. 它開始讓板子和電腦進行序列通訊
  3. 9600 是通訊速度，要和監控視窗的速度設定一致
  4. 它把一個值印出並換到下一行

20 程式寫成 if (條件) { 第一段 } else { 第二段 }，它的意思是什麼？

  1. 不論條件是否成立，兩段都會執行
  2. 條件成立時先做第二段，再做第一段
  3. 只有條件不成立時才做第一段
  4. 條件成立就做第一段，不成立就做第二段
