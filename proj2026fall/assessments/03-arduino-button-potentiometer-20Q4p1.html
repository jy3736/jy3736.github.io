應用實務專題（一）03-arduino-button-potentiometer-20Q4p1

課前前測：Arduino 按鈕與可變電阻

01 按鈕一隻腳接 5V，另一隻腳接第 2 號腳位；第 2 號腳位同時經過一顆電阻接到 GND，並設為 INPUT。按鈕「沒按」時，digitalRead(2) 讀到什麼？

  1. HIGH
  2. 讀值不斷亂跳
  3. LOW
  4. 512

02 以 pinMode(2, INPUT_PULLUP); 設定第 2 號腳位並接好一顆按鈕。按鈕「沒按」時，第 2 號腳位讀到什麼？

  1. HIGH
  2. LOW
  3. 一下 HIGH 一下 LOW，無法確定
  4. 1023

03 程式在 setup() 中寫了 Serial.begin(9600);，但打開序列埠監控視窗後，畫面出現一堆亂碼。最可能的原因是什麼？

  1. 按鈕插在麵包板上的方向不對
  2. 按鈕腳位沒有設定成輸出
  3. 讀取按鈕的 loop() 最後沒有加 delay()
  4. 監控視窗的速度設定和程式中的 9600 不一致

04 按鈕電路依接線圖接好，程式也沒有錯，但按下按鈕完全沒反應。最可能的原因與解決方式是什麼？

  1. 序列通訊速度不一致，把速度改成 115200
  2. 按鈕插的方向不對，兩隻腳本來就相通，把按鈕轉 90 度再插一次
  3. 程式缺少註解，補上說明文字
  4. 按鈕腳位號碼太小，改接到第 13 號腳位

05 某個輸入腳位以 digitalRead() 讀到 HIGH，再用 Serial.println() 把讀值印出。序列埠監控視窗會顯示什麼？

  1. 1
  2. 0
  3. 5
  4. 1023

06 下列程式中，腳位已完成輸入與輸出設定。目前 buttonState 為 HIGH 時 LED 亮、為 LOW 時 LED 滅。若要改成「HIGH 時 LED 滅、LOW 時 LED 亮」，下列哪一種改法正確？

int buttonState = digitalRead(buttonPin);

if (buttonState == HIGH) {
  digitalWrite(ledPin, HIGH);
} else {
  digitalWrite(ledPin, LOW);
}
  1. 把 if 條件的 HIGH 改成 LOW，並同時對調兩個 digitalWrite 中的 HIGH 與 LOW
  2. 刪除整個 else 區塊
  3. 把兩個 digitalWrite 中的 HIGH 與 LOW 對調
  4. 在 if 前面加上 delay(1000)

07 讀取按鈕時，用 INPUT_PULLUP 取代「INPUT 加外接電阻」的接法，主要好處是什麼？

  1. 按鈕不必再接到 GND
  2. 啟用腳位內部的上拉電阻，不必再外接電阻
  3. 腳位會同時變成輸出，可以直接點亮 LED
  4. 讀值範圍會變成 0 到 1023

08 課堂使用的按鈕是「瞬時開關」。下列哪一個敘述正確描述它的特性？

  1. 按一下接通，要再按一下才會斷開
  2. 按下時兩隻腳斷開，放開時接通
  3. 不論按或不按，兩隻腳都保持接通
  4. 按下時兩隻腳接通，放開時兩隻腳斷開

09 程式上傳後，要打開 Arduino IDE 的序列埠監控視窗，應該怎麼做？

  1. 按工具列上的打勾圖示
  2. 按工具列上的向右箭頭圖示
  3. 按下板子上的重置按鈕
  4. 點選 Arduino IDE 右上角的放大鏡圖示

10 要用 UNO 讀取一顆三隻腳的可變電阻（旋鈕），下列哪一種接法正確？

  1. 兩側的腳分別接 5V 與 GND，中間的腳接 A0
  2. 兩側的腳分別接 5V 與 A0，中間的腳接 GND
  3. 兩側的腳分別接 GND 與 A0，中間的腳接 5V
  4. 中間的腳接 5V，兩側的腳都接 GND

11 UNO 內部負責把類比輸入腳位上的電壓轉成數字的元件叫什麼？

  1. 序列埠監控視窗
  2. 內建上拉電阻
  3. 類比數位轉換器（ADC）
  4. 可變電阻

12 程式中的 int sensorValue = analogRead(A0); 這一行做了什麼事？

  1. 把 A0 設定成輸出腳位
  2. 建立名叫 sensorValue 的變數，並把從 A0 讀到的數字放進去
  3. 把 sensorValue 的數字印到序列埠監控視窗
  4. 讓 A0 輸出和 sensorValue 相同的電壓

13 程式要存放像 3.3 這種帶有小數點的電壓值，應該選用哪一種變數型態？

  1. int，因為電壓都是整數
  2. float，因為它可以存小數
  3. int，因為它可以存小數
  4. 不需要型態，直接寫變數名稱即可

14 UNO 用公式 電壓 = 讀值 × (5.0 ÷ 1023.0) 把類比讀值換算成電壓。讀值為 512 時，電壓大約是多少？

  1. 約 5.00 伏特
  2. 約 0.50 伏特
  3. 約 512 伏特
  4. 約 2.50 伏特

15 下列程式中，另外印出的 reading 會隨旋鈕正常變化，但印出的換算結果一直是 0。最可能的原因是什麼？

int reading = analogRead(A0);
Serial.println(reading * (5 / 1023));
  1. 5 / 1023 是兩個整數相除，結果為 0
  2. analogRead() 只能讀到 0
  3. Serial.println() 不能印出計算結果
  4. A0 必須先用 pinMode() 設為 OUTPUT

16 讀取 A0 並印出數值的 loop() 最後原本是 delay(1);。改成 delay(500); 之後，序列埠監控視窗會有什麼變化？

  1. 數字更新變快
  2. 讀值的範圍變成 0 到 500
  3. 數字更新變慢，大約每半秒才出現一個新數值
  4. 數字停止更新，只顯示一次

17 可變電阻的訊號線原本插在 A0，現在改插到 A1。程式要怎麼改，才能繼續讀到數值？

  1. 把 analogRead(A0) 改成 analogRead(A1)
  2. 把 Serial.begin(9600) 改成 Serial.begin(1)
  3. 在 setup() 中加上 pinMode(A1, OUTPUT)
  4. 不必修改，程式會自動改讀 A1

18 上傳讀取旋鈕的程式後，想把數字畫成一條隨時間變化的曲線，應該使用工具選單中的哪一個功能？

  1. 序列埠監控視窗
  2. 序列埠繪圖家
  3. 開發板
  4. 連接埠

19 已有整數變數 sensorValue 與小數變數 voltage。要在同一行印出「讀值、一個空格、電壓」，然後換到下一行，下列哪一種做法正確？

  1. 三個部分都用 Serial.println() 印出
  2. 先用 Serial.println() 印讀值，再用 Serial.print() 印空格和電壓
  3. 三個部分都用 Serial.print() 印出，最後不需要換行
  4. 先用 Serial.print() 印讀值，再用 Serial.print() 印一個空格，最後用 Serial.println() 印電壓

20 UNO R3 的類比讀值解析度是 10 位元。UNO R4（Minima、WiFi）的類比讀值解析度最高可以到幾位元？

  1. 8 位元
  2. 10 位元
  3. 14 位元
  4. 12 位元
