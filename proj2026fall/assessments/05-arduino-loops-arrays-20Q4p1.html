應用實務專題（一）05-arduino-loops-arrays-20Q4p1

課前前測：Arduino 迴圈、陣列與多顆 LED

20 題單選。可選「逐題檢查」，每題選好就按「檢查答案」；或選「全部一次檢查」，全部作答後按「全部檢查」一次批改。答錯可以再試，試過 2 個不同的錯誤答案後才能看答案。

答對 60% 以上的題目（看答案的不算）後，可以下載含答案的 HTML 檔。作答紀錄不會保存，重新整理或離開頁面後會從頭開始。

01 要把 6 個連續的腳位都設定成輸出，原本得一行一行寫 6 次。改用 for 迴圈來寫，最主要的好處是什麼？

  1. 重複的指令只要寫一次，LED 數量改變時也只需要改動一個數字
  2. 程式的執行速度會變成原本的 6 倍
  3. 可以省下每一顆 LED 需要的限流電阻
  4. 腳位從此不必再設定輸出入模式

02 程式裡出現 thisPin++ 這樣的簡寫，它的意思是什麼？

  1. 把 thisPin 的值變成 0
  2. 把 thisPin 的值加 1，和寫成 thisPin = thisPin + 1 的意思相同
  3. 把 thisPin 的值乘以 2
  4. 把 thisPin 的值減 1

03 一段迴圈寫成 for (int thisPin = 2; thisPin < 8; thisPin++)，迴圈裡會依序處理哪些腳位？

  1. 第 2 號到第 8 號，共 7 個腳位
  2. 只有第 2 號腳位，其餘都不處理
  3. 第 2 號到第 7 號，共 6 個腳位
  4. 第 3 號到第 8 號，共 6 個腳位

04 一段應該從大數字數回小數字的迴圈，上傳之後完全沒有執行。最可能的原因是什麼？

  1. 迴圈變數的名字取得太長
  2. 迴圈裡面忘了加上等待時間
  3. LED 的限流電阻阻值太大
  4. 往回數時用成了遞增與小於，應該改用遞減與大於等於

05 跑馬燈程式用一個變數決定每顆 LED 亮著的毫秒數，原本是 100。若把它改成 30，會有什麼變化？

  1. 跑馬燈跑得比原本快
  2. 跑馬燈跑得比原本慢
  3. LED 會變得比原本亮
  4. 會比原本多亮一顆 LED

06 跑馬燈的迴圈裡，原本在等待之後會把該腳位轉回 LOW。若把那一行刪掉，畫面會變成什麼？

  1. 程式會無法編譯
  2. 所有 LED 都完全不會亮
  3. 亮過的 LED 不會熄滅，看起來一顆一顆累積亮著
  4. 只剩最後一顆 LED 會亮

07 6 顆 LED 接在 2、7、4、6、5、3 這種跳來跳去的腳位上，想依這個順序點亮，為什麼需要用到陣列？

  1. 因為跳著接的腳位沒有辦法設定成輸出
  2. 因為只靠一個往上數的迴圈變數，無法表示不連續的腳位順序
  3. 因為陣列可以讓 LED 亮得更亮
  4. 因為不連續的腳位需要額外的限流電阻

08 程式中宣告 int pins[] = {8, 3, 5, 9};。pins[1] 的值是多少？

  1. 8
  2. 1
  3. 5
  4. 3

09 來回跑馬燈原本有往前與往回兩段迴圈。若把「往回」那一整段刪掉，效果會變成什麼？

  1. LED 只會朝同一個方向依序亮過去，不再折返
  2. 所有 LED 會同時亮起來
  3. LED 亮起的順序會變成隨機的
  4. 每顆 LED 亮著的時間會變成兩倍

10 用陣列控制跑馬燈時，迴圈變數 i 代表的是什麼？

  1. 代表這一顆 LED 的亮度
  2. 代表這一輪要等待幾毫秒
  3. 代表陣列的索引，真正的腳位要用 ledPins[i] 取出來
  4. 代表這一顆 LED 搭配的電阻值

11 陣列裡放了 6 個腳位，程式把迴圈條件由 i < pinCount 改寫成 i <= pinCount，會發生什麼事？

  1. 迴圈會少跑一次，最後一顆 LED 不會亮
  2. 迴圈會多跑一次，讀到超出陣列範圍的那一格
  3. 程式會在執行到一半時自動停止
  4. 陣列裡的內容會全部被清成 0

12 跑馬燈中只有其中一顆 LED 從頭到尾都不亮，其他幾顆都正常。最可能的原因與檢查方式是什麼？

  1. 迴圈的結束條件寫錯了，要重新計算次數
  2. 每顆 LED 亮著的毫秒數設得太小
  3. 陣列裡的索引超出了範圍
  4. 那一顆的正負腳接反或電阻沒插好，單獨測試那一顆的接線

13 跑馬燈的每一顆 LED 都用相同的方式接到板子上。下列哪一種接法正確？

  1. 腳位接 220 歐姆電阻，電阻接 LED 長腳，LED 短腳接 GND
  2. 腳位直接接 LED 短腳，LED 長腳接 GND
  3. 腳位接 LED 長腳，短腳再經 10k 歐姆電阻接到 5V
  4. 所有 LED 共用一顆電阻，串在通往 GND 的線路上

14 長條圖程式先讀取旋鈕，再把讀值換算成另一個數字。這個換算後的數字代表什麼？

  1. 每一顆 LED 的亮度高低
  2. 要亮起來的 LED 顆數
  3. 迴圈每一輪要等待的毫秒數
  4. 可變電阻目前的電阻值

15 下列程式中 ledCount 是 10，ledPins 依序存放第 2 到第 11 號腳位，而 ledLevel 目前的值是 4。這段迴圈跑完之後會有幾顆 LED 亮著？

for (int i = 0; i < ledCount; i++) {
  if (i < ledLevel) {
    digitalWrite(ledPins[i], HIGH);
  } else {
    digitalWrite(ledPins[i], LOW);
  }
}
  1. 3 顆
  2. 10 顆
  3. 5 顆
  4. 4 顆

16 長條圖程式把陣列裡的腳位順序整個反過來寫，其他都不改。結果會是什麼？

  1. 亮起來的顆數會減少一半
  2. 所有 LED 會同時亮起
  3. 長條圖會改成從另一端開始亮起
  4. 旋鈕轉到底也不會有任何 LED 亮

17 想確認旋鈕轉到底時，程式換算出來代表顆數的那個數值到底是多少。最直接的做法是什麼？

  1. 加上一行 Serial.println(ledLevel);，再打開序列埠監控視窗觀察
  2. 把所有 LED 都改接到同一個腳位
  3. 把迴圈的等待時間拉長到 10 秒
  4. 把可變電阻換成一顆按鈕

18 想把長條圖改成只亮「最高的那一顆」，做出一個會移動的光點。應該怎麼改？

  1. 把判斷裡的小於改成大於
  2. 把原本比較大小的判斷，改成比較是不是相等
  3. 把迴圈改成從最後一格往回數
  4. 把陣列的長度改成 1

19 長條圖電路中的可變電阻應該怎麼接？

  1. 兩側接 5V 與 GND，中間腳接到第 13 號腳位
  2. 中間腳接 5V，兩側都接到 GND
  3. 中間腳空著不接，只接兩側就好
  4. 兩側分別接 5V 與 GND，中間腳接到 A0

20 下列迴圈 for (int i = 0; i < 6; i++) 會重複執行幾次？i 又會依序是哪些數字？

  1. 重複 5 次，i 依序是 1 到 5
  2. 重複 7 次，i 依序是 0 到 6
  3. 重複 6 次，i 依序是 0、1、2、3、4、5
  4. 重複 6 次，i 依序是 1、2、3、4、5、6
