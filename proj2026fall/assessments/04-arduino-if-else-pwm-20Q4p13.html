課後形成性評量：Arduino 條件判斷與 LED 調光

01 旋鈕門檻程式原本設定「讀值大於 400 就讓 LED 亮」，現在把門檻的數字改成 800。下列敘述哪些正確？

  1. 旋鈕要轉到讀值超過 800，LED 才會亮
  2. 門檻改大之後就不必再讀取旋鈕的數值
  3. 能讓 LED 亮起的旋鈕範圍比原本更小
  4. LED 會變成一直亮著不再熄滅

02 變數 x 目前的值是 500。下列哪些條件成立？

  1. x > 400
  2. x >= 500
  3. x != 500
  4. x == 500

03 程式用一個變數記住按鈕上一次的狀態，並在狀態改變而且變成按下時才把次數加 1。下列哪些情況不會讓次數增加？

  1. 上一次讀到 LOW，這一次讀到 HIGH
  2. 上一次讀到 HIGH，這一次讀到 HIGH
  3. 上一次讀到 HIGH，這一次讀到 LOW
  4. 上一次讀到 LOW，這一次讀到 LOW

04 取餘數運算子 % 會算出相除之後剩下的數。下列哪些運算的結果是 0？

  1. 8 % 4
  2. 12 % 4
  3. 9 % 4
  4. 6 % 4

05 按鈕計次程式在偵測到狀態改變之後，加了一行 delay(50)。關於這一行，下列哪些敘述正確？

  1. 可以避開按鈕接觸瞬間造成的抖動
  2. 它決定了 LED 亮起來的亮度高低
  3. 它會把序列埠的通訊速度設定成 50
  4. 把它刪掉之後快速按壓，次數可能會被多算

06 一段程式在按下次數是 4 的倍數時讓 LED 亮起。若要改成「每按滿 3 次 LED 才亮」，應該怎麼改？

  1. 把偵測到狀態改變後的等待時間由 50 毫秒改成 30 毫秒
  2. 把按鈕改接到第 3 號腳位
  3. 把判斷倍數時用來相除的那個數字由 4 改成 3
  4. 把序列埠的通訊速度改成 3

07 有人在判斷的括號裡，把「檢查是不是相等」誤寫成只有一個等號。程式最可能出現什麼現象？

  1. 程式一定無法上傳到板子上
  2. 那個條件看起來好像永遠都成立
  3. 序列埠監控視窗會顯示一堆亂碼
  4. LED 會以一半的亮度亮起

08 一個計算按鈕次數的程式，列印出來的次數永遠停在 1。下列哪些敘述正確？

  1. 這是因為按鈕沒有接下拉電阻造成的
  2. 這是因為程式沒有呼叫 Serial.begin(9600)
  3. 計數變數被宣告在 loop() 裡面，每一輪都會重新歸零
  4. 把計數變數改成宣告在 loop() 外面就能正常累加

09 要讓一顆按鈕接在第 2 號腳位，並且在沒有按下時穩定讀到 LOW。下列哪些接法正確？

  1. 按鈕的一隻腳接第 2 號腳位，同一隻腳再經 10k 歐姆電阻接到 GND
  2. 按鈕的另一隻腳接到 5V
  3. 按鈕的另一隻腳接到 A0
  4. 第 2 號腳位要用 pinMode() 設定成 OUTPUT

10 想做一個「按一下亮、再按一下滅」的 LED 開關，改用按下次數的奇偶來判斷。下列哪些做法正確？

  1. 每次按下之後都把次數重新歸零
  2. 用 % 2 判斷次數是奇數還是偶數
  3. 次數是奇數時讓 LED 亮，是偶數時讓 LED 滅
  4. 把次數除以 10 之後再拿餘數來判斷

11 下列哪些腳位在 UNO R3 上可以用來做 LED 調光？

  1. 3
  2. 8
  3. 6
  4. 11

12 關於可以調光的腳位以及它的運作方式，下列哪些敘述正確？

  1. 這些腳位真的會輸出一半大小的電壓
  2. 這些腳位在板子上都以字母 A 開頭
  3. 這些腳位的數字旁邊印有 ~ 符號
  4. 它用很快的速度讓腳位開與關，開著的時間比例越長看起來越亮

13 用 analogWrite() 設定 LED 亮度時，下列哪些敘述正確？

  1. 可以設定的數值範圍是 0 到 255
  2. 數值 127 大約是一半的亮度
  3. 數值可以一路設定到 1023
  4. 數值只能填 0 或 1 兩種

14 呼吸燈電路要把一顆 LED 接到第 9 號腳位。下列哪些接法正確？

  1. LED 的長腳直接接到 GND
  2. 第 9 號腳位先接上 220 歐姆電阻的一端
  3. LED 要串一顆 10k 歐姆電阻才不會燒壞
  4. LED 的短腳（負極）接到 GND

15 一段迴圈寫成 for (int n = 10; n <= 40; n += 10)。關於括號裡的三個部分，下列哪些說明正確？

  1. n 是從 10 開始
  2. 只要 n 還沒有超過 40 就繼續執行
  3. 每做完一次 n 就減少 10
  4. 每做完一次 n 就增加 10

16 一段讓 LED 亮度逐步變化的程式，每變化一次就等待 30 毫秒。若把等待時間改成 5 毫秒，會有什麼改變？

  1. 亮度變化的速度變快
  2. LED 最亮的時候會比原本更亮
  3. LED 會完全不亮
  4. 程式會無法編譯

17 一段讓 LED 由暗漸亮的程式，原本亮度每一次增加 5。若改成每一次增加 50，亮度的變化會怎麼樣？

  1. 比原本更平順
  2. 會超過可以設定的亮度上限
  3. 變得一格一格，不再平順
  4. LED 會停在最亮而不再變化

18 可變電阻讀到的數值範圍，和設定 LED 亮度所需要的數值範圍並不相同。關於這個換算，下列哪些敘述正確？

  1. map() 可以把數值從一個範圍換算到另一個範圍
  2. 兩個範圍其實一樣，不需要做任何換算
  3. 沒有換算就直接拿讀值設定亮度，數值會超出亮度可以接受的上限
  4. 換算之後得到的一定會是小數

19 旋鈕調光器程式把讀值換算成亮度。若把換算後的新範圍改成 0 到 100，LED 最亮的時候會如何？

  1. 和原本最亮的時候一樣亮
  2. 比原本最亮的時候更暗
  3. 比原本最亮的時候更亮
  4. 旋鈕會失去控制亮度的作用

20 想在旋鈕控制亮度的程式中加一個提醒：當亮度數值大於 200 時，讓板上第 13 號腳位的 LED 也亮起來。下列哪些做法是必要的？

  1. 把第 13 號腳位設定成類比輸入
  2. 把亮度數值再換算成 0 到 1023
  3. 用 if 判斷亮度數值是不是大於 200
  4. 在 setup() 裡把第 13 號腳位設定成 OUTPUT
