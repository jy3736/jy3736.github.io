應用實務專題（一）03-arduino-button-potentiometer-20Q4p12

課後形成性評量：Arduino 按鈕與可變電阻

20 題複選，每題 1 至 2 個正確選項。可選「逐題檢查」，每題選好就按「檢查答案」；或選「全部一次檢查」，全部作答後按「全部檢查」一次批改。答錯可以再試，試過 2 個不同的錯誤答案後才能看答案。

答對 60% 以上的題目（看答案的不算）後，可以下載含答案的 HTML 檔。作答紀錄不會保存，重新整理或離開頁面後會從頭開始。

01 按鈕一隻腳接第 2 號腳位（設為 INPUT），想用下拉電阻讓按鈕沒按時穩定讀到 LOW。下列哪些接法正確？

  1. 按鈕接第 2 號腳位的同一隻腳，再經過 10k 歐姆電阻接到 GND
  2. 按鈕的另一隻腳接到 5V
  3. 按鈕的另一隻腳接到 GND
  4. 不需要任何電阻，直接接好按鈕即可

02 程式中寫了 pinMode(buttonPin, INPUT);，這一行的作用是什麼？

  1. 讓 buttonPin 代表的腳位輸出高電位
  2. 讀取 buttonPin 代表的腳位並印出
  3. 把 buttonPin 代表的腳位設定成輸入
  4. 把 buttonPin 的數值改成 0

03 某個輸入腳位什麼都沒接，就直接用 digitalRead() 反覆讀取。下列哪些敘述正確？

  1. 讀到的值會亂跳，一下 HIGH 一下 LOW
  2. 會一直穩定讀到 HIGH
  3. 這種狀態叫做下拉
  4. 這種狀態叫做浮接

04 以 pinMode(2, INPUT_PULLUP); 設定第 2 號腳位並接好按鈕。下列關於讀值的敘述，哪些正確？

  1. 沒按按鈕時讀到 LOW
  2. 沒按按鈕時讀到 HIGH
  3. 按下按鈕時讀到 LOW
  4. 按下按鈕時，腳位直接連到 5V

05 程式在 setup() 中寫了 Serial.begin(9600);。要在電腦上正確看到板子印出的數值，下列哪些操作正確？

  1. 點選 Arduino IDE 右上角的放大鏡圖示，打開序列埠監控視窗
  2. 按工具列上的打勾圖示，打開序列埠監控視窗
  3. 監控視窗的速度可以任意設定，不影響顯示
  4. 確認監控視窗右下角的速度設定為 9600

06 反覆印出按鈕讀值的程式中，把 Serial.println(buttonState) 改成 Serial.print(buttonState);。監控視窗的畫面會有什麼不同？

  1. 畫面會變成亂碼
  2. 數值不再換行，會一個接一個印在同一行
  3. 只會印出第一個數值
  4. 數值會以曲線方式呈現

07 按鈕以下拉電阻接法接在 buttonPin（按下時讀到 HIGH），ledPin 接一顆 LED，兩個腳位都已設定好。loop() 內容如下，下列哪些敘述正確？

void loop() {
  int buttonState = digitalRead(buttonPin);

  if (buttonState == HIGH) {
    digitalWrite(ledPin, HIGH);
  } else {
    digitalWrite(ledPin, LOW);
  }
}
  1. 放開按鈕時 LED 亮
  2. 程式會把讀值印到序列埠監控視窗
  3. 按住按鈕時 LED 亮
  4. 放開按鈕時 LED 滅

08 按鈕電路依接線圖接好，程式也沒有錯，但按下按鈕完全沒反應。最可能的原因是什麼？

  1. 按鈕插的方向不對，兩隻腳其實本來就相通
  2. 監控視窗的速度設定不一致
  3. 按鈕讀值使用了 Serial.println()
  4. 按鈕腳位沒有加註解

09 關於 digitalRead() 的讀取結果，下列哪些敘述正確？

  1. 結果是 0 到 5 之間的任意整數
  2. 結果只有 HIGH 或 LOW 兩種
  3. 用 Serial.println() 印出時，HIGH 顯示為 1、LOW 顯示為 0
  4. 它用來讓腳位輸出電壓

10 要用 UNO 讀取一顆三隻腳的可變電阻（旋鈕），下列哪些接法正確？

  1. 兩側的腳分別接 5V 和 GND
  2. 中間的腳接到 5V
  3. 兩側的腳都接到類比輸入腳位
  4. 中間的腳接到類比輸入腳位

11 Arduino UNO 上的類比輸入腳位是標示為哪些名稱的腳位？

  1. A0 到 A13
  2. A0 到 A5
  3. D0 到 D5
  4. 第 0 到 13 號腳位

12 關於 int sensorValue = analogRead(A0); 這一行，下列哪些敘述正確？

  1. 它把 A0 設定成輸出腳位
  2. 讀到的數字會自動換算成伏特
  3. 它建立了一個名叫 sensorValue 的變數
  4. 它把從 A0 讀到的數字放進 sensorValue

13 關於 int 與 float 兩種變數型態，下列哪些敘述正確？

  1. int 用來存放整數
  2. float 可以存放帶小數點的數
  3. int 可以正確存放 2.5
  4. float 只能存放 0 到 1023 之間的數

14 UNO 用公式 電壓 = 讀值 × (5.0 ÷ 1023.0) 把類比讀值換算成電壓。讀值為 205 時，電壓大約是多少？

  1. 約 2.5 伏特
  2. 約 4.1 伏特
  3. 約 1.0 伏特
  4. 約 205 伏特

15 下列程式中，reading 會隨旋鈕正常變化，但印出的換算結果一直是 0。最可能的原因是什麼？

int reading = analogRead(A0);
Serial.println(reading * (5 / 1023));
  1. Serial.println() 不能印出計算結果
  2. analogRead() 讀到的數字一直是 0
  3. A0 必須先用 pinMode() 設為 OUTPUT
  4. 5 / 1023 是兩個整數相除，結果為 0

16 讀取旋鈕時，不論怎麼轉，讀值一直停在 0 附近。下列哪些是可能的原因？

  1. 接到 A0 的那條線沒接好
  2. 接到 5V 的那條線沒接好
  3. 旋鈕轉得太快
  4. 序列埠監控視窗的速度設定不一致

17 讀取 A0 並印出數值的 loop() 最後原本是 delay(1);，改成 delay(500);。下列哪些敘述正確？

  1. 讀值的範圍變成 0 到 500
  2. 數字更新的速度變快
  3. 數字更新的速度變慢
  4. 大約每 0.5 秒才出現一個新數值

18 可變電阻的訊號線原本插在 A0，現在改插到 A1。程式要怎麼改，才能繼續讀到數值？

  1. 把 analogRead(A0) 改成 analogRead(A1)
  2. 把 Serial.begin(9600) 改成 Serial.begin(1)
  3. 在 setup() 中加上 pinMode(A1, OUTPUT)
  4. 不必修改，程式會自動改讀 A1

19 想把旋鈕讀值畫成一條隨時間變化的曲線，應該使用 Arduino IDE 工具選單中的哪一個功能？

  1. 序列埠監控視窗
  2. 序列埠繪圖家
  3. 開發板
  4. 連接埠

20 關於 UNO R3 與 UNO R4（Minima、WiFi）的類比讀值解析度，下列哪些敘述正確？

  1. UNO R3 最高可到 14 位元
  2. UNO R4 沒有類比輸入腳位
  3. UNO R3 預設為 10 位元
  4. UNO R4 最高可到 14 位元
