課前前測：ChatGPT、Work 與 Codex 的選用

20 題單選。可選「逐題檢查」，每題選好就按「檢查答案」；或選「全部一次檢查」，全部作答後按「全部檢查」一次批改。答錯可以再試，試過 2 個不同的錯誤答案後才能看答案。

答對 60% 以上的題目（看答案的不算）後，可以下載含答案的 HTML 檔。作答紀錄不會保存，重新整理或離開頁面後會從頭開始。

01 某位同學要在自己的專題程式碼中找出 bug、執行測試並實作一個新功能。在同一個 ChatGPT 裡，下列哪一種工作方式最適合？

  1. Chat，以來回問答的方式討論問題
  2. Codex
  3. ChatGPT Work，交付一份簡報或報告
  4. Sites，建立一個分享用的網站

02 ChatGPT Work 與 Codex 的能力有重疊。關於兩者的差別，下列敘述何者正確？

  1. ChatGPT Work 不能搜尋網路，研究工作只能交給 Codex
  2. Codex 只能修改程式碼，無法產出文件或簡報
  3. 兩者各自擁有獨立的用量額度，互不影響
  4. Work 會隱藏 Git 或 shell 指令等技術細節，Codex 則會顯示 diff 與審查畫面

03 某同學請 AI 準備期中考複習，並在提示中寫下：「只出考試範圍內的題目，不要直接給我程式題答案，等我作答後再批改。」這段文字屬於提示四要素中的哪一個？

  1. 界線
  2. 脈絡
  3. 產出
  4. 目標

04 撰寫一個比較大或比較重要的提示時，下列哪一個建議最恰當？

  1. 每次送出前都必須把所有要素逐項填滿，缺一項就不能送出
  2. 一律先列出 AI 應該依序執行的每一個步驟，再描述想要的結果
  3. 先描述想要的結果，只有步驟本身很重要時才寫出流程
  4. 第一個提示必須一次寫到完美，否則應該刪掉對話重來

05 某同學想靠自己推理弄懂一個演算法觀念，希望 AI 扮演「蘇格拉底式家教」。下列哪一個提示最符合這個目的？

  1. 請直接給我完整的解釋，再附上三個例子讓我背起來
  2. 請不要直接告訴我答案，一次只問我一個問題引導我推理，等我回答後再決定下一個問題
  3. 請一次出 10 題選擇題並在每題下方附上詳解
  4. 請用表格比較這個演算法和另外兩種演算法的效率

06 當 AI 無法取得某個來源，或無法完成任務的某一部分時，下列哪一種處理方式最恰當？

  1. 只要回答讀起來流暢，就可以直接引用到報告中
  2. 只要 AI 附上了網址，重要的數字與日期就不必再核對
  3. 需要最新資訊時，應避免讓 AI 使用網路搜尋，以免結果被干擾
  4. 請 AI 明確說出哪些部分無法取得或無法完成，因為說清楚的缺口比自信的猜測容易處理

07 作業與考試是用來確認「你」學會了什麼。下列哪一種使用 AI 的方式違反學習誠信？

  1. 把作業題目貼給 AI，直接把 AI 的答案當成自己的作業交出
  2. 請 AI 依自己的筆記出練習題，作答後再請它批改
  3. 請 AI 用生活中的類比解釋一個看不懂的觀念
  4. 先確認授課教師的規定，並依要求在作業中註明 AI 的使用方式

08 下列哪一種情況最適合在 ChatGPT 中建立一個「專案（Project）」？

  1. 臨時想查一個英文單字的意思
  2. 想請 AI 解釋一則只出現一次的錯誤訊息
  3. 一整學期的課程，需要反覆使用同一批講義與筆記，產生多份複習成果
  4. 想把一句話改寫得更有禮貌

09 若要讓 ChatGPT 的專案直接讀取電腦裡的課程資料夾，下列敘述何者正確？

  1. 網頁版專案可以直接讀取，只要在專案指示中寫出資料夾路徑即可
  2. 網頁版專案無法直接讀取，需要上傳檔案或透過外掛連接；桌面版則可以建立連到本機資料夾的本機專案
  3. 網頁版與桌面版都可以直接讀取，但只限 PDF 檔
  4. 網頁版與桌面版都無法使用本機資料夾，只能手動複製貼上內容

10 某同學執行程式時出現錯誤，想上傳錯誤訊息的截圖請 ChatGPT 協助。下列哪一種做法最恰當？

  1. 只上傳截圖，不附任何文字，讓 AI 自行判斷要看哪裡
  2. 先把截圖轉成純文字再貼上，因為 ChatGPT 無法處理圖片
  3. 不要上傳截圖，因為圖片只適合用在設計類作業
  4. 上傳截圖並說明要看圖中哪個地方、想得到什麼結果

11 某同學希望 ChatGPT 在「所有對話」中都一律用繁體中文回答，而且舉例偏向工程情境。這類偏好最適合放在哪裡？

  1. Settings > Personalization 的自訂指示
  2. 每一次提問時都在提示開頭重寫一遍
  3. 只寫在某一個專案的專案指示中
  4. 寫在程式專題資料夾的規則檔裡

12 下列哪一項任務最適合直接用 Chat 處理，而不必交給 ChatGPT Work？

  1. 閱讀 6 篇論文並建立一份含總結工作表的比較試算表
  2. 每週固定整理課程截止日與會議，產生一份待辦清單
  3. 把一句社團公告改寫得更簡短
  4. 搜尋並比較多個網站的資料，整理成一份可下載的分析報告

13 某同學在 ChatGPT 桌面版交給 Work 一個耗時較長的任務，希望關掉 App 或電腦後任務仍會繼續，之後還能從手機接著查看。應該選擇哪一種執行方式？

  1. Work locally，使用自己電腦上的檔案與 App
  2. 改用 Chat 逐步來回討論
  3. 改用 Codex 的非互動模式執行
  4. Cloud

14 某同學請 Work 整理一份資料，最後要寄給全班同學。為了讓任務保持在掌控之中，下列哪一個要求最恰當？

  1. 請先提出計畫，並在寄出之前停下來讓我核准
  2. 為了節省時間，完成後直接寄給全班，不用再問我
  3. 盡量蒐集所有找得到的來源，不必限制範圍或日期
  4. 把必要的工作和有空再做的潤飾混在同一段一起描述

15 某同學想讓 ChatGPT 每週固定整理一份待辦清單，而且需要讀取自己的行事曆。關於設定排程任務，下列哪一個做法最恰當？

  1. 先建立排程，之後再根據每週的結果慢慢修改提示
  2. 先在一般對話中把提示調整到結果穩定，再在該對話中設定排程，並事先連接行事曆的外掛
  3. 排程任務會自動讀取行事曆，不需要連接任何外掛
  4. 排程任務只能在網頁版的 Chat 中設定，無法搭配其他工具

16 Codex 會讀檔、改檔與執行指令。下列哪一項描述的是「沙箱（Sandbox）」？

  1. 決定 Codex 什麼時候要停下來詢問你的設定
  2. 依優先順序列出程式問題的清單
  3. 技術上的邊界，決定 Codex 能存取哪些檔案與網路資源
  4. 放在專案資料夾中、記錄組內開發規則的檔案

17 使用 Codex 做專題時，建議養成「每次任務前後都建立 Git 檢查點」的習慣。主要原因是什麼？

  1. 建立檢查點後，Codex 會自動取得網路存取權限
  2. 建立檢查點可以減少 Codex 消耗的用量額度
  3. Codex 必須先看到新的 commit 才能讀取專案檔案
  4. 當 AI 的修改不滿意時，可以還原到修改前的狀態

18 某同學的全域設定 ~/.codex/AGENTS.md 要求「註解使用英文」，而專案中的 backend/AGENTS.md 要求「註解使用繁體中文」。當 Codex 在 backend/ 資料夾中工作時，會以哪一條規則為準？

  1. 以 backend/AGENTS.md 為準，因為越靠近目前資料夾的檔案越晚合併，會覆寫較前面的規則
  2. 以全域檔案為準，因為個人偏好永遠優先於專案規則
  3. 兩條規則互相衝突，Codex 會忽略兩個檔案
  4. 以最早建立的檔案為準，與資料夾位置無關

19 交作業或送 PR 前，某同學在 Codex 中輸入 /review。關於這個指令，下列敘述何者正確？

  1. 它會自動修正找到的所有問題，並直接建立 commit
  2. 它會啟動專門的審查者，列出依優先順序排好的問題，不會更動程式碼，且專案必須是 Git 儲存庫
  3. 它只能在 GitHub 的 PR 留言中使用，無法在 CLI 中執行
  4. 它會先訪談你的需求細節，再提出分階段的實作計畫

20 好的 Codex 長期目標應包含成果、限制與驗證三件事。下列哪一個目標描述最完整？

  1. 把站內訊息功能做得更好。
  2. 盡快寫出越多程式碼越好，不需要測試。
  3. 完成站內訊息第一階段（一對一文字訊息）；使用現有的 FastAPI 與資料庫，不新增第三方服務；新增的 API 測試全部通過。
  4. 研究一下站內訊息功能，看看有沒有什麼可以改的地方。
