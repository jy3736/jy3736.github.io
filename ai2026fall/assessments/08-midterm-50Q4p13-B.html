01 某位同學想確認自己是否真的學會一個概念，而不只是拿到一份答案。下列哪一種做法最能提供理解的證據？

24 下面這個 Python 函式想計算一串分數的平均，但結果不正確。關於它的問題與修正方向，下列哪些敘述正確？

def average(scores):
    total = 0
    for score in scores:
        total = total + score
    return total / 3

本題的正確選項有 3 個。

  1. 它固定除以 3，所以輸入 100 與 60 兩個分數時會算出 53.33，而不是正確的 80
  2. 應該改成除以實際的分數個數，也就是串列的長度
  3. 只要把最後一行改成直接回傳總和，就能得到正確的平均
  4. 沒有任何分數時回答 0.0 會誤導人，比較好的做法是回傳代表「沒有值」的 None

35 Mac 版 Muse 的漏洞示範中，攻擊者偷偷改掉一個設定後，可以拿到語音輸入的聲音和 Muse 的登入資料。為什麼這類 AI 代理被攻破時，影響可能比一般程式更大？

本題的正確選項有 1 個。

  1. 代理的模型檔案較大，修補所需時間比較長

  4. 代理只在雲端執行，使用者無法自行更新版本

  3. 那樣做會讓程式的執行速度明顯變慢
  4. 預期結果只能由工具自動產生，人不可以編輯

37 某看板對分區順序與區內排序訂了固定規則。下列哪些符合這些規則？

本題的正確選項有 2 個。

  1. 同一區裡一律把考試類型排在最前面
  2. 同一區裡依科目名稱的字數多寡排序
  3. 四個分區依「已過期、緊急、本週、之後」的順序出現
  4. 同一區裡剩餘天數少的排在前面

38 請 AI 只根據一份虛構的小組會議紀錄整理待辦表，欄位為工作項目、負責人、期限、待確認事項。下列哪些是正確的要求或檢核？

本題的正確選項有 2 個。

  1. 交付的檔案內容與對話中顯示的表格不同也沒關係
  2. 可以自動補上來源沒提到、但看起來合理的任務
  3. 紀錄沒寫明的負責人或期限填「待確認」，不替小組決定
  4. 逐列找回來源句子，確認沒有新增來源未提到的任務

39 把自訂 GPT 搬到 OpenAI 的外掛時，下列哪些內容不會跟著搬過去？

本題的正確選項有 3 個。

  1. 自訂動作（連到外部服務的設定）
  2. 分享設定
  3. 指定的模型
  4. 角色說明

40 關於 Agent Skills 與自訂 GPT 的時間線，下列哪些敘述正確？

本題的正確選項有 2 個。

  1. Anthropic 在 2025 年 12 月 18 日把 Agent Skills 公開成開放標準
  2. Anthropic 在 2025 年 10 月 16 日替 Claude 推出 Agent Skills
  3. 獲准延後的企業帳號，自訂 GPT 可以用到 2027 年 6 月 1 日
  4. Agent Skills 一開始是 OpenAI 為 ChatGPT 推出的功能

41 某服飾門市的促銷結帳規則為：當季新品照原價，過季品打 8 折，促銷庫存打 6 折；各項折後金額加總成折後商品小計後，只套用一個最高符合的結帳折扣級距（未滿 1,000 元不折，滿 1,000 元 95 折，滿 2,000 元 88 折，滿 3,000 元 8 折，滿 5,000 元 75 折），應付金額四捨五入到整數元。一位顧客買了 1 件原價 1,000 元的當季新品，以及 2 件原價 500 元的促銷庫存，下列哪些敘述正確？

本題的正確選項有 3 個。

  1. 應付金額是 1,520 元
  2. 套用的結帳折扣是 88 折
  3. 每件促銷庫存的折後單價是 300 元
  4. 折後商品小計是 1,600 元

42 某門市要請 Codex 用一份 60 項虛構商品的資料檔做結帳試算器，第一步只請它檢查並整理商品資料。下列哪些做法或理由正確？

本題的正確選項有 2 個。

  1. 資料檢查通過之後，就不必再用手算核對畫面上的金額
  2. 先確認它讀到的資料和自己以為的一樣，之後算錯時才能排除「資料本身有問題」的可能
  3. 為了讓試算更貼近實際，可以直接連接門市真實的收銀系統資料
  4. 這一步要求它先回報檢查結果，不要修改資料檔，也不要建立網頁

43 一位 AI 公司執行長提議「請外部評估人員長駐公司、業界一起訂安全標準與進步速度上限」，批評者則擔心這會造成「監管俘虜」。下列哪些敘述正確？

本題的正確選項有 3 個。

  1. 只要知道提議者會因規則而獲益，就能斷定他的安全警告不真誠
  2. 評估這類提議時，「能不能讓產品更安全」和「會不會讓競爭對手變少」兩個答案可以同時是「會」
  3. 監管俘虜是指被管的業者反過來影響規則，讓規則對自己有利
  4. 複雜的檢查與認證，大公司做得到，小公司可能付不起

44 某器材管理原型在測試時，重複送出同一筆借用紀錄的歸還後，器材可借數從 1 台變成 2 台，違反資料規則。下列哪些除錯做法恰當？

本題的正確選項有 2 個。

  1. 移除無關的器材與畫面，把問題縮小後再重做一次歸還
  2. 記下版本、初始資料、操作順序，以及「預期仍是 1，實際變成 2」，並保留測試資料副本
  3. 直接請 AI 重寫整套系統，比逐步找原因更有效率
  4. 修正後只要重測重複歸還這一步，不必再重走借出、超額、歸還、重開與匯出的完整流程

45 一個讓 AI 拆解程式的開源工具，官方展示 AI 找出一款 1990 年代遊戲中「依位置決定聲音偏左或偏右」的小計算並改寫成新程式，拿 3,205 組輸入和原版比對，結果都一樣。下列哪些判斷恰當？

本題的正確選項有 2 個。

  1. 這個展示證明整款遊戲已經被完整重做
  2. 分析是在自己的電腦上進行，所以分析內容一定不會送到雲端的模型服務商
  3. 這個展示說明，在有人仔細設定檢查方式時，AI 能正確還原一個小功能
  4. 拿到一份看起來像原始碼的分析結果，不代表取得了原本程式的任何權利

46 某小組想請 AI 協助整理全班問卷，問卷含姓名、學號與自由回答，但這次任務只需要各選項的人數。下列哪些做法或觀念正確？

本題的正確選項有 2 個。

  1. 只送出各選項人數的彙整統計就夠了，不必送出個別回答
  2. 問卷結果曾經公開過，之後不論怎麼使用都合適
  3. 拿掉姓名之後，自由回答的內容仍可能暴露身分
  4. 同學口頭說好，就是唯一而且足夠的法律依據

47 某同學請 AI「幫我準備資料結構期中考」，並補充了幾句話。依提示的目標、脈絡、產出、界線四要素，下列哪些對應正確？

本題的正確選項有 3 個。

  1. 「考試範圍是堆疊、佇列、鏈結串列，我對遞迴比較不熟」：脈絡
  2. 「10 題選擇題加 2 題手寫程式題，附詳解」：產出
  3. 「只出範圍內的題目」：脈絡
  4. 「程式題先不要給答案，等我作答後再批改」：界線

48 某組在計畫確定後，要為 Codex 設定一個持續進行的目標，好的目標包含成果、限制、驗證三件事。以二手書平台的「站內訊息」功能為例，下列哪些對應正確？

本題的正確選項有 3 個。

  1. 「新增的 API 測試全部通過，flutter test 沒有錯誤」：驗證
  2. 「我們會努力開發站內訊息功能」：成果
  3. 「使用現有的 FastAPI 與資料庫，不新增第三方服務」：限制
  4. 「完成站內訊息第一階段：一對一文字訊息」：成果

49 交辦 Codex 製作一個小工具時，除了目標、脈絡、產出、界線，還要附上「驗收例子」。下列哪些敘述正確？

本題的正確選項有 2 個。

  1. 需求只寫「要正確計算」就足夠，AI 會自己知道怎樣才算對
  2. 至少寫出幾組操作與預期結果，AI 才知道你如何確認「正確」
  3. 驗收例子是幾組「這樣操作，應該看到什麼」
  4. 附上驗收例子之後，就不必再親自操作檢查成果

50 某成績工具的總分為作業 × 0.3 + 期中 × 0.3 + 期末 × 0.4，中間計算保留完整數值，最後才四捨五入到小數第一位；等第為 90 以上 A、80 以上 B、70 以上 C、60 以上 D，其餘 F；總分 60 以上為及格。一位學生的作業 70、期中 64、期末 59，下列哪些判定正確？

本題的正確選項有 3 個。

  1. 這位學生及格
  2. 總分是 63.8
  3. 等第是 F
  4. 等第是 D
