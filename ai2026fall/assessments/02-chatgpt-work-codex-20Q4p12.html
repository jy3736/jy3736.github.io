課後形成性評量：ChatGPT 任務交辦與 Codex 協作

20 題複選，每題 1 至 2 個正確選項。可選「逐題檢查」，每題選好就按「檢查答案」；或選「全部一次檢查」，全部作答後按「全部檢查」一次批改。答錯可以再試，試過 2 個不同的錯誤答案後才能看答案。答對 60% 以上的題目（看答案的不算）後，可以下載含答案的 HTML 檔。作答紀錄不會保存，重新整理或離開頁面後會從頭開始。

01 在同一個 ChatGPT 裡，下列哪些任務最適合交給 ChatGPT Work，取得一份可以檢查的完整成品？

  1. 把一學期的讀書筆記做成一份簡報
  2. 請 AI 用來回問答解釋一個看不懂的觀念
  3. 為畢業專題擬定一份專題計畫
  4. 審查組員的程式碼並執行測試

02 關於 ChatGPT Work 與 Codex 的用量，下列敘述何者正確？

  1. 兩者共用同一份用量額度，規模大的任務會消耗較多額度
  2. 兩者各自擁有獨立額度，使用 Work 不影響 Codex 可用的額度
  3. 不論任務規模大小，每次任務消耗的額度都相同
  4. Codex 執行任務時不會消耗任何用量額度

03 某同學請 AI 準備資料結構期中考。下列哪些提示片段屬於四要素中的「脈絡」？

  1. 請出 10 題選擇題加 2 題手寫程式題，附詳解
  2. 考試範圍是堆疊、佇列、鏈結串列
  3. 等我作答後再批改，先不要公布程式題答案
  4. 我對遞迴比較不熟

04 第一個提示只是起點。拿到 AI 的第一個回答後，下列哪些是用來調整方向的簡單追問？

  1. 「給我三種不同的解釋方式。」
  2. 把整段對話刪除，改寫一份十倍長的新提示
  3. 把同一個提示原封不動再送出一次
  4. 「繼續之前，先問我幾個問題。」

05 某同學附上一篇英文論文的摘要與結論，請 AI 用繁體中文整理研究問題、方法、主要發現與限制。為了之後能對照原文查找術語，提示中最適合加上哪一個要求？

  1. 全部專有名詞都只用中文譯名，不保留英文
  2. 把摘要逐字翻譯，不需要分段整理
  3. 專有名詞第一次出現時保留英文原文，並附中文解釋
  4. 只列出主要發現，省略研究方法與限制

06 AI 的回答再流暢，也可能不完整或有錯。下列哪些做法恰當？

  1. 語氣越有自信的回答，越可以省略查證
  2. 把第一個結果當成草稿，檢查重要的數字、人名、日期與引文
  3. 請 AI 對照我提供的原始檔案，再檢查一次這份結果
  4. 法律、醫療等重大決定，以 AI 的建議作為最終決定

07 依照課堂的學習誠信守則，下列哪些使用 AI 的方式是恰當的？

  1. 把作業題目整段貼上，直接交出 AI 產生的答案
  2. 認定每門課對 AI 的規定都一樣，不必另外確認
  3. 請 AI 依自己的筆記出練習題，作答後請它批改
  4. 交作業前確認授課教師的規定，並依要求註明 AI 的使用方式

08 上傳文件、試算表或 PDF 等檔案後，可以請 ChatGPT 做下列哪些事？

  1. 找出多份檔案之間的規律或前後矛盾之處
  2. 擷取、清理或重新整理檔案中的資訊
  3. 保證檔案內容完全正確，不必再檢查
  4. 自動把整理結果繳交到學校的教學平台

09 在 ChatGPT 的專案（Project）中寫下專案指示後，這份指示會套用到哪裡？

  1. 只有專案建立後的第一個對話
  2. 專案裡的每一個對話
  3. 帳號中所有專案的所有對話
  4. 只有上傳檔案的那一個對話

10 某同學上傳 Python 錯誤訊息的截圖請 ChatGPT 協助。下列哪一段附帶說明最恰當？

  1. 「幫我看一下這張圖。」
  2. 「這是什麼？」
  3. 「幫我把整個程式重寫一遍。」
  4. 「請看最下面紅色那一行，解釋錯誤原因，並告訴我最小的修正方式。」

11 某項偏好只跟當下這一個對話有關，例如「這次的簡報要 8 張投影片」。這類細節最適合放在哪裡？

  1. Settings > Personalization 的自訂指示
  2. 直接寫在這一次的提示中
  3. 所有專案共用的專案指示
  4. 帳號的記憶設定中，讓它永久生效

12 ChatGPT Work 可以做到下列哪些事？

  1. 搜尋網路、瀏覽網站並比較來源，整理出研究發現
  2. 保證產出的成果完全正確，不經人工檢查就能直接分享
  3. 設定排程任務，或用技能重複使用某個工作流程
  4. 在沒有連接任何外掛的情況下，讀取你的私人信件

13 在 ChatGPT 桌面版使用 Work 時選擇「Work locally」，這個選項的特點是什麼？

  1. 可以使用你電腦上的檔案、App 或瀏覽器
  2. 關掉 App 或電腦後，任務仍會在雲端繼續
  3. 只能在網頁版選擇，桌面版沒有這個選項
  4. 任務執行中不會因為需要授權而暫停

14 某同學原本只寫「幫我做一份期末報告簡報。」下列哪些補充能讓這個給 Work 的提示變好？

  1. 要求一次做成最終版本，完成後不必讓我檢查
  2. 指定投影片張數、主題、聽眾與報告時間
  3. 不附任何文獻，讓 AI 自由發揮內容
  4. 要求把文獻的發現和自己的看法分開，找不到充分證據的說法要標記出來

15 某組請 Codex 修正「收藏在重新整理後消失」的 bug。下列哪些資訊放進提示最有幫助？

  1. 從啟動服務到重新整理頁面的完整重現步驟
  2. 只寫一句「收藏功能壞了，幫我修好」
  3. 要求 Codex 直接重寫整個專案，不必說明原因
  4. 必須保留的限制（例如不更改 API 回傳格式）與驗證修正的方式

16 下列哪些做法能讓 ChatGPT Work 的任務更有效率、保持聚焦？

  1. 把必要的工作和「有空再做」的潤飾混在一起寫
  2. 只提供相關的來源，必要時限定日期範圍
  3. 任務偏離方向時，縮小範圍或停下來
  4. 盡量附上所有找得到的資料，即使與主題無關

17 某組想把長時間的任務交給 Codex、同時平行跑多個任務，並從 GitHub 發起。最適合使用哪一種 Codex 介面？

  1. IDE 擴充套件
  2. Codex CLI
  3. ChatGPT 桌面版
  4. Codex 雲端

18 大多數情況建議 Codex 使用 Ask for approval 模式。這個模式的行為是什麼？

  1. 每讀取一個檔案都必須先詢問你
  2. 可以任意存取整台電腦與網路，完全不詢問
  3. 可以在目前的工作區內自由作業，要超出這個範圍時會先暫停詢問
  4. 只能讀取檔案，永遠不能修改任何檔案

19 關於 AGENTS.md，下列哪些敘述正確？

  1. 同一層資料夾可以同時採用多份規則檔
  2. Codex 只讀取全域的規則檔，不讀取專案中的規則檔
  3. 在專案資料夾輸入 /init，可以產生一份草稿再自行修改
  4. 可以在子資料夾放各自的規則檔，讓規則只在需要的地方生效

20 Codex 正在工作時，你仍可以在 CLI 中傳送訊息。下列哪些敘述正確？

  1. 按 Enter 是引導（Steer），把訊息加入目前的執行
  2. 按 Tab 是排隊（Queue），等這輪結束再處理
  3. 按 Enter 會立即中止目前的任務
  4. 按 Tab 會另外開一個新的對話
