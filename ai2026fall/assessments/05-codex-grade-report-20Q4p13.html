課後形成性評量：成績報告規格與驗收

20 題複選，每題 1 至 3 個正確選項。可選「逐題檢查」，每題選好就按「檢查答案」；或選「全部一次檢查」，全部作答後按「全部檢查」一次批改。答錯可以再試，試過 2 個不同的錯誤答案後才能看答案。

答對 60% 以上的題目（看答案的不算）後，可以下載含答案的 HTML 檔。作答紀錄不會保存，重新整理或離開頁面後會從頭開始。

01 在一次成績報告工具的實作練習中，重點並不在寫出程式碼。下列哪些是這份練習真正要練的能力？

  1. 把計分規則、輸入資料與邊界條件講清楚
  2. 用手算驗證工具算出來的數字
  3. 把自己發現的問題轉成下一次的具體要求
  4. 自己動手寫出完整程式並逐行除錯

02 某成績表是 UTF-8 的 CSV 檔，第一行為欄位名稱，之後每一行是一位學生，欄位依序為學號、姓名、作業、期中、期末。下列哪一行符合這個欄位順序？

  1. name,student_id,homework,midterm,final
  2. student_id,name,midterm,final,homework
  3. student_id,name,homework,midterm,final
  4. student_id,name,final,midterm,homework

03 某成績工具規定三個分數欄位依作業、期中、期末的順序檢查，而且只回報遇到的第一個問題。若某一位學生的作業欄填的是 abc、期末欄是空白，這一筆會被回報為下列哪一個問題？

  1. 期末欄缺少分數
  2. 作業欄與期末欄的問題各回報一次
  3. 期末欄超出 0-100 的範圍
  4. 作業欄不是數字，並附上原始填入的內容

04 某成績工具的總分公式為：作業 × 0.3 + 期中 × 0.3 + 期末 × 0.4，並四捨五入到小數第一位。一位學生的作業 92、期中 85、期末 88，總分為多少？

  1. 88.3
  2. 88.0
  3. 89.2
  4. 87.5

05 某成績工具的等第門檻為總分 90 以上 A、80 以上 B、70 以上 C、60 以上 D，其餘 F，及格是總分 60 以上。一位學生的總分為 60.2，下列哪些判定正確？

  1. 等第應判為 F
  2. 這位學生屬於不及格
  3. 等第應判為 D
  4. 這位學生屬於及格

06 某成績工具的權重為作業 0.3、期中 0.3、期末 0.4，並規定中間計算全程保留完整數值，只在最後顯示時四捨五入到小數第一位。一位學生的作業 60.5、期中 70、期末 60，顯示出來的總分應為多少？

  1. 63.1
  2. 63.2
  3. 63.0
  4. 64.0

07 開始這項練習之前，要先在終端機執行版本檢查，確認需要用到的工具都已安裝。下列哪些敘述正確？

  1. 畫面顯示版本號碼，代表該工具已經安裝
  2. 畫面出現「找不到指令」，代表該工具尚未安裝
  3. 版本號碼必須與範例完全相同才能開始練習
  4. 畫面沒有顯示任何訊息就代表安裝成功

08 關於某成績工具所產生報告的整體結構，下列哪些敘述符合規定？

  1. 報告以 Markdown 格式輸出
  2. 四個區塊依摘要、個人成績、等第分布、資料問題的順序排列
  3. 報告只在出現問題資料時才需要產生
  4. 等第分布中 A 到 F 五列都要列出，人數是 0 也要列

09 關於某成績報告中個人成績區塊的排列方式，下列哪些敘述符合規定？

  1. 一律依學號由小到大排列，總分不影響順序
  2. 只列出及格的學生，不及格者不列
  3. 依總分由高到低排列
  4. 總分相同時，依學號由小到大排列

10 關於某成績報告中資料問題區塊的呈現方式，下列哪些敘述符合規定？

  1. 列出學號、姓名與問題三項
  2. 依原始成績表的順序列出
  3. 依總分由高到低重新排序後列出
  4. 只列出情況最嚴重的那一筆

11 若某次執行完全沒有挑出任何問題資料，報告中對應的區塊應如何呈現？

  1. 把整個區塊刪除不列
  2. 留成空白，不寫任何文字
  3. 寫上一行「沒有資料問題。」
  4. 改為列出全部學生的姓名

12 某份範例成績表共有十位學生，其中兩筆被判定為問題資料而整筆排除。依驗收清單，執行後的摘要應出現下列哪些數字？

  1. 有效人數 8
  2. 最低 0.0
  3. 平均 73.2
  4. 及格率 87.5%

13 驗收時要先把範例成績表複製成另一個檔案，在副本裡把某一格改成無效內容後再執行一次。下列哪些是這一項要確認的結果？

  1. 工具會自動把無效內容換成 0 分後計入平均
  2. 工具會停下來要求使用者重新輸入那一筆資料
  3. 那一筆會出現在報告的資料問題中
  4. 程式不會中斷，也不會噴出看不懂的錯誤

14 關於這個成績工具在自己電腦上的執行方式，驗收時應確認下列哪些條件？

  1. 必須先註冊線上帳號才能使用
  2. 用一行指令就能執行
  3. 不必連上網路也能產生報告
  4. 不必自行安裝額外套件

15 練習開始前要先為工作資料夾建立一個 Git 存檔點。這個存檔點的作用包括下列哪些？

  1. 之後不論改壞了什麼都回得來
  2. 把現成的實作移走之後，原本的檔案仍保留在存檔點裡
  3. 可以讓工具的執行速度變快
  4. 可以自動修正程式裡的錯誤

16 練習資料夾裡附了一份現成的實作，還有一份寫好的預期報告。練習一開始要先把現成的實作移走，並在驗收完成前不要打開那份預期報告。這樣安排最主要的理由是什麼？

  1. 那些檔案會讓程式無法執行
  2. 那些檔案裡含有真實學生的個人資料
  3. 工作資料夾裡不允許存在多餘的檔案
  4. 練習的重點是自己把需求講清楚，並親手核對結果

17 一段完整的需求說明裡列了一節「不要做的事」。下列哪些屬於這一節的內容？

  1. 不要修改原始成績表裡的任何分數
  2. 不要為了讓數字好看而跳過問題資料卻不列出來
  3. 不要加入任何需要連到外面網站的功能
  4. 不要在終端機印出任何訊息

18 一段完整的需求說明中，對這個工具的使用方式與輸入來源做了規定。下列哪些符合這些規定？

  1. 報告必須輸出成 PDF 檔
  2. 每次執行都要由使用者手動輸入全部學生的分數
  3. 報告預設輸出到 output/report.md
  4. 指令可以接一個 CSV 檔路徑當參數，沒給路徑時使用預設的成績表

19 某成績工具要加上一組可以用一行指令跑完的自動測試。下列哪些屬於這組測試的要求？

  1. 只有作業 100 分、其餘欄位為 0 時，總分應為 30.0
  2. 剛好 90 判為 A、89.9 判為 B、59.9 判為 F
  3. 產生的報告檔案大小不得超過 1 MB
  4. 測試沒通過時要修改程式，而不是改掉測試裡的預期數字

20 某成績工具把整套規則寫成了一份可重複使用的技能。關於這份技能，下列哪些敘述正確？

  1. 在新的對話裡可以直接呼叫它，照同一套步驟重現同一份報告
  2. 技能裡規定用繁體中文回報結果
  3. 技能會自動把報告寄給全班同學
  4. 技能只能在當初建立它的那一次對話裡使用
