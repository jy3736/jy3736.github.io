課前前測：Codex 成績報告產生器

20 題單選。可選「逐題檢查」，每題選好就按「檢查答案」；或選「全部一次檢查」，全部作答後按「全部檢查」一次批改。答錯可以再試，試過 2 個不同的錯誤答案後才能看答案。

答對 60% 以上的題目（看答案的不算）後，可以下載含答案的 HTML 檔。作答紀錄不會保存，重新整理或離開頁面後會從頭開始。

01 在一次成績報告工具的練習中，學習者只寫了一段很短的需求就請 AI 工具做出成品，結果報告裡出現許多當初沒有提過的處理方式。這個現象最主要說明了什麼？

  1. 短版需求一定寫錯了，必須整段刪掉重寫
  2. 那些沒提到的部分，決定權等於交給了工具
  3. 工具的版本太舊，更新後再執行一次就不會出現
  4. 那些自行決定的細節一定是錯的，應該全部反向修改

02 某成績工具規定總分由作業、期中、期末三項加權而得，其中作業與期中各佔三成、期末佔四成。下列哪一個算式符合這個規定？

  1. 作業 × 0.4 + 期中 × 0.3 + 期末 × 0.3
  2. 作業 × 0.3 + 期中 × 0.4 + 期末 × 0.3
  3. 作業 × 0.3 + 期中 × 0.3 + 期末 × 0.4
  4. （作業 + 期中 + 期末）÷ 3

03 某成績工具的等第規則為：總分 90 以上 A、80 以上 B、70 以上 C、60 以上 D，其餘 F。一位學生的總分為 80.0，應判為哪一個等第？

  1. C
  2. F
  3. A
  4. B

04 一份成績報告練習明訂了使用資料的界線。下列哪一項符合這個界線？

  1. 可以放入真實學生的成績，只要把姓名改寫成代號即可
  2. 範例成績表的學號與姓名都是虛構的，練習成果也不可作為實際評分的依據
  3. 只要不公開產出的報告，就可以放入真實學生的個人資料
  4. 練習完成後可以直接把產出的報告送出，當作正式成績

05 某成績工具規定三個分數欄位依作業、期中、期末的順序檢查，而且只回報遇到的第一個問題。若某一位學生的作業欄是空白、期末欄填了 120，這一筆在報告的資料問題區塊應如何記錄？

  1. 只記錄作業欄缺少分數
  2. 只記錄期末欄超出 0-100
  3. 作業與期末兩個問題各記錄一筆
  4. 兩個問題互相抵銷，所以不必記錄

06 某成績工具規定：被檢查出問題的那一行，整筆排除在所有統計之外。若一份成績表中有一位學生的期中欄是空白，這一筆應如何處理？

  1. 把空白視為 0 分，照常計入平均與及格率
  2. 只把期中這一格拿掉，其餘兩科仍計入平均
  3. 整筆不列入任何統計，並列在報告的資料問題區塊
  4. 直接在原始成績表上補填一個分數後再計算

07 某成績工具的檢查規則要求：欄位不是數字或不在 0 到 100 之間時，回報的問題要附上原始填入的內容。若某一欄填的是 abc，下列哪一種回報方式符合這項要求？

  1. 該欄位有誤
  2. 該欄位不是數字，原始內容為 abc
  3. 該欄位已自動修正為 0 分
  4. 該欄位不是數字，原始內容不予顯示

08 某成績工具輸出的報告要依序包含摘要、個人成績、等第分布、資料問題四個區塊。下列哪一個排列符合這個順序？

  1. 個人成績、摘要、資料問題、等第分布
  2. 資料問題、摘要、個人成績、等第分布
  3. 摘要、等第分布、資料問題、個人成績
  4. 摘要、個人成績、等第分布、資料問題

09 某成績報告的摘要區塊要列出有效人數、平均、最高、最低與及格率。關於這些數字的呈現方式，下列哪一項符合規定？

  1. 平均與及格率四捨五入到小數第一位，及格率要帶 % 符號
  2. 平均取整數，及格率以小數呈現且不加任何符號
  3. 平均保留到小數第二位，及格率四捨五入成整數
  4. 平均與及格率都以分數形式呈現，一律不做四捨五入

10 某成績報告的個人成績區塊規定依總分由高到低排列，總分相同時再依學號由小到大。若三位學生的學號與總分分別是 S1130021 為 84.0、S1130014 為 84.0、S1130007 為 91.5，正確的排列順序為何？

  1. S1130007、S1130014、S1130021
  2. S1130007、S1130021、S1130014
  3. S1130014、S1130021、S1130007
  4. S1130021、S1130014、S1130007

11 某成績報告的等第分布區塊規定 A 到 F 五個等第都必須列出。若這次結果中沒有任何人得到 A，報告應如何呈現？

  1. 省略 A 這一列，只列出有人數的等第
  2. 把 A 併入下一個等第一起計算人數
  3. 仍然列出 A 這一列，人數寫 0
  4. 在報告末尾加註說明，但不列出該列

12 某成績工具要求中間計算一律使用完整精確的數值，只在最後顯示時才四捨五入到小數第一位。這樣規定最主要的理由是什麼？

  1. 可以讓程式的執行速度變快
  2. 可以讓報告表格的欄位寬度一致
  3. 四捨五入只能用在整數上
  4. 先把中間結果四捨五入再相加，可能讓最後的總分產生誤差

13 在驗收一個成績報告工具時，其中一項是把 Wi-Fi 關掉再執行一次，確認它照樣產生得出報告。這一項驗收在確認什麼？

  1. 工具不依賴網路上的服務，在自己的電腦上就能完成工作
  2. 工具的執行速度不會受到網路頻寬影響
  3. 產出的報告檔案可以壓縮後用電子郵件寄送
  4. 工具會自動把產出的報告上傳到雲端備份

14 驗收一個成績報告工具時，其中一項做法是先複製一份範例成績表成為另一個檔案，在副本裡把某一格改成無效內容後再執行一次。這個做法的重點之一是什麼？

  1. 副本執行完之後會自動修正原始檔案裡的錯誤
  2. 原始成績表保持不動，異常情況只在副本上測試
  3. 兩個檔案產生的報告必須完全相同才算通過
  4. 副本的檔名必須和原始檔案相同才能執行

15 一份成績報告練習要求學習者最後留下一份驗收紀錄。下列哪一組內容符合這份紀錄要寫的四件事？

  1. 工具的原始碼、使用的程式語言、檔案行數、執行時間
  2. 同組同學的姓名、分工比例、討論時間、繳交日期
  3. 報告的頁數、字數、圖表數量、參考來源數量
  4. 工具正確完成的一件事、自己發現的一個問題、用來重現問題的輸入、要求的修改與如何確認有效

16 一個成績報告工具的最小可行版本已通過驗收，接著要提出改進要求。依照這份練習的做法，這時應該怎麼要求？

  1. 直接在現有這一版上增修，計分規則與報告的四個區塊都不更動
  2. 重新做一個全新的版本，捨棄現有這一版
  3. 先把等第門檻放寬，再加入新的功能
  4. 先把報告縮減成兩個區塊，以便加入新的功能

17 某成績工具加上了一組可以用一行指令跑完的自動測試。當測試沒有通過時，正確的處理方式是什麼？

  1. 把測試裡的預期數字改成程式目前跑出來的結果
  2. 暫時停用沒通過的那幾項測試，之後有空再處理
  3. 修改程式，讓它符合測試原本設定的預期數字
  4. 調降等第門檻，讓測試比較容易通過

18 一項改進要求是把整套成績計算與報告規則寫成一份可重複使用的技能，讓下次換一份成績表時不必重新解釋。下列哪一組是這份技能應該包含的內容？

  1. 需要安裝的套件清單與各自的版本號碼
  2. 用途說明、什麼情況不該用它、輸入有哪些檔案、固定的執行步驟
  3. 每一位學生的姓名、學號與聯絡方式
  4. 程式的完整原始碼與逐行註解

19 某成績工具原本使用五級等第，現在要改成 A+、A、A- 這種十一級制。依照這份練習的做法，在動手修改之前應該先做什麼？

  1. 先把現有的自動測試全部刪除，避免干擾
  2. 先把報告縮減成只留下摘要一個區塊
  3. 先把原始成績表裡的分數調整成新的級距
  4. 先列出需要修改哪些地方的計畫，等確認後再動手

20 當成績工具的等第規則改變時，建議的處理順序是先更新規則說明、再修改程式、最後才更新預期結果。為什麼不直接把預期結果改成程式目前跑出來的樣子？

  1. 那樣做會讓程式的執行速度明顯變慢
  2. 預期結果的檔案格式在技術上不允許修改
  3. 那樣做只是讓比對「通過」，並沒有真的確認程式照新規則運作
  4. 預期結果只能由工具自動產生，人不可以編輯
