課後形成性評量：截止日看板規格與工作副本

20 題複選，每題 1 至 3 個正確選項。可選「逐題檢查」，每題選好就按「檢查答案」；或選「全部一次檢查」，全部作答後按「全部檢查」一次批改。答錯可以再試，試過 2 個不同的錯誤答案後才能看答案。

答對 60% 以上的題目（看答案的不算）後，可以下載含答案的 HTML 檔。作答紀錄不會保存，重新整理或離開頁面後會從頭開始。

01 某實作練習要學習者做出一個在自己電腦上就能執行的小工具，把各科的截止日整理成一個畫面。下列哪些描述符合這份練習的產出與重點？

  1. 產出是一頁可以用瀏覽器打開的看板
  2. 產出是一份純文字的報告檔
  3. 重點在把分類與排序的規則講清楚，而不是自己寫出程式碼
  4. 重點在比較不同程式語言的執行效能

02 某截止日清單的內容片段如下。關於這份資料的結構，下列哪一項描述正確？

[
  { "course": "資料結構", "title": "作業三：鏈結串列", "type": "作業", "due": "2026-09-23" }
]
  1. 最外層的中括號代表一筆資料，裡面的大括號代表一個欄位
  2. 最外層的中括號包住一個串列，裡面每一組大括號是一筆截止日
  3. 這種寫法只能放一筆截止日，要放多筆必須分成多個檔案
  4. 欄位的名稱可以任意更換，工具會自動辨識它的意思

03 某練習所附的範例截止日清單共有 7 筆，並刻意安排了幾種特別的情況以便驗收。下列哪些是刻意放進來的？

  1. 一筆已經過期的項目
  2. 一筆截止日就是天數起算日當天的項目
  3. 兩筆剛好落在分區門檻邊界上的項目
  4. 一筆完全沒有填寫截止日的項目

04 某項目的截止日是 2026-09-18，這次計算使用的天數起算日是 2026-09-21；規則規定剩餘天數小於 0 天的項目屬於已過期區，過期項目的顯示文字寫成「逾期 N 天」。下列哪些敘述正確？

  1. 這一項的剩餘天數是 −3
  2. 這一項應該分到已過期區
  3. 這一項的顯示文字是「剩 3 天」
  4. 這一項的顯示文字是「逾期 3 天」

05 某看板的分區規則為：剩餘天數小於 0 天是已過期，0 到 3 天是緊急，4 到 7 天是本週，8 天以上是之後，邊界一律照字面計算。剩餘天數剛好 4 天的項目屬於哪一區？

  1. 已過期
  2. 緊急
  3. 本週
  4. 之後

06 某看板要求截止日恰為天數起算日當天的項目，顯示文字必須和其他情況明確區隔。下列哪一種寫法符合這個要求？

  1. 剩 0 天
  2. 還有不到一天
  3. 逾期 0 天
  4. 今天到期

07 某看板對分區順序與區內排序訂了固定規則。下列哪些符合這些規則？

  1. 四個分區依「已過期、緊急、本週、之後」的順序出現
  2. 同一區裡剩餘天數少的排在前面
  3. 同一區裡依科目名稱的字數多寡排序
  4. 同一區裡一律把考試類型排在最前面

08 某看板頁面對呈現方式訂了明確要求。下列哪些是這一頁必須做到的？

  1. 每一項只要顯示名稱與截止日，其餘欄位可以省略
  2. 頁面最上面有標題，以及這次使用的天數起算日
  3. 每一個分區的標題上看得到這一區有幾項
  4. 沒有任何項目的分區仍然要列出，並在裡面寫「沒有項目」

09 某看板要求做到「一個檔案就能打開」。下列哪一項符合這個要求？

  1. 樣式直接寫在這一頁裡面，不連到外面的網站
  2. 樣式放在另一個檔案，用網址連進這一頁
  3. 樣式每次開啟時從公開的樣式服務即時下載
  4. 樣式由使用者每次打開頁面時自行設定

10 某人把需求交給 AI 工具時，特別列了一段「不要做的事」。下列哪些屬於這一段合理的內容？

  1. 不要修改原始的截止日資料
  2. 不要加入任何自動檢查的機制
  3. 不要加入需要連到外面網站的功能
  4. 不要放入真實的課程名單或同學姓名

11 在終端機執行版本檢查指令之後，畫面上出現「找不到指令」。這代表什麼？

  1. 那個工具已經安裝，只是版本太舊
  2. 那個工具還沒有安裝
  3. 那個工具安裝正確，只是不顯示版本號碼
  4. 那個工具需要連上網路才會回應

12 某練習在動手之前，先在工作資料夾裡建立一個版本控制的存檔點。下列哪些是這個存檔點的作用？

  1. 讓工具產生頁面的速度變快
  2. 不管後來改壞了什麼，都回得到這個狀態
  3. 自動把資料檔上傳到網路上備份
  4. 即使把附帶的現成實作移走，原本的檔案仍保留在這個存檔點裡

13 某人第一次只用很短的幾句話描述需求，AI 工具仍然做出了一個可以打開的看板。關於這個短版需求，下列哪些說法正確？

  1. 短版需求本身就是錯的，必須整段刪掉不再使用
  2. 短版需求沒有錯，它只是把許多決定交給了工具
  3. 短版需求的結果不必執行就能判斷好壞
  4. 成品上那些「工具自己決定的細節」，正好就是需求裡沒有講的部分

14 某份需求裡有一句話：「同樣的資料配同樣的起算日，不管哪一天執行，產生出來的那一頁都必須一模一樣。」下列哪些是這句話帶來的結果？

  1. 之後每一次修改都有辦法用逐字比對來驗證
  2. 頁面在瀏覽器中的載入速度會明顯變快
  3. 指令上從此不必再提供起算日
  4. 頁面上不能放產生時間這類每次都會變動的內容

15 某人要在既有的看板上追加兩個要求：一是讓作業、考試、報告三種類型用不同的底色標示，二是在標題下方加一行類型統計。下列哪些是交辦時應該說清楚的條件？

  1. 可以順便調整原本的分類與排序規則
  2. 統計的數字要跟著資料自動算，換一份清單也要正確
  3. 用底色區分之後，上面的文字仍然要看得清楚
  4. 統計的數字可以先寫成固定值，之後再回來改

16 關於工作副本（worktree）在同時交辦兩件事時的作用，下列哪一項描述正確？

  1. 它會把兩個對話的修改自動合併成一份
  2. 它讓兩個對話共用同一份檔案，以便互相參考
  3. 它讓每個對話有自己的一份檔案副本，兩邊互不打擾，完成後再整合
  4. 它會阻止其中一個對話執行任何測試

17 兩個追加的要求都完成並合併之後，原本「產生的頁面要和上一次一模一樣」的那項自動檢查失敗了。下列哪些處理方式正確？

  1. 這個失敗是正常的，因為頁面的內容本來就被改變了
  2. 立刻把預期結果換成程式現在產生的那一頁，讓檢查通過
  3. 先更新規則說明，由人親自打開頁面確認，最後才更新預期結果
  4. 這代表兩個要求一定互相改壞了，必須把兩邊全部還原

18 某人在桌面版應用中以工作副本（worktree）的方式進行一項工作。下列哪些描述正確？

  1. 在新對話的輸入框下方選擇工作副本，並選擇起始分支
  2. 建立出來的工作副本預設處於 detached HEAD 狀態
  3. 送出提示之前必須自己先想好分支名稱並建立好分支
  4. 完成後可以在工作副本上建立分支，或用 Hand off 把成果移回本機

19 關於工作副本（worktree）的使用限制與特性，下列哪些正確？

  1. 同一個分支不能同時在兩個地方使用
  2. 它同時也是一道安全邊界，可以阻止工具讀取其他檔案
  3. 被版本控制忽略的檔案不會自動跟著複製過去
  4. 桌面版預設只保留最近 15 個由工具管理的工作副本

20 某人想在既有的看板上多加一個「今天」區。下列哪些是動手之前應有的正確認知？

  1. 只要改一行顯示文字就能完成，不會牽動其他部分
  2. 應該先把修改計畫列出來給人確認，確認後才動手
  3. 修改範圍包含規則說明、自動檢查與預期結果
  4. 這個新增會把當天到期的項目，從它原本所屬的分區獨立出來
