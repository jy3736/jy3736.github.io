課後形成性評量：從機器學習到 AI Agent

20 題複選，每題 1 至 3 個正確選項。可選「逐題檢查」，每題選好就按「檢查答案」；或選「全部一次檢查」，全部作答後按「全部檢查」一次批改。答錯可以再試，試過 2 個不同的錯誤答案後才能看答案。

答對 60% 以上的題目（看答案的不算）後，可以下載含答案的 HTML 檔。作答紀錄不會保存，重新整理或離開頁面後會從頭開始。

01 在生成式 AI 普及之前，許多 AI 早已在生活中工作，它們大多不產生新內容，而是看了資料後給出一個判斷。下列哪些屬於這類 AI 的應用？

  1. 手機用臉部辨識解鎖
  2. 把一段會議紀錄改寫成條列待辦表
  3. 信箱自動過濾垃圾郵件
  4. 銀行在刷卡瞬間判斷是否盜刷

02 交辦一般任務時會交代目標、脈絡、產出、界線四項要素。若要交辦的是一個工具，還應該再加上哪一樣東西？

  1. 規定介面要使用哪些配色
  2. 驗收例子：幾組「這樣操作，應該看到什麼」
  3. 限制產出檔案的大小
  4. 指定要使用的程式語言

03 機器學習的流程依序是收集資料、標上答案、訓練模型、預測新資料、檢驗成效。下列哪些敘述正確？

  1. 學好的規則稱為模型
  2. 訓練時，電腦反覆比對「猜的」和「正確答案」，逐步修正
  3. 傳統程式與機器學習一樣，都要由人把每一條規則寫出來
  4. 檢驗成效時，要用模型沒看過的資料計算準確率或誤差

04 關於辨別式 AI 與生成式 AI 的比較，下列哪些敘述正確？

  1. 生成式 AI 不是用機器學習訓練出來的
  2. 辨別式 AI 通常一個模型就能處理許多不同的任務
  3. 生成式 AI 的成果多半沒有唯一答案，需要人判斷內容是否正確、合用
  4. 辨別式 AI 的輸出是一個類別、分數或數字

05 辨別式 AI 常見的任務有分類、迴歸與異常偵測三種。下列哪些任務與類型的配對正確？

  1. 判斷一筆刷卡是否和平常的消費習慣差很多：分類
  2. 預測一間房子大概能租多少錢：迴歸
  3. 判斷一則商品評論是正評還是負評：分類
  4. 預測明天店裡大約會來多少客人：異常偵測

06 某打磚塊遊戲的電腦模式交給一個小型神經網路控制球拍。關於這個神經網路，下列哪些敘述正確？

  1. 它只學一件事：看到球目前的位置和方向，預測球會落在哪裡
  2. 它會自動產生新的磚塊排列與關卡
  3. 它必須連上網路才能學習
  4. 它會用對話說明自己為什麼這樣移動球拍

07 把打磚塊遊戲裡看到的元素對應到機器學習的名詞。下列哪些對應正確？

  1. 球實際落下的位置：標籤
  2. 球的位置與方向（x、y 與 dx、dy）：特徵
  3. 儲存、匯出、匯入模型：部署
  4. 畫面上代表模型猜測落點的藍色三角形：標籤

08 機器學習需要每個例子的正確答案。關於取得這些答案，下列哪些敘述正確？

  1. 遊戲中球落下時，遊戲本身就知道正確落點，不需要人工標記
  2. 所有真實問題的正確答案都能由系統自動取得
  3. 判斷「這則評論是不是在酸人」這類問題，標上答案通常是最省時間的步驟
  4. 外送平台在送達時，系統會自動記錄實際花了幾分鐘

09 某「學習準備清單」網頁有讀懂題目、整理資料、準備驗收三個勾選項目，下方顯示「已完成 X／3」，勾選或取消時立刻更新。下列哪些驗收結果正確？

  1. 三項全勾後再取消一項，仍顯示 3／3
  2. 之後再加一個項目，完成數的分母會變成 4
  3. 勾選其中兩項時顯示 2／3
  4. 全部不勾時顯示 0／3

10 辨別式 AI 有一些限制。下列哪些敘述正確？

  1. 打磚塊模型只學過球往下掉的落點，球往上飛時球拍只會回到中間等待
  2. 只要資料夠多，模型就能回答它沒被訓練過的問題
  3. 用台北訂單訓練的送達時間模型，搬到其他城市一定一樣準
  4. 這類模型通常不會告訴你它為什麼這樣判斷

11 請 AI 製作小工具的練習，都走題目敘述、建議提示詞、預期成果、完成檢核四個階段。下列哪些做法符合這套流程？

  1. 先寫下畫面應有什麼、每種操作應得到什麼結果，再操作與驗收
  2. 記錄落差，修改後重新測試
  3. 為每個版本留一個存檔點
  4. AI 回報「完成」之後，就可以省略親自操作檢查

12 2026 年 9 月，新創公司 TypeSafe AI 發表了 Jev，並把它稱為 System One Model。下列哪些敘述正確？

  1. Jev 主要是給一般人直接對話使用的
  2. Jev 不聊天、不寫文章，專門做快速的判斷
  3. System One 指的是緩慢、仔細的推理
  4. 名稱借自心理學家康納曼的說法，System 1 指快速、直覺的判斷

13 軟體把一段情況說明和問題交給 Jev，並事先限定可以接受的答案。關於 Jev 的三種題型，下列哪些敘述正確？

  1. 選擇題的每個選項各有一個機率
  2. Jev 可以自由回答不在給定選項內的答案
  3. 是非題回傳「這句話成立」的機率
  4. 量表題回傳一段說明理由的文字

14 某客服系統用一個判斷模型分類訊息，模型回傳每個答案的機率與這次判斷的信心程度。系統應如何運用這些數字？

  1. 只要有機率，就不需要任何人工判斷
  2. 信心不夠時，讓模型自己新增一個選項來回答
  3. 設定門檻：信心夠高就自動處理，信心不夠就再查資料或轉給人工
  4. 機率只是參考，系統一律直接採用最高機率的答案

15 比較傳統機器學習（辨別式 AI）、Jev 與生成式 AI，下列哪些敘述正確？

  1. 依官方說明，Jev 換新問題只要改寫問題與選項，不必重新訓練
  2. 傳統機器學習換一個新問題，要重新收集、標註資料，再訓練一個新模型
  3. 生成式 AI 處理複雜問題的速度，通常比傳統機器學習快
  4. 報導引述官方數字，Jev 的回應時間約在 100 毫秒以內

16 評估一個會附上機率的判斷模型時，除了準確率，還要看機率是否可信。下列哪一項描述了「機率可信」？

  1. 只要準確率夠高，機率是否可信就不重要
  2. 模型回報的機率越高越好，與實際結果無關
  3. 模型說有八成把握的判斷，實際上大約八成是正確的
  4. 模型每一次都回報九成以上的把握

17 閱讀一則關於 Jev 的新產品新聞時，下列哪些態度或事實正確？

  1. 公司募得 4,000 萬美元，代表這些數字已經可信
  2. 速度、成本與判斷品質是公司自行公布的測試結果，尚待第三方驗證
  3. 新聞中的宣傳數字可以直接當成已證實的事實
  4. Jev 目前只開放候補名單的開發者試用

18 關於辨別式 AI、判斷模型、生成式 AI、Chatbot、推理模型與 AI Agent 這些概念，下列哪些敘述正確？

  1. AI Agent 在授權範圍內讀取資料、操作工具並完成多步工作
  2. 回答流暢、步驟很多或網頁很漂亮，都不能代替來源核對與實際操作
  3. 推理模型做出的多步分析一定正確，不需要再核對
  4. 這些名詞是彼此完全分開的盒子，一個 Agent 不能使用生成式模型

19 ChatGPT 的 Chat、Work、Codex 可以依要拿到的成果來選。下列哪些選擇恰當？

  1. 依一份會議紀錄完成整理並交付可保存的待辦表：Work
  2. 只要對話中上傳了附件，就一定要改用 Work
  3. 想弄懂「目標」與「待辦事項」的差別：Chat
  4. 在專案中製作一個能開啟、能勾選的學習準備清單頁：Codex

20 請 AI 只根據一份虛構的小組會議紀錄整理待辦表，欄位為工作項目、負責人、期限、待確認事項。下列哪些是正確的要求或檢核？

  1. 交付的檔案內容與對話中顯示的表格不同也沒關係
  2. 可以自動補上來源沒提到、但看起來合理的任務
  3. 逐列找回來源句子，確認沒有新增來源未提到的任務
  4. 紀錄沒寫明的負責人或期限填「待確認」，不替小組決定
