在 VS Code 中與 Codex 協作

規則寫好之後，接下來是每天真正會用到的操作介面：把選取的程式碼交給 Codex、用斜線指令下達常見任務，並認識代理工作階段與 worktree 的差別。

01本機環境（桌面版）

在 ChatGPT 桌面版的 Codex 中，可以為專案設定本機環境。設定存放在專案根目錄的 .codex 資料夾，可以 commit 分享給組員：

  • Setup scripts（設定腳本）：Codex 建立新 worktree 時自動執行，例如安裝套件、先建置一次。macOS、Windows、Linux 可以分別設定。
  • Actions（快捷動作）：常用任務的按鈕，例如「啟動網站」、「執行測試」，顯示在桌面版上方工具列，點下去就在內建終端機執行。

02在 VS Code 中與 Codex 協作

VS Code 畫面導覽

區域位置用途
活動列最左邊一排圖示切換檔案總管、搜尋、原始檔控制（Git）、擴充套件、Codex
側邊欄活動列右邊顯示目前選擇的功能，例如檔案清單或 Codex 對話
編輯區中間最大的區域打開、閱讀、修改檔案
終端機下方面板執行指令。選單 終端機 > 新增終端機 開啟，會自動位在目前開啟的專案資料夾

開啟 Codex

  1. 在 VS Code 的擴充套件頁搜尋並安裝 OpenAI 的 Codex 擴充套件（ID：openai.chatgpt），依畫面登入。

  2. 選單 檔案 > 開啟資料夾，打開你的專案資料夾。

  3. 點活動列上的 Codex 圖示。看不到的話，開啟命令選擇區，輸入並執行 Codex: Open Codex Sidebar。

VS Code 擴充套件會自動把你開啟的檔案當作脈絡。你也可以選取一段程式碼加入對話，讓 Codex 從你正在看的地方開始。每次任務前後記得建立 Git 存檔點。

擴充套件指令

在命令選擇區輸入指令名稱執行，也可以綁定快捷鍵：

指令 ID預設快捷鍵用途
chatgpt.addToThread無把選取的程式碼範圍加入目前對話
chatgpt.addFileToThread無把整個檔案加入目前對話
chatgpt.newChatmacOS Cmd+N；Windows/Linux Ctrl+N開新對話
chatgpt.newCodexPanel無開新的 Codex 面板
chatgpt.openCommandMenu無開啟 Codex 指令選單
chatgpt.openSidebar無開啟 Codex 側邊欄

綁定快捷鍵

  1. 開啟命令選擇區（Cmd/Ctrl+Shift+P）。

  2. 執行 Preferences: Open Keyboard Shortcuts。

  3. 搜尋 Codex 或指令 ID，例如 chatgpt.addToThread。

  4. 點鉛筆圖示，按下你想要的快捷鍵組合，再按 Enter。

課堂小練習

把 chatgpt.addToThread 綁定到你習慣的快捷鍵。之後選取一段程式碼、按快捷鍵，就能一鍵加入對話。

常用斜線指令

在 Codex 輸入框輸入 /，會列出可用指令，繼續打字可以篩選：

指令用途
/init為目前專案產生 AGENTS.md 草稿
/plan切換到規劃模式，先想清楚多步驟任務再動手
/goal設定一個持續性目標，讓 Codex 朝它工作
/review審查還沒 commit 的修改，或和基準分支比較
/project選擇新對話要使用的專案
/local在本機工作區執行這個對話
/worktree在新的 Git worktree 中執行這個對話
/cloud在雲端執行這個對話（可用時）
/ide-context開關「自動帶入編輯器內容」
/side開一個臨時的側聊，不打斷主對話
/fork把目前的本機對話複製成一個新的本機對話
/compact壓縮目前對話的脈絡，讓長對話繼續順暢
/status顯示對話 ID、脈絡使用量與用量限制
/model、/reasoning選擇模型與推理強度

兩層設定：Codex 設定與編輯器設定

設定層控制什麼在哪裡改
Codex 設定模型、推理強度、權限、沙箱、MCP、個人化；和 CLI 共用Codex 側邊欄齒輪 > Codex Settings，或 Open config.toml 直接編輯
編輯器設定擴充套件在 VS Code 裡的行為，名稱以 chatgpt. 開頭VS Code 設定頁搜尋 @ext:openai.chatgpt 或 Codex

chatgpt. 開頭的設定屬於 VS Code，不要寫進 config.toml。幾個值得認識的編輯器設定：

設定預設說明
chatgpt.followUpQueueModequeueCodex 工作中送出的訊息，要排隊等下一輪（queue），還是立刻引導目前這一輪（steer）。按 Cmd/Ctrl+Shift+Enter 可以單次反轉
chatgpt.composerEnterBehaviorenterEnter 是否直接送出，或多行時需要 Cmd/Ctrl+Enter
chatgpt.reviewDeliveryinline/review 在目前對話執行，或另開一個審查對話
chatgpt.commentCodeLensEnabledtrue在程式中的 TODO 註解上方顯示小按鈕，讓 Codex 處理
chatgpt.localeOverride自動設定 Codex 介面語言
chatgpt.runCodexInWindowsSubsystemForLinuxfalse僅 Windows：在 WSL 中執行 Codex

VS Code 的使用者設定也可以用 JSON 格式編輯（命令選擇區執行 Preferences: Open User Settings (JSON)）。例如想讓工作中送出的訊息立刻引導 Codex：

JSON 的規則：整份用 { } 包住，名稱和文字值都要加雙引號，名稱和值之間用冒號，多個設定之間用逗號分隔。

VS Code 與桌面版同步

當 ChatGPT 桌面版和 VS Code 擴充套件開啟同一個專案時，兩邊會共用進行中的對話與編輯器內容：

  • 在桌面版輸入框開啟 IDE context，Codex 就能使用你在 VS Code 開著的檔案；不想帶入時關掉。
  • 可以從 VS Code 擴充套件打開桌面版的對話，也可以把 VS Code 的對話拿到桌面版繼續。

03在 VS Code 的代理工作階段中使用 Codex

VS Code 本身也有「代理」介面（Chat view 與 Agents window），可以選擇由哪個 AI 代理來執行一個工作階段（session）。Codex 是其中一個選項。一個工作階段包含一段對話、它用到的脈絡和修改，可以暫停、繼續或交接。

讓 Codex 出現在選單中

Codex 預設不在選單裡，下面兩種方式擇一即可：

  • 安裝 OpenAI Codex 擴充套件：在 Chat view 中使用。
  • 實驗功能 Agent Host：在設定中開啟 chat.agentHost.codexAgent.enabled，Codex 會出現在 Agents window。在 Agent Host 上可以選擇登入 ChatGPT，免費帳號即可。

工作階段的控制項

控制項決定什麼本課建議
Session Target由哪個代理執行、工具在哪裡運作（Local、Copilot、Claude、Codex、Cloud）選 Codex
Agent代理扮演的角色，例如 Agent 實作，Plan 先規劃不確定做法時先用 Plan
Language model推理方式、速度與額度消耗用預設值
Permissions哪些動作需要你確認用最保守的選項
Code isolation修改寫進目前資料夾，或另開 Git worktree（只有 Agents window 可選）小任務用 Folder

在 Agent Host 上執行 Codex 時，有三種核准預設：

預設Codex 可以做什麼
Default Permissions讀寫專案檔案、執行一般指令；要連網或存取專案外的資源前會先問你
Auto-Review權限和 Default Permissions 相同，但核准請求交給自動審查者判斷，不問你
Full Access可以修改專案外的檔案並直接連網。等於把整台電腦交給代理，請謹慎使用

Folder 還是 New Worktree

選擇適合注意
Folder需要用到目前檔案、還沒 commit 的修改的小型互動任務修改會立刻出現在你的工作區
New Worktree不想影響目前工作區的平行任務從已 commit 的狀態開始，完成後要自己整合結果
  • New Worktree 需要一個至少有一次 commit 的 Git 儲存庫。還沒 commit 的修改、沒被追蹤的檔案、被 Git 忽略的檔案（例如 .env）預設都不會帶過去；被忽略的檔案可以用 VS Code 設定 git.worktreeIncludeFiles 指定要複製的項目。
  • Worktree 工作階段使用 Allow all 權限。Worktree 只隔離程式碼修改，不是安全邊界，不會限制指令或網路存取。

交接（Handoff）

在進行中的工作階段打開 Session Target 下拉選單，選另一個目標（例如從 Copilot 換成 Codex，或換到 Cloud），VS Code 會把對話紀錄和脈絡一起帶過去。VS Code 也能找到你在 Codex 裡建立的本機工作階段，繼續在 VS Code 中使用。
