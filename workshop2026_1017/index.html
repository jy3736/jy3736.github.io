工作坊定位

本工作坊從真實的教學與實務情境出發，探索 AI Agent 如何協助整理資料、建立教學輔助、發布教材與評量，並進一步帶領學生完成與自身專業相關的 AI 專題。

認識 AI Agent → 建立工作空間 → 建構教材型 Smart TA → 發布教材與評量 → 帶學生完成 AI 專題

文件說明：本頁為工作坊設計初稿，供規劃與溝通使用。為使課程內容能適切回應參與者需求、場地與設備條件、帳號與平台狀況，以及相關專業建議，工作坊講師將於開課前彙整意見，並保有對課程內容、流程、工具與活動安排進行最終調整及定稿的權責。
講師角色與專業界線：講師負責 AI Agent 概念、方法、工具與專題引導。健康、護理與長照是練習情境；內容正確性、適用性、安全、倫理與法規，仍由相關領域教師、場域夥伴或具資格專業人員確認。

教師

選定一門可作為練習的課程，準備可使用的課程大綱、教材、閱讀資料、學習活動、作業或評量規準。

場域夥伴

選定一個可討論的工作情境，準備可公開、已授權或已去識別化的流程、表單、常見問題或案例。

帳號與工具

預計使用 GitHub Pages 者，請預先完成 GitHub 帳號；使用 Notion 者可準備既有帳號。

資料原則

不使用真實病歷、可識別個人資料、未授權教材或未經確認的專業資料。

七個模組總覽

01｜從 Chatbot 到 Agentic AI

認識 AI Agent 與大學教師日常教學工作的可能應用。

02｜VS Code 與工作空間

看懂專案、教材、參考資料與生成內容的位置及基本操作。

03｜建構 RAG 式 Smart TA

讓 AI 先檢索指定教材，再協助學生自學與教師備課。

04｜讓教材上線

發布學生數位教材與教師授課提綱。

05｜讓評量進入課堂

建立學生練習題組與教師端線上測驗工具。

06｜AI 專題：排班小工具

以靜態網頁處理多條件的實務問題。

07｜AI 專題：紀錄草稿填寫

將自然語言整理為待專業人員確認的結構化草稿。

模組練習案例說明：本工作坊使用的練習，特別是照護場域排班與照護紀錄草稿填寫案例，均以簡化、假設性的場域需求設計，用來協助理解 AI Agent、資料、規則與介面的整合方式。這些案例可作為日後與領域專家及場域夥伴共同討論、逐步擴充為實際可用專案的起點；惟本頁範例、程式與原型尚未經真實場域需求確認、專業驗證、安全測試、法規與個資評估，敬請勿直接使用於真實場域或正式工作流程。若未來有導入需求，仍請依場域規範與專業建議，另行完成必要的設計、測試、審核與建置程序。

重要使用界線與兩日成果

使用界線

  • RAG 可降低無依據生成風險，但教材與評量仍須由教師審核。
  • 排班原型僅作教學與討論，不能自行作出正式人力、勞動或照護安全決策。
  • 紀錄原型只能產生待確認草稿，不能自動送出、覆寫或取代正式紀錄。
  • 不得使用真實病歷、可識別個資或未授權表單；正式導入前須另做安全、法規、個資與資安評估。
  • 本頁案例、程式與原型可作後續擴充專案的起點，但不宜直接部署或使用於真實場域。

兩日預期成果

  • 一個以指定教材為基礎的 Smart TA 初步方向。
  • 一份學生教材或教師授課提綱的線上發布草稿。
  • 一組經教師審核的練習題組或教師端評量原型。
  • 兩個 AI 專題教學案例原型。
  • 一份教師後續帶領學生專題的資料準備與檢核重點。
