# 稀釋計算小工具

這是一個可以離線使用的網頁。不用安裝軟體，也不用連網路。

## 怎麼打開

1. 在這個資料夾找到 `index.html`。
2. 用滑鼠雙擊 `index.html`，它會在電腦的瀏覽器中打開。
3. 如果雙擊後看到程式文字，請用滑鼠右鍵點選檔案，再選「打開檔案的應用程式」或「開啟方式」，選 Safari、Chrome、Edge 或 Firefox。

## 怎麼使用

1. 輸入原液濃度。
2. 輸入目標濃度。這兩個濃度必須使用相同單位，例如都用 mg/mL；網頁不會自動換算單位。
3. 輸入最後要配出來的總體積，單位是 mL。這不是額外要加入的稀釋液體積。
4. 按「計算」，查看需要的原液與稀釋液體積。
5. 要重新輸入時，按「清空」。改動任何數字時，舊結果會先清除，請再按「計算」。

例如：原液濃度填 `100`，目標濃度填 `20`，總體積填 `10`。結果是量取原液 **2 mL**，加入稀釋液 **8 mL**，總共 **10 mL**。

三個數字都必須大於 0。目標濃度不能高於原液濃度；如果兩個濃度相同，就不需要加稀釋液。

## 它怎麼算

使用 `C₁V₁ = C₂V₂`：

- 原液體積 =（目標濃度 ÷ 原液濃度）× 總體積。
- 稀釋液體積 = 總體積 − 原液體積。

計算以體積可以相加為前提，顯示的體積最多保留 10 位有效數字。

`index.html` 是完整工具，`README.md` 是這份操作說明，`prompt.md` 是本階段的學生提示。工具不會上傳或儲存輸入資料；關閉網頁後，下次重新開啟即可再使用。
