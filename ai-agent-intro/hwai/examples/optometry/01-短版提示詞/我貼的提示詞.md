# 第一步：短版提示詞（原樣貼給 AI Agent）

> 我是視光系學生，想要一個把負柱鏡處方換成正柱鏡處方的小工具。我輸入球面度數、柱面度數和軸度，按一下就算出轉換後的處方：新球面度數 = 球面 + 柱面，新柱面度數是原柱面度數變號，新軸度是軸度加 90，超過 180 就減 180。請做成在我自己電腦上雙擊就能打開的網頁，不用安裝軟體也不用連網路。我完全不會寫程式，做完請用我看得懂的話告訴我怎麼打開來用。

## 我操作兩分鐘後發現的事

這一版**可以用**，三個欄位、一個按鈕、算得出答案，雙擊 `index.html` 就打得開，關掉 Wi-Fi 也照樣能算。但是我照講義的問題一個一個試，結果如下（都是我實際點出來的畫面）：

| 我做的事 | 它給我的 | 對不對 |
|---|---|---|
| -2.00 / -1.00 / 180 | -3.00 D、1.00 D、90 度 | 答案對，但柱面度數沒有帶正號 |
| +0.25 / -0.75 / **90** | -0.50 D、0.75 D、**0 度** | **錯**。90+90=180 並沒有超過 180，不該減，正確答案是 180 度 |
| -1.00 / -0.50 / 91 | -1.50 D、0.50 D、1 度 | 對 |
| 柱面度數填 **0** | 照算，給我「軸度 0 度」 | **錯**。沒有散光就不需要轉換，也沒有軸度 |
| 柱面度數填 **+1.00** | 照算，給我柱面 -1.00 D | **錯**。那張處方本來就是正柱鏡了，應該提醒我 |
| 軸度填 **3.5** | 照算，給我 93.5 度 | **錯**。軸度只能是整數 |
| 軸度填 **200** | 照算，給我 110 度 | **錯**。超出 1–180 的範圍 |
| 球面度數填 **+30** | 照算，給我 29.00 D | **錯**。超出 -20 到 +20 的合理範圍 |
| 三格全部留空 | 球面度數：**NaN** D | **錯**。應該提醒我還沒填 |

## 我的結論

短版沒有寫錯，它只是把很多決定丟給了 AI：

- 我說「超過 180 就減 180」，AI 寫成「大於等於 180 就減」，**軸度 90 那組就壞了**——這正是講義警告的那個坑。
- 我完全沒提合理範圍、沒提柱面度數必須是負值、沒提錯誤要怎麼處理，所以它什麼都照算。
- 我沒說要顯示轉換規則和「僅供練習」的提醒，畫面上就一個字都沒有。

畫面上每一個「它自己決定的細節」，都是我沒講的部分。
