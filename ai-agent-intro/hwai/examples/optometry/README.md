# 練習單一：視光處方轉換器 — 範例成果

這是照著〈練習單一〉講義做完一輪的成果，按照講義的三個步驟各留一份，方便對照「提示詞寫多少，AI 就幫你決定多少」。

> 本工具僅供自行練習計算，數值均為虛構，不可作為臨床或處方的依據。

## 怎麼打開

每個資料夾裡都有一個 `index.html`，**在檔案上點兩下**就會用瀏覽器打開，不必安裝任何軟體、不必註冊帳號。關掉 Wi-Fi 重新整理也照樣能算。

| 資料夾 | 這是什麼 | 要打開的檔案 |
|---|---|---|
| `01-短版提示詞/` | 貼短版提示詞得到的第一版（**故意保留原樣，裡面有錯**） | `index.html` |
| `02-完整版提示詞/` | 貼完整版提示詞重做的 MVP | `index.html` |
| `03-改進版/` | 在完整版上接著做改進要求的最終版 | `index.html` |

每個資料夾另外附一份 `.md`，記錄那一步貼了什麼提示詞、發現什麼、改了什麼。

## 三版差在哪（一眼版）

拿講義的第 4 組 `+0.25 D / -0.75 D × 90°` 去試，正確答案是 `-0.50 D / +0.75 D × 180°`：

- **01 短版**：給 `軸度 0 度` ← 錯。AI 把「超過 180 才減」寫成「大於等於 180 就減」。
- **02 完整版**：給 `× 180°` ← 對。因為提示詞把這個邊界明講出來了。
- **03 改進版**：同樣對，而且按一個按鈕就能載入這組，旁邊直接寫著預期答案給我對照。

# 學生驗收紀錄

**AI Agent 正確完成的一件事**

第一版（短版提示詞）就真的做出一個雙擊可開、離線可用的單檔網頁，三個欄位、一個「轉換」按鈕、一個結果區都在，計算的主體邏輯（球面相加、柱面變號、軸度加 90）也是對的。我不會寫程式，但不需要看程式碼就能操作它。

**我發現的一個問題或不清楚之處**

短版做出來的工具，**軸度的邊界算錯了**。講義說「只有在結果大於 180 時」才減 180，但 AI 把它寫成「大於或等於 180 就減」，所以原軸度剛好 90 度的時候，90＋90＝180 被多減了一次，變成 0 度——而 0 度根本不是有效的處方軸度。

同時我也發現短版**完全沒有做任何檢查**：柱面度數填 0（沒有散光）、填 +1.00（本來就是正柱鏡）、軸度填 3.5 或 200、球面填 +30，它全部照算不誤；三格留空的話直接顯示 `NaN`。這些都是我在短版提示詞裡沒有講，所以 AI 自己決定「不處理」的部分。

**我用來重現問題的輸入**

| 我填的 | 短版給我的 | 正確應該是 |
|---|---|---|
| 球面 +0.25、柱面 -0.75、軸度 **90** | -0.50 D、0.75 D、**0 度** | -0.50 D / +0.75 D × **180°** |
| 球面 -2.00、柱面 **0**、軸度 90 | -2.00 D、0.00 D、0 度 | 應提醒「沒有散光，不需要轉換」 |
| 球面 -2.00、柱面 **+1.00**、軸度 90 | -1.00 D、-1.00 D、0 度 | 應提醒「這張處方本來就是正柱鏡」 |
| 球面 -2.00、柱面 -1.00、軸度 **3.5** | 93.5 度 | 應提醒「軸度只收整數」 |
| 球面 -2.00、柱面 -1.00、軸度 **200** | 110 度 | 應提醒「軸度是 1–180 度」 |
| 球面 **+30**、柱面 -1.00、軸度 90 | 29.00 D | 應提醒「超出 -20～+20 的範圍」 |
| 三格**全部留空** | 球面度數：**NaN** D | 應提醒三格都還沒填 |

**我要求的修改，以及我如何確認修改有效**

我改用完整版提示詞重做一次，把邊界規則（「等於 180 不要減」，並附上軸度 90 的反例）、合理範圍、柱面必須是負值、錯誤處理、兩位小數與不可出現 -0.00、畫面上要有的說明文字，全部明確寫進去。之後再貼改進要求，加上五組範例按鈕、清除按鈕、把錯誤提醒搬到出錯的欄位旁邊，以及一段「如何核對結果」。

我用這些步驟確認它真的有效（**每一項我都先自己手算再比對**）：

1. 五組核對案例逐一輸入，五組答案全部與我手算的相同。
2. 特別盯第 4 組：得到 `× 180°`，不是 `0°`——原本的錯誤修好了。
3. 特別盯第 5 組：得到 `× 1°`，不是 `181°`——該減的有減。
4. 把七種亂填的情況再試一次：每一種都跳出看得懂的提醒，**都沒有硬算出答案**，頁面也沒有整個沒反應。
5. 柱面度數顯示成 `+1.00 D`，正號有出來；柱面填 0 時直接被擋下，不會出現 `-0.00`。
6. 試了 -20.00 / -2.00 / 45，得到 -22.00 D / +2.00 D × 135°：轉換後球面低於 -20 沒有被誤判成錯誤，這是對的。
7. 完全不碰滑鼠：Tab 依序走過三個欄位、轉換、清除、五個範例按鈕，焦點框看得很清楚；在欄位裡按 Enter 可以直接送出。
8. 按「清除」後三格全空、結果和紅字提醒都消失。
9. 把視窗縮到手機寬度，版面沒破圖，不需要左右捲動。
10. 關掉 Wi-Fi 重新整理，計算、範例按鈕、示意圖都照常。
