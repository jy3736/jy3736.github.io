# 練習單二：醫檢稀釋換算器 — 範例成果

這是照著〈練習單二〉講義做完一輪的成果，按照講義的三個步驟各留一份，方便對照「提示詞寫多少，AI 就幫你決定多少」。

> 本工具僅供自行練習計算，數值均為虛構，不可作為臨床或檢驗實務的依據。

## 怎麼打開

每個資料夾裡都有一個 `index.html`，**在檔案上點兩下**就會用瀏覽器打開，不必安裝任何軟體、不必註冊帳號。關掉 Wi-Fi 重新整理也照樣能算。

| 資料夾 | 這是什麼 | 要打開的檔案 |
|---|---|---|
| `01-短版提示詞/` | 貼短版提示詞得到的第一版（**故意保留原樣，裡面有錯**） | `index.html` |
| `02-完整版提示詞/` | 貼完整版提示詞重做的 MVP | `index.html` |
| `03-改進版/` | 在完整版上接著做改進要求的最終版 | `index.html` |

每個資料夾另外附一份 `.md`，記錄那一步貼了什麼提示詞、發現什麼、改了什麼。

## 三版差在哪（一眼版）

拿「原液 2 mg/mL、目標 10 mg/mL、配 25 mL」這種不可能的題目去試（目標比原液還濃）：

- **01 短版**：照算不誤，告訴我「需要稀釋液 **-100 mL**」← 錯到離譜，但它沒有任何提示。
- **02 完整版**：擋下來，並告訴我「稀釋只會把溶液變稀，配不出比原液更濃的溶液」。
- **03 改進版**：同樣擋下來，而且紅字就出現在 **C2 那一格底下**，我一眼就知道是哪格填錯。

再拿第 4 組 `3 / 1 / 10`：短版給我 `3.3333333333333335 mL`，完整版和改進版給我 `3.333 mL`，並在畫面上註明那是四捨五入後的值。

改進版的「計算過程」還放了講義那張稀釋示意圖，以及一句我自己差點搞混的提醒：**V2 是混合後的目標最終體積，不是要加入的稀釋液體積**。

# 學生驗收紀錄

**AI Agent 正確完成的一件事**

第一版（短版提示詞）就真的做出一個雙擊可開、離線可用的單檔網頁，三個欄位、一個「計算」按鈕、一個結果區都在，C1V1 = C2V2 的主體算法也是對的：前三組核對案例（10/2/25、8/2/12、5/5/10）算出來的數字，跟我用紙筆算的完全一樣。我不會寫程式，但不需要看程式碼就能操作它。

**我發現的一個問題或不清楚之處**

短版做出來的工具**完全沒有檢查輸入合不合理**。最嚴重的是「目標濃度比原液還濃」它照算不誤，算出「需要加入 -100 mL 稀釋液」——負體積在實驗室裡根本不存在，這個答案照抄下去就是配錯。原液濃度填 0 的時候它直接顯示 `Infinity`，三格留空顯示 `NaN`，這兩個字我第一次看到還不知道是什麼意思。

另外兩件事也是 AI 自己決定、我沒講的：**單位被寫死成 mg/mL 和 mL**，沒有下拉選單可選；**小數位數沒人管**，3 / 1 / 10 那組給我 `3.3333333333333335 mL`，實驗室的量具根本量不到那個精度，而且畫面上也沒說這是不是四捨五入過的。

**我用來重現問題的輸入**

| 我填的（C1 / C2 / V2） | 短版給我的 | 正確應該是 |
|---|---|---|
| 2 / **10** / 25（目標比原液濃） | 原液 125 mL、稀釋液 **-100 mL** | 應擋下並說明配不出比原液更濃的溶液 |
| **0** / 2 / 25 | 原液 **Infinity** mL | 應提醒「原液濃度必須大於 0」 |
| **-10** / 2 / 25 | 原液 -5 mL、稀釋液 30 mL | 應提醒濃度必須大於 0 |
| 10 / **0** / 25 | 原液 0 mL、稀釋液 25 mL | 應提醒目標濃度必須大於 0 |
| 10 / 2 / **0** | 原液 0 mL、稀釋液 0 mL | 應提醒要配的體積必須大於 0 |
| 三格**全部留空** | 原液 **NaN** mL | 應提醒三格都還沒填 |
| 3 / 1 / 10 | 原液 **3.3333333333333335** mL | 應顯示 3.333 mL，並註明是四捨五入 |
| 想用 µg/mL | 沒有選項，畫面寫死 mg/mL | 應提供濃度與體積兩個下拉選單 |

**我要求的修改，以及我如何確認修改有效**

我改用完整版提示詞重做一次，把單位下拉選單、合理範圍（C1 > 0、V2 > 0、0 < C2 ≤ C1，且 C2 ＝ C1 要正常出答案）、錯誤處理、顯示三位小數並註明四捨五入、不可出現 -0.000、畫面要印出三個式子和警語，全部明確寫進去。之後再貼改進要求，加上四組範例按鈕、清除按鈕、把錯誤提醒搬到出錯的欄位旁邊，以及一段逐步的「計算過程」。

我用這些步驟確認它真的有效（**每一項我都先自己手算再比對**）：

1. 四組核對案例逐一輸入，四組答案全部與我手算的相同。
2. 特別盯第 3 組（5 / 5 / 10）：得到原液 10.000 mL、稀釋液 **0.000 mL**，沒有報錯，也沒有出現 `-0.000`——C2 ＝ C1 這個邊界是對的。
3. 特別盯第 4 組（3 / 1 / 10）：得到 **3.333** 和 **6.667**，而且畫面上寫著「以上數字為四捨五入到小數點後三位的結果」，我知道螢幕上的數字不是完整值。
4. 把九種亂填的情況再試一次（三格留空、中文字、C1＝0、C1 負值、C2＝0、C2 > C1、V2＝0、V2 負值、1e400）：每一種都跳出看得懂的提醒，**都沒有硬算出答案**，頁面也沒有整個沒反應，`Infinity` 和 `NaN` 再也沒出現過。
5. 單位：把 10 / 2 / 25 改用 µg/mL 和 µL，答案是 5.000 µL 和 20.000 µL——數字沒有被偷偷換算，只有標示跟著改，這正是講義要求的行為。
6. 完全不碰滑鼠：Tab 依序走過兩個下拉、三個欄位、計算、清除、四個範例按鈕，焦點框看得很清楚；在欄位裡按 Enter 可以直接送出。
7. 按「清除」後三格全空、結果和紅字提醒都消失。
8. 把視窗縮到手機寬度，版面沒破圖，不需要左右捲動。
9. 關掉 Wi-Fi 重新整理，計算、範例按鈕和示意圖都照常（圖檔放在同一個資料夾，不需要連網）。

改的過程中我自己又抓到一個小毛病並請 AI 修掉：C1 填 0 的時候，除了「C1 必須大於 0」之外還會多跳一句「C2 比 C1 還濃」。C1 本來就填錯了，這句只會讓人更混亂。修好後 C1 填 0 只跳一句，但 2 / 10 / 25 那種真的 C2 比較濃的情況仍然照樣擋下來。
