# 第一步：短版提示詞（原樣貼給 AI Agent）

> 我是醫檢系學生，想要一個算稀釋的小工具。我輸入原液濃度、目標濃度，還有我要配出來的總體積，它就告訴我該量多少原液、再加多少稀釋液，算法是 C1V1 = C2V2。請做成在我自己電腦上雙擊就能打開的網頁，不用安裝軟體也不用連網路。我完全不會寫程式，做完請用我看得懂的話告訴我怎麼打開來用。

## 我操作兩分鐘後發現的事

這一版**可以用**：三個欄位、一個按鈕、算得出答案，雙擊 `index.html` 就打得開，關掉 Wi-Fi 也照樣能算。前三組數字丟進去答案也是對的。但我照講義的問題一個一個試，就出事了（以下都是我實際點出來的畫面）：

| 我做的事 | 它給我的 | 問題在哪 |
|---|---|---|
| 10 / 2 / 25 | 原液 5 mL、稀釋液 20 mL | 答案對 |
| 5 / 5 / 10 | 原液 10 mL、稀釋液 0 mL | 答案對，C2＝C1 沒有報錯 |
| 3 / 1 / 10 | 原液 **3.3333333333333335** mL、稀釋液 **6.666666666666666** mL | 小數位數根本沒有人決定。實驗室量具量不出小數點後 16 位 |
| 目標濃度比原液濃（2 / **10** / 25） | 原液 125 mL、稀釋液 **-100 mL** | **錯**。稀釋不可能配出比原液更濃的溶液，而且「加 -100 mL 稀釋液」根本做不到 |
| 原液濃度填 **0** | 原液 **Infinity** mL、稀釋液 -Infinity mL | **錯**。除以 0 的結果直接吐給我看 |
| 原液濃度填 **-10** | 原液 -5 mL、稀釋液 30 mL | **錯**。負濃度不存在 |
| 最終體積填 **0** | 原液 0 mL、稀釋液 0 mL | **錯**。配 0 mL 沒有意義，應該提醒 |
| 三格**全部留空** | 原液 **NaN** mL | **錯**。應該提醒我還沒填 |

另外兩件我按下去才想到的事：

- **單位是 AI 自己決定的。** 畫面上直接寫死 mg/mL 和 mL，沒有下拉選單。我如果要用 µg/mL 或 µL，只能自己在心裡換算——這很容易出錯。
- **畫面上沒有四捨五入的說明，也沒有「僅供練習」的警語**，因為我沒有講。

## 我的結論

短版沒有寫錯，它只是把很多決定丟給了 AI：

- 我沒說單位要能選 → AI 幫我挑了 mg/mL 和 mL。
- 我沒說合理範圍（C1 > 0、V2 > 0、0 < C2 ≤ C1）→ 它什麼都照算，連 Infinity 和負的稀釋液體積都直接顯示。
- 我沒說要顯示幾位小數 → 它就把浮點數原封不動印出來。
- 我沒說畫面要有警語 → 就沒有。

畫面上每一個「它自己決定的細節」，都是我沒講的部分。
