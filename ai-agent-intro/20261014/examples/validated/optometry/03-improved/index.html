轉換規則

  1. 新球面度數 = 球面 + 柱面
  2. 新柱面度數 = 原柱面度數變號
  3. 新軸度 = 原軸度 + 90；只有大於 180 才減 180

負柱鏡與正柱鏡是同一處方的不同表示方式，光學效果相同；正負號不代表好壞或嚴重程度。輸入範圍的限制不套用到新球面度數。

如何核對結果

  1. 新球面度數 = 球面 + 柱面
  2. 新柱面度數 = 原柱面度數變號
  3. 新軸度 = 原軸度 + 90；只有大於 180 才減 180

有效軸度是 1° 至 180° 的整數。180° + 90° = 270° 是中間值，減去 180° 才得到 90°。原軸度 90° → 180°；原軸度 91° → 1°。
