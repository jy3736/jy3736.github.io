模組 06｜AI 專題：照護場域排班小工具 · 深度導讀

開場白

各位學員，大家好，歡迎收聽模組六，照護場域排班小工具。排班要讓人力足夠，要遵守每個人的夜班與假日條件，還要盡量公平。這一模組不需要寫程式；您負責看懂規則、準備測試資料，並親自確認班表有沒有守住規則。

01第 01 節：學習目標與階段成果

第一節先說成果。離開時，您會帶走兩樣東西。第一，一個雙擊就能開啟的排班工具，可以匯入人員與班別、自動排班、手動調整並下載班表。第二，一份測試紀錄，寫下每個測試怎麼操作、應該看到什麼、實際看到什麼。

路線分五段：看懂需求、操作範例、用六個案例測範例、請 A I Agent 一層一層做自己的版本，最後用同一組案例驗收。測試紀錄和工具一樣重要，它是您判斷工具可不可信的證據。

02第 02 節：專題需求與範圍

第二節先把範圍縮小。真實排班要考慮法規、機構規範、請假和臨時調度；第一版只做一張可以檢查的一週班表。

期間是七天，範例固定從二〇二六年十月十二日週一，到十月十八日週日。班別有三個：白班早上八點到下午四點，小夜下午四點到半夜十二點，大夜半夜十二點到早上八點。職類有住院醫師、護理人員、照護人員、清潔人員，各四位。個人條件只有三種：不值夜班、假日不可上班，以及指定可上班的星期。工具是單純的網頁，資料只留在瀏覽器。月班表、請假、換班與雲端同步，這一版都先不做。

最重要的一句原則是：有解才產生班表；無解時要清楚回報，不能偷偷忽略限制。單位「安程照護」和所有姓名都是虛構的，最低人數與休息時間也只是練習假設。

03第 03 節：人員資料、班別與規則

第三節看兩份輸入資料。工具讀入兩份 C S V，也就是可以用 Excel 開啟的表格文字檔。請先用這一節的按鈕下載。

人員表每一列是一個人，有編號、姓名、職類，以及三個個人條件。職類文字必須和四種職類完全一樣，例如「護理人員」不能寫成「護理師」。「不值夜班」寫「是」，代表不能排大夜；「假日不可上班」寫「是」，代表週六週日不能排。指定可上班星期留空就是每天可以；照護人員許美玲填的是一到五，意思是只排週一到週五。班別表則寫三個班的時間，以及每班每種職類的最低人數，範例全部是一人。

接著分清兩種規則。必要限制一條都不能違反：每班各職類達到最低人數、每人每天最多一班、班與班之間至少休息八小時，以及三個個人條件。七天乘三班乘四職類，總共八十四格都要有人。偏好只有一條：同職類每人班數盡量平均。分開寫，A I 才不會為了平均或排滿，默默放寬限制。

講義在這裡請您先算一題，這也是本集的第一個完整例子。護理人員有四位：王雅婷不值夜班，吳佩珊假日不上班。週六的三個班各要一位護理人員，每人每天最多一班。可以先暫停算算看。

答案是：週六能上班的是王雅婷、李欣儀、周佳穎三人，王雅婷不排大夜，三個人剛好填滿三班。如果周佳穎請假，只剩兩人要填三班，一定排不出來，週日也一樣。這種資料本身排不出來的情況，工具應該說出缺口，而不是硬排。第五節的測試二，就是用這份少了周佳穎的資料。

04第 04 節：動手操作範例工具

第四節先用做好的範例工具跑一次，知道「完成」長什麼樣子。範例工具是一個網頁檔，不需安裝也不需網路。

練習 A 有六個動作，每做一步就核對畫面。第一，按「選擇人員 C S V」和「選擇班別 C S V」匯入兩份檔案，應看到十六人、三個固定班別，兩邊都標「已匯入」。第二，進到需求與限制，應看到「必要限制不會自動放寬」。第三，按開始自動排班，應看到所有必要限制均已通過。第四，切換四種職類的班表，每一格都有人，下方顯示限制檢查通過。第五，下載班表，用 Excel 開啟，應有日期、星期、班別、時間、職類、人員編號、姓名七欄，中文正常。第六，按發布班表，看到班表已發布。下載不必先發布。

完成後，用自己的眼睛再查兩件事：護理人員班表中，王雅婷沒有排在大夜；週六週日找不到吳佩珊。還要知道，重新整理頁面，資料就會清空，重要班表要先下載。

也可以選做：用 Codex 開啟完整範例包，貼上講義的提示，請它說明首頁入口，但先不修改檔案。

遇到錯誤訊息：匯入失敗，先比對欄位名稱、職類文字和檔案編碼；回報無解，就找出哪天、哪班、哪個職類沒有人選，不要要求忽略限制；結果不平均，記得平均是次要目標。

05第 05 節：用測試案例檢查結果

第五節是本模組的核心：畫面顯示通過，不等於規則真的被遵守。測試案例，就是先寫好怎麼操作、應該看到什麼，再親自操作比對。

練習 B 有六個案例。每個案例都從重新整理、重新匯入開始；需要的測試檔講義都準備好了，每份只和範例差一行。測試一，用範例資料排班，應全部有人且通過。測試二，改用少了周佳穎的人員檔，應說明哪天、哪班、哪個職類排不出來，而且不能發布。測試三，排好後把週三大夜換成王雅婷，應出現她不可值大夜的警告；換回原本的人，警告消失。測試四，跨日休息。測試五，改用白班護理人員最低兩人的班別檔，白班每天應有兩位，或說明人數不足。測試六，改用把李欣儀職類寫成護理師的人員檔，應說明哪一列職類不對。

我們把測試四完整走一遍。在護理人員班表找到週三小夜的人，預設是周佳穎，再把週四大夜也換成她。小夜半夜十二點下班，大夜半夜十二點上班，中間休息零小時，應該出現休息不足的警告。講義的參考結果是：原始範例工具仍顯示限制檢查通過。原因是這一版只檢查小夜接隔天白班，沒檢查小夜接隔天大夜。所以您的紀錄應寫：預期休息不足，實際顯示通過，不符合。

參考結果中，測試四、五、六都不符合。測試五白班仍只有一位，因為最低人數被固定成一，沒有讀班別檔的數字。測試六人數變成十五人卻沒有說明，打錯的那一列被默默略過，排班後看起來像週末人力不足。講義用三句話整理：畫面寫了，不代表程式做了；讀進來，不代表用到了；沒報錯，不代表沒錯。

請先自己做完六個案例，再打開參考結果對照。如果遇到無解，不要叫 A I 想辦法排出來，它可能讓同一人一天上兩班。無解代表人力或規則要由人決定怎麼調整。

06第 06 節：請 AI Agent 做出自己的版本

第六節從空白資料夾開始，請 Codex 這類 A I Agent 做出排班系統的最小可用版本：能匯入、能自動排、能檢查、能手動改、能下載，其他先不做。方法是一次貼一段提示，做完一層就親自檢查，通過才貼下一段。

準備時，新建一個資料夾，放進兩份範例 C S V，用 Codex 開啟，先貼「說明我的程度」的提示。它應該只回覆了解，沒有建立任何檔案。接下來六層，每層都用講義的複製按鈕。

第一層做五個步驟的空白介面，打開網頁檔要停在第一步，而且沒有預載資料。第二層加入匯入，重點是資料有錯時，要列出第幾列、哪個欄位、寫了什麼；可以用測試六的檔案試。第三層建立限制檢查，故意把王雅婷排進大夜，畫面要指出姓名和違反的規則。這一層請留意，提示沒說夜班是哪些班、假日是哪幾天，A I 會自己決定，寫在需求與限制畫面上。讀一遍，不符合您的意思，就在下一段提示寫清楚。第四層加入自動排班，先守限制再求平均，用測試二的檔案應得到無解原因，而不是一張違規班表。第五層加入手動換人，換成不合格的人立即警告、不能發布，換回後警告消失。第六層加入下載，中斷網路仍能使用，Excel 開啟中文正常。

示範成果的外觀可以和您的不同，只要通過同樣的檢查。選做的「改改看」一次只改一處；改壞了，就請 A I 還原。

做完六層，用測試一到三測自己的版本。接著是練習 D：用測試四、五、六測，只把您的版本沒通過的項目留在修正提示裡，請 A I 只修這幾點。修好後，六個測試全部重做，確認原本對的地方沒有改壞。講義說，第六層示範版本六個測試全部符合，因為第二、三層的提示已寫明最低人數與休息時間；但您的版本不一定如此，要以自己的測試為準。

07第 07 節：成果檢核與使用界線

第七節收尾。每一層都走同樣的循環：寫清楚規則，必要限制和偏好分開；一次只加一層；操作前先寫預期；最後以自己看到的結果為準。

離開前確認三項成果：雙擊能開啟、用範例資料完成匯入到下載的工具；一份六個測試的紀錄，含修正前後的實際結果；以及能說明排不出來時，為什麼要由人決定，而不是讓工具放寬限制。

使用界線也請記住。這裡的人員、班別與限制都是虛構的，工具只是教學原型。真實排班涉及勞動法規、機構規範、人員健康與照護安全，須由主管與具資格的人員決定。不要把真實員工姓名、職編、請假或健康資訊放進練習資料；使用雲端 A I 前，先確認機構對資料上傳的規定。

聽後自測

第一題，工具顯示限制檢查通過，是否代表班表遵守了所有規則？請先暫停想想。不代表。它只檢查寫進去的規則；測試四中，原始範例工具沒檢查小夜接隔天大夜，所以休息零小時也顯示通過。

第二題，少了周佳穎排不出來，可以請 A I 想辦法排出來嗎？請暫停。不可以。週末三個班只剩兩位護理人員，這是資料本身的缺口；要求硬排，可能讓人一天上兩班。應由人決定增加人力或調整規則。

第三題，第六層示範版本六個測試都通過，能直接把這個結果寫進自己的紀錄嗎？請暫停。不能。示範和您的版本是不同版本，結果不能混用；要用自己的版本重新操作六個測試。

結語

這一模組請帶走排班工具、測試紀錄與無解原因的說明，也帶走一個習慣：先寫預期，再親自操作，A I 說完成不能代替您的核對。下一模組要做照護紀錄草稿填寫工具，會繼續用同樣的方式，一層一層做、一項一項驗。現在請回到講義第三節，先把兩份 C S V 下載下來。
