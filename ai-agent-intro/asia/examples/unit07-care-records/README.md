# 照護紀錄模組｜本機 Codex 版

這是一套純前端照護紀錄工具。資料只保存在使用者自己的瀏覽器中，不需要登入，也不需要 API 金鑰。

## 開始使用

1. 解壓縮整個資料夾。
2. 雙擊 `啟動照護紀錄.cmd`。
3. 瀏覽器開啟 `http://localhost:8765` 後，在 Codex 內建瀏覽器開啟同一網址。
4. 網頁右上角顯示「Codex 已連結（3 個工具）」後，即可請 Codex 協助。

可以直接對 Codex 說：

> 請開啟 http://localhost:8765，讀取目前照護敘述，整理後回填欄位。

## 主要功能

- 輸入並保留原始照護敘述。
- 辨識中文數字及口語生命徵象。
- 整理日期、時間、食慾、進食量、血壓、心跳、體溫與備註。
- 照護人員及個案以「人名 · 編號」下拉選單管理。
- 新增姓名後自動產生照護人員 `C001` 或個案 `P001` 編號。
- 日期或必要單位缺漏時，以紅框提醒。
- 紀錄保存在瀏覽器 `localStorage`。
- 依個案與日期查詢，並匯出 CSV。
- 提供 Codex Site tools：讀取敘述、回填欄位、查詢本機紀錄。

## 注意事項

- 關閉啟動視窗後，本機網頁會停止；再次雙擊啟動檔即可。
- 不同瀏覽器的資料彼此分開。
- 清除瀏覽器網站資料會刪除本機紀錄，請定期匯出 CSV 備份。
- Codex 只協助整理與回填，個案歸屬及正式儲存仍須由照護人員確認。

## 檔案

- `app/index.html`：照護紀錄工具。
- `guide.html`：完整操作與實作講義。
- `啟動照護紀錄.cmd`：啟動本機網站。
- `給Codex的第一句.txt`：可直接貼給 Codex 的指令。
