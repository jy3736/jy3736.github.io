# 智慧排班模組協作說明

這是一個可離線運作的純前端 package，不需要 npm、資料庫、後端服務或 API 金鑰。

協助使用者時：

- 先閱讀 `README.md`。
- 使用 `啟動智慧排班.cmd` 啟動 `http://localhost:8765`。
- 首頁位於 `index.html`，排班工具位於 `app/index.html`，講義位於 `guide/index.html`。
- 範例匯入資料位於 `samples` 資料夾。
- 系統應從「人員與班別」第一步開始；不要預先寫入人員或班別資料。
- 必要限制不能被自動放寬；無解時應清楚回報。
- 使用者可在發布前直接下載 CSV。
- 保留全綠色的醫護風格，不加入咖啡色元素。
- 修改 HTML 後，檢查頁面內 JavaScript 語法與 CSV 匯入、排班、檢查、下載等主要流程。
