# 照護紀錄草稿（純前端）

雙擊 `index.html`，用瀏覽器開啟即可使用。不需要安裝套件或網路；紀錄與名單只存在目前的瀏覽器。

1. 在「照護人員」旁按「＋ 新增」建立人員，貼上口語敘述，按「擷取欄位」。
2. 逐欄核對右側結果；單位不清楚時保持空白，由人選擇。
3. 在「這是誰的資料？」選擇或新增個案，按「確認並儲存」。缺漏時會出現紅框。
4. 「紀錄查詢與匯出」可依個案與日期篩選，匯出含 UTF-8 BOM 的 CSV。

## 連結 Codex（選做）

在本機啟動網站（例如在這個資料夾執行 `python3 -m http.server 8765`，Windows 可用 `py -m http.server 8765`），再用 Codex 內建瀏覽器開啟 `http://localhost:8765`。右上角顯示「Codex 已連結（3 個工具）」後，Codex 可以：

- `read_care_narrative`：讀取畫面上尚未儲存的原文；
- `fill_extracted_care_fields`：回填右側欄位，供人工核對；
- `list_local_care_records`：查詢這個瀏覽器保存的紀錄。

三個工具都不能選擇個案，也不能按下儲存。用一般瀏覽器開啟時會顯示「請用 Codex 內建瀏覽器開啟」，其他功能照常可用。
