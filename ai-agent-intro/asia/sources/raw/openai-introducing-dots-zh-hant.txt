Dot 是能力出眾、全天候運作的智慧體，專為處理各種事務而打造。Dot 帶來與 AI 協作的全新方式，會了解你在意的事、持續為你工作，並接手重要任務，讓你能把更多時間與心力留給自己。

00:00

[素材：《實驗室現場直播》發表影片]

dot 具備前沿智慧，是你的堅強後盾。dot 由 GPT‑6 Astra 驅動，擁有自己的雲端電腦，能逐漸從回饋中學習，全天候朝你的目標努力。透過我們的外掛程式生態系，dot 能輕鬆連接超過 4,000 個應用程式，運用各種工具，在你需要的地方提供協助。

無論是透過 ChatGPT、Slack 或 Teams，你都能隨時聯絡自己的 dot。你可以提問、探索想法，並在合作過程中提供回饋；需要透過交談理清事情時，也能直接與 dot 進行語音通話。合作得越多，你的 dot 就越了解你的偏好、思考方式，以及你對工作成果的要求。

dot 的神奇之處在於能按照你的做法完成工作，有時甚至在你想到要開口之前，就把成果交到你手中。過去，如果你一直想推動遠大的構想與計劃，卻苦於沒有時間或支援，現在有了 dot 幫忙，你會開始覺得一切都有可能。

在 OpenAI 內部，我們已開始看見智慧系統隨時在旁協作的工作樣貌。Slack 上有人回報程式錯誤，dot 就會立即展開調查。新的設計送來後，dot 會將設計做成可運作的應用程式，讓團隊專注於客戶回饋。新一輪規劃展開時，dot 會協助大家配合彼此的進度，朝如期完成的目標邁進。在 OpenAI 以外，一位早期測試者的 dot 發現他忘了向某份刊物開立發票，便主動準備好發票，並在他核准後寄出。

今天，你可以先從主要的 dot 開始，取個名字，打造專屬於你的 dot。展望未來，我們期待由多個 dot 組成團隊，共同為你工作。我們正開始向適用市場的 Pro、Business Premium 和 Enterprise 方案陸續推出 dot，也計劃近期開放給更多使用者。我們也將開放專職 dot 的預覽版。專職 dot 擁有用於存取管理的專屬身分，使用 IT 部門配置的硬體，並支援與公司的紀錄系統深入整合，藉此在組織內承擔明確的職責。

dot 能獨立工作

dot 可以使用自己的雲端電腦、瀏覽器，以及你已連接的應用程式，完成幾乎任何工作。

你隨時都能開啟 dot 的電腦，檢查工作成果。除了自己的裝置，dot 也能連接其他裝置。你也可以授權 dot 連接並使用你的筆記型電腦，直接在你的工作環境中與你協作。

即使同時處理其他專案，你的 Dot 也能接下新專案並自主推進。你可以持續交付新的任務與想法，不必費心管理多段獨立對話，也無須逐步指揮。

dot 是你的延伸

有了解你目標與標準的 Dot 從旁協助，你就能承擔更多工作，無須逐步指揮。以下是實際應用的情境：

根據回饋修正問題並完成測試

你是一名正在開發應用程式的開發人員。你的 dot 會留意客戶回饋中反覆出現的需求，界定小幅改進與錯誤修正的範圍，實作並測試，再提交完整的 pull request 供你審查，並附上展示變更的影片。你可以一邊繼續開發下一項重要功能，一邊審查 dot 準備好的修正與改進。

隨產品範疇變動調整發表計劃

你正主導一項產品發表計劃。你的 Dot 會了解你的受眾、定位與創意標準。當產品範疇改變時，Dot 會釐清產品故事需要如何調整、修改發表素材，並草擬素材與文件的修改內容。等你回來時，就能審閱依照你設定的方向調整好的發表計劃與創意成果。

根據新證據更新分析

你是一名科學家。你的 Dot 會了解你的研究問題，以及你評估證據的方式。有新資料時，Dot 會重新執行分析、探究意料之外的結果，並更新論文中的圖表。當研究發現改變時，Dot 會修改佐證說明，並標示需要你審閱的部分。當你從實驗室回來，工作成果就已根據最新證據更新。

隨需求變動更新提案

你是一名業務主管，正協助一筆企業交易完成技術審查。你的 Dot 會將客戶需求和往來紀錄與產品文件比對，找出仍需測試的項目，為一項關鍵整合建立概念驗證，並推薦曾處理類似交易的解決方案工程師。隨著需求與測試結果改變，Dot 會更新提案和測試計劃，並標示尚待解決的疑慮。你和工程師則能專注於與客戶溝通，並核准對客戶的承諾。

自動處理內容製作

你是一名內容創作者。你的 Dot 會了解你的表達風格，以及受眾在意的事。收到新的訪談逐字稿時，Dot 會挑出適合剪成短片的片段、整理節目筆記，並草擬社群貼文供你核准。Dot 也會將你的修改同步套用到各項素材，逐漸掌握哪些內容能引起共鳴，讓你有更多時間創作。

你在哪裡工作，Dot 就在哪裡協作

與 dot 合作，就像聊天一樣簡單。你可以在 ChatGPT 桌面版、網頁版和行動版中，向 dot 傳送訊息或與 dot 通話。dot 也能傳訊息給你，回報進度、提出問題，或請你做決定。

你也可以透過 Slack 和 Teams 傳訊息給你的 dot，簡訊功能則即將推出。在 ChatGPT 開始一個專案，到 Slack 與團隊分享背景資訊，再讓你的 dot 接手後續工作。dot 能整合各個管道的資訊，無論你透過哪個管道聯絡，都能掌握完整脈絡。

主導權始終在你手中

dot 在 ChatGPT 原有的保護機制之外，也針對能執行的工作增設安全與隱私防護措施。你可以設定界線、追蹤進度，並參與需要你判斷的決策。

內建防護措施

每個 dot 都在自己的雲端電腦上工作。除非你選擇連接自己的電腦，否則你的電腦及內部資料都會與 dot 的雲端電腦保持隔離。登入支援的網站時，dot 可以使用已儲存的密碼，但不會讓模型取得密碼。

當你沒有直接與 dot 一起工作時，dot 會在背景尋找能幫上忙的事。我們稱之為「主動研究」。進行主動研究時，dot 會透過僅限讀取的工具使用你已連接的應用程式。這些工具無法傳送訊息，也無法變更應用程式內容或控制你的瀏覽器或電腦。

dot 內建的資安防護措施有助於抵禦惡意指令，並監控可能造成危害的行為。如果我們的監控系統偵測到安全疑慮，就可以暫停或停止 dot 的工作。

存取與權限

你可以選擇 dot 能存取哪些應用程式，並透過現有的 ChatGPT 應用程式控制項管理 dot 的權限。

Dot 備有內建規則，規範何時可自主行動、何時需要請求核准。透過「自訂規則」，你可以允許特定動作、要求事先核准，或禁止執行。內建安全要求在任何情況下皆適用。你可以在「活動檢視」中追蹤進度，包括背景工作，並視需要調整 Dot 的工作方向。

我們預設不會使用 ChatGPT Business、Enterprise 或 Edu 工作區的內容來改進模型。使用 ChatGPT 個人方案時，你可以決定是否允許將 dot 的對話與工作內容用於改進我們的模型⁠
(在新視窗中開啟)
。我們不會直接使用主動研究內容或 dot 寫給自己的筆記進行訓練。不過，如果這些資訊用於協助進行符合訓練使用條件的對話或任務，就可能依你的設定用於訓練。

dot 會透過自動審查⁠

為組織打造的專職 dot

你的 dot 代表你工作；專職 dot 則在組織內承擔特定職責。公司可為每個 dot 設定專屬身分、憑證，以及完成任務所需的系統存取權限。在工作過程中，dot 會根據新資訊調整做法，並透過團隊的回饋持續改進。我們正運用 OpenAI 內部早期測試所累積的經驗繼續開發；測試涵蓋採購、發票處理、電子郵件行銷、客戶支援及商業合約作業。

我們將先展開範圍明確的企業試行計劃。我們的工程團隊將直接與組織合作，明確訂定每個 Dot 的職責、可使用的工具，以及人員審閱和核准 Dot 工作的方式。如果你有想交給專職 Dot 處理的工作，我們很樂意聽聽你的想法。

將專職 dot 整合至 Microsoft Agent 365

我們也正與 Microsoft 合作，將專職 dot 與 Agent 365 中的企業治理和安全控制措施整合。目標是讓企業透過既有的 Microsoft 工具管理 dot。

開始使用 dot

即日起，dot 在 ChatGPT 中陸續向適用市場⁠
(在新視窗中開啟)
的 Pro 與 Business Premium 使用者推出。工作區管理員啟用後，Enterprise 使用者（包括 Edu 與醫療照護版）即可試用 Beta 版。

Pro 或 Business Premium 方案已包含你的第一個 dot，無須額外付費。dot 全天候都能與你交談、協助思考，並持續掌握你在意的事。你的方案也包含處理更深入工作的額度，並在推出後的第一個月提供更高的使用上限。未來，你將能新增更多 dot，也能提高每個 dot 的工作速度或每月可處理的總工作量，增加工作產出。

你與 dot 的對話不計入 ChatGPT 使用量上限。當你要求 dot 在 Codex 或 ChatGPT 工作中啟動或管理任務時，這些任務仍會照常計入使用量上限。

若要開始使用，請在 ChatGPT 桌面應用程式或電腦瀏覽器中建立你的第一個 dot，連接你的應用程式，再讓 dot 自我介紹。完成初始設定後，你就能在 ChatGPT 行動應用程式中傳訊息給 dot。

我們會從日常使用經驗中了解 Dot 怎樣才能更有幫助，並持續改進。也會盡可能分享學到的經驗，並用來決定接下來要開發什麼。
