OpenAI DevDay 2026 發表 AI 代理 dots 與 GPT-6.1 Sol：每個 dot 配一台雲端電腦，Sol 以低價逼近 Astra

Claire
  • 2026/09/30
  • OpenAI 、 AI 代理 、 GPT-6 Astra 、 Dots 、 ChatGPT Space 、 GPT-6.1 Sol
OpenAI 發表由 GPT-6 Astra 驅動的 AI 代理 dots，可主動接手並執行任務，同場推出團隊協作區 ChatGPT Space、價格僅 Astra 四分之一的 GPT-6.1 Sol，以及開放公測的 Agents API，從個人助理一路鋪到開發者的底層工具。

OpenAI 於美西時間 9 月 29 日在舊金山 Fort Mason 舉行年度開發者大會 DevDay 2026，執行長 Sam Altman 開場發表全天候運作的 AI 代理 dots。dots 由幾週前推出的 GPT-6 Astra 驅動，定位是不必逐步下指令、會主動接手工作的助手，Altman 表示即日起開放 ChatGPT Pro、Business Premium 與 Enterprise 用戶使用，費用含在既有方案內，與 dots 對話也不計入用量。同場 OpenAI 還推出團隊協作區 ChatGPT Space、價格只有 Astra 四分之一的 GPT-6.1 Sol，以及開放公測的 Agents API，從個人助理一路鋪到開發者的底層工具。

精選文章直送，點擊立刻訂閱 INSIDE 電子報！

每人配一台雲端電腦，串接 4,000 多個 App

dots 擁有自己的雲端電腦與瀏覽器，權限沿用使用者本身的存取範圍，可以自行寫程式、跑測試。Altman 舉的例子是讓它「在舊版 API 停用前把 App 遷移出去」，這類工作的難處在於 API 可能散落在整個程式碼庫，改了之後哪裡會出錯並不明顯，dots 會追出相依關係、找出所有需要修改的地方，寫好程式碼、跑完測試，再把 PR（pull request）交給團隊審查。

dots 可使用 ChatGPT 上 4,000 多個 App，並沿用使用者已連結的外掛。OpenAI 表示，之後也會開放用簡訊聯絡 dots，由它回報進度、提醒變動或請使用者拍板，也能直接打電話與它對話。目前每位使用者先配 1 個 dot，未來可依需求組成一整組，使用者可以設定 dots 能用哪些 App、能如何操作電腦，也能針對它執行的任何動作加上自訂指示。

工程師的 dots 每天修掉數十個 Bug

ChatGPT Space 是 OpenAI 這次為團隊協作打造的工作區，與 dots 同日開放給 Pro、Business Premium 與 Enterprise 用戶，桌面與網頁版先上線，行動版隨後推出。使用者、同事與各自的 dots 可以在同一個頁面裡寫企劃、做研究、產生圖表與試算表，或搭出可互動的原型，在留言中標註 dots 就能請它接手。Altman 指出，現有的生產力軟體幾乎都不是為人與 AI 一起工作而設計。官方並預告協作簡報即將推出，讓多名成員與代理同時編輯，並可匯出為 PowerPoint 或 Google 簡報。

OpenAI 產品團隊以虛構的音樂 App「Blossom」示範內部用法：dots 會在早上主動整理行程異動、測試用戶回饋與最新的設計修改，Slack 上被標註的零碎請求也可以直接轉給 dots 處理。產品團隊表示，OpenAI 工程師的 dots 會接手回報頻道裡的 Bug，調查後開出修正的 PR，每天修掉數十個 Bug。

企業端，OpenAI 同步預覽「專業 dots」（specialist dots），由企業設定、服務整個團隊，承擔會計、行銷、法務等工作，員工給的回饋會在全公司共享。Altman 在台上表示，OpenAI 也正與 Microsoft 合作，把專業 dots 整合進 Agent 365，讓企業用既有的 Microsoft 工具管理。

接近 Astra 的能力，價格只要四分之一

官方說明，GPT-6.1 Sol 的能力接近 Astra、在某些方面甚至更聰明，價格則明顯更低：Altman 在台上稱約為 Astra 的五分之一，官方頁面則寫標準輸入與輸出 token 價格為 Astra 的四分之一。Altman 表示，快取輸入比標準輸入便宜 95%，代理重複使用上下文、反覆修正與處理長任務都會便宜許多，並形容它會成為開發者的「日常主力」。

追求速度的用戶則有 Ultrafast，當天在 API、ChatGPT 與 Codex 同步上線。官方說明，Ultrafast 在 API 中速度最高可達標準版 Astra 的 6 倍，在 Codex 與 ChatGPT Work 中最高可達 8 倍。Altman 另在台上表示，Ultrafast 價格為標準版的 6 倍，每秒最多可生成 300 個 token，而原有的 Fast 則是 2 倍速、2 倍價。Ultrafast 目前搭配 Astra 使用，GPT-6.1 Sol 版本隨後推出。新的 Pro 500 方案（月費 500 美元）用量是 Plus 的 25 倍，可在 ChatGPT 與 Codex 使用 Ultrafast，並能透過 Sign in with ChatGPT 在合作夥伴 App 使用；先前因 Astra 需求暴增而暫停的 Pro 200 方案，也在當天重新開放訂閱，仍可使用全部 Frontier 模型，搭配 GPT-6.1 Sol 就能有接近 Astra 品質的日常主力。

Decisions API 則即日起限量開放預覽，官方表示預計未來幾天內全面推出。它讓 Luna 模型只從開發者預先設定的選項中作答，適用於請求分流、圖片分類、決定代理下一步動作等情境，回應時間不到 1 秒。OpenAI 後訓練研究負責人在台上指出，今年 1 月模型在需要一整天的研究任務上多半失敗，到了 7 月已能在無人介入下完成超過三分之一，模型也在持續運行的迴圈中優化電腦操作的 harness，讓延遲改善超過 2 倍。

雲端版 Codex 上線，代理 API 開放公測

Altman 宣布 Codex 全面上雲，使用者可以在手機上啟動任務，再到瀏覽器或桌機接續，闔上筆電也不會中斷執行。驅動 Codex、ChatGPT Work 與 dots 的 Codex harness 則是開放原始碼。同日上線的 Codex Security Cloud 會在雲端環境持續掃描漏洞，並準備經過驗證的修正供審查，新增自動去除重複項目、排程掃描與新介面等功能。

Agents API 開放公測，讓開發者以代管服務使用驅動 Codex 的任務執行框架，支援多代理、工具搜尋、工具呼叫與上下文壓縮，並新增電腦操作能力，讓代理可以自行開啟瀏覽器、點擊頁面、測試流程。OpenAI 與 AWS 合作推出 Bedrock Managed Agents，同樣建立在 Agents API 核心之上，結合 AWS 的客製與整合能力，運算資源由客戶自行掌控，企業可以在既有的應用與資料旁邊建置 OpenAI 代理。資料保護方面則預覽 OpenAI Private Intelligence：零資料保留（ZDR）搭配私有安全處理，內容完全不存放在 OpenAI 伺服器上，安全審查改以離線自動化進行；私有推論則結合機密運算與可驗證的控制機制，把保護延伸到推論當下。

Altman 也公布，Responses API 過去一年用量成長 100 倍，可靠度維持在 99% 以上，首個 token 的回應時間縮短 45%，工具呼叫與工作流程加快超過 30%。

從 dots 含在月費內、Sol 降價到 Ultrafast 另設高價方案，OpenAI 這次把產品線拉向兩端：一般用戶拿到會主動做事的代理，開發者拿到與 OpenAI 內部相同的 harness 與 API，兩邊都在加深對自家平台的依賴。OpenAI 在官方回顧中揭露，平台使用者總計達 12 億，dots 上線首日，每位 Pro、Business Premium 與 Enterprise 用戶先配 1 個。
