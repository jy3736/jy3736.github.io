Always-On Agents: Dots vs Grok Bot vs Muse
Berk Kalelioğluupdated on Sep 30, 2026See our ethical normsCite This Research
Always-on agents keep working after you close the app. Each one runs on a computer that keeps its files and memory, starts tasks on a schedule or when something happens, and messages you when it needs a decision. We compared five of them: OpenAI Dots, Grok Bot, Meta Muse, Hermes Agent and OpenClaw.

What are always-on AI agents used for?
You give an always-on agent a standing job instead of a one-off question. The examples vendors publish fall into four kinds of work:
Daily briefings: Hermes Agent’s tutorial builds a bot that researches chosen topics at 8:00 AM and sends a summary to Telegram or Discord.
Watching for changes: Meta’s example Muse read school emails and the district website, added key dates to a family calendar and flagged a sports tryout 12 hours before registration closed. OpenClaw’s docs show an inbox check every 30 minutes.
Personal tasks you approve first: a dot finds another time for a meeting that clashes with your child’s recital, or orders dinner on DoorDash once you approve the total.
Team work: a SpaceXAI sales bot updates the CRM from call transcripts and drafts follow-ups, and an ops bot processes invoices received in Gmail.
Feature comparison
Separate agents each keep their own instructions, memory and routines, so a team can give each one a role. Hermes Agent and OpenClaw also keep separate logins. Grok Bot’s bots share one computer and every login on it.
Hermes Agent, OpenClaw and Muse store memory as text files you can open and edit. Dots keeps memory on OpenAI’s side, and clearing it means deleting the dot. Cursor documents no way to view or edit Grok Bot’s memory.

Top always-on AI agents
OpenAI Dots
OpenAI announced dots at DevDay on September 29, 2026, and is rolling them out gradually. Each dot gets its own Linux computer and Chrome browser in OpenAI’s cloud, connects to over 4,000 apps through ChatGPT plugins, and can buy with a card saved on a merchant site after you approve.2
Each user gets one dot. OpenAI says users can add more later but hasn’t priced them.
Key features:
Scheduled tasks, plus follow-ups the dot schedules for itself.
Reads connected apps in the background with read-only tools.
Delegates coding tasks to Codex.
Takes voice calls.
Grok Bot
Grok Bot is SpaceXAI’s app of named AI agents, in beta since August 11, 2026. SpaceX acquired Cursor on August 14, and Cursor builds, hosts and bills the product. Each user gets one cloud computer in the US with a browser, terminal and files, shared by all of that user’s personal bots.3
Up to six bots can share a group chat and pass work to each other. Cursor picks the model for each task, and its documentation doesn’t name one.
Key features:
Team Bots, shared agents with their own Slack handle, in public beta on Teams and Enterprise plans since September 28, 2026.
Sign-in tokens for connected apps stay on Cursor’s servers, outside the bot’s computer.
A separate review model checks risky actions before they run.
Records up to 10 minutes of your screen and drafts a skill from it, a saved set of instructions the bot can reuse.
Meta Muse
Meta launched Muse on September 8, 2026, for adults in the US, and it has since reached Canada. Each user’s Muse runs on a dedicated cloud virtual machine and “keeps working after people close the app.”4 You talk to it in the Muse app, on the web or in WhatsApp.
Muse targets shopping and household errands. It pays with a single-use card from Stripe’s Link, and every purchase needs your approval with the exact details. Training on your data is on by default, with an opt-out.
Key features:
Recurring tasks run until you cancel them.
A separate agent approves every connector action and outbound request.
An activity log lists past and planned actions.
Hermes Agent (Bot Mode)
Hermes Agent is an open-source (MIT) agent from Nous Research, public since February 25, 2026, with 250,000+ GitHub stars on September 30.5
Bot Mode, on by default in the desktop app since August 31, turns Hermes profiles into named bots, each with its own model, memory, skills and routines.
Key features:
28 messaging adapters, including Telegram, Slack, WhatsApp, Signal, email and iMessage bridges.
Any of 45 listed model providers, or a local model through Ollama or vLLM.
Writes its own skills after multi-step tasks.
OpenClaw
OpenClaw is an open-source (MIT) personal agent with 390,000+ GitHub stars on September 30, 2026, the most of any agent here. The OpenClaw Foundation, a US non-profit announced on July 8, maintains it. Reuters reported that Meta modeled Muse on OpenClaw.6
A heartbeat wakes the agent every 30 minutes by default (hourly with Anthropic sign-in) to check for anything that needs attention. The project sells no hosting. Moonshot AI’s Kimi Claw sells a hosted OpenClaw that stays online.
In our experience, OpenClaw is hard to set up without prior server and configuration-file experience. Its configuration reference spans 12 pages, covering chat channels, agents, tools, the gateway, hooks, and secrets.7
Key features:
20+ chat apps, including WhatsApp, Telegram, Signal, iMessage and Teams, plus phone calls through Twilio.
Anthropic, OpenAI, Google, xAI, OpenRouter and many other model providers, or a local model.
Several agents per installation, each with its own workspace and logins.
We compare OpenClaw with Hermes, NanoBot, ZeroClaw and PicoClaw in OpenClaw alternatives.

Two questions decide most of it: who runs the computer, and who pays for the model.
Hosted agents: Dots, Grok Bot and Muse
The vendor runs the computer, so the agent keeps working when your laptop is closed, and model usage is part of the plan. If you already pay for ChatGPT Pro, a Cursor plan or SuperGrok, the agent comes at no extra charge. We picked Grok Bot for that reason: our SuperGrok plan already included it, and we ask it for a daily update on our projects.
Among the three, Dots ties one agent to ChatGPT, Codex and Slack. Grok Bot runs many role-based bots for a team and bills usage past the weekly allowance at token cost. Muse is a consumer app with a free tier that you can text on WhatsApp.
Self-hosted agents: Hermes Agent and OpenClaw
Both run wherever you install them. On a laptop, scheduled jobs pause while it sleeps and run once when it wakes. OpenClaw’s FAQ calls a dedicated host “not required, but recommended for reliability and isolation.”8 Hermes’s security guide advises a separate machine or VM “for maximum security.”9 OpenClaw’s own setup guide uses a 1 GB DigitalOcean server at about $6 a month, and Hermes Cloud costs about $17.
The model is billed separately and can cost more than the server. OpenClaw’s heartbeat runs a full agent turn every 30 minutes, and each turn can resend about 100,000 tokens of conversation history.10 That adds up to 4.8 million input tokens a day, about $19 at Anthropic’s list price for Claude Opus 5.5 ($4 per million).
OpenClaw’s isolated-session setting cuts each heartbeat to 2,000 to 5,000 tokens. Claude subscriptions have not covered OpenClaw since April 4, 2026, so Claude usage there is billed as extra usage or through an API key.11
In return, you pick the model, including a local one that runs on your own hardware, and you keep memory in files you control.
Hermes Agent or OpenClaw?
OpenClaw has the larger community: 390,000+ GitHub stars and a public skill registry. Hermes reached 250,000 stars seven months after its public release, and Nous runs a hosted version, Hermes Cloud. The New Stack puts the difference this way: “One prioritizes ecosystem reach, the other deep learning over time.”12
Each project imports the other’s setup (hermes claw migrate and openclaw onboard –import-from hermes), so switching later is cheap.
Background task agents
These tools run tasks you schedule or trigger in the cloud, so work continues even when your laptop is closed. Unlike Dots, Grok Bot and Muse, none is documented to keep a persistent computer for each user by default. Several of them operate a browser or desktop the way a person would; we explain how that works in computer use agents.
Gemini Spark (Google): tasks in the Gemini app on Google Cloud machines, on a schedule or an event such as a flight delay, up to 15 at once. Tasks that use your local Chrome browser need the device awake. From $19.99/mo.
Microsoft Copilot Cowork: Microsoft 365 tasks started by a schedule, an email or a Teams message. Each task runs in a temporary workspace that is deleted when it finishes. $30/user/mo Copilot license paid yearly, plus usage.
Claude (Anthropic): cloud Cowork sessions, scheduled tasks and Claude Code routines keep running with the laptop closed, except for steps that need local files or apps. From $20/mo.
Perplexity Computer: each task, or each Automation triggered by Slack, Gmail or GitHub, gets a fresh cloud machine. Pro $20/mo plus credits.
Manus: scheduled and triggered Automations on temporary machines; a Cloud Computer that stays on costs $30 or $50/mo extra.
