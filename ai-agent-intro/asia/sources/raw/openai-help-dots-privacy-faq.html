dot 隱私、資安與安全常見問題

了解 dot 可以存取哪些內容、如何使用與保護你的資訊，以及何時需要你的核准。

更新日期：3 天前

存取權與權限

我的 dot 可以使用我已在 ChatGPT、ChatGPT 工作或 Codex 中設定的外掛程式嗎？

可以。外掛程式權限會在 dot、ChatGPT、ChatGPT 工作和 Codex 之間共用。你的 dot 可以在你授予的權限範圍內使用現有連線。

你的 dot 具備完善的預設設定，明確規範哪些動作每次都需要你核准、哪些可以事先核准，以及哪些無須詢問即可執行。詳情請參閱「動作、核准與控制」一節。

我要在哪裡授予新權限或管理現有權限？

你可以在 ChatGPT 的「外掛程式」分頁中連接新的外掛程式，並管理現有外掛程式。這些連線會在 dot、ChatGPT、ChatGPT 工作和 Codex 之間共用。

你也可以為 dot 設定獨立的 Slack 帳號，讓它在這類服務中擁有自己的身分和存取權。即使你的 dot 有自己的電子郵件或 Slack 帳號，它仍然可以使用你已連接至 ChatGPT 的外掛程式。

我要如何控制 dot 能透過外掛程式讀取或變更哪些內容？

你可以在 ChatGPT 的「外掛程式」分頁中管理各個外掛程式的存取權。你的 dot 會遵循完善的預設設定，判斷何時需要先取得你的核准，才能透過外掛程式執行動作。

「自訂規則」可讓你為 dot 設定額外限制，例如要求 dot 絕不傳送電子郵件。這些規則無法凌駕某些內建防護機制與安全要求。

你的 dot 也可以在你提出要求之前，先尋找有用的最新資訊。這稱為「主動研究」。它可以從獲准存取的已連接來源讀取資訊，並儲存私人筆記，但其研究工具無法直接：

  • 傳送訊息給其他人。

  • 透過外掛程式變更內容。

  • 控制瀏覽器或電腦。

任何後續動作都必須遵循一般的動作規則與安全檢查。你已授權並持續在背景執行的任務，也適用同樣的規則。

我的 dot 可以存取我的相機、麥克風或螢幕嗎？

你必須先將電腦連接至 dot，dot 才能存取電腦的相機、麥克風或螢幕。你也必須在裝置設定中，授予 ChatGPT 應用程式存取相機、麥克風或螢幕的權限。 

未滿 18 歲的使用者可以使用 dot 嗎？

不可以。dot 目前尚未開放給未滿 18 歲的使用者。

資料使用、記憶與隱私

我的 dot 會與 ChatGPT 共用記憶嗎？

會。你的 dot 可以接收 ChatGPT 的記憶和近期對話脈絡，而你與 dot 的對話也可以成為 ChatGPT 記憶的一部分。設定完成後，ChatGPT 和你的 dot 可以繼續共用記憶。 

關閉 ChatGPT 的「記憶」功能，即可停止共用。這不會刪除你的 dot 已接收的資訊。

我的 dot 會保留哪些資訊？這些資訊如何受到保護？

只要你保留 dot，它就可以持續保留來自對話與外掛程式的脈絡資訊。你可以透過刪除 dot，刪除它的脈絡資訊。dot 已分享至 ChatGPT 記憶的任何資訊，都可以在 ChatGPT 的記憶設定中另行管理。 

dot 的脈絡資訊不會保留憑證、圖片或螢幕截圖。dot 在其他位置建立或使用的檔案，例如 ChatGPT 資料庫、你的電腦或已連接的儲存服務，會遵循該位置的保留政策。

OpenAI 會加密你的內容，不論是在儲存期間，或是在你、OpenAI 與我們的服務供應商之間傳輸時。

我可以查看、更正或刪除 dot 記住的關於我的資訊嗎？

你可以透過刪除 dot，刪除它的脈絡資訊。目前你無法查看、刪除或直接修改 dot 的個別記憶，包括透過外掛程式納入 dot 脈絡的特定資訊。

如果我中斷透過外掛程式連接的服務，我的資訊會如何處理？

這會停止透過該連線進行新的存取。這不會刪除 dot 已納入其脈絡的資訊。

如果我刪除 dot，我的資訊會如何處理？

  • 刪除 dot：這會刪除 dot 本身的脈絡資訊。

  • 檔案與對話：dot 建立的檔案、Codex 討論串和 ChatGPT 對話會分開儲存。刪除 dot 並不會刪除這些內容。

  • ChatGPT 記憶：來自你其他 ChatGPT 對話的記憶會繼續保留。你可以透過 ChatGPT 的記憶控制項管理這些記憶。

如果我已關閉模型改進功能，OpenAI 相關人員仍可審查我的 dot 活動嗎？

可以。即使已關閉模型改進功能，在少數情況下，仍可能進行人工審查，包括涉及安全的情況。

OpenAI 會使用我的 dot 資訊來改進模型嗎？我要如何退出？

對於 ChatGPT Business、Enterprise 和 Edu 工作區，我們預設不會使用你的資料來訓練模型。對於 ChatGPT 個人方案，「為所有人改進模型」設定會決定你的 dot 對話與工作內容是否可用於改進我們的模型。這可能包括 dot 執行的動作、委派給其他代理的工作、你設定的自動化流程，以及來自已連接應用程式、用於為對話提供參考的資料。在使用符合條件的資料之前，我們會採取措施，盡可能移除可識別個人身分的資訊。

我們不會直接使用背景主動研究或其筆記來訓練模型。如果 dot 將這類研究的資訊帶入符合條件的對話或任務，這些資訊可能會依你的設定用於訓練。你可以在 ChatGPT 設定中關閉「為所有人改進模型」。如要進一步了解你的資料如何使用，請參閱這篇文章。

我要如何要求存取、更正或刪除我的個人資訊？

即使你沒有 OpenAI 帳號，也可以透過 OpenAI 的隱私權入口網站提交要求，或寄信至 dsar@openai.com。

依你的居住地而定，你可能有權存取、更正、刪除個人資料，或取得個人資料副本。我們可能會要求你提供資訊，以驗證你的身分。詳情請參閱我們的隱私權政策。

OpenAI 如何運用服務供應商？

OpenAI 透過服務供應商協助營運服務，包括託管、雲端基礎架構、支援、安全及電子郵件傳送。這些供應商可能會依 OpenAI 的指示，存取、處理或儲存個人資訊，以提供上述服務。

如需更多資訊，請參閱我們的隱私權政策。代表企業客戶處理的資訊，其處理方式受適用的客戶協議規範。

動作、核准與控制

哪些動作需要我核准或接手？

如果你要求 dot 執行敏感動作，它可能會向你確認是否明確核准（某些情況下可事先核准），或要求你接手並自行完成該動作。你的 dot 已收到指示，須遵循以下政策：

  • 變更密碼或轉帳等最敏感的動作，需要由你接手並自行完成

  • 永久刪除資料或安裝軟體等其他動作，可能在每次要求 dot 執行時都需要核准

  • 某些情況下，例如定期傳送訊息，你可以事先核准，不必每次都核准

dot 會根據你的指示，了解何時以及如何代表你採取行動。明確說明你核准的內容，有助於釐清這些界線。對於日後要傳送的訊息，請註明收件人、訊息內容，以及傳送時間或條件。核准一則訊息，並不代表你授予 dot 持續代表你聯絡他人的權限。任何事先核准都僅限於你授權的範圍。dot 仍可能犯錯，因此請務必檢查會造成重要影響的工作。

我可以透過「自訂規則」允許或封鎖哪些動作？哪些核准要求或安全檢查無法覆寫？

你的 dot 具備完善的預設設定，明確規範哪些動作需要在執行時確認、哪些可事先核准，以及哪些無須確認。「自訂規則」可讓你調整這些設定，告訴 dot 在支援的動作中，哪些可以獨立執行、哪些需要你的核准，以及哪些不應執行。你可以前往設定，查看你的「自訂規則」。自訂規則無法關閉核心安全要求，例如 dot 要求你接手以變更密碼的規定。自訂規則也無法變更獨立的安全審查系統「自動審查」，或主動研究的限制。

我要如何檢視並引導 dot 的活動？

桌面應用程式中的「活動檢視」會顯示 dot 正在執行及已委派的任務。你可以查看任務說明與狀態，掌握進度。你也可以檢視 dot 已執行的步驟。

你可以補充脈絡、更正誤解、調整方向，或要求 dot 停止。

我可以讓 dot 停止、修正給它的指示，或復原它已執行的動作嗎？

dot 工作時，你可以提供更新的指引、調整方向，或要求它停止。

已完成的動作能否復原，取決於該動作及涉及的應用程式。你可以要求 dot 協助修正錯誤，但有些動作無法復原。

如果 dot 犯錯、意外分享資訊，或執行了不符合我本意的動作，我該怎麼辦？

你的 dot 可能會犯錯。如果你發現錯誤，可以要求 dot 修正問題，它或許能夠復原相關動作。例如，dot 或許能復原非預期的文件編輯，或收回電子郵件。如果你想回報錯誤，請造訪我們的 dot 支援頁面，取得更多指引。

安全性與內建防護機制

使用 dot 時，我可以如何協助保護帳號安全？

多重要素驗證（MFA）會在你登入 ChatGPT 帳號時增加一道驗證步驟，提供額外保護，防範網路釣魚與未經授權的存取。你可以在「設定」→「安全性與登入」中開啟。了解如何設定 MFA。

有哪些安全檢查，有助於防止 dot 分享私人資訊或超出我授予的權限行事？

你的 dot 採用多層防護：

  • 模型防護機制：GPT-6 Astra 經過訓練，會拒絕有害要求，包括涉及生物或網路安全濫用的要求。

  • 外掛程式權限會限制它能存取的內容。

  • 自訂規則可讓你為支援的動作設定額外限制。

  • 自動審查會在某些規劃中的動作執行前，檢查是否符合你的指示、自訂規則與安全要求。

  • 安全監控會在 dot 工作時偵測可能有害的行為。

例如，在 dot 傳送電子郵件前，「自動審查」會檢查收件人與訊息內容，協助找出錯誤的地址或你無意分享的資訊。

如果「自動審查」封鎖了動作，而釐清指示或取得核准能解除封鎖，dot 可能會向你詢問；它也可能嘗試獲准的替代方案，或停止執行。你的核准無法凌駕核心安全要求。

當 dot 委派工作或繼續在背景執行工作時，動作規則同樣適用。主動研究另有額外限制：其工具無法直接傳送訊息給其他人、透過外掛程式變更內容，或控制瀏覽器或電腦。

你的 dot 無法關閉必要的自動審查檢查，也無法移除上述研究限制。這些防護機制有助於降低風險，但你的 dot 仍可能犯錯。

如要了解如何自訂自動審查政策，請參閱自動審查設定。

我的 dot 如何防範提示注入、網路釣魚與惡意指示？

網站、電子郵件或文件可能包含指示，試圖誘使 dot 執行你未要求的動作，例如分享私人資訊。這稱為提示注入。

你的 dot 在設計上會區分你的指示與工作過程中接觸到的內容。這些內容本身並不構成授權。

額外防護包括限制工具可執行的操作、在某些動作執行前自動檢查、要求核准，以及安全監控。我們也透過人工與自動化測試找出弱點，並改進這些防護機制。

這些防護有助於降低惡意指示導致非預期動作的風險，但無法完全消除風險。

密碼、驗證與付款

我的 dot 如何處理密碼？

對於支援的登入方式，dot 會暫停，讓你在安全的登入表單中輸入憑證。表單會將你的憑證直接傳送至瀏覽器環境，不會向模型揭露。接著，dot 就能使用已登入的工作階段繼續操作。

這些防護適用於支援的登入流程。你另外在聊天或文件中，或透過外掛程式分享的密碼，不在這些防護的涵蓋範圍內。

我的 dot 可以代我完成登入與安全檢查嗎？

你可能需要提供驗證碼，或接手完成安全檢查。 

使用儲存在商家網站上的付款卡購物

你的 dot 也可以使用你儲存在商家網站上的付款卡購物。這些購買交易需要你的核准；若事先核准明確涵蓋該筆交易，也可事先給予核准。
