dot 入門指南

瞭解如何在 ChatGPT 中設定你的 dot、連結應用程式，以及管理任務和控制設定。

更新日期：昨天
概覽

你的 dot 是 ChatGPT 中持續運作的智慧體，能協助你將專案從構想化為可用的成果。只要給它一個目標、提供背景資訊，它就能在對話之間持續推進工作。

透過自己的電腦和你連結的應用程式，你的 dot 能進行研究、創作，並將任務執行到底。它會先運用 ChatGPT 記憶中的背景資訊，逐步了解你偏好的工作方式。你可以決定它能自行處理哪些事、檢視它的成果，並在過程中提供意見或調整方向。你隨時都能暫停它。

我的 dot 能幫上什麼忙？

從一個你希望有人協助完成的專案開始：

準備簡報。彙整資料與客戶意見、調查有哪些變化，並隨著新資訊陸續到位更新簡報。

創作內容。將訪談逐字稿轉為節目摘要與社群貼文，再將你的修改同步套用到各份草稿。

改善應用程式。界定修改範圍、撰寫程式碼並進行測試，讓你能檢視可正常運作的修改成果。

哪些方案包含 dot？

dot 今天起在 ChatGPT 中逐步向 Pro 使用者推出，適用市場不包括歐洲經濟區、瑞士和英國。所有 ChatGPT 支援地區的 Business Premium 使用者也能使用 dot。Enterprise 使用者（包括 Edu 和 Healthcare）可在工作區管理員啟用後試用測試版，但此功能最初預設為關閉。

你的 Pro 或 Business Premium 方案已包含第一個 dot，無需額外付費。它全天候都能與你對話、協助你思考，並持續關注你重視的事。你的方案也包含用於更深入工作的額度，推出後的第一個月還會提高額度上限。未來，你將能新增更多 dot，並透過提高速度或增加每月可承擔的工作總量，提升各個 dot 的產出。

dot 正在逐步推出。你的帳號可能需要幾天後才會取得使用權限。

開始使用
如何設定我的 dot？

在 ChatGPT 桌面應用程式或電腦版 ChatGPT 網頁中建立你的 dot。依照初始設定指引即可開始使用。桌面應用程式也支援 Windows。

建立 dot 後，待行動裝置使用權限開放，你就可以在 ChatGPT 行動應用程式中與它對話。目前無法在行動裝置上建立 dot，行動網頁版也不支援 dot。

請使用電腦連結 Slack 或簡訊等通訊管道。

你可以在設定時為 dot 命名。它的預設帳號代稱為 @yourname-dot。命名後，它的帳號代稱會變成 @yourname-agentname。若之後想變更名稱或頭像，請選取它的名稱或頭像以開啟個人檔案，然後選取鉛筆圖示。

你可以從現有角色中挑選，或為 dot 選擇一隻寵物。你的 dot 也可能為你生成一隻寵物。

與你的 dot 協作
我的 dot 與一般 ChatGPT 對話有何不同？

你的 dot 是 ChatGPT 中持續運作的智慧體，能長期負責你交付的工作，並在對話之間持續推進。它由 GPT-6 Astra 驅動，擁有自己的雲端電腦，能跨你選擇連結的應用程式執行工作，並記住相關脈絡，協助處理持續進行的工作。

為你的 dot 設定目標，並界定它能自行執行哪些操作。它能處理複雜問題、判斷下一步該做什麼，並將結果交給你檢視。遇到需要你判斷的決策時，它會請你決定。

如何交付任務給我的 dot？

描述你希望 dot 做什麼，並提供它需要的詳細資訊。例如，你可以請它查看你的行事曆、研究某個主題，或稍後提醒你某件事。你可以在對話中回覆，提供更多資訊或變更要求。

若要附加檔案或照片，請在對話中選取 +。

在桌面應用程式中開啟 dot 的個人檔案，即可在進行中、已排程和已完成下查看活動。你也可以從個人檔案開啟 dot 的電腦，查看並操作它。在行動裝置上開啟電腦時，控制權會交給你。

我的 dot 可以使用我自己的電腦嗎？

你的 dot 擁有自己的雲端電腦。你可以自行選擇是否開放存取本機電腦，此功能最初為關閉狀態。若要連結電腦，請使用該電腦上的 ChatGPT 桌面應用程式。在本機電腦上執行的工作會以獨立任務進行，並顯示在側邊欄。

連結電腦並確認「允許存取」後，你就能透過 dot 的任何通訊管道，讓它存取該電腦上的檔案並執行工作。確認「撤銷存取權」，即可停止 dot 存取該電腦上的檔案或執行工作。

啟用本機電腦存取權後，dot 就能建立「工作」或 Codex 任務、使用本機技能，並在雲端瀏覽器遭封鎖時使用你的本機瀏覽器。

我的 dot 可以使用 Codex 雲端環境嗎？

你的 dot 可以在 Codex 雲端環境中建立雲端任務。請先在 Codex 中建立環境，再請 dot 使用。

已連結的應用程式
如何連結及管理應用程式？

已連結的應用程式可讓 dot 取得執行任務所需的資訊。即使你沒有針對這些資訊提出具體問題，dot 也能主動查看，並據此建立記憶。

若要在行動裝置上查看或連結應用程式，請開啟 dot 的個人檔案，然後前往自訂 → 外掛程式。選取支援的應用程式，並在連結前檢視其權限。「外掛程式」畫面使用共用的 ChatGPT 設定。可用的應用程式可能有所不同。

你可以中斷已連結應用程式的連線。中斷應用程式的連線，不會刪除 dot 已從中取得的資訊。若要刪除這些資訊，你需要刪除該 dot。請參閱〈如何重設我的 dot？〉（見下文）。

我可以將 dot 連結至 Slack 或電子郵件嗎？

你可以將 dot 連結至 Slack。請在電腦上設定通訊管道。

你可以連結個人電子郵件帳號，讓 dot 使用該帳號執行你的任務。推出初期，你還無法為 dot 設定專屬的獨立電子郵件地址。

我的 dot 可以打電話給我嗎？

推出初期，dot 無法主動打電話給你。

排程任務
如何排定任務並接收最新消息？

請你的 dot 設定提醒或定期執行檢查。例如，你可以請它每天早上查看你的行事曆，告訴你接下來有哪些行程。

排程任務的執行結果和主動提供的最新消息會顯示在對話中。若要管理排程任務，請在 dot 個人資料中的「最近活動」選取該任務，或開啟 ChatGPT 中的「已排程」區塊。你可以查看進行中、已暫停和已完成的任務。開啟任務即可變更重複執行的頻率、時間或完成通知。

在什麼情況下，dot 不需要我傳送新訊息就能開始工作？

你的 dot 可以在背景進行研究，並建議能如何提供協助。即使你沒有提出新問題，它也能主動查看已連結的資訊，並據此建立記憶。它可以執行你排定的提醒或週期性任務。你可以在 dot 的個人檔案中查看已排程的工作，或在不希望它繼續時暫停 dot。

簡訊
如何傳簡訊給我的 dot？

在開放使用的地區，簡訊功能由第三方供應商提供，並以有限測試版形式推出。透過簡訊分享敏感資訊時，請務必謹慎。

此測試版僅限美國的 Pro 使用者使用，不適用於 Business 或 Enterprise 工作區。使用名額有限，並非所有 Pro 使用者都能使用。

如果你的帳號已開放簡訊功能，就可以使用桌面應用程式連結手機，並依照提示完成設定。設定完成後，你就可以用手機傳訊息給 dot。

如何停止接收 dot 的簡訊？

回覆 STOP，即可讓 dot 停止傳送簡訊。若要刪除 dot 的對話和已儲存的記憶，請依照下文說明使用「重設」功能。

會產生簡訊或數據費用嗎？

可能會產生簡訊和數據費用。啟用簡訊功能時，請閱讀相關通知，以及 OpenAI 的使用條款和隱私權政策。

記憶
我的 dot 如何使用記憶？

你的 dot 會接收 ChatGPT 的記憶，也能建立自己的記憶，包括根據已連結應用程式中的資訊建立記憶。這讓它能在持續進行的工作中運用相關脈絡。

在行動裝置上，自訂 → 記憶會顯示 ChatGPT 記住的內容。這個畫面使用共用的 ChatGPT 記憶設定。

若要刪除 dot 自己儲存的記憶，你需要刪除該 dot。請參閱〈如何重設我的 dot？〉（見下文）。

控制設定與核准
如何管理確認要求和自訂規則？

對於某些操作，你可以設定規則，決定 dot 能分享、購買或存取哪些內容。

在行動裝置上，開啟自訂 → 自訂規則，即可查看預設規則或新增規則。描述規則適用的操作，然後選擇以下其中一種執行方式：

直接執行，不需詢問

事先核准後即可執行

執行前先詢問

交由你處理

「事先核准」表示你已在提示詞中明確要求執行該操作。選取勾號以儲存規則，然後到自訂規則中查看。

你的 dot 可能會出錯，包括在遵循你設定的規則時。在採用結果前，請檢視它完成的工作，並核對重要細節。

如何暫停我的 dot？

若要讓 dot 停止運作，直到你準備好恢復，請在它的個人檔案中開啟 ••• 選單，然後選取暫停。若要讓它重新開始運作，請選取已暫停 • 輕觸以恢復。

如何重設我的 dot？

重設會刪除你的 dot，包括它的對話、已儲存的記憶和排程任務。確認前，請先閱讀刪除通知。

開啟 dot 的個人檔案，並選取 ••• 選單。

選取重設。

檢視即將刪除的內容，然後選取重設以確認，或選取取消以保留你的 dot。

重設後，你會回到新的 ChatGPT 對話。你可以在 ChatGPT 桌面應用程式或電腦版網頁中建立新的 dot。
