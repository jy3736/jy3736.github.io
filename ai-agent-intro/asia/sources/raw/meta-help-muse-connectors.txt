Muse 如何與連接器搭配運作
已更新：
4週前

你可以選擇將 Muse 連結到 Meta 或第三方提供的應用程式和服務。我們將這些應用程式和服務稱為連接器。設定連接器後，Muse 便會獲得新功能，例如查看行事曆或撰寫電子郵件。

若要連結連接器

你可以透過要求 Muse（例如：「Connect my Gmail」（連結我的 Gmail））或按照以下步驟來連結連接器：

前往設定，然後點按連接器。
點按所需連接器旁的連結，並閱讀資訊。
點按繼續以授權連線。
按照任何其他登入或授權步驟操作。

連結後，Muse 將與你所指派任務的相關連接器交換資訊。連接器有自已的使用條款和隱私政策，會說明它們如何使用所接收的資訊。

Muse 與連接器的資料交換機制經過精心設計，僅會交換為提供你服務所需的資料。舉例來說，連結電子郵件帳號後，Muse 便可搜尋你的電子郵件，但不會下載整個收件匣（除非你提出要求）。部分連接器也可主動與 Muse 分享資訊。舉例來說，行事曆連接器可以在你的行程異動時自動更新 Muse。我們會在你連結之前，先找出有此功能的連接器。

若要取消連結連接器

你隨時可以在設定中，於連接器下方取消連結連接器。取消連結後，Muse 會停止與連接器交換資料。Muse 先前用於透過該連接器執行任務的資訊可能仍會保留在 Muse 的記憶和你的對話紀錄中。

注意：你也可以要求 Muse 忘記互動。

核可連接器動作

根據預設，Muse 不會在未經你核可的情況下採取諸多重要動作，例如寄送電子郵件。許多連接器也可以進行設定，讓 Muse 只能擷取資料，而無法採取動作（例如傳送行事曆邀請）。你可以在「設定」中變更 Muse 要求你核可的時機。深入瞭解如何設定核可功能。

Meta 連接器

部分連接器會連結至 Meta 產品。如果你的帳號位於相同的帳號管理中心，系統會自動連結 Facebook、Instagram 和 Threads 這三個平台。你無須採取任何行動來設定。你隨時可以在帳號管理中心管理帳號。請參閱《Muse 隱私政策》，深入瞭解我們使用各帳號資訊的方式和時機。

自訂連接器

如果你要連結的服務尚未列於連接器清單中，你可以要求 Muse 建立自訂連接器。Muse 將會引導你完成整個流程，包括從服務擷取 API 資訊。Muse 會將這些資訊儲存在其安全憑證儲存庫中。Meta 不會檢閱自訂連接器或自訂連接器如何使用你的資訊，因此請謹慎授予存取權限，並檢閱供應商的隱私政策。

注意：
完成設定之後，你可以在裝置設定中管理 Muse 對 Apple 健康或 Android 簡訊等連接器的存取權限。
連結 Google 後，使用由 Workspace API 接收之資訊的行為將須遵守《Google 使用者資料政策》，包括限制使用要求。
