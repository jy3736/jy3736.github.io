模組 05｜從來源到教案，再讓教材上線 · 深度導讀

台灣華語單人導讀 · 14 分 13 秒 · 對應目前講義與練習單。可邊聽邊閱讀，操作時先暫停。

開場白

各位學員，大家好，歡迎收聽模組五，從來源到教案，再讓教材上線。這一模組要做的事很像備課：先把資料找齊，整理成學生看得懂的教案，自己核對過，再放到學生能看到的地方。不同的是，整理和上傳的動作，可以交給 A I Agent 來做；判斷內容對不對、適不適合學生，仍然是您的工作。

01第 01 節：先看完整示範路線

第一節先看整條路線。講義把它畫成七站：連接工具、讀固定來源、產生教案、放進 Notion、把同一份內容轉成網頁、發布到 GitHub Pages，最後換成自己的教材再做一次。一句話說，就是一份教案，兩個目的地。Notion 是線上文件，GitHub Pages 是一個公開網站。

示範題材是 Grok Bot、Meta Muse 和 Open A I Dots 三款新的 A I 工具。它們只是教案要介紹的內容，您不必註冊或購買。真正要操作的是 Codex、Notion 和 GitHub。

讀講義時，每一步都有四樣東西：說明、可以複製的提示、摺起來的可能回覆，以及完成檢核。可能回覆只是示例，不是您帳號裡發生的事。畫面截圖也分三種：實際的插件目錄、先前已經存在的遠端成果，以及這次在本機產生的範例。它們都不代表本頁每個提示已經替您執行過。提示裡的方括號，請換成自己的資料。

02第 02 節：工具準備：把 Notion 連進 Codex

第二節先接好工具。這裡有三件事要分開確認：有帳號、有連線、能找到目的地。

插件，就是把 Notion 的工具帶進 A I Agent 的現成套件。講義會提到 M C P，可以把它想成 Agent 使用外部工具的接頭；它不是您的 Notion 帳號本身，您也不需要自己架設任何東西。

步驟是：在 Codex 打開插件入口，畫面上可能寫 Plugins；搜尋 Notion，確認開發者是 Notion AI，再按安裝；接著按連接，由您本人登入原本的 Notion 帳號，選擇工作空間和頁面，看清楚它要求的存取範圍再同意。請不要把密碼貼進對話。

然後用提示一。這個提示只做檢查：確認目前連接的是哪個 Notion 使用者，並讀取您提供的父頁。父頁，就是新教案要放在底下的那一頁。這一步不建立、也不發布任何教材。

怎麼判斷完成？插件出現在清單上，不等於帳號已經連好；要看 Agent 回報的使用者和工作空間是不是您本人。它也要說出父頁的名稱。如果讀不到父頁，先解決連線，不要讓它上傳到自己猜的位置。

03第 03 節：指定 sources，產生學生教案

第三節開始做教案。重點是「指定來源」：A I 只能根據我們給它的資料寫，不能自己上網補。講義已經準備好一組固定資料，放在講義網站的來源資料夾，裡面有一份來源清單，還有官方頁面與媒體報導的存檔。大家用同一份資料，成果才能互相比較。

教案要有三款工具各自的簡介、一張比較表、臺灣目前的使用狀況、一個短練習和逐項來源。這是給學生讀的教案。每個說法要標成三種之一：官方確認、來源推論，或待確認。請使用提示二的複製按鈕。它會把教案存成一個 Markdown 文字檔和一份來源對照，放在專案的示範輸出資料夾，而且先不寫入 Notion 或 GitHub。

我們用一個例子，看看核對時會遇到什麼。假設 A I 交出的比較表寫著：Grok Bot 可以在 macOS、Windows 和 Linux 使用；Meta Muse 在美國和加拿大開放，免費，也有二十美元和一百美元的方案。看起來很完整，對吧？

但這兩句其實來自遠見雜誌的報導，不是官方說法。回到來源清單會看到：Grok Bot 官方的常見問題只寫桌面版 macOS 或 Windows，再加上 iOS，沒有提到 Linux。Muse 的官方頁面只說免費但有用量上限，可以升級付費，沒有寫金額，也沒有寫開放地區。所以正確的寫法是：Grok Bot 依官方列出三個平台，Linux 只是媒體說法；Muse 的地區和價格標成待確認，並列出媒體與官方的差異。不猜數字。

Open A I Dots 又是另一種情況。官方列出幾個排除地區，臺灣不在其中。可以寫成來源推論：臺灣不在排除名單上；但不能寫成每個帳號都已經開通。

檢核有三點：三款工具的名稱和簡介都在，說法能回到指定來源；臺灣段落有資料日期，推論和待確認分開標示；還有，您自己找到並打開了那個 Markdown 檔，而不是只看 A I 的回覆。

04第 04 節：把核對後的教案上傳到 Notion

第四節把教案放進 Notion。順序很重要：先核對，才上傳。這一步用的是上一節那份已經核對的檔案，不要請 A I 重新產生一份新的比較結果，否則您核對過的內容就白費了。

提示三請 Agent 先確認帳號和父頁，再把內容轉成 Notion 本身的標題、段落、列表和表格。它也會設定頁面圖示和封面。圖示是標題旁邊的小圖，從工作坊吉祥物的圖片中挑選；封面是頁面頂端的橫幅，優先用 Notion 內建的 Unsplash 選圖，並記下來源。如果工具設定不了圖示，就請它回報缺項，不要把圖片塞進正文假裝是圖示。

這一頁先保持私人。建立後，請 Agent 讀回內容，再自己開啟頁面看一次。如果畫面上還是舊圖，先重新整理再判斷。如果建立的時候逾時，要先查查是不是已經建好，避免出現兩份重複頁面。

接著是提示四，讓預定的學生能讀。目標是指定學生閱讀，不是公開到整個網路。分享設定由您在 Notion 的分享選單完成，閱讀者名單由您提供。這裡有一個很容易混淆的地方：頁面連結存在，不等於學生打得開。要用學生的身分實際開一次入口、子頁和來源連結；還沒測，就記「待測」。

05第 05 節：同一份教案，再發布到 GitHub Pages

第五節換目的地，不換內容。Notion 是線上文件，GitHub Pages 是靜態網頁，也就是一組放在網路上、大家都能打開的網頁檔案。

先用提示五，把同一份 Markdown 轉成一個網頁檔，存在示範輸出資料夾的網站資料夾裡。只改呈現方式，不重寫事實、比較、日期和來源。然後打開本機預覽核對：內容和 Markdown 一致，來源連結打得開，用手機寬度看，整頁不會左右滑動。這一步不推送、不部署。請記得，本機預覽看起來很好，還不是上線。

再用提示六發布。Agent 先確認您的 GitHub 身分，以及您有沒有權限寫入目標儲存庫。儲存庫，可以想成 GitHub 上放這個網站檔案的專案資料夾。如果還沒登入，由您本人完成官方授權，不要貼密碼或權杖。只發布這個網站資料夾，不要把原始研究存檔、私人資料一起放上去。如果 Agent 無法自己設定 Pages，它應該告訴您在設定頁面的 Pages 項目怎麼操作。

完成的判斷是：建置成功之後，用沒有登入的瀏覽器視窗，打開真正的網址，核對標題、三款工具、比較表、臺灣的待確認和來源。只看到推送成功，或只看到本機檔案，都不算上線。

講義也提醒：免費的 GitHub 帳號，Pages 通常使用公開儲存庫，所以只發布可以公開的示範內容。也不要照抄講師的帳號、儲存庫或網址，那些是講師的目的地，不是您的。

06第 06 節：換成自己的資料，完成兩個目的地

第六節換成您自己的教材。動手前先決定四件事：學生對象、題目、確切來源，以及哪些內容可以公開。來源可以是有權使用的課程教材、課本節錄、參考文件，或深度研究的結果。課本只能用有權分享的部分，不要整本公開上傳。學生或課程的個人資料，先移除。

把資料放進工作空間裡、講義指定的來源資料夾，資料夾名稱請看講義第六節；提示就是讀這裡，放在別處，就改提示裡的路徑。這一節有三段提示，順序和示範一樣：先產生草稿，再上傳 Notion，最後轉網頁發布到 Pages，並寫一份交付清單。和示範不同的是兩個標記：來源沒有說明的，標待確認；您新增的教學活動，標教學改編。深度研究引用不足的地方，也要明列，不當作已經查證。

預期成果是五樣：一份本機教案、一份來源紀錄、一個 Notion 連結、一個 Pages 公開網址，以及一份能指出完成和缺項的交付清單。完成檢核有四點：讀過自己的草稿；自己開過 Notion 並確認學生的存取狀態；自己開過 Pages 真正網址，比較兩邊的標題、重點、日期與引用；最後確認沒有公開原始課本、個資或未授權素材，交付紀錄裡也沒有密碼。

同步練習單把這些整理成五個核對項目：Notion 連線、自己的來源與教案、上傳 Notion、學生閱讀權限、同內容發布到 Pages。有缺項，就寫待完成。

07第 07 節：最後驗收：看到成果，也查得到依據

第七節是最後驗收。Agent 可以完成很多動作，但教材適不適合學生，由您判斷。驗收的順序是：先找檔案，再看頁面，最後用閱讀者的身分走一次。

講義列出四項要留下的證據。來源與教案：確切來源、日期、Markdown 檔和未確認事項。Notion：真實頁面連結、父頁、讀回的內容、圖示封面和閱讀權限。GitHub Pages：自己的儲存庫、發布資料夾、建置成功和真正網址。最後是兩邊一致：重要內容、日期和來源相同，只是呈現格式不同。

請記得，講義裡的可能回覆不是執行證據，舊成果的截圖也不是這次的新發布。講義的依據整理在二〇二六年十月十一日；三款工具在臺灣能不能用，並沒有用實際帳號測過，這也是教案裡要保留待確認的原因。

聽後自測

第一題，A I 回覆說已經上傳到 Notion，還附了連結，這樣算完成了嗎？請先暫停想一想。還不算。要自己打開頁面，核對內容、父頁、圖示和封面。而且私人頁面的連結，不代表學生打得開；沒有用學生身分測過，就記待測。

第二題，本機預覽的網頁看起來很漂亮，可以告訴學生網站已經上線嗎？請暫停。不可以。本機檔案只有您自己的電腦看得到。要推送到自己的儲存庫、等建置成功，再用沒有登入的視窗打開真正網址，才算上線。

第三題，來源沒有提到 Meta Muse 在臺灣是否開放，教案可以寫成臺灣不能用嗎？請暫停。不可以。來源沒說，就標待確認。寫成可以用或不能用，都是在替來源下結論。

結語

這一模組請帶走五樣東西：教案、來源紀錄、Notion 連結、Pages 網址和交付清單，也帶走一個習慣：每個說法查得到來源，每個上線動作看得到證據。下一個模組進入 A I 專題，會帶著同樣先核對、再交付的習慣，做出照護場域的排班小工具。現在請回到講義第二節，先確認您的 Notion 連線。
