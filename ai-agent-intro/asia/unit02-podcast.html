模組 02｜讓 AI 進入專案：VS Code 與工作空間 · 深度導讀

台灣華語單人導讀 · 13 分 41 秒 · 對應目前講義與練習單。可邊聽邊閱讀，操作時先暫停。

← 回到講義

開場白

各位學員，大家好。歡迎收聽模組二的深度導讀。這次從一個資料夾開始，讓第一位 A I 做出清單，保存紀錄，再交給第二位加一個按鈕。您不必寫程式，要練的是確認位置、說清楚規則，以及親手檢查成果。需要操作時，請暫停，使用講義或練習單的複製提示。

01第 01 節：學習目標與階段成果

第一節，學習目標與階段成果。我們要留下能接手的本機專案與交班紀錄。第一版有三項清單與完成數；第二版只加「全部取消」，原有功能要繼續正常。

順序是確認環境與兩個可用工具、建立第一版、自己試、存紀錄、換工具、再驗收。換工具不是比誰回答得漂亮，而是看同一份規格能不能延續。簡單任務用一個工具也可以；這次用兩種，是練習接力。工具不足時記下阻礙，不用臨時購買多個訂閱。

02第 02 節：專案、工作空間與對話，哪裡不一樣

第二節，把三個地方分清楚。V S Code 像工作桌，專案資料夾像工作夾，裡面存材料、規格、成果與紀錄。工作空間，是這次開啟、讓 A I 一起工作的資料夾；這堂課只用一個，不需要先學多資料夾設定。

對話像您和一位助理的討論。換另一位，他不一定知道前面說過什麼；把決定寫進工作夾，才有共同依據。用同一個資料夾，不代表兩個工具會共享對話。

換模型、換工具、換帳號也不同。同一工具換模型，不算完成兩種工具接力；換工具要各自確認登入與存取；換帳號是換身分。三種情況都先讀保存的文件，不猜前面的討論。

03第 03 節：安裝 VS Code，開啟一個練習專案

第三節，環境準備與練習 A。由講義的官方下載連結安裝 V S Code；已安裝就確認能開啟。機構限制或看不懂的授權，請講師協助，不繞過限制。安裝方式依作業系統與官方頁面，不從音訊抄指令。

先用電腦的檔案總管建立講義指定的練習資料夾，放在找得到、能寫入的位置。在 V S Code 的檔案選單選「開啟資料夾」。左邊的 Explorer，就是檔案總管，頂端名稱要和您建立的資料夾相同。擴充功能區管理工具，Agent 面板用來交辦。

練習 A 只請 A I 回報看得到的位置與檔案，不建立或修改任何東西。您拿它說的路徑，和檔案總管對照。若它說看到整個文件資料夾，或另一個專案，先修正範圍。它說讀不到時，請它解釋怎麼提供指定材料，不讓它猜。

04第 04 節：四種 Agent 的安裝、登入與可用性確認

第四節認識 Codex、Claude Code、GitHub Copilot 與 Google Antigravity。講義有各工具的官方入口。裝好、本人登入、確認存取資格，再做只讀測試，才算可用；看見圖示還不夠。這次需要兩種真正能處理專案的 Agent，不是四種都要訂閱。

先從官方連結核對產品與發行者，再依自己的畫面登入。密碼與驗證碼本人輸入，不貼進提示。能回答文字，也不一定能讀寫目前專案；請用練習 A 確認。沒有權限或額度，就如實記下，選另一個已可用工具，或看講師示範。

安裝也可以請已可用的 GitHub Copilot 協助。還沒有 V S Code 時，網站上的 Chat 通常提供步驟，不代表能直接在電腦安裝。已有 V S Code，才在它的 Copilot Agent 模式交辦三個官方擴充功能。核對講義的識別碼，不多裝其他項目，也不代替您登入。

講義裡直接完成安裝的回覆，是有本機存取權的示例，不是您的電腦已完成。請自己關閉再開啟 V S Code，查看已安裝清單、核對發行者，再逐一登入與測試。讀不懂安裝動作時，先請它用一般話解釋。

05第 05 節：一份共用說明，讓不同 AI 接力做同一件事

第五節準備共用說明。像交班一樣，接手靠紀錄，不靠記憶；這個比喻只用來理解合作，本題沒有真實照護資料。

規格是虛構的「工作坊準備清單」。三項依序為「讀懂題目、整理資料、準備驗收」。勾一項，完成數多一；取消一項，少一；最少零、最多三。第一次開啟與重新整理後，都回到全部未勾、零項完成。這是本單元明確規則，不能自行改成保存勾選。第二版只多全部取消按鈕。

網頁雙擊就能離線用，不登入、不上傳、不增加其他功能。網頁離線，不代表協助製作的 A I 模型也離線；提供給服務的材料仍可能送出，所以只用虛構資料。

六份文件各有用途：簡介說明怎麼開啟，共用說明定規格，原始資料保存三個項目，網頁是操作成果，交班紀錄記進度，試用紀錄記預期與實際結果。確切檔名在講義，不必從音訊背路徑。請 A I 建立，您在檔案總管找得到就好。原始資料由下一位核對，不要自行改寫。

看不懂就請它說：改了哪些地方、開啟後會看到什麼。結果不對，就描述操作、預期與實際結果。突然有新點子先寫在之後再考慮，這輪仍只做原來那一件事。

06第 06 節：第一個 AI：做出第一版，自己動手試

第六節，練習 B。把完整提示交給第一位已可用的 Agent，讓它在指定資料夾建立網頁與五份配套文件。資料檔照提示原樣保存；已有檔案先讀，不刪掉或覆蓋。第一版還不加全部取消。

收到完成回覆後，依簡介找到 app 資料夾的網頁，雙擊用瀏覽器開啟。在編輯器只看到一大段文字，還不算打開成果。您應看到標題、三個勾選項與完成數。

七項檢查這樣走：初次打開，零項完成；勾讀懂題目與整理資料，兩項；再勾準備驗收，三項；取消整理資料，回到兩項；重新整理，三項全未勾、零項。接著核對文字與順序，不多第四項；最後確認沒有登入、上傳、雲端儲存，也沒有全部取消。每一步看勾選和數字是否一起符合。

假設取消整理資料後，畫面仍顯示三項。請告訴 A I：「我取消了一項，預期兩項，實際三項」，要求照共用說明修正。不要只說壞了，也不要因全勾正確就跳過取消測試。修好後重試受影響步驟。

把親手結果存進試用紀錄，和 A I 自己試的分開。它說全過，只能代表它的宣告；您沒試的仍寫尚未測試。問題未解決就留待辦，不勉強寫完成。

07第 07 節：寫好交班紀錄，交給下一個 AI

第七節，練習 C。請第一位依現有文件與試用紀錄，寫清楚目標、完成與未完成、檔案位置、親手結果、下一步，以及不能改的規則。這一步只寫紀錄，不改網頁。

一份可能的紀錄會說：「三項清單已建立；全勾顯示三項，取消後兩項，重新整理零項，依學員實測記錄。全部取消尚未開始，下一位只做這個改進。」這些句子只有真的試過才能寫；如果重新整理沒試，就明寫尚未測試。

親自點開交班檔，不只看對話摘要。它說有的文件要真的存在，測試結果要和試用紀錄一致。想像下一位沒看過對話，只讀這份也知道現況、待辦與界線，才算有用。核對完，請第一位停止所有修改，再讓第二位接手，避免同時覆寫。

08第 08 節：第二個 Agent：接手小幅改進，保留原有功能

第八節，練習 D 與 E。換另一種已確認可用的 Agent，仍開同一個專案。先送只讀提示，請它讀六份文件，復述五件事：目標、目前成果、待處理問題、這次改進、舊功能怎麼確認。讀不到或矛盾的資訊，先列待確認。

核對復述、確認第一版待辦安排後，才授權在同一個網頁新增全部取消。它不能重做專案、改原始資料或加入其他功能。簡介、交班與試用紀錄也要更新。

新按鈕有三個直接測試：全勾後按，三項全未勾、零項；本來全未勾再按，仍零項且無錯誤；按完再勾準備驗收，能回到一項。第三種很重要，清空不能讓勾選失效。

接著重新做第一版前六項操作。這叫回歸檢查，就是加東西後，舊功能再試一次。重新整理仍歸零、文字順序仍相同。再核對同一專案與網頁、原始資料未改、紀錄區分實測與尚未測試。第一版不准全部取消，第二版這個按鈕是預期改進；不要把它判成違規，其他界線都還在。

練習 E 的錯誤回覆說，重做更完整的專案，改五項、加登入和雲端同步，保存勾選、刪原始資料，最後說全部測試通過。請先自己找至少三個問題，每個對照規格。五項與額外功能超出範圍，保存勾選改掉重新整理規則，刪檔破壞來源，而完成宣告缺少實測證據。這時先停止改動，請它列出多改的地方，依共用說明修正；不要因看起來更完整就接受。

09第 09 節：講師示範：帳號、工作階段與可用額度

第九節，遇到工具限制先保存成果與交班，停止新任務，再查看自己的帳號狀態，選擇等待或另一個原已取得存取權的工具。沒有第二種可用工具，就記下阻礙請講師協助，不把換模型說成已完成接力。

講師換本人帳號的示範，是辨認身分、登出登入、再讀檔案。學員不必有多個付費帳號。切換不會重置原帳號額度，也不保證對話或權限跟著轉移。密碼與驗證碼本人操作，不寫進專案；選單位置以現場介面核對。

聽後自測

第一題，另一個 Agent 看得到同一個資料夾，是不是也知道上一段對話？請暫停想想。不能假設；要指定它讀共用說明與交班，先復述再修改。

第二題，全部取消能把三項變零，就算第二版通過嗎？請暫停。還不能。零項時再按、清空後再勾，以及舊功能，都要重試；新功能正常，不代表原本沒被改壞。

第三題，A I 為了方便，讓重新整理保留勾選，這題可以接受嗎？請暫停。不能，本單元規格是重新整理歸零。方便不等於符合這次需求，要照原規則修正。

結語

離場前，能指出專案位置、兩種可用工具、六份文件，以及第一版、第二版與回歸的實際結果。尚未完成照實留下來，不把示例當自己的成果。保留整個專案與交班；進入模組三建構 Smart TA，繼續先指定來源，再核對回答與證據。現在請回到練習單，一次做一小步。
