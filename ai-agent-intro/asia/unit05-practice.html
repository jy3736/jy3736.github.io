模組 05 · 練習單

同一份教材，兩種發布方式

同一份既有教材，先整理成學生能上網閱讀的網頁，放到自己的 GitHub Pages；接著連接 Notion，再把同一份教材放進自己的 Notion。不用重新研究，也不用另做一份教案。

提示是口說參考，不必逐字照念。老師示範後，用自己的帳號與空間操作；完成後開啟自己的成果確認。

01先選一份教材，兩個練習都用它

題目敘述 · Problem Statement

先在自己的專案選定一份既有教材。可以用單元四自己整併完成的新講義，也可以從 C-basic 選一份原始講義。兩個練習都從這一份開始；不需要重新研究，也不用另外寫一份新教案。

教材原本是 HTML 網頁或 Markdown 文字都可以。已是網頁就按需要整理；文字教材則由 Codex 做成網頁，呈現方式交給它處理。原本的說明、例子與來源都要保留。

需要教材？下載 C-basic 原始講義

下載包與單元四相同，內有 14 份原始講義。解壓後選其中一份就能開始；例如第 01 週的程式入門講義。若使用自己整併的新講義，就直接沿用，不必再下載。

02練習一：先放到 GitHub Pages

題目敘述 · Problem Statement

先把選定教材整理成適合學生上網閱讀的網頁，再放到你自己的 GitHub Pages。老師用自己的帳號示範；輪到你練習時，使用自己的帳號與網站，不能把老師的目的地當成自己的。

教材如果已是 HTML，不必重做一遍，只調整需要的地方。還不是網頁時，交給 Codex 整理成 HTML。你只要說明想讓學生怎麼閱讀，不需要指定製作方法。

03接著準備：連接自己的 Notion

題目敘述 · Problem Statement

GitHub Pages 練習完成後，才開始準備 Notion。接下來要把同一份教材放到自己的 Notion，先請 Codex 協助安裝、連接 Notion 外掛；如果已經連好，就確認目前連到哪個帳號與空間。

你可以直接口說請 Codex 幫忙連接。它可以提供可用入口並協助確認狀態；需要本人登入、選擇工作空間或允許存取時，要由你在正式頁面完成。不要把密碼貼進對話裡。畫面入口依當時版本為準，不需要背按鈕名稱。

可能的 AI 回覆｜接著連接 Notion

以下只是參考，不是已在你的帳號執行的紀錄。請用實際開啟的檔案與頁面確認結果。

我會先看 Notion 是否已能使用。若需要安裝或連接，會引導你前往正式頁面，讓你自己登入、選空間並完成授權；完成後再確認能否使用你選的頁面。

04練習二：同一份教材放到 Notion

題目敘述 · Problem Statement

回到最前面選的那份教材，整理成適合 Notion 閱讀的內容，再放進剛剛連好的自己的空間。這次改的是呈現方式，教材的意思、例子與來源和 GitHub Pages 版本一致。

Notion 可以用清楚的標題、段落、列表或表格呈現。你只需說想怎麼讀，格式由 Codex 安排；不用再找新資料，也不必建立另一份不同主題的教案。

看過內容後，提供你自己想放置的 Notion 頁面連結，或指出剛剛選好的頁面；不要照抄老師的頁面。短教材可以一頁讀完，較長時再依閱讀需要安排。

作者自己能開啟，還要看看學生能不能讀。依你要分享的對象設定 Notion 閱讀範圍，並找預定讀者實際開啟一次；如果還沒試，就保留為待確認。
