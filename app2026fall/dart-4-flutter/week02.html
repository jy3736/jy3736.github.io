這週我們要讓電腦幫忙「記住資料」和「算算數」，最後寫出會問你問題、再幫你算出答案的小程式，例如 BMI 計算機、聚餐分帳。

本週你會學到（學會了就打勾，會自動記在這台電腦的瀏覽器裡）

1. 開始之前：程式是什麼？怎麼執行？

程式就是寫給電腦看的「步驟清單」。電腦很聽話，但也很死板：它會從上到下、一行一行照著做，一個符號寫錯就看不懂。所以寫程式最重要的習慣是：仔細、小步前進、常常執行看看。

方法一：用 DartPad（不用安裝，打開瀏覽器就能寫）

  1. 打開 https://dartpad.dev。
  2. 左邊是寫程式的地方，右邊是顯示結果的地方。
  3. 把左邊原本的程式全部刪掉，貼上講義裡的範例（每個範例右上角都有「複製」按鈕）。
  4. 按下 Run，右邊就會出現執行結果。

方法二：在自己的電腦執行（第 6 段「讀取鍵盤輸入」一定要用這個方法）

  1. 依照官方說明安裝 Dart SDK：Get the Dart SDK。
  2. 打開「終端機」：Mac 搜尋 終端機（Terminal）；Windows 搜尋 PowerShell。終端機是用「打字」來指揮電腦的視窗。
  3. 輸入下面的指令並按 Enter，看到版本號就代表安裝成功。
dart --version
  1. 用文字編輯器（建議 VS Code）建立一個資料夾，例如 dart-week02，在裡面新增檔案 hello.dart，貼上程式並存檔。
  2. 在終端機用 cd 指令「走進」那個資料夾，再用 dart run 執行檔案：
cd dart-week02
dart run hello.dart

小技巧

在 VS Code 裡可以直接開啟內建終端機（選單「終端機 → 新增終端」），它會自動在你目前的資料夾，比較不會迷路。

符號名稱在 Dart 裡的用途

( )小括號放函式需要的資料，例如 print('嗨')
{ }大括號把好幾行程式包成一組
[ ]中括號清單（下週會學）

最常見的陷阱：全形符號

用中文輸入法打字時，很容易打出全形的 ；、（、“。電腦只看得懂半形符號。寫程式時請切換成英文輸入，只有「引號裡面的文字」可以打中文。

錯誤訊息（實際執行結果）
e7_fullwidth_symbols.dart:2:17: Error: The non-ASCII character '；' (U+FF1B) can't be used in identifiers, only in strings and comments.
Try using an US-ASCII letter, a digit, '_' (an underscore), or '$' (a dollar sign).
  var price = 55；
                ^
e7_fullwidth_symbols.dart:2:15: Error: Expected ';' after this.
  var price = 55；

錯誤訊息的意思是：「全形分號 ； 不能出現在這裡，只能出現在字串或註解裡」，接著又說「這裡應該要有 ;」。把全形 ； 改成半形 ; 就好了。

3. 變數與型別：幫資料找個盒子

變數（variable）就像一個貼了名字標籤的盒子，可以把資料放進去，之後叫名字就能拿出來用。型別（type）則決定盒子裡可以放什麼東西。

三種宣告變數的方式

  • 寫出型別：int age = 19;，清楚告訴電腦這個盒子只放整數。
  • 用 var：var cups = 2;，讓 Dart 看初始值自己判斷型別，這叫「型別推論」。2 是整數，所以 cups 就是 int。
  • 用 final 或 const：放進去之後不能再改。學號這種不會變的資料適合用 final；稅率這種寫程式時就知道的固定值適合用 const。

重點：盒子的「型別」不能換

盒子裡的值可以換（cups = 3; 沒問題），但裝整數的盒子不能改放文字（cups = '三杯'; 會出錯）。Dart 會在執行之前就提醒你，幫你提早抓到錯誤。

動手試試

種類符號意思要特別注意
算術+ - * /加、減、乘、除乘號是 *，不是 ×；/ 的結果一定是小數：7 / 2 得到 3.5
整數除法~/除完只留整數7 ~/ 2 得到 3，適合算「幾張」「幾小時」
取餘數%除完剩下多少125 % 60 得到 5，適合算「剩幾分」「零錢」
比較== != > < >= <=等於、不等於、大於、小於……結果只會是 true 或 false；= 是放進去，== 才是比較
邏輯&& || !而且、或者、不是&& 兩邊都成立才是 true；|| 一邊成立就是 true
複合指定+= -= *= ++算完再放回去steps += 500 等於 steps = steps + 500；count++ 是加 1

運算的先後順序

和數學課一樣，先乘除、後加減；比較運算在算術之後，&&、|| 最後才算。不確定的時候就加小括號，程式也會比較好讀。

一定要會的三個技巧

  • 字串插值：在字串裡寫 $變數名稱，就會換成變數的值；要放算式的話用 ${算式}，例如 '總共 ${price * cups} 元'。
  • 保留小數位數：bmi.toStringAsFixed(1) 會四捨五入到小數點後 1 位。電腦算出來的小數常常很長（例如 20.312499999999996），印出來前記得處理。

7. 看懂錯誤訊息，並請 AI 幫忙

寫程式出錯是每個人每天都會遇到的事，錯誤訊息不是在罵你，而是在告訴你「哪裡怪怪的」。

錯誤訊息怎麼讀？

以 e1_type_mismatch.dart:3:10: Error: ... 為例：

檔名 e1_type_mismatch.dart:第 3 行:第 10 個字→Error 後面是原因

先找到位置，再讀原因。英文看不懂沒關係，下面會教你怎麼請 AI 翻譯和解釋。

常見錯誤圖鑑（都是實際執行的結果）

① 型別不合：把文字放進整數盒子

錯誤訊息（實際執行結果）
e1_type_mismatch.dart:3:10: Error: A value of type 'String' can't be assigned to a variable of type 'int'.
  cups = '三杯';
         ^
怎麼改？

cups 是 int，只能放整數。改成 cups = 3;。

② 文字不能直接加數字

錯誤訊息（實際執行結果）
e2_string_plus_number.dart:3:24: Error: A value of type 'int' can't be assigned to a variable of type 'String'.
  var nextYear = age + 1;
                       ^
怎麼改？

'19' 有引號，是文字。先轉成數字：var nextYear = int.parse(age) + 1;。

③ 忘了分號

錯誤訊息（實際執行結果）
e3_missing_semicolon.dart:2:15: Error: Expected ';' after this.
  var price = 55
              ^^
怎麼改？

在 55 後面加上 ;。注意：少了分號時，錯誤常常指向「那一行的結尾」，所以要往錯誤位置的前面找。

④ 修改 final 變數

錯誤訊息（實際執行結果）
e4_final_reassign.dart:3:3: Error: Can't assign to the final variable 'studentId'.
  studentId = 'B99999999';
  ^^^^^^^^^
怎麼改？

final 只能設定一次。如果這個值真的需要改，就改用 var 宣告。

⑤ 把 null 放進不能是空的盒子

錯誤訊息（實際執行結果）
e5_null_safety.dart:2:17: Error: A value of type 'Null' can't be assigned to a variable of type 'String'.
  String name = null;
                ^
怎麼改？

String 盒子不能是空的（null）。給它一個真正的文字，例如 String name = '小明';；如果真的允許空值，要寫成 String? name = null;（型別後面加 ?）。

⑥ 執行到一半才出錯：文字無法轉成數字

錯誤訊息（實際執行結果）
Unhandled exception:
FormatException: Invalid radix-10 number (at character 1)
五十
^
怎麼改？

int.parse 只看得懂阿拉伯數字，'五十' 要改成 '50'。這種錯誤要執行時才會發現，所以輸入資料時要特別小心。

兩種錯誤

①～⑤ 是還沒執行就被抓到的錯誤，Dart 會先幫你檢查。⑥ 是執行到一半才發生的錯誤。能提早被抓到的錯誤，其實是好事。

請 AI 幫忙解釋錯誤

把下面的提問範本複製起來，貼上你的程式和完整、原封不動的錯誤訊息：

使用 AI 的三個原則

  1. 先自己看一次：先找出錯誤的行號，猜猜原因，再問 AI。
  2. 自己動手改：請 AI 解釋「為什麼」，而不是直接給答案。
  3. 一定要重新執行：AI 也可能說錯。改完之後程式真的能跑、結果也正確，才算解決。

8. 本週重點整理

  • 程式從 main() 開始，由上到下一行一行執行；print() 顯示結果。
  • 變數是有名字的盒子：int 整數、double 小數、String 文字、bool 是／否。
  • var 讓 Dart 自己判斷型別；final／const 設定後不能改。
  • / 得小數，~/ 得整數，% 得餘數；= 是放進去，== 是比較。
  • 字串插值 $變數、${算式}；toStringAsFixed(1) 保留 1 位小數。
  • 鍵盤輸入是文字，要用 int.parse／double.parse 轉成數字才能計算。
  • 看錯誤訊息：先找「第幾行」，再讀原因；請 AI 解釋後，自己改、自己重跑。
