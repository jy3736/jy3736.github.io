01 寫 if 判斷時，後面小括號裡應該放什麼？

  1. 一個算出來會是 true 或 false 的條件
  2. 這個函式要回傳的型別名稱
  3. 一段之後要重複執行很多次的程式
  4. 一個一定要用單引號包起來的字串

02 關於 else if 與 else 的用法，下列哪些描述正確？

  1. else if 是在它前面的條件不成立時，再檢查另一個條件
  2. else 的大括號要在上面所有條件都不成立時才會執行
  3. 一個 if 後面最多只能接一個 else if
  4. else 後面一定要再寫一個小括號條件

03 下面這段程式用條件運算子決定字串，畫面上會出現什麼？

var stock = 0;
var status = stock > 0 ? '有貨' : '缺貨';
print(status);
  1. 有貨
  2. 缺貨
  3. 0
  4. false

04 關於 Dart 的 switch，下列哪些描述正確？

  1. switch 只能用在整數上，不能拿字串來比對
  2. 每個 case 做完會自動結束，不必自己寫 break
  3. 兩個 case 疊在一起時，代表它們共用同一段程式
  4. default 代表其他所有情況

05 一個 while 迴圈一直停不下來，可能的原因與處理方式有哪些？

  1. 大括號裡沒有改變條件用到的變數，條件永遠成立
  2. Dart 規定 while 最多只能跑 100 次，超過就會出錯
  3. 在終端機可以按 Ctrl + C 強制停止
  4. 因為 while 的大括號裡每次只能放一行程式

07 下列哪些工作最適合用 for-in 把資料一個一個拿出來處理？

  1. 逐一檢查全班每位同學的成績
  2. 每個月存一筆錢，一直存到存款超過某個金額為止
  3. 依照天氣好壞二選一，只要做一次判斷
  4. 把水果清單裡的每個名稱都印出來

08 下面這段程式在迴圈裡用了 continue 和 break，畫面上會出現哪些數字？

for (var n = 1; n <= 6; n++) {
  if (n == 3) {
    continue;
  }
  if (n == 5) {
    break;
  }
  print(n);
}
  1. 1
  2. 2
  3. 3
  4. 4

09 全班 40 位同學的分數要一起存放和處理，最適合的做法是哪一個？

  1. 宣告 40 個名稱不同的變數分別存放
  2. 用一個 bool 變數存放這 40 個分數
  3. 用一個 List 存放這 40 個分數
  4. 直接寫 40 行 print，不要存起來

10 關於 Map（對照表）的敘述，下列哪些正確？

  1. Map 的資料一定要用 0、1、2 這樣的編號才讀得到
  2. Map 用大括號建立，鍵和值中間用冒號隔開
  3. 在 Map 裡查一個不存在的鍵，會得到 null
  4. Map 的鍵一定要是數字，不能是文字

11 已知 var marks = [70, 85, 91];，下列哪些「寫法與說明」的搭配是正確的？

  1. marks.add(64); 會在清單最後面加入一筆資料
  2. marks[2] = 95; 會把清單裡的第 3 筆改成 95
  3. marks.length 會得到清單目前的資料筆數
  4. marks[3] 會取到清單裡的第 3 筆資料

12 下面這段程式對一個 Map 新增和修改資料，畫面上會依序出現哪兩個結果？

var menu = {'漢堡': 60, '薯條': 40};
menu['可樂'] = 25;
menu['薯條'] = 45;
print(menu.length);
print(menu['薯條']);
  1. 2
  2. 3
  3. 40
  4. 45

13 關於函式的敘述，下列哪些正確？

  1. 參數就是呼叫函式時交給它的材料
  2. 一個函式寫好之後只能被呼叫一次，用過就不能再用
  3. return 會把結果交回去，函式執行到這裡就結束
  4. void 表示這個函式只負責做事，不交回結果

14 函式宣告成 String order({required String item, int count = 2})，下列哪一個呼叫方式是正確的？

  1. order(item: '便當')
  2. order('便當', 3)
  3. order(count: 3)
  4. order()

15 關於箭頭語法 => 的敘述，下列哪些正確？

  1. 用箭頭語法寫的函式一定不能有參數
  2. 箭頭語法只能用在不交回結果的函式上
  3. 只有當函式的內容是一行運算式時才能用箭頭語法
  4. 箭頭後面那個運算式算出來的值，就是這個函式交回去的結果

16 關於處理清單的 map、any、every，下列哪些描述正確？

  1. map 會把清單裡的資料筆數變成原本的一半
  2. map 會把每一筆資料都轉換成一個新的值
  3. any 用來問「是否至少有一筆符合」
  4. every 用來問「是否全部都符合」

17 感測器讀取失敗時會記成 -999.0。執行下面的程式，畫面上會依序出現哪兩個結果？

var hums = [55.0, -999.0, 72.0, -999.0, 80.5];
var ok = hums.where((h) => h != -999.0).toList();
print(ok.length);
print(ok);
  1. 3
  2. [55.0, 72.0, 80.5]
  3. 5
  4. [55.0, -999.0, 72.0, -999.0, 80.5]

19 關於寫測試，下列哪些敘述正確？

  1. 測試是先寫好「給這個輸入，應該得到這個結果」，再讓電腦自動對答案
  2. 測試的說明文字只能用英文，寫中文就無法執行
  3. group 可以把同一類的測試放在一起
  4. 「邊界值」是剛好在分界上的輸入，最容易出錯，要特別測

20 執行測試後看到 Expected: 'A' 和 Actual: 'B' 兩行訊息，這代表什麼？

  1. 這個測試已經通過了，不需要再處理
  2. 測試檔案本身有語法錯誤，整個檔案沒有執行
  3. 這個測試原本應該要得到 'A'
  4. 程式實際算出來的結果是 'B'
