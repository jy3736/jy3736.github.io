06 下列關於 DartPad 的敘述，何者正確？

  1. 必須先在本機安裝 Dart SDK 才能使用
  2. 可以任意使用 pub.dev 上的套件
  3. 不支援 dart:io 這類 VM 函式庫，所以無法用 stdin.readLineSync() 讀取鍵盤輸入
  4. 只能執行 Flutter 範例，不能寫命令列程式

07 執行 dart analyze 得到下列訊息：error - e8_method_typo.dart:3:30 - The method 'spit' isn't defined for the type 'String'. 其中的 3:30 代表什麼？

  1. 第 30 行、第 3 個字元
  2. 第 3 行、第 30 個字元
  3. 發現 3 個錯誤、30 個警告
  4. 分析花了 3.30 秒

08 關於 dart analyze 與 dart run，下列敘述何者正確？

  1. dart analyze 必須先把程式跑起來，才能找到錯誤
  2. 用 dart run 執行時，方法名稱打錯字造成的錯誤會被自動忽略
  3. dart analyze 只檢查排版，不檢查方法名稱是否存在
  4. dart analyze 做的是靜態分析，不必執行程式就能先找出錯誤

09 某生已經安裝 Flutter SDK，想在終端機使用 dart 指令。下列敘述何者正確？

  1. 不必另外安裝 Dart SDK，因為 Flutter SDK 內含完整的 Dart SDK
  2. 必須另外安裝 Dart SDK，否則無法使用 dart 指令
  3. 只能改用 DartPad，本機無法執行 Dart 程式
  4. 要先執行 dart create，才會自動安裝 Dart SDK

  3. 2 小時 77 分

13 聚餐總金額 1000 元，由 3 人分帳。執行下列程式會印出什麼？

var people = 3;

var left = total % people;

  2. 每人 334 元，還差 2 元由主揪補上
  3. 每人 $each 元，還差 $left 元由主揪補上
  4. 每人 333 元，還差 1 元由主揪補上

18 一支在本機用 dart run 執行的 BMI 程式有下列一行。其中 ?? '' 的作用是什麼？

var heightText = stdin.readLineSync() ?? '';
  1. stdin.readLineSync() 可能拿到 null，此時改用空字串當預設值
  2. 把輸入的文字轉成 double
  3. 去掉輸入前後的空白
  4. 把輸入的文字全部轉成大寫

19 某個 BMI 程式先用 stdout.write('請輸入身高（公分）：'); 印出提示，再讀取鍵盤輸入。使用 stdout.write() 而不是 print() 的原因是什麼？

  1. stdout.write() 會自動把輸入轉成數字
  2. print() 無法印出中文
  3. stdout.write() 印出的數字會自動保留 1 位小數
  4. 印出提示文字後不換行，讓使用者在同一行輸入
