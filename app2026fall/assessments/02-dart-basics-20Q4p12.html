課後形成性評量：Dart 開發流程與語法基礎

20 題複選，每題 1 至 2 個正確選項。可選「逐題檢查」，每題選好就按「檢查答案」；或選「全部一次檢查」，全部作答後按「全部檢查」一次批改。答錯可以再試，試過 2 個不同的錯誤答案後才能看答案。

答對 60% 以上的題目（看答案的不算）後，可以下載含答案的 HTML 檔。作答紀錄不會保存，重新整理或離開頁面後會從頭開始。

01 依本課程的 PEA 學習循環，下列哪些活動屬於 Engage（課中參與）階段？

  1. 課堂上動手寫程式、看執行結果並修正錯誤
  2. 和同學、老師討論程式的執行結果
  3. 課前閱讀本週重點，並用 AI 釐清觀念
  4. 完成列入檢核的後測

02 依本課程的 PEA 學習循環，下列哪一項是 Assess（檢核）階段中教師／課程的任務？

  1. 巡堂協助學生除錯
  2. 提供本週重點與官方文件連結
  3. 出 n 選 m 前測／後測，並批閱作業
  4. 帶領課堂示範

03 依本課程的生成式 AI 協作規範，下列哪些情境可以使用生成式 AI？

  1. 參加考試時作答
  2. 作答隨堂測驗
  3. 專題開發時請 AI 協助除錯
  4. 課前請 AI 用不同方式解釋一個 Dart 語法

04 本課程規定列入檢核的前測與後測不可使用 AI 作答。下列哪些是這項規定的理由？

  1. 前後測檢核的是學生自己現在懂多少，用 AI 作答就無法反映真實的學習狀態
  2. AI 回答 Dart 題目一定會答錯
  3. 用 AI 作答後，老師無法依據結果調整教學
  4. 前後測的結果不列入任何檢核

05 執行 dart create hello_dart 後，下列哪些檔案會出現在 hello_dart/ 專案資料夾中？

  1. main.py
  2. test/hello_dart_test.dart
  3. index.html
  4. analysis_options.yaml

06 用 dart create 建立的 Dart 專案中，pubspec.yaml 用來設定什麼？

  1. 靜態分析規則
  2. 測試程式
  3. 程式的進入點 main()
  4. 專案名稱與套件相依

07 專案中的 bin/hello_dart.dart 內容如下。在專案資料夾執行 dart run 會印出 Hello world: 42!。其中的 42 從哪裡來？

import 'package:hello_dart/hello_dart.dart' as hello_dart;

void main(List<String> arguments) {
  print('Hello world: ${hello_dart.calculate()}!');
}
  1. pubspec.yaml 裡設定的版本號
  2. 執行時傳入的 arguments
  3. lib/hello_dart.dart 裡 calculate() 的回傳值
  4. Dart SDK 內建、固定印出的數字

08 關於 dart analyze 指令，下列哪些敘述正確？

  1. dart analyze 會分析目前資料夾下所有 Dart 檔案
  2. dart analyze 會先執行程式，再印出執行結果
  3. dart analyze 只能在 DartPad 中使用
  4. dart analyze bin 只分析 bin/ 資料夾

09 某生把程式中的 'hello'.split('') 誤打成 'hello'.spit('')，沒有先分析就直接執行 dart run。下列哪些敘述正確？

  1. 程式照常一行一個字母印出 h、e、l、l、o
  2. 程式在建置時就失敗，不會印出任何字母
  3. 錯誤訊息指出 String 型別沒有名為 spit 的方法
  4. Dart 會自動把 spit 改成 split 後執行

10 下列哪些是 Dart 語言的特色？

  1. 型別安全：用靜態型別檢查確保變數的值符合它的型別
  2. null safety：除非明確允許，否則值不能是 null
  3. 每個變數都必須手動寫出型別，不能由 Dart 推論
  4. 程式從檔案第一行開始執行，不需要 main()

11 下列哪些宣告會出現型別錯誤？

  1. var a = 1;
  2. double d = 2.5;
  3. int c = '3';
  4. String name = 19;

12 已宣告 var score = 72;，下列哪些運算式的結果是 true？

  1. score >= 60
  2. score == 100
  3. score != 100
  4. score < 60

13 關於 Dart 的 = 與 ==，下列何者正確？

  1. = 判斷兩邊是否相等
  2. == 把右邊的值放進左邊的變數
  3. = 與 == 意思相同，可以互換
  4. == 判斷兩邊是否相等，結果是 bool

14 下列哪些程式與輸出的配對正確？

  1. print(7 / 2); 印出 3
  2. print(7 / 2); 印出 3.5
  3. print(7 ~/ 2); 印出 3.5
  4. print(7 ~/ 2); 印出 3

15 執行下列程式會印出什麼？

var price = 60;
var cups = 2;
print('總共 ${price * cups} 元');
  1. 總共 120 元
  2. 總共 ${price * cups} 元
  3. 總共 price * cups 元
  4. 總共 602 元

16 關於下列字串運算式的值，哪些敘述正確？

  1. 'Flutter'.length 的值是 7
  2. 'Dart'.toUpperCase() 的值是 'dart'
  3. ' Hello Dart '.trim() 會去掉所有空白，得到 'HelloDart'
  4. '台南市永康區'.contains('永康') 的值是 true

17 要在 Dart 中建立一段跨越多行的字串（例如收據），應使用哪一種寫法？

  1. 在每一行開頭加上 //
  2. 用三個引號包住字串
  3. 把每一行放進 ${} 裡
  4. Dart 的字串無法跨越多行

18 已宣告 var score = 88;，下列哪些運算式的值是字串「分數：88」？

  1. '分數：' + score
  2. '分數：' + score.toString()
  3. '分數：$score'
  4. '分數：score'

19 執行下列攝氏轉華氏程式會印出什麼？

const celsius = 28.5;
var fahrenheit = celsius * 9 / 5 + 32;
print('攝氏 $celsius 度 = 華氏 ${fahrenheit.toStringAsFixed(1)} 度');
  1. 攝氏 28.5 度 = 華氏 83.30 度
  2. 攝氏 28.5 度 = 華氏 51.3 度
  3. 攝氏 28.5 度 = 華氏 83.3 度
  4. 攝氏 28.5 度 = 華氏 83 度

20 下列哪些錯誤在程式執行之前（例如執行 dart analyze 時）就會被抓到？

  1. 漏掉分號（Expected ';' after this.）
  2. 對已經設定過的 final 變數重新指定值
  3. int.parse('五十') 無法把文字轉成數字
  4. 執行到一半才丟出的 FormatException
