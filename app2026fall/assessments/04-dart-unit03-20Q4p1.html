12 要把一個 Map 裡每一組「鍵」和「值」都逐一取出來印，正確的寫法是哪一個？

  1. for (var entry in inventory.entries)，再用 entry.key 與 entry.value
  2. for (var entry in inventory)，再用 entry[0] 與 entry[1]
  3. for (var i = 0; i < inventory.length; i++)，再用 inventory[i]
  4. for (var key in inventory)，再用 inventory.key

14 下列哪一種寫法和 bool isHot(double c) => c >= 30; 的意義完全相同？

  1. bool isHot(double c) { print(c >= 30); }
  2. void isHot(double c) { c >= 30; }
  3. bool isHot(double c) { return c >= 30; }
  4. bool isHot(double c) { c = 30; }

15 依下面的函式定義，呼叫 makeTicket(show: '音樂會') 會得到什麼結果？

String makeTicket({required String show, String seat = '自由座', int count = 1}) {
  return '$show（$seat）x $count';
}
  1. 音樂會（自由座）x 1
  2. 音樂會（）x 1
  3. 音樂會（自由座）x 0
  4. 會產生錯誤，因為呼叫時沒有給 seat 和 count

17 對同一個清單使用 any 和 every 時，兩者的差別是什麼？

  1. any 會回傳符合條件的新清單，every 會回傳資料筆數
  2. any 問的是「是否至少一筆符合」，every 問的是「是否全部符合」
  3. any 問的是「是否全部符合」，every 問的是「是否至少一筆符合」
  4. 兩者意思完全相同，只是名稱不一樣
