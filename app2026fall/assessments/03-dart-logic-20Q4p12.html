02 執行下列秒數換算程式會印出什麼？

var seconds = 3725;
var h = seconds ~/ 3600;
var m = seconds % 3600 ~/ 60;
var s = seconds % 60;
print('$h 小時 $m 分 $s 秒');

  2. 1 小時 2 分 5 秒
  3. 1.03 小時 2 分 5 秒
  4. 1 小時 2 分 125 秒

08 某票價程式如下。age 與 isStudent 為下列哪些組合時會印出「票價：學生票」？

if (age < 12 || age >= 65) {
  print('票價：愛心票');
} else if (isStudent && age < 25) {
  print('票價：學生票');
} else {
  print('票價：全票');
}
  1. age 為 20，isStudent 為 true
  2. age 為 24，isStudent 為 true
  3. age 為 70，isStudent 為 true
  4. age 為 20，isStudent 為 false

09 在 Dart 的 switch 陳述式中，一個非空的 case 執行完之後會怎樣？

  1. 繼續執行下一個 case 的程式
  2. 一定要寫 break，否則出現錯誤
  3. 回到 switch 開頭重新判斷
  4. 自動跳出 switch，不必寫 break

10 某溫度標籤程式使用 switch 運算式，如下所示。temp 為下列哪些值時，label 會是「溫暖」？

  >= 30 => '熱',
  >= 25 => '溫暖',
  _ => '涼',
};

  2. 24
  3. 25
  4. 29

13 下列哪些「情況 → 迴圈寫法」的配對正確？

  1. 不知道要做幾次 → break
  2. 知道要做幾次 → for (var i = 1; i <= n; i++)
  3. 跳過讀取失敗的那一筆 → while (條件)
  4. 把清單裡每一筆拿出來處理 → for (var x in list)

15 關於 Dart 的 Map，下列哪些敘述正確？

  1. 像 List 一樣用索引 1 取得第一組資料

16 下列兩個函式的寫法中，哪些敘述正確？

double celsiusToFahrenheit(double c) => c * 9 / 5 + 32;

void printLine(String title) {
  print('==== $title ====');
}
  1. 函式本體只有一個運算式時，可以用 => 箭頭語法
  2. void 表示函式沒有回傳值
  3. => 只能用在 main() 函式
  4. printLine 會回傳一個 String
