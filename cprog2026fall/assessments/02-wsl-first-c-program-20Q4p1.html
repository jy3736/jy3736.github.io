課前前測：WSL 環境與第一支 C 程式

01 下列關於 WSL（Windows Subsystem for Linux）的敘述，何者正確？

  1. 它讓 Windows 可以直接執行 Linux 程式，不需要另外安裝虛擬機器或雙系統
  2. 它是一種必須先安裝虛擬機器軟體才能使用的 Linux 模擬器
  3. 它是讓 Linux 電腦執行 Windows 程式的相容層
  4. 它是 Windows 內建、用來取代 PowerShell 的文字編輯器

02 要用一行指令安裝 WSL，電腦的 Windows 版本至少要符合哪一個條件？

  1. Windows 7 以上即可
  2. 只能是 Windows 11，Windows 10 一律不支援
  3. Windows 10 版本 2004（組建 19041）以上，或 Windows 11
  4. Windows 10 任何版本皆可，不需要檢查組建編號

03 在以系統管理員身分執行的 PowerShell 中安裝 WSL，進度卻一直停在 0.0%。下列哪一個指令是建議的替代安裝方式？

  1. wsl --list --verbose
  2. wsl --install --web-download -d Ubuntu
  3. wsl -u root
  4. winver

04 第一次開啟 Ubuntu 設定密碼時，小芸按了好幾個鍵，畫面上卻完全沒有出現任何字，連星號都沒有。她應該怎麼判斷與處理？

  1. 代表 Ubuntu 當機，需要關閉視窗重新開啟
  2. 代表輸入法設定錯誤，要先切換成全形再輸入
  3. 代表 WSL 安裝失敗，要重新執行安裝
  4. 這是正常現象，照常輸入完密碼後按 Enter 即可

05 關於第一次開啟 Ubuntu 時建立的使用者名稱與密碼，下列敘述何者正確？

  1. 必須和自己的 Windows 登入帳號密碼完全相同
  2. 它和 Windows 帳號無關，是 Ubuntu 專用的帳號密碼
  3. 只有第一次開啟時需要，之後不會再用到
  4. 每次開啟 Ubuntu 視窗時，都必須重新建立一組新的帳號

06 官方建議在 Ubuntu 中定期執行 sudo apt update && sudo apt upgrade。下列哪一項是這麼做的理由？

  1. Windows 不會自動更新 Ubuntu 裡的套件，而且套件清單太舊時可能導致新軟體安裝失敗
  2. 這個指令會順便把 Windows 系統更新到最新版本
  3. 不定期執行的話，Ubuntu 的密碼會自動過期
  4. 這是在電腦上安裝 VS Code 的唯一方法

07 在 Ubuntu 中執行 sudo apt install build-essential gdb。其中 gdb 是哪一種工具？

  1. 程式編輯器
  2. 套件管理工具
  3. 檔案總管
  4. 除錯器

08 阿哲在 Ubuntu 中輸入 pwd，顯示目前位置是 /mnt/c/Users/ajhe/Documents/cprog，而且在這裡編譯和開啟檔案都非常慢。最合適的處理方式是什麼？

  1. 把課程資料夾改放到 Windows 桌面
  2. 把 .c 檔的副檔名改成 .txt 後再編譯
  3. 把檔案搬到 Linux 檔案系統的家目錄底下，例如 ~/cprog/
  4. 每次編譯前先重新開機一次

09 小傑在 Windows 裝好 VS Code 後，在 Ubuntu 輸入 code . 卻出現「command not found」，重新開啟 Ubuntu 視窗再試也一樣。最可能的原因是什麼？

  1. 安裝 VS Code 時沒有勾選「加入 PATH」（Add to PATH）
  2. VS Code 必須安裝在 Ubuntu 裡，不能安裝在 Windows
  3. 尚未在 Ubuntu 中建立任何 .c 檔案
  4. 指令最後的句點應該改成逗號

10 從 Ubuntu 開啟 VS Code 後，視窗左下角顯示 WSL: Ubuntu。這代表什麼？

  1. Ubuntu 有新版本，需要立即更新
  2. VS Code 目前處於離線模式，無法存檔
  3. C 編譯器已經自動安裝完成
  4. VS Code 已經連線到 Ubuntu

11 C 程式通常執行得很快。依照 C 的編譯方式，下列哪一項是原因之一？

  1. C 程式在執行時才一行一行翻譯，所以不必等待
  2. 編譯器產生的是 CPU 可以直接執行的機器碼
  3. .c 原始檔的檔案大小比其他語言小
  4. C 程式執行時會自動使用所有 CPU 核心

12 在終端機執行 gcc -std=c17 -Wall -Wextra -Wpedantic greet.c -o hi 且編譯成功。接下來要執行這支程式，應該輸入哪一個指令？

  1. ./greet.c
  2. ./greet
  3. ./hi
  4. ./hi.c

13 小安已經把 score.c 編譯成可執行檔 score 並執行過。接著他修改 score.c 裡要印出的文字並存檔，但沒有重新編譯，就直接執行 score。會發生什麼事？

  1. 仍然印出修改前的文字，因為執行的是先前編譯出來的檔案
  2. 印出修改後的文字，因為存檔時會自動重新編譯
  3. 終端機會自動改為執行 score.c 這個文字檔
  4. score 這個檔案會在存檔時被刪除

14 C 程式第一行寫著 #include <stdio.h>。這一行的作用是什麼？

  1. 指定編譯時使用 C17 標準
  2. 把程式的輸出另存成 stdio.h 檔案
  3. 讓程式印出的每一段文字自動換行
  4. 請前置處理器把 stdio.h 的內容放進來，printf 就是在其中宣告的

15 關於 int main(void) 這一行，下列敘述何者正確？

  1. 程式從檔案第一行開始逐行執行，main 只是一個普通的名稱
  2. 每個完整的程式至少要有一個 main 函式，程式從這裡開始執行；void 表示 main 不使用任何引數
  3. void 表示 main 執行完後不會回傳任何值
  4. 只要程式中有 printf，就可以不寫 main

16 main 中依序有下列三個敘述（\n 表示換行）。執行後螢幕上的輸出是什麼？

printf("早安");
printf("，同學\n");
printf("上課囉\n");
  1. 三行：「早安」、「，同學」、「上課囉」
  2. 一行：「早安，同學上課囉」
  3. 兩行：第一行「早安，同學」，第二行「上課囉」
  4. 兩行：第一行「早安」，第二行「，同學上課囉」

17 main 中有下列敘述。執行後螢幕上的輸出是什麼？

/* 印出課程名稱 */
printf("C 程式\n");
// printf("實習\n");
printf("加油\n");
  1. 兩行：「C 程式」、「加油」
  2. 三行：「C 程式」、「實習」、「加油」
  3. 四行：先印出「印出課程名稱」，再印出「C 程式」、「實習」、「加油」
  4. 無法編譯，因為 // 後面不能出現程式碼

18 下列關於 main 結尾的 return 0; 的敘述，何者正確？

  1. 它會在螢幕上印出數字 0
  2. main 少寫這一行時，程式一律無法編譯
  3. 任何函式執行到結尾沒有寫 return，效果都等同回傳 0
  4. 它讓 main 結束並回傳結束狀態 0；main 執行到結尾沒寫 return 時也等同回傳 0，但這個特例只適用於 main

19 已知 %d 在 printf 的文字中表示「這裡要放一個整數」。main 中有下列敘述，使用 -Wall 等警告選項編譯。下列敘述何者正確？

printf("成績是 %d 分\n");
  1. 程式完全正確，執行時會印出「成績是 0 分」
  2. 編譯器會發出警告；即使仍產生可執行檔，印出的數字也不可靠
  3. %d 會被原樣印出，編譯器不會有任何訊息
  4. 編譯器會自動補上一個整數，讓輸出正確

20 編譯時終端機顯示一則訊息，開頭是 bmi.c:6:12: warning:。其中 6 和 12 代表什麼？

  1. 這是第 6 則警告，總共有 12 則
  2. 問題出現在 bmi.c 的第 12 行、第 6 欄附近
  3. 問題出現在 bmi.c 的第 6 行、第 12 欄附近
  4. 程式執行了 6 秒 12 毫秒後發生問題
