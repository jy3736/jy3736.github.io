01 下列關於 C 變數命名規則的敘述，哪些正確？

  1. 變數名稱可以使用英文字母、數字 0-9 與底線 _
  2. 變數名稱可以用兩個底線開頭
  3. 變數名稱不能以數字開頭
  4. 變數名稱中完全不能出現數字

02 敘述 int foo; 的作用是什麼？

  1. 在螢幕上印出 foo
  2. 定義一個名叫 int 的新型別
  3. 把 foo 的值印成 0
  4. 宣告一個 int 型別、名叫 foo 的變數

03 庫存變數 stock 依序經過下列敘述更新。下列敘述哪些正確？

int stock = 120;
stock = stock - 45;
stock = stock + 30;
  1. 第二行在數學上不可能成立，所以編譯會失敗
  2. 執行完後，stock 的值是 105
  3. 執行完後，stock 的值仍然是 120
  4. 第二行先算出右邊的值，再把結果存回 stock

04 下列關於整數型別的敘述，哪些正確？

  1. 有號（signed）整數型別可以存放正數和負數
  2. 無號（unsigned）整數型別只能存放 0 和正數
  3. 無號（unsigned）整數型別也可以存放負數
  4. 型別佔用的位元組數，和它能存放的數值範圍無關

05 在大多數電腦上，short 型別佔幾個位元組？

  1. 1 個位元組
  2. 8 個位元組
  3. 2 個位元組
  4. 4 個位元組

06 一個長度與一個數量分別存在 double 與 int 變數中，並以下列敘述印出。螢幕上印出的內容是什麼？

double len = 12.5;
int cnt = 12;
printf("%f %d\n", len, cnt);
  1. 12.5 12
  2. 12.500000 12
  3. 12.500000 12.000000
  4. 12 12

07 下列關於餘數運算子 % 的敘述，哪些正確？

  1. 23 % 4 的值是 5
  2. % 會把數值換算成百分比
  3. 23 % 4 的值是 3
  4. % 只能用在整數上

08 下列哪些運算式的值是 2.5？

  1. 5.0 / 2
  2. 5 / 2
  3. (double)(5 / 2)
  4. (double)5 / 2

09 執行 int r = 30 / (2 + 3) * 2; 之後，下列敘述哪些正確？

  1. r 的值是 3
  2. r 的值是 12
  3. 小括號內的 2 + 3 最先計算
  4. 乘法一定比同一級的除法先算

10 程式中有 const double RATE = 0.08;。下列敘述哪些正確？

  1. 程式中任何改寫 RATE 的敘述，都會被當成錯誤
  2. 加上 const 之後，RATE 只能存放整數
  3. 稅率這類在程式執行中不應被改動的數值，適合用 const 宣告
  4. 宣告之後，仍然可以再寫一行指定敘述把 RATE 改成 0.1

11 一個 int 變數的計算結果超出了 int 能表示的範圍（溢位）。依照 C 的規則，結果會如何？

  1. 自動改用 long long 存放，結果仍然正確
  2. 自動變成 int 能表示的最大值
  3. 編譯器一定會拒絕產生可執行檔
  4. 原則上是未定義的，什麼事都可能發生

12 下列關於 scanf 的敘述，哪些正確？

  1. scanf 會把讀到的值自動印在螢幕上
  2. scanf 的格式字串寫法和 printf 很像
  3. 程式執行到 scanf 時，不會停下來等待輸入
  4. scanf 需要改變變數的內容，所以要在變數前面加上 & 交出它的位址

13 使用 scanf 讀取時，變數型別和格式碼必須對應。下列哪些對應正確？

  1. 讀取 int 變數用 %d
  2. 讀取 double 變數用 %d
  3. 讀取 double 變數用 %lf
  4. 讀取 int 變數用 %lf

14 直接用 scanf 讀取鍵盤輸入時，使用者一旦輸入錯誤的資料，scanf 很容易停在半路，後面的讀取也跟著出錯。下列哪一種作法是建議的處理方式？

  1. 把程式中所有的 scanf 都改成 printf
  2. 先用 fgets 讀入一整行，再從那一行取出資料
  3. 每次輸入之前，先把電腦重新開機
  4. 把所有格式碼都改成只讀取一個字元

15 已宣告 int mon; 與 int day;，程式執行下列敘述時，使用者輸入 9/14 後按 Enter。下列敘述哪些正確？

int got = scanf("%d-%d", &mon, &day);
  1. got 的值是 2
  2. scanf 會把 / 自動當成 - 處理
  3. got 的值是 1
  4. day 沒有被存入任何值，不應該拿來計算

16 已宣告 int p; 與 int q;，程式執行下列敘述。使用者輸入 12 後按 Enter，再輸入 30 後按 Enter。結果如何？

scanf("%d %d", &p, &q);
  1. p 是 12，q 是 30
  2. p 是 12，q 沒有被讀取
  3. p 是 1230，q 沒有得到任何值
  4. 遇到換行就讀取失敗，p 與 q 都沒有得到值

17 數字 42 經由下列 printf 敘述輸出。螢幕上印出的內容是什麼？

printf("[%05d]\n", 42);
  1. [ 42]
  2. [42000]
  3. [00042]

18 五位數 98765 用下列敘述印出。螢幕上印出的內容是什麼？

printf("[%3d]\n", 98765);
  1. [987]

  4. [ 98765]

19 平均分數 avg 用下列敘述印出。下列敘述哪些正確？

double avg = 86.375;
printf("%.1f\n", avg);
  1. 螢幕上印出 86.4
  2. 印完之後，avg 的值仍然是 86.375
  3. 螢幕上印出 86.3
  4. printf 會把 avg 改存成 86.4

20 執行下列敘述。下列關於輸出的敘述，哪些正確？

printf("%-6s%6d\n", "tea", 3);
  1. 「tea」靠左對齊，連同後面補的空白共佔 6 格
  2. %s 用來印出一個整數
  3. 輸出是 tea3，中間沒有任何空白
  4. 不計換行，這一行輸出共佔 12 個字元位置
