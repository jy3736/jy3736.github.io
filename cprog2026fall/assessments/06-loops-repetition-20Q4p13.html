課後形成性評量：C 迴圈與重複處理

答對 60% 以上的題目（看答案的不算）後，可以下載含答案的 HTML 檔。作答紀錄不會保存，重新整理或離開頁面後會從頭開始。

共 20 題，每題 A 至 D 四個選項，每題正確選項為 1 至 3 個，請選出所有正確選項。

01 關於 while 小括號中的條件，下列敘述哪些正確？

  1. 條件的值不是 0 就視為真，會執行迴圈主體
  2. 條件為真時，主體執行完會回到開頭再檢查一次
  3. 條件只在程式開始時計算一次，之後就不再檢查
  4. 條件的值必須剛好是 0 才會執行迴圈主體

02 關於 do-while 的寫法與執行順序，下列敘述哪些正確？

  1. 先執行主體，每一輪結束時才計算條件
  2. 主體執行完就一定離開迴圈，最多只能執行一次
  3. 條件為真就再執行一次主體
  4. 結尾的 while 小括號後面要加上分號

03 執行下列程式片段後，下列敘述哪些正確？

int point = 0;
int week = 0;
while (point < 300) {
    point = point + 80;
    week = week + 1;
}
  1. 迴圈結束後 point 恰好是 300
  2. 迴圈結束後 week 是 4
  3. 迴圈結束後 point 是 320
  4. 迴圈主體一次都不會執行

04 執行下列程式片段後，下列敘述哪些正確？

int shown = 0;
int tries = 0;
do {
    shown = shown + 1;
    tries = tries + 1;
} while (tries < 0);
printf("shown = %d\n", shown);
  1. 迴圈主體執行了一次
  2. 螢幕印出 shown = 0
  3. 程式會一直重複執行下去
  4. 螢幕印出 shown = 1

05 使用者依序輸入 9、0、2。執行下列程式片段後，下列敘述哪些正確？

int no = 0;
do {
    printf("請輸入 1 到 4 的代號：");
    scanf("%d", &no);
} while (no < 1 || no > 4);
printf("代號 %d\n", no);
  1. 輸入 9 之後就會離開迴圈
  2. 提示文字總共顯示 3 次
  3. 螢幕最後印出 代號 2
  4. 提示文字只會顯示 1 次

06 在 for 小括號裡用分號隔開的三個部分分別是起始、繼續條件與前進。關於它們的執行時機，下列敘述哪些正確？

  1. 起始只在最開始執行一次
  2. 繼續條件在每一輪開始前計算
  3. 三個部分在每一輪都各執行一次
  4. 前進在每一輪主體執行完之後執行

07 關於在 for 的起始部分直接宣告迴圈變數，下列敘述哪些正確？

  1. 離開迴圈之後仍然可以繼續使用這個變數
  2. 起始的部分不能宣告新的變數
  3. 這樣宣告的變數只在這個 for 裡面有效
  4. 這樣宣告的變數一定要給初始值

08 執行下列程式片段後，螢幕上印出的內容是什麼？

int line = 0;
for (int step = 5; step <= 40; step = step + 5) {
    line = line + 1;
}
printf("line = %d\n", line);
  1. line = 8
  2. line = 7
  3. line = 9
  4. line = 40

09 執行下列程式片段後，螢幕上印出的內容是什麼？

int done = 0;
for (int g = 6; g <= 2; g++) {
    done = done + 1;
}
printf("done = %d\n", done);
  1. done = 1
  2. done = 0
  3. done = 4
  4. done = 6

10 執行下列程式片段後，下列敘述哪些正確？

int p = 7;
int u = 100 + p++;
int q = 7;
int v = 100 + ++q;
  1. u 的值是 107
  2. u 與 v 的值相等
  3. v 的值是 108
  4. 最後 p 與 q 都是 8

11 關於單獨成一行的遞增與遞減運算子，下列敘述哪些正確？

  1. 單獨成一行的 i++ 會把 i 變成 0
  2. 單獨成一行的 i++ 意思就是 i = i + 1
  3. 單獨成一行的 i-- 意思就是 i = i - 1
  4. 遞增運算子只能寫在迴圈的繼續條件裡

12 執行下列程式片段後，下列敘述哪些正確？

int rounds = 0;
for (int w = 1; w <= 5; w++);
{
    rounds = rounds + 1;
}
printf("rounds = %d\n", rounds);
  1. 螢幕印出 rounds = 1
  2. 大括號裡的敘述已經不屬於迴圈，只執行一次
  3. 螢幕印出 rounds = 5
  4. 編譯時會出現「迴圈主體是空的」這一類警告

13 關於 break; 的作用，下列敘述哪些正確？

  1. 會讓整個程式立刻結束執行
  2. 只能寫在 switch 裡面，不能寫在迴圈裡
  3. 會立刻離開最內層的迴圈
  4. 迴圈有好幾層時，只會離開包住它的那一層

14 關於 continue; 的作用，下列敘述哪些正確？

  1. 會放棄這一輪剩下的步驟，直接進入下一輪
  2. 在 for 迴圈中，接下來仍然會執行前進的部分
  3. 適當使用可以減少 if 一層包一層的情況
  4. 只能用在 while 迴圈，不能用在 for 迴圈

15 執行下列程式片段後，下列敘述哪些正確？

int box = 0;
for (int e = 1; e <= 11; e = e + 2) {
    box = box + e;
}
  1. box 最後是 36
  2. box 最後是 66
  3. 前進的部分每次只能加 1，不能加 2
  4. 迴圈主體總共執行 6 次

16 某支程式用 printf("%d x %d = %2d\n", n, i, n * i); 印出乘法表的一列。關於其中的 %2d，下列敘述哪些正確？

  1. 它讓印出的結果保留小數 2 位
  2. 它讓印出的結果至少佔 2 格
  3. 個位數的結果前面會補一個空白，等號後面的數字才會對齊
  4. 它讓印出的結果變成原來的 2 倍

17 要在螢幕上印出 1 到 100 時，用迴圈取代 100 行相同的輸出敘述。關於迴圈，下列敘述哪些正確？

  1. 迴圈讓同一段程式碼重複執行
  2. 迴圈重複的次數固定是 10 次，不能改變
  3. 迴圈必須寫在 main 之外才會生效
  4. 每一輪之前或之後會檢查一個條件，決定要不要再來一次

18 關於什麼時候適合選用 for 迴圈，下列敘述哪些正確？

  1. 同樣的迴圈不可能改用 while 寫出來
  2. 事先就知道要重複幾次時特別合適
  3. 它把「從哪裡開始、做到什麼時候、每次怎麼前進」寫在同一行，比較精簡
  4. 它只能用來印出 1 到 9 這九個數字

19 執行下列程式片段後，下列敘述哪些正確？

int stars = 0;
for (int band = 1; band <= 3; band++) {
    for (int slot = 1; slot <= 4; slot++) {
        stars = stars + 1;
    }
}
  1. stars 最後是 12
  2. stars 最後是 7
  3. 內層迴圈只會在外層的第一輪執行
  4. 外層每跑一輪，內層都從 slot 等於 1 重新開始

20 某支程式的 while 條件是 stock < 500，stock 一開始是 0，而迴圈主體從頭到尾都沒有改變 stock 的值。下列敘述哪些正確？

  1. 迴圈會在第 5 輪自動停止
  2. 條件不會變成假，程式會一直重複下去
  3. 這種情形就是無窮迴圈
  4. 編譯器會拒絕編譯，無法產生執行檔
