課前前測：C 迴圈與重複處理

共 20 題，每題 A 至 D 四個選項，只有一個正確選項。

01 執行下列程式片段後，螢幕上印出的內容是什麼？

int water = 0;
int cups = 0;
while (water < 900) {
    water = water + 250;
    cups = cups + 1;
}
printf("cups = %d\n", cups);
  1. cups = 4
  2. cups = 3
  3. cups = 5
  4. cups = 900

02 執行下列程式片段時，螢幕上會印出幾行文字？

int k = 8;
do {
    printf("走一次\n");
    k = k + 1;
} while (k < 4);
  1. 零行
  2. 一行
  3. 四行
  4. 八行

03 某支程式的 while 條件是 boxes < 12，boxes 一開始是 0，而迴圈主體從頭到尾都沒有改變 boxes 的值。執行這段程式會發生什麼事？

  1. 迴圈主體只執行一次就自動停止
  2. 迴圈主體一次都不會執行
  3. 條件不會變成假，程式會一直重複下去，形成無窮迴圈
  4. 編譯器會拒絕編譯，無法產生執行檔

04 使用者依序輸入 8、0、3。執行下列程式片段後，螢幕最後一行印出的內容是什麼？

int pick = 0;
do {
    printf("請輸入 1 到 3：");
    scanf("%d", &pick);
} while (pick < 1 || pick > 3);
printf("選擇 %d\n", pick);
  1. 選擇 8
  2. 選擇 0
  3. 這段程式不會印出任何內容
  4. 選擇 3

05 下列哪一項正確描述 while 迴圈每一輪的執行順序？

  1. 每一輪開始時先計算條件，條件為真才執行主體
  2. 每一輪先執行主體，等到主體跑完才計算條件
  3. 條件只在程式開始時計算一次，之後就不再檢查
  4. 主體與條件同時進行，先後順序由編譯器決定

06 在 for 小括號裡用分號隔開的三個部分中，「起始」這一段的執行時機是什麼？

  1. 每一輪主體執行完之後都會執行一次
  2. 只在最開始執行一次
  3. 每一輪開始前都會重新執行一次
  4. 要等整個迴圈結束之後才執行

08 在 for 的起始部分直接宣告的迴圈變數，在迴圈結束之後再拿來使用會怎樣？

  1. 這個變數會自動歸零，之後仍可正常使用
  2. 這個變數在整個 main 裡都有效，之後仍可正常使用
  3. 這個變數會保留最後一輪的值，之後仍可正常使用
  4. 這個變數只在該 for 裡面有效，離開迴圈之後不能再使用

12 單獨成一行的 i-- 相當於下列哪一個敘述？

  1. i = i + 1;

  3. i = i - 2;
  4. i = i - 1;

13 下列哪一種使用遞增運算子的方式最不容易造成混淆？

  1. 把 i++ 單獨寫成一行，或只用在 for 的前進部分
  2. 把 i++ 放進比較長的算式裡，讓程式看起來精簡
  3. 在同一行中對同一個變數連續使用兩次 i++
  4. 把 i++ 寫進迴圈的繼續條件，同時當成判斷依據

17 要在螢幕上印出 1 到 100，與寫 100 行相同的輸出敘述相比，改用迴圈的好處是什麼？

  1. 同一段程式碼可以重複執行，每一輪之前或之後檢查一個條件，決定要不要再來一次
  2. 程式完全不需要任何條件判斷就能自動停止
  3. 輸出的數字會自動改成由大到小排列
  4. 所有結果在編譯時就算好，執行時不必再計算

18 某支程式用 printf("%d x %d = %2d\n", n, i, n * i); 印出乘法表的一列。其中 %2d 的作用是什麼？

  1. 讓印出的結果保留小數 2 位
  2. 讓印出的結果至少佔 2 格，個位數前面補一個空白，等號後面的數字才會對齊
  3. 讓印出的結果變成原來的 2 倍
  4. 讓這一列只印出 2 個數字就換行

19 若 for 的「繼續條件」在第一次檢查時就是假，迴圈主體會執行幾次？

  1. 一次
  2. 兩次
  3. 零次
  4. 無限次

20 事先就知道要重複固定次數時，選用 for 而不是 while 的主要好處是什麼？

  1. for 的執行速度一定比 while 快
  2. for 不需要任何條件就能自己停下來
  3. for 的主體可以省略大括號，while 的主體不行
  4. for 把控制迴圈的三件事集中寫在同一行，比較精簡，一眼就看得出會跑幾次
