15 在 C 語言中，一個等號是「存入」，兩個等號才是比較。下列程式片段編譯後執行，會有什麼結果？

int answer = 3;
if (answer = 5) {
    printf("相等\n");
}
  1. 不會印出任何內容，因為 answer 原本的值是 3
  2. 編譯失敗，無法產生執行檔
  3. 一定會印出「相等」，因為小括號內是把 5 存入 answer，運算式的值 5 不是 0
  4. 會印出「相等」兩行

16 執行下列程式片段後，螢幕上印出的內容是什麼？

int mark = 76;
if (mark >= 90) {

} else if (mark >= 80) {
    printf("等第 B\n");
} else if (mark >= 70) {
    printf("等第 C\n");
} else {
    printf("等第 D\n");
}
  1. 等第 A
  2. 等第 B
  3. 等第 C
  4. 等第 D

17 下列程式片段執行時不會發生除以 0 的錯誤，原因是什麼？

int sum = 300;
int people = 0;
if (people != 0 && sum / people >= 60) {
    printf("平均及格\n");
} else {
    printf("沒有資料\n");
}
  1. 「而且」運算子左邊的條件為假時，右邊的運算式就不會被計算
  2. C 語言會自動把除以 0 的結果當成 0
  3. 右邊的除法會先算出來，只是結果被忽略
  4. 小括號裡的條件一律從最右邊開始計算

18 連續寫好幾個 case 標籤共用同一段程式碼，是常見的寫法。執行下列程式片段後，螢幕上印出什麼？

int code = 3;
switch (code) {
    case 2:
    case 3:
        printf("藍色\n");
        break;
    case 4:
        printf("綠色\n");
        break;
    default:
        printf("未定義\n");
        break;
}
  1. 綠色
  2. 藍色
  3. 未定義
  4. 不會印出任何內容

19 執行下列程式片段後，螢幕上會出現什麼？

int level = 1;
switch (level) {
    case 1:
        printf("第一層\n");
    case 2:
        printf("第二層\n");
        break;
    case 3:
        printf("第三層\n");
        break;
}
  1. 只印出「第一層」一行
  2. 印出「第一層」與「第二層」兩行
  3. 只印出「第二層」一行
  4. 印出「第一層」、「第二層」與「第三層」三行

20 關於 switch 敘述中 case 後面所寫的值，下列敘述何者正確？

  1. 可以是任何運算式，包括執行時才決定的變數
  2. 必須是編譯時就能確定的整數常數，而且不能有兩個 case 使用同一個值
  3. 必須是有小數的浮點數常數
  4. 必須由小到大排列，否則無法編譯
