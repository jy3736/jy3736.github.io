  2. r 是 7，s 是 0
  3. r 是 1，s 是 7
  4. r 是 0，s 是 1

10 檢查門是否開著的程式片段如下。執行時會發生什麼事？

int door = 0;
if (door = 1) {
    printf("門開著\n");
}
  1. 不印出任何內容，因為 door 原本是 0
  2. 編譯失敗，因為 if 的條件裡不能出現 =
  3. 印出「門開著」，因為 door = 1 會把 1 存進 door，這個運算式的值不是 0，條件成立
  4. 程式會停下來，等使用者輸入 door 的值

16 用總和 sum 與人數 n 判斷平均的程式片段如下。執行時會發生什麼事？

int sum = 300;
int n = 0;

  3. 兩行訊息都會印出
  4. 左邊的 n != 0 為假，右邊不會被計算，印出「無法判斷」

18 依關卡 stage 解鎖題目的程式片段如下。螢幕上印出的內容是什麼？

int stage = 1;
switch (stage) {
    case 1:
        printf("基本\n");
    case 2:
        printf("進階\n");
    case 3:
        printf("挑戰\n");
        break;
    default:
        printf("不存在\n");
        break;
}
  1. 只有一行「基本」
  2. 兩行：「基本」、「進階」
  3. 三行：「基本」、「進階」、「挑戰」
  4. 四行：「基本」、「進階」、「挑戰」、「不存在」

20 下列關於 switch 中 case 標籤的敘述，何者正確？

  1. case 後面可以寫範圍條件，例如分數大於或等於 90
  2. case 後面的值必須是編譯時就能確定的整數常數，而且不能有兩個 case 是同一個值
  3. case 後面可以寫有小數的值，例如 2.5
  4. 兩個 case 可以寫同一個值，符合時兩段都會執行
