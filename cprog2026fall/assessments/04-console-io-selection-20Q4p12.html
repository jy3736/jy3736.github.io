01 下列關於 scanf 的敘述，哪些正確？

  1. scanf 讓程式在執行時停下來，等待從鍵盤輸入資料
  2. 每次呼叫 scanf，都會先清除螢幕上原有的內容
  3. scanf 依照格式字串解析輸入，再把結果存進提供的變數
  4. scanf 讀到的值會自動印在螢幕上

02 已宣告 int qty; 與 int box;，執行下列敘述時，使用者輸入 3 abc 後按 Enter。ok 的值是多少？

int ok = scanf("%d %d", &qty, &box);
  1. 0
  2. 1
  3. 2
  4. 3

03 使用 scanf 讀取時，變數型別和格式碼必須對應。下列哪些對應正確？

  1. 讀取 double 變數用 %d
  2. 讀取 float 變數用 %f
  3. 讀取 float 變數用 %d
  4. 讀取 double 變數用 %lf

04 已宣告 int r; 與 int k;，程式執行 scanf("%d,%d", &r, &k);。要讓 r 讀到 3、k 讀到 4，使用者應該輸入什麼？

  1. 3,4
  2. 3 4
  3. 3;4
  4. 3/4

05 圓周率近似值 3.14159 放進下列格式中印出。螢幕上印出的內容是什麼？

printf("[%-7.2f]\n", 3.14159);
  1. [ 3.14]
  2. [3.14159]
  3. [3.14 ]
  4. [0003.14]

06 小數 78.6 用下列敘述印出。螢幕上印出的內容是什麼？

printf("%.0f\n", 78.6);
  1. 78
  2. 78.6
  3. 78.0
  4. 79

07 執行下列敘述。下列關於這一行輸出的敘述，哪些正確？

printf("%-6s%6d%8d\n", "tea", 3, 135);
  1. 不計換行，這一行共佔 20 個字元位置
  2. 「tea」前面會補 3 個空白
  3. 數字 3 緊接在「tea」後面，中間沒有空白
  4. 數字 135 前面會補 5 個空白

08 下列關於 scanf 格式碼在讀取前是否跳過空白的敘述，哪些正確？

  1. 所有格式碼在讀取前都不會跳過空白
  2. %d 在讀取前會自動跳過空白和換行
  3. %c 在讀取前不會自動跳過空白
  4. %lf 在讀取前不會跳過換行

09 下列關於比較運算子的敘述，哪些正確？

  1. != 表示「不等於」
  2. 比較的結果是一個數字：條件成立時是 1，不成立時是 0
  3. >= 只表示「大於」，不包含等於
  4. <= 表示「小於」，不包含等於

10 下列關於 = 與 == 的敘述，何者正確？

  1. 兩者意思相同，可以互換使用
  2. = 判斷兩邊是否相等，== 把值存入變數
  3. == 只能用在 switch 敘述中
  4. == 判斷兩邊是否相等，= 則是把右邊的值存入左邊的變數

11 依 v 的大小印出訊息的程式片段如下（注意最後一個 printf 的縮排）。螢幕上印出的內容是什麼？

int v = 3;
if (v > 5)
    printf("大\n");
else
    printf("小\n");
    printf("完成\n");
  1. 只有一行「小」
  2. 兩行：「大」、「完成」
  3. 兩行：「小」、「完成」
  4. 只有一行「完成」

12 依氣溫 t 分成四種感受的程式片段如下。下列敘述哪些正確？

int t = 18;
if (t >= 30) {
    printf("熱\n");
} else if (t >= 20) {
    printf("溫暖\n");
} else if (t >= 10) {
    printf("涼\n");
} else {
    printf("冷\n");
}
  1. 印出「涼」和「冷」兩行
  2. 因為 t >= 10 成立，最後的 else 那段也會執行
  3. 只印出一行「涼」
  4. t >= 30 與 t >= 20 都被檢查過，而且結果都是假

13 main 中依序執行下列敘述。執行完後，x 與 y 的值各是多少？

int a = -2;
int b = 0;
int x = a && 1;
int y = !b;
  1. x 是 1，y 是 1
  2. x 是 -2，y 是 0
  3. x 是 0，y 是 1
  4. x 是 1，y 是 0

14 用總分 tot 與人數 cnt 判斷平均是否及格的程式片段如下。下列敘述哪些正確？

int cnt = 0;
int tot = 90;
if (cnt != 0 && tot / cnt >= 60) {
    printf("平均及格\n");
} else {
    printf("沒有資料\n");
}
  1. 程式會先計算 tot / cnt，發生除以 0 的問題
  2. 右邊的 tot / cnt 不會被計算
  3. 螢幕上印出「平均及格」
  4. 螢幕上印出「沒有資料」

15 依年齡 age 決定票種的程式片段如下。下列敘述哪些正確？

int age = 70;
if (age < 12 || age >= 65) {
    printf("半價\n");
} else {
    printf("全票\n");
}
  1. 螢幕上印出「半價」
  2. 螢幕上印出「全票」，因為 age < 12 為假
  3. age < 12 為假，但 age >= 65 為真，所以整個條件成立
  4. || 要左右兩邊都為真，整個條件才成立

16 在同一個條件中同時使用 && 和 || 時，建議採用哪一種寫法？

  1. 不加括號，直接依賴兩個運算子之間的優先順序
  2. 一律加上括號，標明哪一部分先算
  3. 改寫成兩個 switch 敘述
  4. 把 && 改成單一個 &

17 下列關於 switch 敘述的說明，哪些正確？

  1. 沒有 default 時，只要值對不上任何 case，編譯就會失敗
  2. 兩個 case 可以寫同一個值，符合時兩段都會執行
  3. switch 計算小括號裡的整數值，再跳到對應的 case 開始執行
  4. default 處理所有沒有對應 case 的值

18 依關卡 stage 解鎖題目的程式片段如下。下列敘述哪些正確？

int stage = 2;
switch (stage) {
    case 1:
        printf("基本\n");
    case 2:
        printf("進階\n");
    case 3:
        printf("挑戰\n");
        break;
    default:
        printf("不存在\n");
        break;
}
  1. 螢幕上印出「進階」、「挑戰」兩行
  2. 螢幕上只印出一行「進階」
  3. 若希望每個等級只印出自己那一行，應在每個 case 的結尾都加上 break
  4. 編譯會失敗，因為 case 1 與 case 2 的結尾沒有 break

19 下列哪一種情況，最適合用 else if 鏈而不是 switch 來寫？

  1. 依選單代碼 1、2、3 執行不同功能
  2. 判斷身高是否超過 175.5 公分
  3. 依星期代碼 1 到 7 顯示當天課表
  4. 依月份代碼 1 到 12 顯示該月天數

20 查詢庫存 stock 的程式片段如下。螢幕上印出的內容是什麼？

int stock = 0;
if (stock > 0) {
    printf("有貨\n");
}
printf("查詢完畢\n");
  1. 兩行：「有貨」、「查詢完畢」
  2. 只有一行「有貨」
  3. 什麼都不印
  4. 只有一行「查詢完畢」
