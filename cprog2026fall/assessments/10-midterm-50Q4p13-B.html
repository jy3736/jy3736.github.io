10 某支程式的開頭寫了 const int LIMIT = 50;。關於 const，下列哪些敘述正確？

本題的正確選項有 3 個。

  1. 使用者輸入 2026 10 24 後按 Enter，三個變數也都能讀到值
  2. 使用者輸入 2026-10-24 後按 Enter，三個變數依序讀到 2026、10、24
  3. 使用者輸入 2026/10/24 後按 Enter，只有 year 讀到值
  4. 格式字串中的 - 是一般字元，輸入中必須在相同位置出現 -

44 依星期代碼 day 印出平日或週末的程式片段如下。下列哪些敘述正確？

int day = 6;
switch (day) {
    case 1:
    case 2:
    case 3:
    case 4:
    case 5:
        printf("平日\n");
        break;
    case 6:
    case 7:
        printf("週末\n");
        break;
    default:
        printf("錯誤\n");
}

本題的正確選項有 3 個。

  1. 若把 day 改成 0，什麼都不會印出
  2. 執行後印出「週末」
  3. 若把 day 改成 2，會印出「平日」
  4. 連續寫好幾個 case 標籤，可以共用同一段程式碼

45 執行下列程式片段後，下列哪些敘述正確？

int p = 7;
int a = 3 + p++;
int q = 7;
int b = 3 + ++q;

本題的正確選項有 2 個。

  1. 執行完之後，p 的值仍然是 7
  2. a 與 b 的值相等
  3. a 的值是 10
  4. b 的值是 11

46 執行下列程式片段後，下列哪些敘述正確？

int sum = 0;
for (int i = 1; i <= 6; i++) {
    if (i % 3 == 0) {
        continue;
    }
    sum = sum + i;
}

本題的正確選項有 3 個。

  1. sum 最後是 12
  2. 執行 continue 時，整個迴圈立刻結束
  3. i 為 3 和 6 的那兩輪，sum 沒有被加上
  4. 執行 continue 之後，仍然會執行 i++ 再檢查條件

47 下列程式（已引入標準輸入輸出標頭檔）執行後，下列哪些敘述正確？

int addTen(int score);

  3. 第二行印出 85
  4. 第二行印出 75

48 某支程式在 main 裡有下列兩個陣列宣告。下列哪些敘述正確？

int seats[] = {3, 8, 5};
int lamp[6] = {[1] = 4, 9};

本題的正確選項有 2 個。

  1. lamp 的第一格沒有指定，所以裡面是無法預測的垃圾值
  2. seats 沒寫長度，所以編譯會失敗
  3. seats 沒寫長度，編譯器依大括號裡的值配置 3 格
  4. lamp 的內容依序是 0 4 9 0 0 0

49 下列程式片段讀取成績，輸入 -1 代表結束。使用者輸入 70 85 -1 後按 Enter。下列哪些敘述正確？

#define MAX 4
int scores[MAX];
int count = 0;
int value;
while (count < MAX && scanf("%d", &value) == 1 && value != -1) {
    scores[count] = value;
    count++;
}

本題的正確選項有 3 個。

  1. 迴圈結束後，count 是 2
  2. 若改成輸入 70 85 90 60 55 -1，count 最多只會到 4
  3. -1 也會被存進 scores[2]
  4. 之後要印出讀到的資料時，迴圈條件應寫成小於 count，而不是小於 MAX
