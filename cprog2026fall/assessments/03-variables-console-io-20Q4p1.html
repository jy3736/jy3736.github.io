04 在大多數電腦上，下列哪一個整數型別的大小敘述正確？

  1. int 佔 4 位元組（32 位元）
  2. short 佔 1 位元組（8 位元）
  3. long long 佔 4 位元組（32 位元）
  4. long 在所有電腦上都固定佔 8 位元組

05 下列關於浮點數型別 double 與 float 的敘述，何者正確？

  1. float 使用 64 位元，是一般情況下應該優先使用的浮點數型別
  2. double 使用 64 位元，是一般情況下應該使用的浮點數型別；float 使用 32 位元，主要用在需要節省空間的場合
  3. 兩者都只能存放整數，不能存放有小數的數值
  4. 兩者佔用的空間完全相同，只是名稱不同

  2. 可以編譯，但執行後 LIMIT 仍然是 30

  4. 可以編譯，執行後 LIMIT 變成 70

11 在 scanf("%d", &qty); 中，變數 qty 前面的 & 有什麼作用？

  1. 把 qty 的位址交給 scanf，讓 scanf 能改變 qty 的內容
  2. 讓讀進來的數值自動變成兩倍
  3. 表示 qty 是不能被修改的常數
  4. 讓輸入的數字自動四捨五入成整數

14 已宣告 int x; 與 int y;，程式執行下列敘述。使用者先輸入 5 按 Enter，再輸入 8 按 Enter。結果如何？

scanf("%d%d", &x, &y);

  2. x 是 5，y 是 8

  4. 遇到換行就讀取失敗，x 與 y 都沒有得到值
