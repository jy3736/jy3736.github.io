01 C 語言的變數名稱可以使用英文字母、數字與底線，但不能以數字開頭、不能以兩個底線開頭，也不能以「底線加大寫字母」開頭。下列哪些是合法的變數名稱？

  1. priceTag
  2. __count
  3. _Total
  4. item_3

02 關於下列程式片段，哪些敘述正確？

int coins = 120;
coins = coins - 45;
coins = coins * 2;
printf("%d\n", coins);
  1. 第三行先算出 coins 乘以 2 的結果，再把結果存回 coins
  2. 最後印出 150
  3. 第二行執行完後，coins 的值是 75
  4. 最後印出 240

03 關於 C 的資料型別與 sizeof，下列哪些敘述正確？（位元組數以大多數電腦為準）

  1. float 使用 64 位元，是一般情況下應該優先使用的浮點數型別
  2. 無號（unsigned）整數型別可以存放負數
  3. sizeof 的結果型別是 size_t，用 %zu 印出
  4. short 佔 2 位元組

04 兩個整數相除時，結果仍然是整數。下列哪些運算式的值是 3？

  1. 17 / 5
  2. 17 % 7
  3. 15 / 4
  4. -17 / 5

05 已宣告 int p = 9; 與 int q = 4;，下列哪些運算式算出的值是 2.25？

  1. p / q
  2. p / (double)q
  3. (double)(p / q)
  4. (double)p / q

06 某支程式的開頭寫了 const int LIMIT = 50;。關於 const，下列哪些敘述正確？

  1. 程式後面若寫了 LIMIT = 60;，編譯會失敗
  2. 在宣告前面加上 const，這個變數就不能再被指定新的值
  3. 像稅率、折扣這種在程式執行中不應該被改動的數值，適合用 const 宣告
  4. 程式後面若寫了改寫 LIMIT 的敘述，只會出現警告，執行後 LIMIT 就變成新的值

07 乘、除比加、減先算，同一級由左到右，小括號可以指定先算的部分。下列哪些運算式的值是 20？

  1. (1 + 4) * 5
  2. 40 / 4 / 2
  3. 30 - (6 - 4)
  4. 2 + 3 * 6

08 已宣告 float f; 與 int n;，下列哪些 scanf 呼叫能把輸入的數值正確存進這兩個變數？

  1. scanf("%f %d", &n, &f);
  2. scanf("%d %f", &n, &f);
  3. scanf("%lf %d", &f, &n);
  4. scanf("%f %d", &f, &n);

09 scanf 會回傳成功存進變數的項目數。執行下列程式片段時，使用者輸入 7 x 後按 Enter，螢幕上印出什麼？

int a;
int b;
int got = scanf("%d %d", &a, &b);
printf("%d\n", got);
  1. 0
  2. 2
  3. 1
  4. 7

10 關於 scanf 的格式碼在讀取前是否會跳過空白與換行，下列哪些敘述正確？

  1. %d 讀取前會自動跳過空白與換行
  2. %c 讀取前也會自動跳過空白
  3. 用 "%d %d" 讀兩個整數時，把兩個數分成兩行輸入，結果和用空白隔開相同
  4. %lf 讀取前不會跳過換行，所以前一行留下的換行會讓讀取失敗

11 格式字串中的一般字元必須在輸入中出現於相同位置。執行下列程式片段時，使用者輸入哪些內容，能讓 mon 得到 3、day 得到 15？

int mon;
int day;
scanf("%d/%d", &mon, &day);
  1. 3 15
  2. 3,15
  3. 3-15
  4. 3/15

12 已宣告 int big = 123456;，下列哪些 printf 呼叫與它印出的內容對應正確？

  1. printf("[%3d]", big); 印出 [123456]
  2. printf("[%08d]", big); 印出 [00123456]
  3. printf("[%07d]", big); 印出 [1234560]
  4. printf("[%2d]", big); 印出 [12]

13 已宣告 double avg = 63.758;，關於用 printf 印出 avg，下列哪些敘述正確？

  1. 用 %.1f 印出 63.8
  2. 用 %.0f 印出 64
  3. 用 %f 印出 63.758
  4. 用 %.1f 印出之後，avg 本身的值變成 63.8

14 關於下列程式片段印出的那一行，哪些敘述正確？

printf("%-5s%7d\n", "pen", 30);
  1. %s 只能印出單一字元，所以只會印出 p
  2. 30 靠右對齊，左邊補 5 個空白
  3. 不含換行字元，這一行共佔 12 個字元位置
  4. pen 印在欄位的左邊，右邊補空白湊滿 5 格

15 執行下列程式片段後，螢幕上會出現什麼？

int temp = 31;
if (temp >= 30) {
    printf("開冷氣\n");
} else {
    printf("開窗\n");
}
printf("完成\n");
  1. 印出「開冷氣」與「完成」兩行
  2. 只印出「開冷氣」一行
  3. 只印出「完成」一行
  4. 印出「開窗」與「完成」兩行

16 關於下列程式片段，哪些敘述正確？

int lives = 0;
if (lives = 2) {
    printf("繼續\n");
}
  1. 一定會印出「繼續」
  2. 因為 lives 原本是 0，所以不會印出任何內容
  3. 編譯時可能出現「把指定的結果當成條件」的警告
  4. 執行後 lives 的值變成 2

17 關於下列程式片段，哪些敘述正確？

int s = 95;
if (s >= 60) {
    printf("及格\n");
} else if (s >= 90) {
    printf("優秀\n");
} else {
    printf("加油\n");
}
  1. 執行後印出「優秀」
  2. 執行後印出「及格」
  3. 不論 s 是多少，「優秀」都不可能印出
  4. 範圍條件應該從最嚴格的條件開始寫

18 關於下列程式片段的執行，哪些敘述正確？

int n = 0;
if (n != 0 && 50 / n > 2) {
    printf("高\n");
} else {
    printf("低\n");
}
  1. 不會發生除以 0，螢幕印出「低」
  2. 條件中的 50 / n 會先被計算，只是結果被忽略
  3. 把 && 兩邊的條件對調後，仍然不會發生除以 0
  4. 螢幕印出「高」

19 關於下列程式片段，哪些敘述正確？

int stage = 1;
switch (stage) {
    case 1:
        printf("甲\n");
    case 2:
        printf("乙\n");
        break;
    case 3:
        printf("丙\n");
        break;
}
  1. 執行後會印出「丙」
  2. case 結尾沒有 break 而繼續執行下一個 case 的程式碼，稱為貫穿（fall through）
  3. 如果貫穿是刻意的，應該加上註解說明
  4. 執行後依序印出「甲」與「乙」兩行

20 關於 switch 敘述中的 case 與 default，下列哪些敘述正確？

  1. 沒有 default，而值又對不上任何 case 時，switch 什麼都不做
  2. case 後面的值必須是編譯時就能確定的整數常數
  3. 同一個 switch 裡可以有兩個 case 使用同一個值
  4. 可以寫 case 2.5: 來比對有小數的數值
