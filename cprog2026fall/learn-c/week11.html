關於位址的數值：實際的位址每次執行都可能不同。本講義凡是印出位址的地方，都只標示「一串十六進位數字」，追蹤表中的位址（例如 1000）是為了說明而假設的數字，這和練習檔「位址為假設值」的作法相同。

1. 位址與取址運算子 &

用白話說

電腦的記憶體就像一整條街上的信箱，每個信箱都有一個門牌號碼。你宣告一個變數，就等於租下一個（或幾個相連的）信箱來放資料。這個門牌號碼就是變數的位址（address）。

&變數 的意思是「告訴我這個變數的門牌號碼」。其實你從第 4 週就在用它了：scanf("%d", &age) 就是把 age 的門牌號碼交給 scanf，讓它知道要把讀到的數字放進哪個信箱。

教材怎麼說

  • 記憶體中的每一個位元組都用一個整數來識別，這些整數依序遞增；代表每個位置的數字稱為位址。可以把記憶體想成一排編了號的格子，每格放一個位元組。出處：Beej §5.1 Memory and Variables。
  • 像 int 這類佔用多個位元組的型別，它的位元組在記憶體中一定是相鄰的。出處同上。
  • 產生指標最基本的方法是用取址運算子 &：&i 得到變數 i 的位址，&a[3] 得到陣列 a 索引 3 那一格的位址。出處：GNU C 手冊 §14.1 Address of Data。

補充範例 1-1：印出變數的位址

檔名 address.c：

#include <stdio.h>

int main(void)
{
    int age = 19;
    double height = 172.5;

    printf("age 的值是 %d，位址是 %p\n", age, (void *)&age);
    printf("height 的值是 %.1f，位址是 %p\n", height, (void *)&height);
    printf("age 佔 %zu 位元組，height 佔 %zu 位元組\n", sizeof age, sizeof height);
    return 0;
}

執行結果的樣子（位址的數字每台電腦、每次執行都可能不同）：

age 的值是 19，位址是 0x16f5a2b3c
height 的值是 172.5，位址是 0x16f5a2b30
age 佔 4 位元組，height 佔 8 位元組

一步一步看

  1. %p 是用來印出位址的格式碼，位址通常以 0x 開頭的十六進位數字顯示。
  2. (void *)&age 中的 (void *) 是把位址轉成 printf 的 %p 所期待的型別。本講義在引用的教材中沒有找到這個轉型的完整說明，這裡依照 -Wpedantic 的要求加上。
  3. 「值」是信箱裡的東西（19），「位址」是信箱的門牌號碼，兩者是不同的東西。

2. 指標變數與解參照 *

用白話說

指標（pointer）是一種專門用來存放「門牌號碼」的變數。

  • int *p;：宣告一個指標 p，它存放的是「某個 int 的門牌號碼」。
  • p = &score;：把 score 的門牌號碼存進 p，我們說「p 指向 score」。
  • *p：照著 p 裡的門牌號碼找到那個信箱，打開來用。讀 *p 就是讀 score，改 *p 就是改 score。

教材怎麼說

宣告指標

  • 在型別之後、變數名稱之前加上星號 *，就宣告了一個指標。int *p; 的型別是「指向 int 的指標」，它可以存放其他 int 的位址。出處：Beej §5.2 Pointer Types。
  • 對一個變數取址，得到的就是「指向那個型別的指標」，所以 int *p = &i; 的左右兩邊型別剛好一致。出處同上。
  • 星號屬於變數，不屬於型別名稱。所以 int *p, q; 只宣告了一個指標 p，q 只是普通的 int。出處：Beej §5.6 A Note on Declaring Pointers。

解參照

  • 透過指標取用它所指的資料，稱為解參照（dereference），運算子是 *。如果 p 指向 i，*p 就可以完全當成 i 來使用。出處：Beej §5.3 Dereferencing；GNU C 手冊 §14.5 Dereferencing Pointers。
  • 宣告時的 * 和解參照的 * 是同一個符號，但在不同的地方意思不同。出處：Beej §5.3。
寫在哪裡 例子 意思
宣告中 int *p; p 是指向 int 的指標
運算式中 *p = 5; 把 5 存進 p 所指的地方

對照練習

練習「單元 1」的基本範例宣告指標並印出位址，延伸練習讓指標改指向另一個變數；「單元 2」的基本範例透過 * 讀取與修改資料。下面的補充範例用追蹤表把「變數、位址、指標」三者的關係並排列出來。

補充範例 2-1：透過指標修改變數

檔名 deref.c：

#include <stdio.h>

int main(void)
{
    int stock = 10;
    int *p = &stock;

    printf("一開始：stock = %d，*p = %d\n", stock, *p);

    *p = *p - 3;
    printf("賣出 3 件後：stock = %d，*p = %d\n", stock, *p);

    stock = stock + 20;
    printf("進貨 20 件後：stock = %d，*p = %d\n", stock, *p);
    return 0;
}

預期輸出：

一開始：stock = 10，*p = 10
賣出 3 件後：stock = 7，*p = 7
進貨 20 件後：stock = 27，*p = 27

一步一步看（假設 stock 的位址是 1000）

執行到的敘述 stock（位址 1000） p 存的值 *p
int stock = 10; 10 尚未宣告
int *p = &stock; 10 1000 10
*p = *p - 3; 7 1000 7
stock = stock + 20; 27 1000 27
  • p 裡存的一直是 1000，從來沒有改變；改變的是位址 1000 那格裡的數字。
  • 不論是透過 stock 還是透過 *p 修改，改的都是同一格記憶體，所以兩者永遠一致。

補充範例 2-2：讓指標指向「比較大的那一個」

問題：兩位選手的分數，替分數比較高的那一位加上 5 分獎勵。

檔名 pick_higher.c：

#include <stdio.h>

int main(void)
{
    int playerA;
    int playerB;
    int *winner;

    printf("請輸入兩位選手的分數：");
    scanf("%d %d", &playerA, &playerB);

    if (playerA >= playerB) {
        winner = &playerA;
    } else {
        winner = &playerB;
    }

    *winner = *winner + 5;

    printf("加分後：A = %d，B = %d\n", playerA, playerB);
    return 0;
}

執行範例：

請輸入兩位選手的分數：82 91
加分後：A = 82，B = 96

一步一步看

  1. 82 >= 91 為假，所以 winner = &playerB;，winner 指向 playerB。
  2. *winner = *winner + 5; 透過指標修改，實際改到的是 playerB。
  3. 這一行加分的程式碼不需要知道「是 A 還是 B」，它只管「winner 指向誰就改誰」。

補充範例 2-3：星號跟著變數走

檔名 declare.c：

#include <stdio.h>

int main(void)
{
    int *p, q;

    q = 50;
    p = &q;

    printf("q 是 %d，佔 %zu 位元組\n", q, sizeof q);
    printf("*p 是 %d\n", *p);
    return 0;
}

預期輸出：

q 是 50，佔 4 位元組
*p 是 50

int *p, q; 中只有 p 前面有星號，所以 p 是指標、q 是普通的 int（Beej §5.6）。q 可以直接存 50，也可以被 p 指向。為了避免誤會，建議一行只宣告一個指標。

3. NULL 指標：「目前沒有指向任何地方」

用白話說

指標宣告後如果還沒有要指向誰，可以先存一個特別的值 NULL，意思是「空的，沒有門牌號碼」。使用指標之前先檢查它是不是 NULL，可以避免打開一個根本不存在的信箱。

教材怎麼說

  • 任何型別的指標都可以設為特別的值 NULL，表示這個指標沒有指向任何東西。出處：Beej §5.5 The NULL Pointer。
  • NULL 是定義在 stddef.h 中的標準巨集。要測試指標是不是空的，可以和 NULL 比較，例如 if (p != NULL)。出處：GNU C 手冊 §14.6 Null Pointers。
  • 對 NULL 指標解參照是錯誤的，在大多數平台上會讓程式收到訊號並被終止。出處：GNU C 手冊 §14.7 Dereferencing Null or Invalid Pointers；Beej §5.5。
  • 指標和其他變數一樣，如果沒有明確設定位址或 NULL，它裡面就是無意義的值。出處：Beej §5.5。

對照練習

練習「單元 2」的延伸練習示範用 NULL 檢查避免對可能無效的指標解參照。下面的補充範例把這個檢查放進函式中。

補充範例 3-1：先檢查，再使用

檔名 null_check.c：

#include <stdio.h>
#include <stddef.h>

void showScore(int *score);

int main(void)
{
    int midterm = 88;
    int *finalExam = NULL;      /* 期末考還沒考，先設為 NULL */

    showScore(&midterm);
    showScore(finalExam);
    return 0;
}

void showScore(int *score)
{
    if (score == NULL) {
        printf("尚無成績\n");
        return;
    }
    printf("成績：%d\n", *score);
}

預期輸出：

成績：88
尚無成績

一步一步看

  1. 第一次呼叫傳入 &midterm，不是 NULL，印出 *score 也就是 88。
  2. 第二次呼叫傳入 NULL。函式先檢查到 score == NULL，印出「尚無成績」後用 return; 提早結束，完全不會執行 *score。
  3. 如果少了這個檢查，第二次呼叫就會對 NULL 解參照，程式很可能直接被終止（GNU C 手冊 §14.7）。

4. 指標參數：讓函式修改呼叫端的變數

用白話說

第 7 週學到：函式拿到的是引數的複本，改參數不會影響呼叫端。那如果希望函式真的幫忙改掉呼叫端的變數，或是一次交回兩個結果，該怎麼辦？

答案是：把變數的門牌號碼交給函式。函式拿到的仍然是複本，但那是「門牌號碼的複本」；照著門牌號碼找過去，開的還是同一個信箱。

教材怎麼說

  • 把指標當作引數傳給函式時，參數拿到的仍是指標的複本，這和第 7 週「所有引數都會被複製」的規則一致。出處：Beej §5.4 Passing Pointers as Arguments。
  • 但因為這個指標事先已經指向某個變數，函式可以對它的複本解參照，找回原本的變數並加以修改。函式看不到那個變數本身，卻可以透過指標找到它。出處同上。
  • Beej 也指出，這解決了「函式只能回傳一個值」的限制：透過指標參數，函式可以帶回不只一項資料。出處同上。

對照練習

練習「單元 3」的基本範例用指標參數修改呼叫端的資料，延伸練習同時修改兩個變數，並討論「哪個參數要用指標、哪個不用」；綜合實作用 addBonus(int *score, int bonus) 修正兩位學生的分數。下面的補充範例示範另外兩種典型用途：一次帶回兩個結果，以及用回傳值表示成功與否、用指標帶回資料。

補充範例 4-1：一次帶回兩個結果

問題：第 3 週用 / 和 % 把分鐘換算成小時和分鐘。現在把它寫成函式，但函式只能 return 一個值，要怎麼交回「小時」和「分鐘」兩個結果？

檔名 split_time.c：

#include <stdio.h>

void splitTime(int totalMinutes, int *hours, int *minutes);

int main(void)
{
    int total;
    int h;
    int m;

    printf("請輸入總分鐘數：");
    scanf("%d", &total);

    splitTime(total, &h, &m);
    printf("%d 分鐘 = %d 小時 %d 分鐘\n", total, h, m);
    return 0;
}

void splitTime(int totalMinutes, int *hours, int *minutes)
{
    *hours = totalMinutes / 60;
    *minutes = totalMinutes % 60;
}

執行範例：

請輸入總分鐘數：135
135 分鐘 = 2 小時 15 分鐘

一步一步看（假設 h 的位址是 2000、m 的位址是 2004）

步驟 main 的 h main 的 m 函式的 hours 函式的 minutes
呼叫前 未設定 未設定
呼叫 splitTime(total, &h, &m) 未設定 未設定 2000 2004
*hours = 135 / 60; 2 未設定 2000 2004
*minutes = 135 % 60; 2 15 2000 2004
函式結束 2 15 消失 消失
  • totalMinutes 只需要讀，所以用一般的 int 參數。
  • hours、minutes 需要寫回呼叫端，所以用指標參數，呼叫時要傳 &h、&m。

補充範例 4-2：回傳成功與否，用指標帶回資料

問題：寫一個讀取成績的函式。讀到 0 到 100 的整數時回傳 1，並透過指標把成績交回；否則回傳 0。這和 scanf 本身的設計很像：回傳值表示成功筆數，資料則寫進你給的位址。

檔名 read_score.c：

#include <stdio.h>

int readScore(int *result);

int main(void)
{
    int score;

    printf("請輸入成績：");
    if (readScore(&score)) {
        printf("登錄成功：%d 分\n", score);
    } else {
        printf("成績必須是 0 到 100 的整數\n");
    }
    return 0;
}

int readScore(int *result)
{
    int value;

    if (scanf("%d", &value) != 1) {
        return 0;
    }
    if (value < 0 || value > 100) {
        return 0;
    }
    *result = value;
    return 1;
}

執行範例（合法）：

請輸入成績：88
登錄成功：88 分

執行範例（超出範圍）：

請輸入成績：105
成績必須是 0 到 100 的整數

一步一步看（輸入 105）

  1. scanf 成功讀到 105，回傳 1，第一個 if 不成立。
  2. 105 > 100 成立，執行 return 0;，函式立刻結束，*result = value; 沒有執行，main 的 score 沒被改動。
  3. main 的 if 收到 0（假），印出錯誤訊息。因為 score 沒有被設定，所以錯誤時不去印它。

常見錯誤 1：呼叫時忘了 &

檔名 forgot_amp.c：

#include <stdio.h>

void doubleIt(int *n);

int main(void)
{
    int x = 21;
    doubleIt(x);
    printf("%d\n", x);
    return 0;
}

void doubleIt(int *n)
{
    *n = *n * 2;
}

本講義測試用的編譯器把這個問題視為錯誤，不會產生可執行檔（有些編譯器只會發出警告）：

forgot_amp.c:8:14: error: incompatible integer to pointer conversion passing 'int' to parameter of type 'int *'; take the address with & [-Wint-conversion]

編譯器已經提示解法：「用 & 取得位址」。函式期待的是一個位址，卻收到了整數 21；如果編譯器只發出警告而讓程式執行，就會把 21 當成位址去存取，結果無法預測。改成 doubleIt(&x); 即可。

常見錯誤 2：函式裡忘了 *

檔名 forgot_star.c：

#include <stdio.h>

void addTen(int *n);

int main(void)
{
    int x = 5;
    addTen(&x);
    printf("x = %d\n", x);
    return 0;
}

void addTen(int *n)
{
    n = n + 10;     /* 少了 *：改到的是指標本身 */
}

預期輸出：

x = 5

一步一步看

  1. n = n + 10; 沒有解參照，改變的是參數 n 這個指標複本所存的位址，而不是它指向的 x。
  2. 函式結束後，這個複本就消失了，x 仍然是 5。
  3. 這個錯誤不會產生警告，因為對指標做加法是合法的（第 12 週會學到指標運算）。所以要特別留意：想改指向的資料，就要寫 *n = *n + 10;。

本講義未涵蓋的內容

  • %p 印位址時轉型成 (void *) 的原因：本講義在引用的教材中沒有找到說明。
  • 「信箱與門牌號碼」的比喻：Beej §5.1 用的是「編了號的盒子」和「住家地址」的比喻，本講義的信箱說法是延伸的說明方式。
