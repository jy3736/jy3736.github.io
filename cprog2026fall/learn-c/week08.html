1. 陣列：一排編了號的格子

用白話說

如果要記錄一週七天的步數，宣告 day1、day2……day7 七個變數很麻煩，而且沒辦法用迴圈處理。陣列（array）就像一排置物櫃：整排共用一個名字，每一格用編號（索引，index）區分。

最重要的一件事：編號從 0 開始。7 格的陣列，編號是 0 到 6。

教材怎麼說

  • 宣告陣列的方法，是在名稱後面寫 [長度]。例如 double a[5]; 宣告了一個可以放 5 個 double 的陣列。出處：GNU C 手冊 §16.2 Declaring an Array。
  • 陣列 a 的第 N 格寫成 a[N]，可以讀出它的值，也可以存入新的值。出處：GNU C 手冊 §16.1 Accessing Array Elements。
  • 最小的合法索引是 0，不是 1；最大的合法索引是「元素個數減 1」。出處同上。
  • 宣告時可以用大括號給初始值，例如 int a[5] = {22, 37, 3490, 18, 95};。出處：Beej §6.3 Array Initializers。
  • 初始值的個數少於陣列長度時，其餘的格子會自動設為 0；所以 int a[100] = {0}; 常被用來把整個陣列設為 0。初始值的個數多於陣列長度時，編譯器會發出警告。出處：Beej §6.3。

對照練習

練習「單元一」的最小程式宣告了 4 筆溫度紀錄，並用索引個別印出每一格。下面的補充範例示範「修改某一格」和「只給部分初始值」這兩件事。

補充範例 1-1：索引與修改

檔名 steps.c：

#include <stdio.h>

int main(void)
{
    int steps[7] = {6200, 8100, 5400, 9900, 7300, 12000, 4500};

    printf("第 1 天：%d 步\n", steps[0]);
    printf("第 7 天：%d 步\n", steps[6]);

    steps[2] = 5800;              /* 第 3 天的紀錄更正 */
    printf("更正後第 3 天：%d 步\n", steps[2]);

    int weekend = steps[5] + steps[6];
    printf("週末合計：%d 步\n", weekend);
    return 0;
}

預期輸出：

第 1 天：6200 步
第 7 天：4500 步
更正後第 3 天：5800 步
週末合計：16500 步

一步一步看

索引 0 1 2 3 4 5 6
一開始 6200 8100 5400 9900 7300 12000 4500
執行 steps[2] = 5800; 後 6200 8100 5800 9900 7300 12000 4500
  • 「第 1 天」是索引 0，「第 7 天」是索引 6。日常說的「第幾天」要減 1 才是索引。
  • steps[5] + steps[6] 就是 12000 加 4500。每一格用起來和一般的 int 變數完全一樣。

補充範例 1-2：沒給初始值的格子是 0

檔名 votes.c：

#include <stdio.h>

int main(void)
{
    int votes[5] = {3, 1};

    printf("%d %d %d %d %d\n", votes[0], votes[1], votes[2], votes[3], votes[4]);
    return 0;
}

預期輸出：

3 1 0 0 0

只給了兩個初始值，後面三格自動變成 0（Beej §6.3）。

補充範例 1-3：用 sizeof 算出陣列有幾格

教材怎麼說：C 不會自動記錄陣列的長度。在宣告陣列的同一個範圍內，可以用「整個陣列的位元組數」除以「一格的位元組數」算出格數；但把陣列傳給函式之後，這個方法就不管用了。出處：Beej §6.2 Getting the Length of an Array。

檔名 length.c：

#include <stdio.h>

int main(void)
{
    double prices[6] = {35.0, 42.5, 60.0, 18.0, 25.5, 80.0};

    size_t totalBytes = sizeof prices;
    size_t oneBytes = sizeof prices[0];
    size_t count = totalBytes / oneBytes;

    printf("整個陣列 %zu 位元組\n", totalBytes);
    printf("每一格 %zu 位元組\n", oneBytes);
    printf("共有 %zu 格\n", count);
    return 0;
}

預期輸出（在 double 佔 8 位元組的電腦上）：

整個陣列 48 位元組
每一格 8 位元組
共有 6 格

一步一步看

  1. sizeof prices 是整個陣列佔用的空間：6 格乘以每格 8 位元組，等於 48。
  2. sizeof prices[0] 是一格佔用的空間，8 位元組。
  3. 48 除以 8 得到 6，就是陣列的格數。這個寫法的好處是：之後把陣列改成 10 格，count 會自動跟著變。

動手改改看

  • 在補充範例 1-2 中，把初始值改成 {3, 1, 4, 1, 5, 9}（6 個值放進 5 格），讀讀看編譯器的警告。
  • 在補充範例 1-1 印出 steps[3]，想一想它是「第幾天」。

2. 用迴圈走訪陣列

用白話說

陣列真正好用的地方，是可以把索引換成迴圈變數：steps[i]。讓 i 從 0 跑到「長度減 1」，就能一格一格處理整個陣列，這個動作稱為走訪。

教材怎麼說

  • Beej 的第一個陣列範例就是用 for (i = 0; i < 4; i++) 走訪 4 格的陣列，逐一印出每一格。注意條件寫的是 i < 4，所以最後一次是 i 等於 3。出處：Beej §6.1 Easy Example。

對照練習

練習「單元二」的最小程式用 for 印出溫度陣列的每一格，變化版本在迴圈中把每一格換算成華氏溫度。下面的補充範例示範另外兩種走訪：把使用者輸入存進陣列，以及倒著走訪。

補充範例 2-1：讀進陣列，再倒著印出來

檔名 reverse.c：

#include <stdio.h>

int main(void)
{
    int numbers[5];

    for (int i = 0; i < 5; i++) {
        printf("請輸入第 %d 個數字：", i + 1);
        if (scanf("%d", &numbers[i]) != 1) {
            printf("輸入錯誤\n");
            return 1;
        }
    }

    printf("倒過來是：");
    for (int i = 4; i >= 0; i--) {
        printf("%d ", numbers[i]);
    }
    printf("\n");
    return 0;
}

執行範例：

請輸入第 1 個數字：8
請輸入第 2 個數字：3
請輸入第 3 個數字：11
請輸入第 4 個數字：6
請輸入第 5 個數字：2
倒過來是：2 6 11 3 8

一步一步看

  1. 第一個迴圈的 i 依序是 0、1、2、3、4。提示文字印的是 i + 1，讓使用者看到的是「第 1 個」到「第 5 個」。
  2. &numbers[i] 是「第 i 格的位址」，scanf 把讀到的整數存進那一格。和一般變數一樣，要加 &。
  3. 第二個迴圈從 i = 4 開始，每次 i--，直到 i >= 0 不成立，所以依序印出索引 4、3、2、1、0。

補充範例 2-2：用常數管理陣列長度

問題：陣列長度同時出現在宣告和迴圈條件中，改一處忘了改另一處就會出錯。用 const 常數（第 3 週）把長度集中管理。

檔名 const_len.c：

#include <stdio.h>

int main(void)
{
    const int DAYS = 5;
    int sales[5] = {1200, 980, 1500, 1100, 1320};

    int total = 0;
    for (int i = 0; i < DAYS; i++) {
        total = total + sales[i];
        printf("第 %d 天累計：%d\n", i + 1, total);
    }

    printf("平均每天：%.1f\n", (double)total / DAYS);
    return 0;
}

預期輸出：

第 1 天累計：1200
第 2 天累計：2180
第 3 天累計：3680
第 4 天累計：4780
第 5 天累計：6100
平均每天：1220.0

一步一步看

i sales[i] 加完後的 total
0 1200 1200
1 980 2180
2 1500 3680
3 1100 4780
4 1320 6100

最後用 (double)total / DAYS 算平均，避免整數除法把小數去掉（第 3 週）。

動手改改看

  • 把補充範例 2-1 改成讀入 7 個數字。你需要改哪幾個地方？如果用補充範例 2-2 的常數寫法，只要改哪裡？
  • 把補充範例 2-2 的迴圈條件改成 i <= DAYS，重新編譯執行，看看最後一天的累計發生什麼事（並閱讀第 4 節）。

3. 統計、篩選與搜尋

用白話說

把資料放進陣列之後，就能回答各種問題：「有幾天超過目標？」「是哪幾天？」「有沒有某個值？在第幾格？」這些問題都用同一個骨架解決：走訪每一格，對每一格做檢查。

對照練習

練習「單元三」的最小程式找出最高溫，變化版本找出最低溫並記錄是第幾筆；綜合迷你專案則一次算出總分、平均、最高、最低和及格人數。下面的補充範例示範另外兩種常見問題：計數並列出符合條件的格子，以及搜尋某個值的位置。

補充範例 3-1：有幾天達標，是哪幾天

檔名 goal_days.c：

#include <stdio.h>

int main(void)
{
    int steps[7] = {6200, 8100, 5400, 9900, 7300, 12000, 4500};
    const int GOAL = 8000;
    int count = 0;

    printf("達標的日子：");
    for (int i = 0; i < 7; i++) {
        if (steps[i] >= GOAL) {
            printf("第 %d 天 ", i + 1);
            count++;
        }
    }
    printf("\n共 %d 天達標\n", count);
    return 0;
}

預期輸出：

達標的日子：第 2 天 第 4 天 第 6 天 
共 3 天達標

一步一步看

i steps[i] >= 8000？ 動作 count
0 6200 否 無 0
1 8100 是 印出第 2 天 1
2 5400 否 無 1
3 9900 是 印出第 4 天 2
4 7300 否 無 2
5 12000 是 印出第 6 天 3
6 4500 否 無 3

補充範例 3-2：搜尋座位號碼

問題：已報到的座位號碼存在陣列中，輸入一個號碼，查詢是否已報到，以及是第幾位報到的。

檔名 find_seat.c：

#include <stdio.h>

int main(void)
{
    int checkedIn[6] = {12, 5, 33, 8, 21, 17};
    int target;
    int position = -1;

    printf("要查詢的座位號碼：");
    scanf("%d", &target);

    for (int i = 0; i < 6; i++) {
        if (checkedIn[i] == target) {
            position = i;
            break;
        }
    }

    if (position == -1) {
        printf("座位 %d 尚未報到\n", target);
    } else {
        printf("座位 %d 是第 %d 位報到\n", target, position + 1);
    }
    return 0;
}

執行範例（找得到）：

要查詢的座位號碼：8
座位 8 是第 4 位報到

執行範例（找不到）：

要查詢的座位號碼：40
座位 40 尚未報到

一步一步看（輸入 8）

  1. position 先設為 -1。索引不可能是負數，所以 -1 可以用來代表「還沒找到」。
  2. 迴圈檢查索引 0（12）、1（5）、2（33），都不是 8。
  3. 索引 3 的值是 8，把 position 設為 3，break 離開迴圈，不再檢查後面的格子（第 6 週）。
  4. 迴圈結束後，position 不是 -1，印出「第 4 位」（索引加 1）。
  5. 輸入 40 時，六格都比對失敗，position 維持 -1，印出「尚未報到」。

動手改改看

  • 修改補充範例 3-1，讓它另外印出「未達標的日子共走了幾步」。
  • 在補充範例 3-2 的陣列中放兩個相同的號碼（例如兩個 8），程式會回報哪一個位置？如果拿掉 break 呢？

4. 超出範圍的索引

教材怎麼說

  • C 語言不會檢查索引是否在合法範圍內。使用超出範圍的索引時，程式會去存取陣列以外的記憶體。確保只使用合法的索引，是寫程式的人自己的責任。出處：GNU C 手冊 §16.1。
  • 讀取超出陣列結尾的格子屬於未定義行為（undefined behavior）：可能讀到 0、讀到亂七八糟的數字，也可能讓程式當掉，而且編譯器不一定會警告。出處：Beej §6.4 Out of Bounds!。

補充範例 4-1：讓編譯器幫忙抓

檔名 out_of_bounds.c：

#include <stdio.h>

int main(void)
{
    int scores[5] = {90, 85, 77, 68, 95};

    printf("最後一格：%d\n", scores[4]);
    printf("超出範圍：%d\n", scores[5]);
    return 0;
}

編譯時會看到類似下面的警告：

out_of_bounds.c:8:35: warning: array index 5 is past the end of the array (that has type 'int[5]') [-Warray-bounds]

一步一步看

  1. 陣列有 5 格，合法索引是 0 到 4。scores[4] 是最後一格，沒有問題。
  2. scores[5] 已經超出陣列。這一行印出來的值無法預測，每台電腦、每次執行都可能不同，所以本講義不列出執行結果。
  3. 這次編譯器能發出警告，是因為索引直接寫成常數 5。如果索引是變數（例如迴圈的 i），編譯器通常看不出來，Beej §6.4 也提醒編譯器「不一定會警告」。所以要特別檢查迴圈條件是 i < 長度，而不是 i <= 長度。
