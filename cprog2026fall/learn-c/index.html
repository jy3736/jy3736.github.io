計算機程式及實習：C 語言講義

這份講義從零開始，陪你寫出第一支 C 程式，一路到完成自己的小型專題。每一週都有白話的觀念說明、可以直接執行的範例程式，以及一步一步的追蹤說明。

怎麼使用這份講義

  1. 使用 Windows 電腦的同學，先依照〈在 Windows 用 WSL 寫 C 程式〉完成環境設定。
  2. 先讀「用白話說」，掌握這一段要解決什麼問題。
  3. 把「補充範例」的程式碼複製到自己的檔案（右上角有「複製」按鈕），編譯並執行。
  4. 對照「預期輸出」和「一步一步看」，確認每一行程式做了什麼。
  5. 完成「動手改改看」，再回到課堂的實作練習。

每一週使用的編譯指令都相同：

gcc -std=c17 -Wall -Wextra -Wpedantic 檔名.c -o 檔名

執行範例中，像這樣標示的文字是你用鍵盤輸入的內容，輸入完按 Enter。
