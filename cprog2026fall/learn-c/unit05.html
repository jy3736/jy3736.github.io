1. while 與 do-while

用白話說

如果要印出 1 到 100，寫 100 行 printf 顯然不是好辦法。迴圈讓同一段程式碼重複執行，每一輪之前（或之後）檢查一個條件，決定要不要再來一次。

  • while：先檢查，再執行。像是「還有作業沒寫完，就繼續寫」。
  • do-while：先執行，再檢查。像是「先試吃一口，好吃就再吃一口」。

教材怎麼說

  • while 每一輪開始時先計算條件；條件為真（不是 0）就執行迴圈主體，然後回到開頭再檢查。出處：GNU C 手冊 §19.6.1 while Statement。
  • do-while 先執行主體，每一輪結束時才計算條件；條件為真就再執行一次。出處：GNU C 手冊 §19.6.2 do-while Statement。
  • 兩者的差別在第一輪：如果條件一開始就是假，while 的主體一次都不執行，do-while 的主體仍會執行一次。出處：Beej §3.3.3 The do-while statement。
  • while (1) 的條件永遠為真，會一直重複下去，形成無窮迴圈。出處：Beej §3.3.2 The while statement。

對照練習

練習「單元一」的最小程式用 while 印出 1 到 4 的平方；變化版本則改成 do-while，並說明「要讓條件一開始就是假，才看得出兩者的差異」。下面的補充範例 1-2 就把這個差異直接跑出來。

補充範例 1-1：存錢存到目標

問題：每個月存 1200 元，存款要到達 5000 元以上需要幾個月？

檔名 saving.c：

#include <stdio.h>

int main(void)
{
    int balance = 0;
    int months = 0;

    while (balance < 5000) {
        balance = balance + 1200;
        months = months + 1;
        printf("第 %d 個月：存款 %d 元\n", months, balance);
    }

    printf("共需要 %d 個月\n", months);
    return 0;
}

預期輸出：

第 1 個月：存款 1200 元
第 2 個月：存款 2400 元
第 3 個月：存款 3600 元
第 4 個月：存款 4800 元
第 5 個月：存款 6000 元
共需要 5 個月

一步一步看

輪次 檢查 balance < 5000 時的 balance 條件 執行後的 balance 執行後的 months
1 0 真 1200 1
2 1200 真 2400 2
3 2400 真 3600 3
4 3600 真 4800 4
5 4800 真 6000 5
第 6 次檢查 6000 假 離開迴圈

每一輪都會改變 balance，所以條件總有一天會變成假。如果忘了寫 balance = balance + 1200;，balance 永遠是 0，程式就會變成無窮迴圈。

補充範例 1-2：條件一開始就是假

檔名 first_round.c：

#include <stdio.h>

int main(void)
{
    int count = 10;

    while (count < 3) {
        printf("while 執行了一次\n");
        count = count + 1;
    }

    count = 10;
    do {
        printf("do-while 執行了一次\n");
        count = count + 1;
    } while (count < 3);

    printf("結束\n");
    return 0;
}

預期輸出：

do-while 執行了一次
結束

一步一步看

  1. while：一開始 10 < 3 就是假，主體完全沒有執行，所以沒有印出「while 執行了一次」。
  2. do-while：先執行主體，印出一行，count 變成 11；接著才檢查 11 < 3，是假，離開迴圈。
  3. 注意 do-while 的 while (count < 3); 後面要有分號。

補充範例 1-3：輸入不合法就重問

問題：do-while 很適合「至少要問一次」的情況。要求使用者輸入 1 到 3 的選項，輸入錯了就再問一次。

檔名 menu.c：

#include <stdio.h>

int main(void)
{
    int choice = 0;

    do {
        printf("請選擇（1 查詢、2 新增、3 離開）：");
        if (scanf("%d", &choice) != 1) {
            printf("讀取失敗\n");
            return 1;
        }
    } while (choice < 1 || choice > 3);

    printf("你選擇了 %d\n", choice);
    return 0;
}

執行範例：

請選擇（1 查詢、2 新增、3 離開）：7
請選擇（1 查詢、2 新增、3 離開）：0
請選擇（1 查詢、2 新增、3 離開）：2
你選擇了 2

一步一步看

輪次 輸入 choice < 1 \|\| choice > 3 結果
1 7 7 > 3 為真 再問一次
2 0 0 < 1 為真 再問一次
3 2 兩邊都假 離開迴圈

動手改改看

  • 把補充範例 1-1 的目標改成 6000，需要幾個月？先想再執行。
  • 刪掉補充範例 1-2 do-while 結尾的分號，重新編譯，讀讀看錯誤訊息。

2. for 迴圈

用白話說

很多時候我們事先就知道要重複幾次，例如「印出 1 到 9」。for 把「從哪裡開始、做到什麼時候、每次怎麼前進」這三件事寫在同一行，一眼就看得出迴圈會跑幾次。

教材怎麼說

for 的小括號裡有三個部分，用分號隔開。出處：GNU C 手冊 §19.6.4 for Statement；Beej §3.3.4 The for statement。

for (起始; 繼續條件; 前進)
部分 作用 什麼時候執行
起始 準備迴圈，例如 int i = 1 只在最開始執行一次
繼續條件 決定要不要再跑一輪，例如 i <= 9 每一輪開始前
前進 為下一輪做準備，例如 i++ 每一輪主體執行完之後
  • 如果繼續條件一開始就是假，主體一次都不會執行。出處：GNU C 手冊 §19.6.4；Beej §3.3.4。
  • 同樣的迴圈也能用 while 寫出來，但 for 把控制迴圈的三件事集中在一起，比較精簡；事先知道次數時特別合適。出處：Beej §3.3.4。
  • 可以在起始的部分直接宣告變數，例如 for (int i = 0; ...)。這樣宣告的變數只在這個 for 裡面有效，離開迴圈後就不能再使用。這種變數一定要給初始值。出處：GNU C 手冊 §19.6.7 for-Index Declarations；Beej §13.3 for-loop Scope。

i++ 是什麼

  • i++ 單獨成一行時，意思就是 i = i + 1；i-- 則是 i = i - 1。出處：Beej §3.2.3 Pre-and-Post Increment-and-Decrement。
  • 如果放在更長的算式中，i++ 和 ++i 就有差別，見補充範例 2-3。

對照練習

練習「單元二」的最小程式用 for 計算 1 到 20 的總和，變化版本只加總能被 3 整除的數字。下面的補充範例示範另外兩種常見用法：依照輸入決定次數，以及用 for 和 while 寫出相同的迴圈來互相比較。

補充範例 2-1：九九乘法表的一列

檔名 times.c：

#include <stdio.h>

int main(void)
{
    int n;

    printf("要印哪一個數字的乘法表？");
    scanf("%d", &n);

    for (int i = 1; i <= 9; i++) {
        printf("%d x %d = %2d\n", n, i, n * i);
    }
    return 0;
}

執行範例：

要印哪一個數字的乘法表？7
7 x 1 =  7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
7 x 6 = 42
7 x 7 = 49
7 x 8 = 56
7 x 9 = 63

一步一步看

  1. 起始：int i = 1，只做一次。
  2. 檢查 i <= 9：1 小於等於 9，為真，執行主體，印出 7 x 1 = 7。
  3. 前進：i++，i 變成 2。再檢查條件、執行主體，如此重複。
  4. 當 i 變成 10，10 <= 9 為假，迴圈結束，總共執行 9 次。
  5. %2d 讓結果佔 2 格，所以個位數前面會補一個空白，等號後面的數字才會對齊（第 4 週的欄寬）。

補充範例 2-2：同一件事，兩種寫法

問題：計算 1 到 n 之間所有奇數的總和，分別用 for 和 while 完成。

檔名 odd_sum.c：

#include <stdio.h>

int main(void)
{
    int n;

    printf("請輸入 n：");
    scanf("%d", &n);

    int sumFor = 0;
    for (int i = 1; i <= n; i = i + 2) {
        sumFor = sumFor + i;
    }

    int sumWhile = 0;
    int j = 1;
    while (j <= n) {
        sumWhile = sumWhile + j;
        j = j + 2;
    }

    printf("for 的結果：%d\n", sumFor);
    printf("while 的結果：%d\n", sumWhile);
    return 0;
}

執行範例：

請輸入 n：9
for 的結果：25
while 的結果：25

一步一步看

for 的部分 對應到 while 寫法的哪裡
int i = 1 迴圈前面的 int j = 1;
i <= n while 小括號裡的 j <= n
i = i + 2 主體最後的 j = j + 2;

兩個迴圈都依序加上 1、3、5、7、9，總和 25。前進的部分不一定是 i++，這裡每次加 2，只挑奇數。

補充範例 2-3：i++ 和 ++i 的差別

檔名 increment.c：

#include <stdio.h>

int main(void)
{
    int i = 5;
    int a = 10 + i++;
    printf("a = %d, i = %d\n", a, i);

    int j = 5;
    int b = 10 + ++j;
    printf("b = %d, j = %d\n", b, j);
    return 0;
}

預期輸出：

a = 15, i = 6
b = 16, j = 6

一步一步看

  1. 10 + i++：先用 i 原本的值 5 計算，a 得到 15；算完之後 i 才變成 6。
  2. 10 + ++j：j 先變成 6，再用 6 計算，b 得到 16。
  3. 出處：Beej §3.2.3。為了避免混淆，建議把 i++ 單獨寫成一行，或只用在 for 的前進部分。

常見錯誤：for 後面多了分號

檔名 extra_semicolon.c：

#include <stdio.h>

int main(void)
{
    int total = 0;

    for (int i = 1; i <= 3; i++);
    {
        total = total + 1;
    }

    printf("total = %d\n", total);
    return 0;
}

編譯時會看到類似下面的警告（程式仍然可以執行）：

extra_semicolon.c:7:33: warning: for loop has empty body [-Wempty-body]

執行後的輸出：

total = 1

一步一步看

  1. 單獨一個分號是空敘述，什麼事都不做。出處：GNU C 手冊 §19.11 Null Statement。
  2. for (...); 的迴圈主體變成了這個空敘述，所以迴圈空轉 3 次，什麼都沒做。
  3. 下面大括號裡的程式碼已經不屬於迴圈，只執行一次，所以 total 是 1，不是 3。
  4. GNU C 手冊也提醒，空敘述容易和迴圈結構混淆，要用明顯的寫法區分。出處：GNU C 手冊 §19.6.2。開啟 -Wall 等警告選項時，編譯器會指出「迴圈主體是空的」，這正是第 2 週說的「程式可以跑，不代表沒問題」。

動手改改看

  • 把補充範例 2-1 改成印出 n x 9 到 n x 1（倒過來）。提示：起始、條件、前進三個部分都要改。
  • 在補充範例 2-2 的迴圈結束後加上 printf("%d\n", i);，重新編譯，讀讀看編譯器怎麼說。為什麼 j 可以印，i 卻不行？

3. break 與 continue

用白話說

  • break：「找到了，不用再找了」，立刻離開整個迴圈。
  • continue：「這一筆跳過，看下一筆」，放棄這一輪剩下的步驟，直接進入下一輪。

教材怎麼說

  • break; 會立刻離開最內層的迴圈（或 switch）。迴圈有好幾層時，只會離開包住它的那一層。出處：GNU C 手冊 §19.6.3 break Statement。
  • continue; 會立刻跳到最內層迴圈這一輪的結尾。如果是 for 迴圈，接下來仍然會執行前進的部分。出處：GNU C 手冊 §19.6.8 continue Statement。
  • 使用 continue 可以減少 if 一層包一層的情況，讓程式比較好讀。出處同上。

對照練習

練習「單元三」的最小程式讀入 5 個整數，用 break 在找到 0 時提前結束；變化版本用 continue 跳過偶數。「綜合迷你專案」則同時用到兩者：請假的學生用 continue 跳過，資料格式錯誤就用 break 停止。下面的補充範例分別示範單獨使用和多層迴圈的情況。

補充範例 3-1：找出第一個符合條件的數

問題：從 100 開始往上找，第一個 7 的倍數是多少？

檔名 first_multiple.c：

#include <stdio.h>

int main(void)
{
    int answer = 0;

    for (int n = 100; n <= 200; n++) {
        if (n % 7 == 0) {
            answer = n;
            break;
        }
    }

    printf("第一個 7 的倍數：%d\n", answer);
    return 0;
}

預期輸出：

第一個 7 的倍數：105

一步一步看

n n % 7 動作
100 2 繼續
101 3 繼續
102 4 繼續
103 5 繼續
104 6 繼續
105 0 記錄 105，break 離開迴圈

雖然條件寫到 200，但找到 105 之後就不再檢查 106 到 200。

補充範例 3-2：跳過不合理的成績

問題：讀入 6 筆成績，超出 0 到 100 範圍的成績不列入計算，最後印出有效筆數與及格人數。

檔名 valid_scores.c：

#include <stdio.h>

int main(void)
{
    int score;
    int validCount = 0;
    int passCount = 0;

    for (int i = 1; i <= 6; i++) {
        printf("第 %d 筆成績：", i);
        scanf("%d", &score);

        if (score < 0 || score > 100) {
            printf("  超出範圍，略過\n");
            continue;
        }

        validCount++;
        if (score >= 60) {
            passCount++;
        }
    }

    printf("有效 %d 筆，及格 %d 人\n", validCount, passCount);
    return 0;
}

執行範例：

第 1 筆成績：88
第 2 筆成績：-5
  超出範圍，略過
第 3 筆成績：72
第 4 筆成績：101
  超出範圍，略過
第 5 筆成績：45
第 6 筆成績：90
有效 4 筆，及格 3 人

一步一步看

輸入 超出範圍？ 動作 validCount passCount
88 否 計入，及格 1 1
-5 是 continue，下面的計數都跳過 1 1
72 否 計入，及格 2 2
101 是 continue 2 2
45 否 計入，不及格 3 2
90 否 計入，及格 4 3

即使執行了 continue，for 的前進部分 i++ 仍然會執行，所以總共還是讀 6 筆。

補充範例 3-3：break 只離開一層

問題：用兩層迴圈印出三角形，觀察內層的 break 不會影響外層。

檔名 triangle.c：

#include <stdio.h>

int main(void)
{
    for (int row = 1; row <= 4; row++) {
        for (int col = 1; col <= 10; col++) {
            if (col > row) {
                break;
            }
            printf("* ");
        }
        printf("\n");
    }
    return 0;
}

預期輸出：

*
* *
* * *
* * * *

一步一步看

  1. 外層每跑一輪（row 從 1 到 4），內層就從 col = 1 重新開始。
  2. 當 col 超過 row，內層的 break 只會離開內層迴圈，接著執行外層的 printf("\n") 換行。
  3. 外層迴圈不受影響，繼續下一個 row。所以第 1 列印 1 顆星，第 4 列印 4 顆星。

動手改改看

  • 把補充範例 3-1 的 7 改成 13，並把範圍改成 100 到 110，找不到時 answer 會是多少？怎麼讓程式印出「找不到」？
  • 把補充範例 3-3 的 break 改成 continue，輸出會有什麼不同？為什麼迴圈的次數變多了，印出來的星號卻一樣？
