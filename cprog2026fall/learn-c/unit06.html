1. 函式：把一件事包起來，取一個名字

用白話說

你其實已經用過函式了：printf 和 scanf 都是別人寫好的函式，你只要知道「給它什麼、它會做什麼」，不需要知道它裡面怎麼寫。本週要學的是自己寫函式：把一段會重複使用的程式碼包起來、取一個名字，之後只要「呼叫」這個名字就能執行它。

可以把函式想像成一台果汁機：放進水果（參數），按下開關（呼叫），倒出果汁（回傳值）。

教材怎麼說

函式定義

函式定義的形式如下，大括號前面那一行稱為函式標頭（function header）。出處：GNU C 手冊 §22.1 Function Definitions。

回傳型別 函式名稱(參數宣告)
{
    主體
}
  • 函式不回傳任何值時，回傳型別寫 void。出處同上。

函式原型（prototype）

  • 要呼叫一個函式，在呼叫的位置之前，編譯器必須已經知道這個函式的宣告。函式定義本身就是一種宣告；但如果想先呼叫、後定義，就要在前面先寫一個函式宣告。出處：GNU C 手冊 §22.2 Function Declarations。
  • 函式宣告長得像函式標頭，但結尾用分號取代主體。有寫出參數型別的宣告稱為函式原型。出處同上。
  • Beej 的說法更直接：原型就是「把函式定義的第一行複製下來，後面加上分號」。出處：Beej §4.2 Function Prototypes。
  • 沒有先宣告就呼叫函式的寫法，早期的 C 標準允許，但現在的標準已經不允許了。出處：Beej §4.2。
  • 函式沒有參數時，要在括號裡寫 void。尤其在原型中，foo() 和 foo(void) 意思不同：省略 void 等於告訴編譯器「不提供參數資訊」，編譯器就無法檢查呼叫是否正確。出處：Beej §4.3 Empty Parameter Lists。

對照練習

練習「單元一」的最小程式寫了一個計算立方的函式，變化版本則把同一個函式呼叫好幾次，並用回傳值繼續計算。下面的補充範例用「矩形面積」再走一次完整流程，並示範忘記寫原型時編譯器會怎麼反應。

補充範例 1-1：原型、呼叫、定義

檔名 area.c：

#include <stdio.h>

int rectangleArea(int width, int height);   /* 函式原型 */

int main(void)
{
    int classroom = rectangleArea(12, 8);
    int office = rectangleArea(5, 4);

    printf("教室面積：%d 平方公尺\n", classroom);
    printf("辦公室面積：%d 平方公尺\n", office);
    printf("合計：%d 平方公尺\n", classroom + office);
    return 0;
}

int rectangleArea(int width, int height)    /* 函式定義 */
{
    return width * height;
}

預期輸出：

教室面積：96 平方公尺
辦公室面積：20 平方公尺
合計：116 平方公尺

一步一步看

  1. 第 3 行的原型告訴編譯器：有一個叫 rectangleArea 的函式，接收兩個 int，回傳一個 int。
  2. main 執行到 rectangleArea(12, 8) 時，跳到下面的函式定義：width 得到 12、height 得到 8。
  3. return width * height; 算出 96，函式結束，96 回到呼叫的地方，存進 classroom。
  4. 第二次呼叫時，width 和 height 換成 5 和 4，得到 20。同一個函式，給不同的資料，得到不同的結果。

補充範例 1-2：忘記寫原型

目的：把補充範例 1-1 的原型刪掉，觀察編譯器的反應。

檔名 no_prototype.c：

#include <stdio.h>

int main(void)
{
    printf("面積：%d\n", rectangleArea(3, 4));
    return 0;
}

int rectangleArea(int width, int height)
{
    return width * height;
}

編譯時會出現類似下面的錯誤，而且不會產生可執行檔：

no_prototype.c:5:29: error: call to undeclared function 'rectangleArea'; ISO C99 and later do not support implicit function declarations [-Wimplicit-function-declaration]

一步一步看

  1. 編譯器由上往下讀程式。讀到第 5 行時，它還不認識 rectangleArea。
  2. 錯誤訊息說「呼叫了未宣告的函式」，並指出 C99 之後的標準不支援「隱含的函式宣告」，和 Beej §4.2 的說明一致。
  3. 修正方法有兩種：在 main 前面加上原型，或把整個函式定義搬到 main 前面。

補充範例 1-3：沒有參數、也沒有回傳值的函式

問題：練習「單元三」的最小程式寫了一個印出分隔線的函式。這裡改寫成印出程式標題的函式，注意括號中的 void。

檔名 banner.c：

#include <stdio.h>

void printBanner(void);

int main(void)
{
    printBanner();
    printf("今日營業額：12800 元\n");
    printBanner();
    return 0;
}

void printBanner(void)
{
    printf("====================\n");
    printf("   小吃店營業報表\n");
    printf("====================\n");
}

預期輸出：

====================
   小吃店營業報表
====================
今日營業額：12800 元
====================
   小吃店營業報表
====================

一步一步看

  1. 回傳型別是 void，表示這個函式只負責「做事」（印出文字），不交回任何值。
  2. 括號裡的 void 表示不接收參數，呼叫時括號裡什麼都不放：printBanner()。
  3. void 函式執行到主體結尾就會自動回到呼叫的地方。

動手改改看

  • 在補充範例 1-1 中再算一間 6 x 7 的倉庫面積，並加進合計。
  • 把補充範例 1-3 原型中的 (void) 改成 ()，再把呼叫改成 printBanner(5)，分別用兩種原型編譯，比較編譯器的反應（對照 Beej §4.3）。

2. 參數、引數與傳值呼叫

用白話說

  • 參數（parameter）：函式定義裡，用來接收資料的變數，例如 rectangleArea 的 width。
  • 引數（argument）：呼叫函式時，實際放進去的值，例如 rectangleArea(12, 8) 的 12 和 8。

C 語言傳資料給函式時，傳的是複本。就像把考卷影印一份給同學訂正，同學在影本上怎麼改，你手上的正本都不會變。

教材怎麼說

  • 參數是函式裡的區域變數，用來存放呼叫時傳進來的值。出處：GNU C 手冊 §22.1.1 Function Parameter Variables。
  • 每個參數都要寫出完整的型別，用逗號隔開。例如兩個 int 參數要寫成 (int a, int b)，不能寫成 (int a, b)。出處同上。
  • 參數的初始值就是呼叫時傳進來的值，所以宣告參數時不能自己指定初始值。出處同上。
  • 呼叫函式時，會先算出每個引數的值，再把這些值的複本交給函式，這種方式稱為傳值呼叫（call by value）。函式結束後，它回傳的值就成為整個呼叫運算式的值。出處：GNU C 手冊 §22.4 Function Call Semantics。
  • 因為參數只是複本，在函式裡改變參數的值，不會影響呼叫端的變數。出處：GNU C 手冊 §22.4；Beej §4.1 Passing by Value。

對照練習

練習「單元二」的變化版本在函式裡修改參數，再回到 main 檢查原本的變數有沒有被影響。下面的補充範例用「加分」情境再驗證一次，並用追蹤表把兩邊的變數並排比較。

補充範例 2-1：函式改的是複本

檔名 bonus.c：

#include <stdio.h>

void addBonus(int score);

int main(void)
{
    int myScore = 70;

    addBonus(myScore);
    printf("回到 main：myScore = %d\n", myScore);
    return 0;
}

void addBonus(int score)
{
    score = score + 10;
    printf("在 addBonus 裡：score = %d\n", score);
}

預期輸出：

在 addBonus 裡：score = 80
回到 main：myScore = 70

一步一步看

步驟 main 的 myScore addBonus 的 score
呼叫前 70 還不存在
呼叫 addBonus(myScore)，複製值 70 70
score = score + 10; 70 80
函式結束 70 消失

score 只是拿到 myScore 的值的複本，兩者之間沒有其他關聯（GNU C 手冊 §22.4）。

如果真的想更新成績，該怎麼做？ 讓函式把新的值回傳，呼叫端再把回傳值存回去：

檔名 bonus_return.c：

#include <stdio.h>

int withBonus(int score);

int main(void)
{
    int myScore = 70;

    myScore = withBonus(myScore);
    printf("加分後：myScore = %d\n", myScore);
    return 0;
}

int withBonus(int score)
{
    return score + 10;
}

預期輸出：

加分後：myScore = 80

第 11 週學到指標後，會看到另一種讓函式修改呼叫端變數的方法。

補充範例 2-2：引數可以是運算式

檔名 expr_arg.c：

#include <stdio.h>

int square(int n);

int main(void)
{
    int a = 3;

    printf("%d\n", square(a));
    printf("%d\n", square(a + 2));
    printf("%d\n", square(square(2)));
    return 0;
}

int square(int n)
{
    return n * n;
}

預期輸出：

9
25
16

一步一步看

  1. square(a)：a 的值 3 複製給 n，回傳 9。
  2. square(a + 2)：先算出引數的值 5，再複製給 n，回傳 25。這對應到 GNU C 手冊 §22.4「先算出引數的值」。
  3. square(square(2))：先算裡面的 square(2) 得到 4，再把 4 當作外面那一次呼叫的引數，回傳 16。

動手改改看

  • 在補充範例 2-1 的 addBonus 裡，把參數名稱 score 改成 myScore，重新執行。輸出會改變嗎？為什麼？（提示：看第 4 節的作用域。）
  • 把補充範例 2-2 的原型改成 int square(int n, int m);，讀讀看編譯器的錯誤訊息。

3. 回傳值與 return

教材怎麼說

  • return 值; 會計算那個值，並讓函式立刻結束，把值交回呼叫的地方。出處：GNU C 手冊 §19.5 return Statement。
  • 如果回傳的值和函式宣告的回傳型別不同，會像「存進那個型別的變數」一樣先做型別轉換。出處同上。
  • 只寫 return;、不帶值的形式，是給 void 函式用的。在有回傳型別的函式裡這樣寫，會讓函式回傳無意義的值，是不好的寫法。出處同上。

對照練習

練習「單元三」的變化版本讓一個函式負責計算並回傳判斷結果，另一個 void 函式負責依結果印出訊息。下面的補充範例示範「一個函式裡有好幾個 return」，以及回傳值的型別轉換。

補充範例 3-1：遇到 return 就結束

問題：寫一個函式，傳回兩個整數中較大的那個。

檔名 max_of.c：

#include <stdio.h>

int maxOf(int a, int b);

int main(void)
{
    int x;
    int y;

    printf("請輸入兩個整數：");
    scanf("%d %d", &x, &y);

    printf("較大的是 %d\n", maxOf(x, y));
    return 0;
}

int maxOf(int a, int b)
{
    if (a > b) {
        return a;
    }
    return b;
}

執行範例：

請輸入兩個整數：17 42
較大的是 42

一步一步看（輸入 17 和 42）

  1. a 是 17、b 是 42。17 > 42 為假，跳過 if 裡的 return a;。
  2. 執行 return b;，回傳 42。
  3. 如果輸入 50 和 42，if 成立，執行 return a; 之後函式立刻結束，下面的 return b; 不會執行。

補充範例 3-2：回傳值會轉成宣告的型別

檔名 return_type.c：

#include <stdio.h>

double average3(int a, int b, int c);
int boxesNeeded(int items, int perBox);

int main(void)
{
    printf("平均：%.2f\n", average3(80, 75, 92));
    printf("需要 %d 個箱子\n", boxesNeeded(25, 6));
    return 0;
}

double average3(int a, int b, int c)
{
    return (a + b + c) / 3.0;
}

int boxesNeeded(int items, int perBox)
{
    int boxes = items / perBox;
    if (items % perBox != 0) {
        boxes = boxes + 1;
    }
    return boxes;
}

預期輸出：

平均：82.33
需要 5 個箱子

一步一步看

  1. average3：(a + b + c) 是整數 247，除以 3.0（浮點數）時整數先轉成浮點數，得到 82.333...；函式的回傳型別是 double，所以小數被保留下來。
  2. boxesNeeded：25 / 6 是整數除法，得到 4；25 % 6 是 1，不是 0，表示還有剩下的物品，所以再加一箱，回傳 5。
  3. 這兩個函式都把第 3 週的除法規則包裝成一個有意義的名字，main 讀起來就像在描述要做的事。

動手改改看

  • 在補充範例 3-2 中，把 average3 的回傳型別改成 int（原型和定義都要改），printf 改用 %d。平均變成多少？這對應到哪一條規則？
  • 寫一個 int minOf(int a, int b)，並在 main 中用它找出三個數的最小值。

4. 區域變數與作用域

用白話說

每個函式都像一個獨立的房間。在房間裡宣告的變數，只有房間裡的人看得到；別的房間就算有同名的變數，也是完全不同的東西。一個名字「在哪些地方可以使用」，稱為它的作用域（scope）。

教材怎麼說

  • 在函式裡宣告的變數是區域變數，它的名字從宣告的位置開始有效，一直到所在的那一對大括號結束。出處：GNU C 手冊 §20.5 Local Variables。
  • 區域變數的儲存空間只存在於「宣告處到區塊結尾」這段期間，區塊結束時就被釋放。出處同上。
  • 在同一個作用域中，同一個名字宣告兩次是錯誤的。出處同上。
  • 在大括號區塊中宣告的變數，作用域就是那個區塊；內層區塊宣告的變數，外層看不到。出處：Beej §13.1 Block Scope。

補充範例 4-1：兩個函式裡的同名變數

檔名 scope.c：

#include <stdio.h>

void showCount(void);

int main(void)
{
    int count = 100;

    showCount();
    printf("main 的 count = %d\n", count);
    return 0;
}

void showCount(void)
{
    int count = 5;
    printf("showCount 的 count = %d\n", count);
}

預期輸出：

showCount 的 count = 5
main 的 count = 100

一步一步看

  1. main 的 count 和 showCount 的 count 名字相同，但分別屬於兩個不同的區塊，是兩個獨立的變數。
  2. showCount 結束後，它的 count 就消失了；main 的 count 始終是 100。

補充範例 4-2：區塊內的變數出不了區塊

檔名 block_scope.c：

#include <stdio.h>

int main(void)
{
    int price = 120;

    if (price > 100) {
        int discount = 20;
        printf("折扣後：%d\n", price - discount);
    }

    /* printf("%d\n", discount);   這行會編譯失敗：discount 只在 if 的區塊裡有效 */
    printf("原價：%d\n", price);
    return 0;
}

預期輸出：

折扣後：100
原價：120

把註解那一行恢復再編譯，編譯器會說 discount 沒有宣告，因為它的作用域只到 if 區塊的右大括號為止。

動手改改看

  • 在補充範例 4-1 的 showCount 裡，把 int count = 5; 刪掉，只留下 printf。編譯器會怎麼說？這說明了什麼？
