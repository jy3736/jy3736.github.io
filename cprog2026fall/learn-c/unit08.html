1. 字串就是「以 \0 結尾的字元陣列」

用白話說

姓名、學號、一句話，這些文字資料在 C 裡稱為字串。C 沒有專門的「字串型別」，而是用上週學的陣列來存：每一格放一個字元（char），最後再多放一個特別的字元 \0，表示「字串到這裡結束」。

可以想像成一排座位坐滿了人，最後放一塊「此處為止」的牌子。printf、strlen 這些函式都是一格一格往後看，看到牌子就停下來。

教材怎麼說

  • 字串是一串 char 元素，以數值為 0 的空字元（null character）作為結尾。出處：GNU C 手冊 §16.3 Strings。
  • 用雙引號包起來的文字，例如 "Hello"，稱為字串字面量（string literal）；單引號包起來的是單一字元，兩者不同。出處：Beej §7.1 String Literals。
  • 要存放可以修改的字串，就宣告 char 陣列，而且長度要多留一格給結尾的空字元。例如 char text[] = "Hello"; 會得到 6 格：5 個字母加上結尾的空字元。出處：GNU C 手冊 §16.3。
  • 宣告成陣列之後，就可以用 s[i] 取出個別字元，並用 %c 印出單一字元；用 %s 則印出整個字串。出處：Beej §7.2、§7.3。
  • C 用「結尾的 0 值位元組」來標記字串的結束，而不是另外記錄長度。出處：Beej §7.6 String Termination。

對照練習

練習「單元一」的最小程式先用 %s 印出整個字串，再逐字元印出直到遇到 '\0'；變化版本手動一格一格建立座位代碼。下面的補充範例讓你親眼看到那個看不見的 \0，並示範「把 \0 放在不同位置，字串就在那裡結束」。

補充範例 1-1：看見結尾的 \0

檔名 see_null.c：

#include <stdio.h>

int main(void)
{
    char word[] = "cat";

    printf("陣列共 %zu 格\n", sizeof word);
    for (int i = 0; i < 4; i++) {
        printf("word[%d] 的數值是 %d\n", i, word[i]);
    }
    return 0;
}

預期輸出：

陣列共 4 格
word[0] 的數值是 99
word[1] 的數值是 97
word[2] 的數值是 116
word[3] 的數值是 0

一步一步看

  1. "cat" 只有 3 個字母，但 sizeof word 是 4，多出來的一格就是結尾的空字元（GNU C 手冊 §16.3）。
  2. 字元在電腦裡是用數字存放的，用 %d 印出來就會看到它的編碼。本講義不要求記住 99、97、116 這些數字。
  3. 最後一格的數值是 0，這就是 '\0'。

補充範例 1-2：修改字元，以及提早結束字串

檔名 cut_string.c：

#include <stdio.h>

int main(void)
{
    char code[] = "EE-101";
    printf("原本：%s\n", code);

    code[3] = '2';
    printf("改第 4 個字元後：%s\n", code);

    char date[] = "2026-09-14";
    date[4] = '\0';
    printf("只留年份：%s\n", date);
    return 0;
}

預期輸出：

原本：EE-101
改第 4 個字元後：EE-201
只留年份：2026

一步一步看

陣列 date 的索引 0 1 2 3 4 5 6 ...
修改前 2 0 2 6 - 0 9 ...
執行 date[4] = '\0'; 後 2 0 2 6 \0 0 9 ...

printf 的 %s 從索引 0 開始印，遇到索引 4 的 \0 就停止，所以只印出 2026。後面的字元其實還在陣列裡，只是不會被當成字串的一部分。

補充範例 1-3：用迴圈數字元

問題：不用任何字串函式，自己數出一句話裡有幾個空白。

檔名 count_space.c：

#include <stdio.h>

int main(void)
{
    char sentence[] = "C is fun to learn";
    int spaces = 0;

    for (int i = 0; sentence[i] != '\0'; i++) {
        if (sentence[i] == ' ') {
            spaces++;
        }
    }

    printf("「%s」裡有 %d 個空白\n", sentence, spaces);
    return 0;
}

預期輸出：

「C is fun to learn」裡有 4 個空白

一步一步看

  1. 迴圈條件是 sentence[i] != '\0'：還沒遇到結尾就繼續。這樣不需要事先知道字串有多長。
  2. ' ' 是單引號包起來的一個空白字元。每遇到一個就把 spaces 加 1。
  3. 字串中有 4 個空白，迴圈遇到結尾的 \0 時停止。

動手改改看

  • 在補充範例 1-1 中，把 "cat" 改成 "lion"，迴圈的次數要改成多少才能看到結尾的 0？能不能改用 sizeof word 當迴圈條件？
  • 修改補充範例 1-3，改成計算字母 n 出現幾次。

2. 用 fgets 讀取一行文字

用白話說

第 4 週的 scanf("%d", ...) 很適合讀數字，但如果要讀「一整句話」，例如含有空白的地址或姓名，就需要能一次讀一整行的函式，也就是 fgets。它最大的好處是：你可以告訴它最多讀多少，避免讀進來的文字超出陣列的空間。

教材怎麼說

  • fgets 從主控台或檔案讀取一行文字。出處：Beej 函式庫參考 §23.15 gets(), fgets()。
  • 從鍵盤讀取的寫法是 fgets(陣列, sizeof 陣列, stdin)。這裡的 sizeof 會得到陣列的總位元組數，因為一個 char 就是一個位元組，剛好等於陣列的格數。出處同上。
  • fgets 最多讀取「大小減 1」個字元，然後在後面補上結尾的空字元。出處同上。
  • fgets 會把行尾的換行字元也存進字串（空間足夠的話）。如果不需要這個換行，要自己把它去掉。出處同上。
  • 另一個讀一行的函式 gets 無法指定陣列大小，輸入太長時會寫到陣列外面，所以從 C11 起已經從標準中移除，不要使用。出處同上。
  • 讀取失敗或已經到了輸入結尾時，fgets 回傳 NULL。出處：Beej 函式庫參考 §23.15 Return Value。

對照練習

練習「單元二」的最小程式用 fgets 讀入一句話並印出；變化版本讀入代號、移除結尾的換行，再加上前後綴印出。下面的補充範例先把「換行被存進去」這件事看清楚，再示範「最多讀取大小減 1 個字元」。

補充範例 2-1：換行字元跟著進來了

檔名 see_newline.c：

#include <stdio.h>

int main(void)
{
    char line[50];

    printf("請輸入一句話：");
    if (fgets(line, sizeof line, stdin) == NULL) {
        printf("讀取失敗\n");
        return 1;
    }

    printf("[%s]\n", line);
    return 0;
}

執行範例：

請輸入一句話：Hello C
[Hello C
]

一步一步看

  1. 輸入 Hello C 並按 Enter。fgets 會把 Hello C 和按下 Enter 產生的換行字元一起存進 line。
  2. 用方括號把字串框起來印出，右方括號跑到下一行，證明字串的最後有一個換行字元。
  3. 空白也被完整讀進來了，這是 scanf("%s", ...) 做不到的（%s 讀到空白就停止，見 Beej 函式庫參考 §23.11）。

補充範例 2-2：去掉結尾的換行

問題：沿用第 1 節「在某個位置放 \0，字串就在那裡結束」的觀念，把換行字元換成 \0。

檔名 trim_newline.c：

#include <stdio.h>

int main(void)
{
    char name[30];

    printf("請輸入姓名：");
    if (fgets(name, sizeof name, stdin) == NULL) {
        return 1;
    }

    for (int i = 0; name[i] != '\0'; i++) {
        if (name[i] == '\n') {
            name[i] = '\0';
            break;
        }
    }

    printf("[%s] 你好！\n", name);
    return 0;
}

執行範例：

請輸入姓名：Lin Mei
[Lin Mei] 你好！

一步一步看

  1. 讀入後，name 的內容是 Lin Mei、換行字元、\0。
  2. 迴圈逐格尋找，找到換行字元（索引 7）時，把它改成 \0，然後 break。
  3. 現在字串在索引 7 就結束了，印出時右方括號緊接在 Mei 後面。

補充範例 2-3：fgets 不會讀超過陣列

檔名 limit.c：

#include <stdio.h>

int main(void)
{
    char small[6];

    printf("請輸入一個長單字：");
    fgets(small, sizeof small, stdin);

    printf("存進去的是：[%s]\n", small);
    return 0;
}

執行範例：

請輸入一個長單字：abcdefghij
存進去的是：[abcde]

一步一步看

  1. small 有 6 格，所以 fgets 最多讀 6 - 1 = 5 個字元，第 6 格留給結尾的 \0（Beej 函式庫參考 §23.15）。
  2. 只存進了 abcde，其餘的字元沒有被寫到陣列外面。這就是 fgets 比 gets 安全的原因。
  3. 這次輸入太長，所以換行字元沒有被讀進來；補充範例 2-2 的迴圈找不到換行時什麼都不改，一樣可以正常運作。

動手改改看

  • 在補充範例 2-1 中，把陣列改成 char line[5];，輸入 Hello C，方括號裡會印出什麼？
  • 把補充範例 2-2 的去換行迴圈拿掉，比較輸出的差異。

3. strlen 與 strcmp

用白話說

  • strlen：告訴你字串「有幾個字元」，不包含結尾的 \0。
  • strcmp：比較兩個字串是否相同，或誰排在前面。

使用這兩個函式，要加上 #include <string.h>。

教材怎麼說

strlen

  • strlen 回傳字串的長度，不包含結尾的空字元。它的做法是從頭往後數，數到空字元為止，所以需要花一點時間；同一個字串要重複使用長度時，可以先存進變數。出處：Beej 函式庫參考 §26.15 strlen()。
  • 回傳型別是 size_t，用 %zu 印出。出處：Beej §7.5 Getting String Length。
  • 回傳的是位元組數。對於中文這類一個字佔多個位元組的文字，位元組數可能和字數不同。出處：Beej 函式庫參考 §26.15 Return Value。

strcmp

  • strcmp(s1, s2) 比較兩個字串：完全相同時回傳 0；不同時，找到第一個不同的字元，s1 的字元比較小就回傳小於 0 的值，比較大就回傳大於 0 的值。出處：Beej 函式庫參考 §26.5 strcmp()。
  • 所以判斷「兩個字串相同」要寫 strcmp(a, b) == 0。
  • 不能用 = 複製字串，也不能用 == 比較字串內容。Beej 說明，用 = 只會複製「指向第一個字元的位置」，不會複製字串本身。出處：Beej §7.7 Copying a String。

對照練習

練習「單元三」的最小程式比較同一個字串的 strlen 和 sizeof；變化版本用 strcmp 比對使用者輸入的科系代碼。下面的補充範例示範 strcmp 的三種結果，以及用 == 比較字串時編譯器的警告。

補充範例 3-1：strlen 不算 \0，中文算位元組

檔名 length_bytes.c：

#include <stdio.h>
#include <string.h>

int main(void)
{
    char english[] = "hello";
    char chinese[] = "你好";

    printf("english：strlen = %zu，sizeof = %zu\n", strlen(english), sizeof english);
    printf("chinese：strlen = %zu，sizeof = %zu\n", strlen(chinese), sizeof chinese);
    return 0;
}

在使用 UTF-8 編碼的環境下，預期輸出：

english：strlen = 5，sizeof = 6
chinese：strlen = 6，sizeof = 7

一步一步看

  1. "hello" 有 5 個字元，strlen 是 5；陣列多一格放 \0，sizeof 是 6。
  2. "你好" 只有兩個字，但在 UTF-8 中每個中文字佔 3 個位元組，所以 strlen 是 6。這對應到 Beej 函式庫參考「回傳的是位元組數」的說明。
  3. 本講義沒有在引用的教材中找到 UTF-8 每個中文字佔幾個位元組的說明，「3 個位元組」是依本講義測試環境的執行結果。

補充範例 3-2：strcmp 的三種結果

檔名 compare.c：

#include <stdio.h>
#include <string.h>

void showOrder(char a[], char b[]);

int main(void)
{
    showOrder("apple", "banana");
    showOrder("cherry", "banana");
    showOrder("kiwi", "kiwi");
    return 0;
}

void showOrder(char a[], char b[])
{
    int result = strcmp(a, b);

    if (result == 0) {
        printf("%s 和 %s 相同\n", a, b);
    } else if (result < 0) {
        printf("%s 排在 %s 前面\n", a, b);
    } else {
        printf("%s 排在 %s 後面\n", a, b);
    }
}

預期輸出：

apple 排在 banana 前面
cherry 排在 banana 後面
kiwi 和 kiwi 相同

一步一步看

  1. "apple" 和 "banana" 的第一個字元就不同，a 比 b 小，所以回傳小於 0 的值。
  2. "cherry" 的 c 比 b 大，回傳大於 0 的值。
  3. 兩個 "kiwi" 完全相同，回傳 0。
  4. 程式只判斷結果是「等於 0、小於 0、大於 0」，不去依賴實際的數值，因為教材只保證正負號（Beej 函式庫參考 §26.5）。
  5. showOrder 的參數寫成 char a[]，表示接收一個字串。為什麼這樣寫就能把字串傳進函式，會在第 12 週說明。

補充範例 3-3：輸入口令

檔名 passcode.c：

#include <stdio.h>
#include <string.h>

int main(void)
{
    char input[20];

    printf("請輸入通關口令：");
    if (fgets(input, sizeof input, stdin) == NULL) {
        return 1;
    }

    for (int i = 0; input[i] != '\0'; i++) {
        if (input[i] == '\n') {
            input[i] = '\0';
            break;
        }
    }

    if (strcmp(input, "open sesame") == 0) {
        printf("歡迎進入\n");
    } else {
        printf("口令錯誤（你輸入了 %zu 個字元）\n", strlen(input));
    }
    return 0;
}

執行範例（正確）：

請輸入通關口令：open sesame
歡迎進入

執行範例（錯誤）：

請輸入通關口令：open
口令錯誤（你輸入了 4 個字元）

一步一步看

  1. 如果沒有去掉換行，input 會是 open sesame 加上換行字元，和 "open sesame" 不相同，永遠比對失敗。這就是第 2 節要先去掉換行的原因。
  2. fgets 讓口令中的空白也能被讀進來。

常見錯誤：用 == 比較字串

檔名 wrong_compare.c：

#include <stdio.h>

int main(void)
{
    char answer[] = "yes";

    if (answer == "yes") {
        printf("相同\n");
    } else {
        printf("不同\n");
    }
    return 0;
}

編譯時會看到類似下面的警告：

wrong_compare.c:7:16: warning: result of comparison against a string literal is unspecified (use an explicit string comparison function instead) [-Wstring-compare]

一步一步看

  1. == 比較的不是兩個字串的內容，而是它們在記憶體中的位置（Beej §7.7 說明字串變數代表的是「第一個字元的位置」）。
  2. 編譯器建議「改用明確的字串比較函式」，也就是 strcmp(answer, "yes") == 0。
  3. 這個程式的執行結果是「未指定的」，所以本講義不列出輸出。

動手改改看

  • 在補充範例 3-2 加上一行 showOrder("Apple", "apple");，執行看看。大寫和小寫會被當成相同嗎？
  • 修改補充範例 3-3：輸入錯誤時，允許再試一次，最多三次（提示：第 6 週的迴圈）。

本講義未涵蓋的內容

  • 先用 scanf 讀數字、再用 fgets 讀一行時，fgets 會讀到殘留換行的問題：本次檢索的資料沒有說明這個情況的原因與處理方式，請以課程講義和練習為準。
  • 字元編碼（例如 99 代表 c）的對照表：引用的教材中沒有直接列出，本講義不要求記憶。
  • strcpy、strncpy 等複製字串的函式：Beej §7.7 與 GNU C 手冊 §16.3 有提到，但本週講義與練習沒有使用，這裡不展開。
