1. 用 scanf 讀取使用者輸入

用白話說

到上週為止，程式裡的數字都是事先寫好的。scanf 讓程式在執行時停下來，等你從鍵盤輸入資料，再把輸入的內容存進變數。這樣同一支程式就能處理不同的資料。

教材怎麼說

  • scanf 會讀取輸入、依照格式字串解析，再把結果存進你提供的變數。格式字串的寫法和 printf 很像，例如 "%d" 表示讀一個 int。出處：Beej 函式庫參考 §23.11 scanf()。
  • scanf 需要改變變數的內容，所以要把變數的位址交給它，做法是在變數前面加上 &。出處同上。
  • 型別和格式碼必須對應：
變數型別 scanf 用的格式碼 出處
int %d Beej 函式庫參考 §23.11
float %f cppreference fscanf 轉換規格表
double %lf cppreference fscanf 轉換規格表；K&R §7.4 的範例也用 %lf 讀取 double（PDF 第 129 頁）
  • scanf 會回傳成功存進變數的項目數。輸入不符合格式時，讀取會在那裡停止，回傳值就會比預期少。出處：Beej 函式庫參考 §23.11 Return Value；cppreference fscanf Return value。
  • 除了 %c、%s、%[ 之外，其他格式碼在讀取前會自動跳過空白和換行。出處：Beej 函式庫參考 §23.11.0.4 The Deep Details。

對照練習

練習「單元一」的基本範例讀入一個整數，印出加 10 之後的值。下面的補充範例依序加上三件事：一次讀兩個數、讀有小數的數、以及檢查使用者是否真的輸入了數字。

補充範例 1-1：一次讀入兩個整數

檔名 sum_two.c：

#include <stdio.h>

int main(void)
{
    int first;
    int second;

    printf("請輸入兩個整數（用空白隔開）：");
    scanf("%d %d", &first, &second);

    printf("%d + %d = %d\n", first, second, first + second);
    return 0;
}

執行範例：

請輸入兩個整數（用空白隔開）：12 30
12 + 30 = 42

一步一步看

  1. 程式印出提示文字後停下來，等待輸入。
  2. 輸入 12 30 並按 Enter。第一個 %d 讀到 12，存進 first；第二個 %d 先跳過空白，再讀到 30，存進 second。
  3. 因為 %d 會自動跳過空白與換行，所以分兩行輸入 12 和 30，結果也一樣。

補充範例 1-2：讀入有小數的數字

問題：輸入攝氏溫度，換算成華氏溫度（華氏 = 攝氏 × 9 ÷ 5 + 32）。

檔名 temp.c：

#include <stdio.h>

int main(void)
{
    double celsius;

    printf("請輸入攝氏溫度：");
    scanf("%lf", &celsius);

    double fahrenheit = celsius * 9 / 5 + 32;
    printf("華氏溫度：%.1f\n", fahrenheit);
    return 0;
}

執行範例：

請輸入攝氏溫度：36.5
華氏溫度：97.7

注意：讀取 double 要用 %lf。printf 印 double 則用 %f，%.1f 表示印到小數點後 1 位（第 2 節說明）。

補充範例 1-3：檢查輸入是否成功

問題：使用者可能輸入不是數字的內容。利用 scanf 的回傳值檢查。

檔名 check_input.c：

#include <stdio.h>

int main(void)
{
    int age;

    printf("請輸入年齡：");
    int count = scanf("%d", &age);

    printf("scanf 成功讀取了 %d 個項目\n", count);
    return 0;
}

輸入數字時：

請輸入年齡：19
scanf 成功讀取了 1 個項目

輸入文字時：

請輸入年齡：abc
scanf 成功讀取了 0 個項目

一步一步看

  1. 格式字串只有一個 %d，所以讀取成功時回傳 1。
  2. 輸入 abc 時，%d 讀不到整數，沒有任何值被存進 age，回傳 0。此時 age 裡的值是不可靠的，不應該拿來計算。
  3. 第 5 週學會 if 之後，就能根據回傳值決定「顯示錯誤訊息」或「繼續計算」。練習檔的程式也都用這個方式檢查輸入。

補充範例 1-4：依照固定格式輸入日期

問題：讓使用者用 2026-09-14 這種格式輸入日期。

檔名 date.c：

#include <stdio.h>

int main(void)
{
    int year;
    int month;
    int day;

    printf("請輸入日期（年-月-日）：");
    scanf("%d-%d-%d", &year, &month, &day);

    printf("%d 年 %d 月 %d 日\n", year, month, day);
    return 0;
}

執行範例：

請輸入日期（年-月-日）：2026-09-14
2026 年 9 月 14 日

格式字串中的 - 是一般字元，輸入中必須在相同位置出現 -；對不上時，scanf 會在那裡停止。出處：Beej 函式庫參考 §23.11.0.1 Consuming Other Characters。

使用 scanf 要小心的地方

Beej 提醒，直接用 scanf 讀鍵盤輸入時，只要使用者輸入了錯誤的資料，scanf 很容易停在半路，後面的讀取也會跟著出錯。他建議的作法是先用 fgets 讀入一整行，再從那一行取出資料。出處：Beej 函式庫參考 §23.11.0.2 Problems with scanf()。fgets 會在第 9 週介紹，本週先養成「檢查回傳值」的習慣。

動手改改看

  • 執行補充範例 1-1，只輸入 12 就按 Enter，程式會怎麼樣？再輸入 30 呢？
  • 把補充範例 1-2 的 %lf 改成 %f 重新編譯，讀讀看編譯器的警告。

2. printf 格式化輸出

用白話說

同樣是印出數字，有時候需要排成整齊的表格，有時候只想顯示到小數點後兩位。printf 的格式碼可以控制「佔多寬」和「印幾位小數」。

教材怎麼說

Beej 把一個完整的格式碼整理成以下順序，方括號內的部分都可以省略。出處：Beej 函式庫參考 §23.10.0.1 Format Specifier Layout。

%[旗標][欄寬][.精度][長度修飾]轉換字元
功能 寫法範例 效果 出處
欄寬 %6d 至少佔 6 格，不足的用空白補在左邊（靠右對齊） §23.10.0.5 Field Width
靠左對齊 %-6d 至少佔 6 格，空白補在右邊 §23.10.0.5、§23.10.0.6 Flags
補 0 %05d 至少佔 5 格，不足的用 0 補 §23.10 Description
精度 %.2f 浮點數印到小數點後 2 位 §23.10.0.4 Precision
欄寬加精度 %8.2f 整個欄位至少 8 格，小數點後 2 位 §23.10 Description
  • 如果內容比指定的欄寬還長，欄寬會被忽略，內容會完整印出。出處：§23.10.0.5。

對照練習

練習「單元二」的基本範例比較了不同欄寬對整數輸出的影響。下面的補充範例把欄寬、對齊、精度組合起來，做出對齊的收據。

補充範例 2-1：看見欄寬

目的：用方括號把輸出框起來，就能看清楚補了幾個空白。

檔名 width.c：

#include <stdio.h>

int main(void)
{
    int score = 85;

    printf("[%d]\n", score);
    printf("[%5d]\n", score);
    printf("[%-5d]\n", score);
    printf("[%05d]\n", score);
    printf("[%1d]\n", score);
    return 0;
}

預期輸出：

[85]
[   85]
[85   ]
[00085]
[85]

一步一步看

格式碼 說明
%d 不指定欄寬，有幾位就佔幾格
%5d 85 只有 2 位，左邊補 3 個空白湊滿 5 格
%-5d 一樣湊滿 5 格，但空白補在右邊
%05d 用 0 補滿 5 格
%1d 欄寬 1 比 85 的位數還小，欄寬被忽略，完整印出

補充範例 2-2：控制小數位數

檔名 precision.c：

#include <stdio.h>

int main(void)
{
    double average = 78.4567;

    printf("預設：%f\n", average);
    printf("一位：%.1f\n", average);
    printf("兩位：%.2f\n", average);
    printf("不留小數：%.0f\n", average);
    return 0;
}

預期輸出：

預設：78.456700
一位：78.5
兩位：78.46
不留小數：78

指定精度時，印出的數字會取到那一位（以本例來說是四捨五入的效果），但變數 average 本身的值沒有改變。

補充範例 2-3：排列整齊的收據

問題：結合 scanf 與 printf，讀入兩項商品的數量，印出對齊的收據。

檔名 receipt.c：

#include <stdio.h>

int main(void)
{
    const int TEA_PRICE = 45;
    const int CAKE_PRICE = 60;
    int teaQty;
    int cakeQty;

    printf("紅茶要幾杯？");
    scanf("%d", &teaQty);
    printf("蛋糕要幾塊？");
    scanf("%d", &cakeQty);

    int teaTotal = teaQty * TEA_PRICE;
    int cakeTotal = cakeQty * CAKE_PRICE;

    printf("\n%-6s%6s%8s\n", "item", "qty", "amount");
    printf("%-6s%6d%8d\n", "tea", teaQty, teaTotal);
    printf("%-6s%6d%8d\n", "cake", cakeQty, cakeTotal);
    printf("%-6s%14d\n", "total", teaTotal + cakeTotal);
    return 0;
}

執行範例：

紅茶要幾杯？3
蛋糕要幾塊？2

item     qty  amount
tea        3     135
cake       2     120
total            255

一步一步看

  1. %-6s 讓品名靠左、佔 6 格；%6d、%8d 讓數字靠右，所以個位數會上下對齊。
  2. %s 用來印一段文字，這裡直接印出雙引號裡的英文品名。
  3. 最後一行用 %14d：6（數量欄）加 8（金額欄）等於 14，讓總金額對齊金額欄的右邊。
  4. 表格用英文品名，是因為欄寬以「字元位置」計算。本講義在引用的教材中沒有找到中文字寬度如何影響對齊的說明，所以先用英文觀察效果。

動手改改看

  • 把補充範例 2-1 的 score 改成 123456，五行輸出各會變成什麼？
  • 在補充範例 2-3 加上第三項商品（例如 cookie，單價 25），並維持表格對齊。
