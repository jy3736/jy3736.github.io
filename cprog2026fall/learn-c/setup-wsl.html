開始之前：在 Windows 用 WSL 寫 C 程式

適用對象：使用 Windows 10（版本 2004 以上）或 Windows 11 電腦的同學。

本指南的步驟整理自 Microsoft 與 Visual Studio Code 的官方文件，每個步驟都附上出處，完整連結列在文末「參考資料」。

完成後你會得到什麼

依照本指南做完一次，你的電腦會具備下面這些能力，之後每一週的講義都可以直接使用：

  • 在 Windows 裡執行一個 Linux 系統（Ubuntu），不需要另外安裝虛擬機器或雙系統。
  • 用 gcc 編譯 C 程式，並在終端機中執行。
  • 用 Visual Studio Code（簡稱 VS Code）編輯程式，而且 VS Code 裡的終端機就是 Linux 終端機。

整個過程需要網路連線，第一次安裝大約需要 20 到 40 分鐘（依網路速度而定），中間需要重新開機一次。

0. 先認識幾個名詞

名詞 白話說明
WSL Windows Subsystem for Linux，讓 Windows 可以直接執行 Linux 程式的功能
Ubuntu 一種 Linux 系統，WSL 預設安裝的就是它
終端機 用「打字輸入指令」來操作電腦的視窗
PowerShell Windows 內建的終端機
sudo 在 Linux 中以系統管理員身分執行指令，執行前會要求輸入密碼
VS Code 微軟推出的免費程式編輯器

WSL 讓開發者在同一台 Windows 電腦上同時使用 Windows 與 Linux，並且可以直接執行 Linux 的命令列工具，不需要傳統虛擬機器或雙系統開機的額外負擔。出處：Microsoft Learn〈How to install Linux on Windows with WSL〉。

本課程為什麼使用 WSL：講義中的編譯指令 gcc -std=c17 -Wall -Wextra -Wpedantic 和執行方式 ./程式名稱，都是 Linux 終端機的用法。使用 WSL，你在 Windows 上看到的結果就會和講義一致。

1. 確認 Windows 版本

安裝指令需要 Windows 10 版本 2004（組建 19041）以上，或 Windows 11。出處：Microsoft Learn〈How to install Linux on Windows with WSL〉Prerequisites。

檢查方法

  1. 按下鍵盤的 Windows 鍵 + R，開啟「執行」視窗。
  2. 輸入 winver，按 Enter。
  3. 視窗中會顯示版本與組建編號。

如果版本比 2004 還舊，請先執行 Windows Update 更新系統，或向授課教師詢問。

2. 安裝 WSL

步驟

  1. 在 Windows 的開始選單搜尋 PowerShell。
  2. 在搜尋結果上按滑鼠右鍵，選擇 「以系統管理員身分執行」。
  3. 如果出現「是否允許此應用程式變更你的裝置」，選擇「是」。
  4. 在 PowerShell 視窗中輸入下面的指令，按 Enter：
wsl --install
  1. 等待安裝完成後，重新啟動電腦。

這個指令會開啟執行 WSL 所需的功能，並安裝 Ubuntu。出處：Microsoft Learn〈How to install Linux on Windows with WSL〉Install WSL command。

如果安裝時遇到問題

狀況 處理方式 出處
輸入 wsl --install 後，只出現一大段英文說明文字 代表電腦上已經裝過 WSL 的部分功能。先輸入 wsl --list --online 查看可安裝的系統，再輸入 wsl --install -d Ubuntu Microsoft Learn〈How to install Linux on Windows with WSL〉
安裝進度一直停在 0.0% 改用 wsl --install --web-download -d Ubuntu 同上
想確認裝了哪些系統、使用哪一版 WSL 輸入 wsl --list --verbose 同上

3. 第一次開啟 Ubuntu：建立使用者名稱與密碼

步驟

  1. 重新開機後，在開始選單搜尋 Ubuntu 並開啟。
  2. 第一次開啟時，會看到視窗在解壓縮、安裝檔案，請耐心等候。之後再開啟通常不到一秒。出處：Microsoft Learn〈How to install Linux on Windows with WSL〉。
  3. 畫面要求輸入 User Name（使用者名稱）時，輸入一個英文小寫的名稱，例如 student，按 Enter。
  4. 畫面要求輸入 Password（密碼）時，輸入密碼後按 Enter，再輸入一次確認。

一定要知道的三件事

  • 輸入密碼時，畫面上不會出現任何字，連星號都沒有。 這是正常的，照常輸入完按 Enter 即可。出處：Microsoft Learn〈Set up a WSL development environment〉。
  • 這組帳號密碼和你的 Windows 帳號無關，是 Ubuntu 專用的。請把密碼記下來，之後安裝軟體（sudo）時會用到。出處同上。
  • 這個帳號是 Ubuntu 的管理員，可以執行 sudo 指令。出處同上。

忘記密碼怎麼辦

  1. 開啟 PowerShell，輸入 wsl -u root，以最高權限進入 Ubuntu。
  2. 輸入 passwd 你的使用者名稱（例如 passwd student），依照提示輸入兩次新密碼。
  3. 輸入 exit 離開。

出處：Microsoft Learn〈Set up a WSL development environment〉Set up your Linux username and password。

4. 更新系統並安裝 C 編譯器

以下指令都在 Ubuntu 視窗中輸入。

步驟一：更新套件

sudo apt update && sudo apt upgrade
  • 輸入後會要求輸入 Ubuntu 密碼（一樣看不到字）。
  • 過程中如果出現 Do you want to continue? [Y/n]，輸入 Y 再按 Enter。

Windows 不會自動幫你更新 Ubuntu 裡的套件，官方建議定期執行這個指令。出處：Microsoft Learn〈Set up a WSL development environment〉Update and upgrade packages。另外，VS Code 官方文件也提醒，套件清單太舊時，有時會導致新軟體安裝失敗。出處：VS Code 文件〈Using C++ and WSL in VS Code〉。

步驟二：安裝編譯器與除錯器

sudo apt install build-essential gdb

build-essential 包含 GNU 的編譯工具，gdb 是除錯器。出處：VS Code 文件〈Using C++ and WSL in VS Code〉Set up your Linux environment（文件中的寫法是 sudo apt-get install build-essential gdb，效果相同）。

步驟三：確認安裝成功

gcc --version

如果看到類似下面的訊息（版本數字可能不同），就代表編譯器已經可以使用：

gcc (Ubuntu 13.3.0-6ubuntu2~24.04) 13.3.0
Copyright (C) 2024 Free Software Foundation, Inc.

如果出現 Command 'gcc' not found，請重新執行步驟一和步驟二。VS Code 文件也建議，找不到工具時先再執行一次更新指令。出處：VS Code 文件〈Using C++ and WSL in VS Code〉。

5. 建立課程資料夾：放在 Linux 這一邊

為什麼不放在「文件」或桌面

官方建議：用 Linux 工具處理的檔案，就放在 WSL（Linux）的檔案系統裡，也就是 /home/你的使用者名稱/ 底下。放在 Windows 的資料夾（在 Ubuntu 中看起來是 /mnt/c/Users/...）雖然也能使用，但速度可能明顯變慢。出處：Microsoft Learn〈Working across Windows and Linux file systems〉File storage and performance across file systems。

步驟

在 Ubuntu 視窗中輸入：

cd ~
mkdir -p cprog/week02
cd cprog/week02
pwd

最後一行 pwd 會顯示你目前所在的資料夾，例如：

/home/student/cprog/week02
指令 作用
cd ~ 回到自己的家目錄（/home/使用者名稱）
mkdir -p cprog/week02 建立 cprog 資料夾，以及裡面的 week02 資料夾
cd cprog/week02 進入那個資料夾
pwd 顯示目前所在的位置

用 Windows 檔案總管查看這些檔案

在 Ubuntu 視窗中輸入（最後的句點不能省略，它代表「目前這個資料夾」）：

explorer.exe .

Windows 檔案總管就會打開這個 Linux 資料夾。你也可以在檔案總管的網址列輸入 \\wsl$，看到所有 Linux 系統的檔案。出處：Microsoft Learn〈Working across Windows and Linux file systems〉View your current directory in Windows File Explorer。

6. 安裝 VS Code 並連線到 WSL

步驟一：在 Windows 安裝 VS Code

  1. 到 VS Code 官方網站下載 Windows 版並安裝。請安裝在 Windows 這一邊，不是在 Ubuntu 裡。 出處：VS Code 文件〈Developing in WSL〉Installation。
  2. 安裝過程中出現「選擇附加的工作」（Select Additional Tasks）時，勾選「加入 PATH」（Add to PATH），之後才能在 Ubuntu 中用 code 指令開啟 VS Code。出處同上。

步驟二：安裝 WSL 擴充功能

  1. 開啟 VS Code，按 Ctrl + Shift + X 開啟「擴充功能」面板。
  2. 搜尋 WSL，安裝由 Microsoft 發布的 WSL 擴充功能。

出處：VS Code 文件〈Developing in WSL〉Installation。

步驟三：從 Ubuntu 開啟 VS Code

回到 Ubuntu 視窗，確認自己在課程資料夾中，然後輸入（最後的句點不能省略）：

cd ~/cprog/week02
code .
  • 第一次執行時，會看到正在安裝「VS Code Server」的訊息。這是 VS Code 在 Linux 這一邊安裝一個小型伺服器，只需要安裝一次。出處：VS Code 文件〈Using C++ and WSL in VS Code〉Run VS Code in WSL。
  • VS Code 視窗開啟後，左下角會顯示 WSL: Ubuntu，代表 VS Code 已經連線到 Ubuntu。出處同上（文件說明可以從狀態列看出目前的遠端環境）。

步驟四：在 WSL 中安裝 C/C++ 擴充功能

  1. 在 VS Code 中按 Ctrl + Shift + X。
  2. 搜尋 C/C++，安裝由 Microsoft 發布的擴充功能。如果畫面上顯示「在 WSL: Ubuntu 中安裝」，就點那個按鈕。

大部分擴充功能需要安裝在 WSL 這一邊才能運作；在 WSL 視窗中從擴充功能面板安裝時，VS Code 會自動裝到正確的位置。出處：VS Code 文件〈Developing in WSL〉Managing extensions；〈Using C++ and WSL in VS Code〉Install the C/C++ extension。

7. 第一支程式：編輯、編譯、執行

步驟一：建立檔案

  1. 在 VS Code 左側的檔案總管中，點「新增檔案」圖示，檔名輸入 hello.c。
  2. 貼上下面的程式，按 Ctrl + S 存檔。

檔名 hello.c：

#include <stdio.h>

int main(void)
{
    printf("WSL 環境設定完成！\n");
    return 0;
}

步驟二：開啟 VS Code 裡的終端機

從上方選單選擇 終端機 → 新增終端機（Terminal → New Terminal）。在 WSL 模式下，這個終端機會直接在 Ubuntu 中執行。出處：VS Code 文件〈Developing in WSL〉Opening a terminal in WSL。

步驟三：編譯並執行

在終端機中輸入（和每週講義使用的指令相同）：

gcc -std=c17 -Wall -Wextra -Wpedantic hello.c -o hello
./hello

預期輸出：

WSL 環境設定完成！

看到這一行，就代表整個環境都設定好了。

步驟四：確認檔案都在

ls

會看到兩個檔案：

hello  hello.c

hello.c 是你寫的原始碼，hello 是編譯出來的可執行檔。

8. 每次上課的使用流程

環境只需要設定一次。之後每次寫程式，只要：

  1. 開啟 Ubuntu。
  2. 進入當週的資料夾，例如 cd ~/cprog/week03（資料夾不存在時，先用 mkdir -p ~/cprog/week03 建立）。
  3. 輸入 code . 開啟 VS Code。
  4. 在 VS Code 中寫程式、存檔。
  5. 在 VS Code 的終端機中編譯、執行。

常用指令速查

指令 作用
pwd 顯示目前所在的資料夾
ls 列出目前資料夾中的檔案
cd 資料夾名稱 進入某個資料夾
cd .. 回到上一層資料夾
cd ~ 回到家目錄
mkdir -p 資料夾名稱 建立資料夾
code . 用 VS Code 開啟目前的資料夾
explorer.exe . 用 Windows 檔案總管開啟目前的資料夾
clear 清除終端機畫面

9. 常見問題

問題 可能的原因與處理方式
在 Ubuntu 輸入 code . 出現「command not found」 重新開啟 Ubuntu 視窗再試一次；如果還是不行，可能是安裝 VS Code 時沒有勾選「加入 PATH」，請重新安裝並勾選。出處：VS Code 文件〈Developing in WSL〉
輸入密碼時畫面沒有反應 這是正常的，密碼輸入時不會顯示任何字元，照常輸入完按 Enter。出處：Microsoft Learn〈Set up a WSL development environment〉
編譯或開啟檔案非常慢 檢查目前資料夾是否在 /mnt/c/ 底下（用 pwd 查看）。請把檔案搬到 ~/cprog/ 底下。出處：Microsoft Learn〈Working across Windows and Linux file systems〉
在 Windows 的「文件」資料夾找不到程式檔 程式檔存在 Linux 這一邊。在 Ubuntu 中輸入 explorer.exe .，或在檔案總管網址列輸入 \\wsl$。出處同上
執行 ./hello 出現「No such file or directory」 編譯沒有成功，或目前不在程式所在的資料夾。先用 ls 確認有沒有 hello 這個檔案，再重新編譯，並閱讀編譯器的訊息
VS Code 左下角沒有顯示 WSL: Ubuntu 這個視窗不是從 WSL 開啟的。關閉它，回到 Ubuntu 視窗，在資料夾中輸入 code .
wsl --install 卡住或失敗 參考第 2 節的表格；仍無法解決時，請帶著畫面的錯誤訊息向授課教師詢問
