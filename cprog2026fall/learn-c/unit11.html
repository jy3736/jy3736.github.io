1. 從需求到函式原型

用白話說

程式越寫越長時，全部擠在 main 裡會很難閱讀和修改。比較好的作法是：先把需求拆成幾件各自獨立的小事，每件事寫成一個函式，main 只負責依序呼叫它們，讀起來就像一份工作清單。

拆解時可以先只寫出函式原型：函式叫什麼、需要什麼資料、交回什麼結果。原型定好之後，再一個一個完成函式的內容。

教材怎麼說

  • 函式原型寫出回傳型別、函式名稱和參數型別，結尾是分號。只要原型出現在呼叫之前，函式的定義就可以寫在檔案後面。出處：GNU C 手冊 §22.2 Function Declarations；Beej §4.2 Function Prototypes。
  • 原型中參數的名稱可以省略；如果寫出來，名稱不影響程式，但可以當作說明文件。出處：GNU C 手冊 §22.2。

本節的「如何拆解需求」屬於設計方法，引用的教材中沒有直接說明，請見文末「本講義未涵蓋的內容」。以下範例只示範「拆好之後，原型與函式怎麼寫」。

對照練習

練習「單元 1」的基本範例先寫出原型，再完成各函式；延伸練習換一種實作方式，驗證只要原型不變，main 完全不用修改。下面的補充範例用「電費計算」再走一次「先列原型、再完成函式」的流程。

補充範例 1-1：電費計算程式

需求：讀入本月用電度數；前 120 度每度 2.1 元，超過 120 度的部分每度 3.0 元；印出帳單。

第一步：拆成三件事，只寫原型

要做的事 函式原型 為什麼這樣設計
讀入並檢查度數 int readUsage(int *usage); 需要交回「是否成功」和「度數」兩個結果，所以用回傳值加指標參數（第 11 週）
計算電費 double calcFee(int usage); 只需要讀度數，回傳一個金額
印出帳單 void printBill(int usage, double fee); 只負責輸出，不需要回傳

第二步：完成程式

檔名 power_bill.c：

#include <stdio.h>

int readUsage(int *usage);
double calcFee(int usage);
void printBill(int usage, double fee);

int main(void)
{
    int usage;

    if (!readUsage(&usage)) {
        printf("度數必須是 0 以上的整數\n");
        return 1;
    }

    double fee = calcFee(usage);
    printBill(usage, fee);
    return 0;
}

int readUsage(int *usage)
{
    printf("請輸入本月用電度數：");
    if (scanf("%d", usage) != 1 || *usage < 0) {
        return 0;
    }
    return 1;
}

double calcFee(int usage)
{
    const int BASE_LIMIT = 120;
    const double BASE_RATE = 2.1;
    const double EXTRA_RATE = 3.0;

    if (usage <= BASE_LIMIT) {
        return usage * BASE_RATE;
    }
    return BASE_LIMIT * BASE_RATE + (usage - BASE_LIMIT) * EXTRA_RATE;
}

void printBill(int usage, double fee)
{
    printf("------ 電費帳單 ------\n");
    printf("用電度數：%8d 度\n", usage);
    printf("應繳金額：%8.1f 元\n", fee);
}

執行範例：

請輸入本月用電度數：250
------ 電費帳單 ------
用電度數：     250 度
應繳金額：   642.0 元

一步一步看

  1. main 只有幾行，讀起來就是「讀度數 → 算電費 → 印帳單」，細節都藏在各函式裡。
  2. readUsage 裡的 scanf("%d", usage) 沒有寫 &，因為 usage 本身已經是指標（位址）了。
  3. calcFee(250)：超過 120 度，所以金額是 120 × 2.1 + 130 × 3.0 = 252 + 390 = 642。
  4. 如果之後電價調整，只要修改 calcFee 裡的常數，main 和其他函式都不用動。

動手改改看

  • 用 0、120、121 三個度數測試，先算出預期金額再執行。
  • 新增一個函式 double withTax(double fee)，加上 5% 營業稅，並整合進程式。你需要修改哪些地方？

2. 區域變數、全域變數與作用域

用白話說

  • 區域變數：宣告在函式（或任何大括號區塊）裡面，只有那個區塊看得到，區塊結束就消失。第 7 週已經介紹過。
  • 全域變數：宣告在所有函式的外面，從宣告的位置開始，後面所有的函式都看得到、都能修改。

全域變數很方便，但因為「誰都能改」，程式出錯時很難追查是哪個函式改了它。所以一般的原則是：能用參數和回傳值傳遞的資料，就不要用全域變數。

教材怎麼說

  • 在所有區塊與函式定義之外宣告的名稱，從那個位置開始到檔案結尾都看得到，稱為檔案作用域（file scope）；在區塊內宣告的名稱只在該區塊內看得到，稱為區塊作用域（block scope）。出處：GNU C 手冊第 25 章 Scope；Beej §13.1、§13.2。
  • 檔案作用域的變數可被該檔案中位於它之後的所有函式看到並共用，最接近其他語言所說的「全域」。如果把它宣告在使用它的函式之後，程式就無法編譯。出處：Beej §13.2 File Scope。
  • 檔案作用域變數的儲存空間在程式載入時就配置並初始化。它的初始值不能呼叫函式，也不能依賴其他變數的內容。出處：GNU C 手冊 §20.6 File-Scope Variables。
  • 區域變數的儲存空間只從宣告處存在到區塊結尾。出處：GNU C 手冊 §20.5 Local Variables。
  • 名稱遮蔽：內層區塊宣告了和外層同名的變數時，在內層區塊裡使用的是內層那一個，外層的暫時被「遮住」。出處：Beej §13.1.2 Variable Hiding；GNU C 手冊第 25 章。

對照練習

練習「單元 2」的基本範例用全域變數累計低庫存商品的數量，延伸練習驗證不同函式裡的同名區域變數彼此獨立。下面的補充範例示範「多個函式共用全域變數」，以及「區域變數遮蔽全域變數」時容易造成的誤會。

補充範例 2-1：兩個函式共用一個全域變數

檔名 global_share.c：

#include <stdio.h>

int seatsLeft = 30;          /* 全域變數：剩餘座位 */

void book(int count);
void cancel(int count);

int main(void)
{
    book(12);
    cancel(3);
    book(8);
    printf("最後剩餘：%d 位\n", seatsLeft);
    return 0;
}

void book(int count)
{
    seatsLeft = seatsLeft - count;
    printf("訂位 %d 位，剩餘 %d 位\n", count, seatsLeft);
}

void cancel(int count)
{
    seatsLeft = seatsLeft + count;
    printf("取消 %d 位，剩餘 %d 位\n", count, seatsLeft);
}

預期輸出：

訂位 12 位，剩餘 18 位
取消 3 位，剩餘 21 位
訂位 8 位，剩餘 13 位
最後剩餘：13 位

一步一步看

呼叫 修改者 seatsLeft
程式開始 初始值 30
book(12) book 18
cancel(3) cancel 21
book(8) book 13

seatsLeft 宣告在所有函式之前，所以 main、book、cancel 都能直接使用，而且用的是同一個變數（Beej §13.2）。

補充範例 2-2：同名的區域變數遮住了全域變數

檔名 hiding.c：

#include <stdio.h>

int total = 100;             /* 全域變數 */

void addPoints(int points);

int main(void)
{
    addPoints(20);
    printf("main 看到的 total：%d\n", total);
    return 0;
}

void addPoints(int points)
{
    int total = 0;           /* 區域變數，名字和全域的一樣 */
    total = total + points;
    printf("addPoints 裡的 total：%d\n", total);
}

預期輸出：

addPoints 裡的 total：20
main 看到的 total：100

一步一步看

  1. addPoints 裡宣告了區域變數 total。在這個函式中，total 指的是區域的那一個，全域的 total 被遮住了（Beej §13.1.2）。
  2. 所以 total = total + points; 改的是區域變數（0 + 20），全域的 total 完全沒被碰到。
  3. 回到 main，看到的是全域的 total，仍然是 100。
  4. 如果原本的用意是「把分數加到全域的 total」，這就是一個不容易發現的錯誤。避免的方法是：區域變數不要取和全域變數相同的名字。

動手改改看

  • 把補充範例 2-1 中 int seatsLeft = 30; 這一行移到檔案最後面，重新編譯，讀讀看錯誤訊息（對照 Beej §13.2）。
  • 刪掉補充範例 2-2 中 int total = 0; 這一行，輸出會變成什麼？

3. static 區域變數：跨呼叫仍然記得

用白話說

一般的區域變數在函式結束時就消失，下次呼叫時重新建立。如果希望函式「記得上一次的狀態」，例如累計總共處理過幾筆資料，又不想用誰都能改的全域變數，就可以在區域變數前面加上 static。

static 區域變數的特性可以整理成兩句話：

  • 看得到的範圍和一般區域變數一樣，只有這個函式看得到。
  • 存在的時間和全域變數一樣，從程式開始一直存在到程式結束。

教材怎麼說

  • 在區域變數的宣告中加上 static，這個變數的儲存空間就會像檔案作用域變數一樣永久存在，所以它的值會從這一次呼叫保留到下一次呼叫。它的名稱作用域則和一般區域變數一樣，只到所在區塊結尾。出處：GNU C 手冊 §20.7 Static Local Variables。
  • 有初始值的 static 區域變數只在程式開始時初始化一次，而不是每次呼叫函式時都重新初始化。出處：Beej §16.2.2 static（static in Block Scope）。
  • static 區域變數沒有給初始值時，預設是 0。出處同上。
  • static 區域變數的初始值和檔案作用域變數有相同的限制：不能依賴其他變數的內容，也不能呼叫函式。出處：GNU C 手冊 §20.7。

對照練習

練習「單元 3」的基本範例用 static 變數讓函式記住呼叫次數，延伸練習拿掉 static，觀察每次呼叫都重新歸零；綜合實作用 static int seatCounter 產生遞增的報到序號。下面的補充範例示範另一種常見用途：函式自己記住累計資料，隨時算出目前的平均。

補充範例 3-1：邊輸入邊算平均

問題：陸續輸入溫度讀數，每輸入一筆，就印出「到目前為止」的平均溫度。輸入 0 以下的值時結束。

檔名 running_avg.c：

#include <stdio.h>

double addReading(double value);

int main(void)
{
    double value;

    while (1) {
        printf("輸入溫度（0 以下結束）：");
        if (scanf("%lf", &value) != 1 || value <= 0) {
            break;
        }
        printf("  目前平均：%.2f\n", addReading(value));
    }
    printf("結束\n");
    return 0;
}

double addReading(double value)
{
    static double sum = 0.0;
    static int count = 0;

    sum = sum + value;
    count++;
    return sum / count;
}

執行範例：

輸入溫度（0 以下結束）：24.5
  目前平均：24.50
輸入溫度（0 以下結束）：26.0
  目前平均：25.25
輸入溫度（0 以下結束）：22.0
  目前平均：24.17
輸入溫度（0 以下結束）：0
結束

一步一步看

第幾次呼叫 傳入的 value 呼叫結束時的 sum 呼叫結束時的 count 回傳值
1 24.5 24.5 1 24.50
2 26.0 50.5 2 25.25
3 22.0 72.5 3 24.17
  1. static double sum = 0.0; 只在程式開始時設定一次（Beej §16.2.2）。第 2 次呼叫時，這一行不會再把 sum 設回 0，所以 sum 保留了上一次的 24.5。
  2. sum 和 count 只有 addReading 看得到，main 無法直接修改它們，這比使用全域變數安全。
  3. 如果拿掉 static：每次呼叫時 sum 和 count 都會重新從 0 開始，每次回傳的平均就只是「這一筆」的值。
  4. while (1) 是刻意寫成的無窮迴圈（Beej §3.3.2），靠 break 在輸入 0 以下或讀取失敗時離開。

補充範例 3-2：三種變數放在一起比較

檔名 three_kinds.c：

#include <stdio.h>

int globalCalls = 0;

void visit(void);

int main(void)
{
    visit();
    visit();
    visit();
    printf("main 看到 globalCalls = %d\n", globalCalls);
    return 0;
}

void visit(void)
{
    int localCalls = 0;
    static int staticCalls;      /* 沒有初始值，預設為 0 */

    globalCalls++;
    localCalls++;
    staticCalls++;
    printf("global=%d local=%d static=%d\n", globalCalls, localCalls, staticCalls);
}

預期輸出：

global=1 local=1 static=1
global=2 local=1 static=2
global=3 local=1 static=3
main 看到 globalCalls = 3

一步一步看

變數 宣告位置 誰看得到 每次呼叫會重設嗎
globalCalls 函式外面 宣告之後的所有函式 不會
localCalls 函式裡面 只有 visit 會，每次都從 0 開始
staticCalls 函式裡面，加 static 只有 visit 不會
  • localCalls 每次都印 1，因為它每次呼叫都重新建立（GNU C 手冊 §20.5）。
  • staticCalls 沒寫初始值，預設就是 0（Beej §16.2.2），之後每次呼叫持續累加。
  • main 可以印出 globalCalls，但沒辦法直接使用 staticCalls。

動手改改看

  • 在補充範例 3-2 的 main 中加上 printf("%d\n", staticCalls);，讀讀看編譯器的錯誤訊息。
  • 修改補充範例 3-1，讓 addReading 另外記住「目前的最高溫」，並在結束前印出來。提示：需要讓 main 取得這個值，想想看要用回傳值、指標參數，還是另一個函式。
