1. 陣列名稱就是「第一格的位址」

用白話說

第 8 週把陣列比喻成一排置物櫃，第 11 週把位址比喻成門牌號碼。把兩者合起來：陣列的名字，其實就代表這排櫃子「第一格」的門牌號碼。知道第一格在哪裡，又知道每格一樣大，就能算出任何一格在哪裡。

教材怎麼說

  • 一般說「指向陣列的指標」，指的是指向陣列第一個元素的指標。出處：Beej §6.6.1 Getting a Pointer to an Array。
  • p = &a[0]; 可以簡寫成 p = a;：單獨寫出陣列名稱，就等於取得第一個元素的指標。出處同上。
  • 陣列名稱單獨出現在運算式中時（sizeof 除外），代表指向第 0 個元素的指標。出處：GNU C 手冊 §14.11 Pointers and Arrays。

補充範例 1-1：陣列名稱和 &a[0] 相同

檔名 array_name.c：

#include <stdio.h>

int main(void)
{
    int rainfall[4] = {12, 0, 35, 8};
    int *p = rainfall;

    printf("rainfall == &rainfall[0] 的結果：%d\n", rainfall == &rainfall[0]);
    printf("*p 是 %d，rainfall[0] 是 %d\n", *p, rainfall[0]);
    printf("sizeof rainfall 是 %zu，sizeof p 是 %zu\n", sizeof rainfall, sizeof p);
    return 0;
}

在本講義測試的電腦上，預期輸出：

rainfall == &rainfall[0] 的結果：1
*p 是 12，rainfall[0] 是 12
sizeof rainfall 是 16，sizeof p 是 8

一步一步看

  1. 比較結果是 1（真），證明 rainfall 和 &rainfall[0] 是同一個位址。
  2. int *p = rainfall; 不需要寫 &，因為陣列名稱本身就代表第一格的位址。
  3. sizeof 是例外（GNU C 手冊 §14.11）：sizeof rainfall 算的是整個陣列（4 格 × 4 位元組 = 16），sizeof p 算的是指標本身的大小（本講義測試的電腦上是 8）。所以陣列和指標並不是完全相同的東西。

2. 指標運算：p + i 就是往後數 i 格

用白話說

如果 p 指向某一格，p + 1 就是「下一格」的位址，p + 2 是「再下一格」。這裡的「加 1」不是位址數字加 1，而是往後移動一整格，不管那一格佔幾個位元組。

教材怎麼說

  • 指標加上一個整數是合法的，前提是指標指向陣列中的某個元素；加正數往後移、加負數往前移，移動的單位是「陣列元素」。出處：GNU C 手冊 §14.10 Pointer Arithmetic。
  • C 知道 p 指向 int，也知道一個 int 佔幾個位元組，所以 p + 1 會跳過一個 int 的大小，到達下一個元素。出處：Beej §11.1.1 Adding to Pointers。
  • 指標變數本身也可以被改變，例如 p++ 讓 p 指向下一個元素。出處：Beej §11.1.2 Changing Pointers。
  • 兩個指向同一個陣列的指標可以相減，得到它們之間相隔幾個元素；指向不同東西的指標相減屬於未定義行為。出處：Beej §11.1.3 Subtracting Pointers。

最重要的公式

  • a[b] 和 *(a + b) 完全相同，可以互換使用。出處：Beej §11.2 Array/Pointer Equivalence。
  • C 的方括號就是用指標加法和解參照來定義的：a[i] 的意思就是 *(a + i)。出處：GNU C 手冊 §14.11；§16.1 Accessing Array Elements。

對照練習

練習「單元 2」的基本範例並排比較 arr[i] 和 *(arr + i)；延伸練習用 int 與 char 兩種陣列觀察指標運算實際移動了幾個位元組。下面的補充範例示範另外兩種用法：用 p++ 走到「結束標記」，以及用指標相減算出位置。

補充範例 2-1：三種寫法，同一個結果

檔名 three_ways.c：

#include <stdio.h>

int main(void)
{
    double temps[4] = {21.5, 23.0, 19.8, 25.1};
    double *p = temps;

    for (int i = 0; i < 4; i++) {
        printf("i=%d：temps[i]=%.1f  *(p+i)=%.1f  p[i]=%.1f\n",
               i, temps[i], *(p + i), p[i]);
    }
    return 0;
}

預期輸出：

i=0：temps[i]=21.5  *(p+i)=21.5  p[i]=21.5
i=1：temps[i]=23.0  *(p+i)=23.0  p[i]=23.0
i=2：temps[i]=19.8  *(p+i)=19.8  p[i]=19.8
i=3：temps[i]=25.1  *(p+i)=25.1  p[i]=25.1

一步一步看（假設 temps 從位址 1000 開始，每個 double 佔 8 位元組）

i p + i 的位址 *(p + i)
0 1000 21.5
1 1008 23.0
2 1016 19.8
3 1024 25.1

p + 1 的位址多了 8，而不是 1，因為一格 double 佔 8 位元組（Beej §11.1.1）。三種寫法取得的都是同一格。

補充範例 2-2：用 p++ 走到結束標記

問題：一週的門票銷售量存在陣列中，最後放一個 -1 表示「資料到此結束」。用指標逐格前進，加總到 -1 為止。

檔名 sentinel.c：

#include <stdio.h>

int main(void)
{
    int tickets[] = {120, 95, 143, 88, -1};
    int *p = tickets;
    int total = 0;

    while (*p != -1) {
        total = total + *p;
        p++;
    }

    printf("共 %d 張，讀了 %td 筆資料\n", total, p - tickets);
    return 0;
}

預期輸出：

共 446 張，讀了 4 筆資料

一步一步看

輪次 p 指向的索引 *p 加完後的 total
1 0 120 120
2 1 95 215
3 2 143 358
4 3 88 446
檢查 4 -1 迴圈結束
  1. 每一輪 p++ 讓 p 往後移一格（Beej §11.1.2）。
  2. 迴圈結束時 p 指向索引 4。p - tickets 是兩個指標相減，得到相隔 4 格（Beej §11.1.3）。
  3. 兩個指標相減的結果型別是 ptrdiff_t，用 %td 印出。本講義在引用的教材中沒有找到 %td 的說明，這是依 -Wall 的要求使用的格式碼。

補充範例 2-3：用指標相減算出位置

問題：找出第一個超過 30 度的日子是第幾天。

檔名 find_hot.c：

#include <stdio.h>

int main(void)
{
    int temps[7] = {26, 28, 29, 31, 33, 30, 27};
    int *p = temps;
    int *end = temps + 7;

    while (p < end && *p <= 30) {
        p++;
    }

    if (p == end) {
        printf("這週沒有超過 30 度\n");
    } else {
        printf("第 %td 天首次超過 30 度（%d 度）\n", p - temps + 1, *p);
    }
    return 0;
}

預期輸出：

第 4 天首次超過 30 度（31 度）

一步一步看

  1. end = temps + 7 指向「最後一格的下一個位置」，只用來比較，絕對不能解參照。
  2. 條件 p < end && *p <= 30：先確認 p 還在陣列裡，才去讀 *p。這利用了第 5 週的「&& 左邊為假就不算右邊」，避免讀到陣列外面。
  3. p 停在索引 3（31 度）。p - temps 是 3，加 1 就是「第 4 天」。

動手改改看

  • 把補充範例 2-3 陣列中的 31 和 33 都改成 30，程式會印出什麼？
  • 把補充範例 2-3 的條件改成 *p <= 30 && p < end，說明為什麼順序對調之後可能會出問題。

3. 把陣列傳給函式

用白話說

第 7 週說過，傳給函式的是複本。但複製一整個陣列很浪費，所以 C 的作法是：傳陣列時，只把「第一格的位址」複製過去。函式拿到位址，就能找到呼叫端的那一整排資料，也就能修改它。

教材怎麼說

  • 把陣列傳給函式時，實際上傳的是指向第一個元素的指標。因此函式對陣列所做的修改，在呼叫端也看得到。出處：Beej §6.6.3 Changing Arrays in Functions。
  • 函式參數寫成 int *a、int a[]、int a[5] 三種形式，意思完全相同；最常見的是第一種。編譯器也不會檢查 a[5] 裡寫的數字。出處：Beej §6.6.2 Passing Single Dimensional Arrays to Functions；§11.2.1。
  • 因為函式拿到的只是指標，在函式裡用 sizeof 算不出陣列長度，所以陣列長度要另外用一個參數傳進去。出處：Beej §6.2 Getting the Length of an Array。
  • 參數寫成 const int *p，表示「不能透過 p 修改它指向的資料」，想修改時編譯器會報錯。只需要讀取陣列的函式，適合用這種寫法。出處：Beej §16.1.1 const（const and Pointers）。

對照練習

練習「單元 1」的延伸練習透過指標參數修改呼叫端的陣列，驗證陣列傳給函式不是傳「副本」；練習中也大量使用 const int *arr, int n 這種「只讀取」的參數寫法。下面的補充範例先示範 sizeof 在函式裡失效，再示範「修改」與「只讀取」兩種函式的差別。

補充範例 3-1：在函式裡，sizeof 算不出陣列長度

檔名 sizeof_param.c：

#include <stdio.h>

void showSize(int arr[]);

int main(void)
{
    int scores[5] = {70, 82, 91, 65, 88};

    printf("在 main：sizeof scores = %zu\n", sizeof scores);
    showSize(scores);
    return 0;
}

void showSize(int arr[])
{
    printf("在函式裡：sizeof arr = %zu\n", sizeof arr);
}

編譯時會看到類似下面的警告：

sizeof_param.c:16:56: warning: sizeof on array function parameter will return size of 'int *' instead of 'int[]' [-Wsizeof-array-argument]

在本講義測試的電腦上，執行後的輸出：

在 main：sizeof scores = 20
在函式裡：sizeof arr = 8

一步一步看

  1. 在 main 中，scores 是真正的陣列：5 格 × 4 位元組 = 20。
  2. 傳進函式後，arr 雖然寫成 int arr[]，實際上是一個 int * 指標，sizeof arr 得到的是指標的大小 8。
  3. 編譯器的警告也直接說明了這件事。所以陣列長度一定要另外傳入（Beej §6.2）。

補充範例 3-2：修改陣列的函式與只讀取的函式

問題：商品價格全部打九折，再找出打折後最貴的價格。

檔名 discount.c：

#include <stdio.h>

void applyDiscount(double *prices, int n, double rate);
double highest(const double *prices, int n);

int main(void)
{
    double prices[4] = {120.0, 80.0, 250.0, 45.0};

    applyDiscount(prices, 4, 0.9);

    for (int i = 0; i < 4; i++) {
        printf("%.1f ", prices[i]);
    }
    printf("\n最貴：%.1f\n", highest(prices, 4));
    return 0;
}

void applyDiscount(double *prices, int n, double rate)
{
    for (int i = 0; i < n; i++) {
        prices[i] = prices[i] * rate;
    }
}

double highest(const double *prices, int n)
{
    double best = prices[0];
    for (int i = 1; i < n; i++) {
        if (prices[i] > best) {
            best = prices[i];
        }
    }
    return best;
}

預期輸出：

108.0 72.0 225.0 40.5 
最貴：225.0

一步一步看

  1. applyDiscount(prices, 4, 0.9)：傳進去的是 prices 第一格的位址。函式裡的 prices[i] = ... 直接改到 main 的陣列，所以回到 main 印出的已經是打折後的價格。
  2. 參數寫成 double *prices，但函式裡照樣可以用 prices[i]，因為 a[i] 就是 *(a + i)（Beej §11.2）。
  3. highest 只需要讀，所以參數寫成 const double *prices。如果在裡面不小心寫了 prices[0] = 0;，編譯器會報錯，幫你擋下誤改。
  4. 兩個函式都另外接收 n，因為函式裡算不出陣列長度。

動手改改看

  • 在補充範例 3-2 的 highest 裡加上一行 prices[0] = 0;，讀讀看編譯器的錯誤訊息。
  • 把 applyDiscount 的參數改寫成 double prices[]，程式的行為會改變嗎？（對照 Beej §6.6.2。）

4. 用指標走訪字串

用白話說

字串就是以 \0 結尾的 char 陣列（第 9 週），所以陣列和指標的所有規則都適用。用指標處理字串時，常見的寫法是：讓指標從第一個字元出發，一路 p++，遇到 \0 就停。這樣不需要事先知道字串有多長。

教材怎麼說

  • 函式參數如果是 char *s，呼叫時傳入 char 陣列或 char * 指標都可以；char *s 和 char s[] 兩種參數寫法相同。出處：Beej §11.2.1 Array/Pointer Equivalence in Function Calls。
  • 用指標從字串開頭往後找，一直到空字元為止，再用「結尾指標減去開頭指標」，就能算出字串長度。出處：Beej §11.1.3 Subtracting Pointers。

對照練習

練習「單元 3」的基本範例用指標走訪字串，延伸練習計算母音數量；綜合實作則計算備註文字中的空白字元。下面的補充範例示範另外兩種常見處理：計算特定符號（為第 14 週讀取檔案做準備），以及逐字元替換。

補充範例 4-1：數一數一行資料有幾個欄位

問題：一行用逗號分隔的資料，例如 A123,Wang,88,92，欄位數等於逗號數加 1。

檔名 count_fields.c：

#include <stdio.h>

int countChar(const char *s, char target);

int main(void)
{
    char record[] = "A123,Wang,88,92";

    int commas = countChar(record, ',');
    printf("「%s」有 %d 個逗號，共 %d 個欄位\n", record, commas, commas + 1);
    return 0;
}

int countChar(const char *s, char target)
{
    int count = 0;

    while (*s != '\0') {
        if (*s == target) {
            count++;
        }
        s++;
    }
    return count;
}

預期輸出：

「A123,Wang,88,92」有 3 個逗號，共 4 個欄位

一步一步看

  1. s 一開始指向 'A'。每一輪先看 *s 是不是 ','，再用 s++ 移到下一個字元。
  2. 遇到結尾的 '\0' 時，*s != '\0' 為假，迴圈結束。
  3. s 是參數，也就是指標的複本。在函式裡移動 s，不會影響 main 的 record（第 11 週）。
  4. const char *s 表示這個函式保證不修改字串內容。

補充範例 4-2：把空白換成底線

問題：把使用者輸入的檔案名稱中的空白換成底線，並算出名稱長度。

檔名 underscore.c：

#include <stdio.h>

int replaceSpaces(char *s);

int main(void)
{
    char name[40];

    printf("請輸入檔案名稱：");
    if (fgets(name, sizeof name, stdin) == NULL) {
        return 1;
    }

    int length = replaceSpaces(name);
    printf("處理後：%s（%d 個字元）\n", name, length);
    return 0;
}

int replaceSpaces(char *s)
{
    char *start = s;

    while (*s != '\0') {
        if (*s == '\n') {
            *s = '\0';
            break;
        }
        if (*s == ' ') {
            *s = '_';
        }
        s++;
    }
    return (int)(s - start);
}

執行範例：

請輸入檔案名稱：my week 11 notes
處理後：my_week_11_notes（16 個字元）

一步一步看

  1. start 記住字串開頭的位址，s 負責往後走。
  2. 遇到空白，就用 *s = '_' 直接修改呼叫端陣列中的那個字元；遇到 fgets 留下的換行，就改成 '\0' 並停止（第 9 週的作法）。
  3. 迴圈結束時，s 停在字串結尾。s - start 是兩個指標相減，得到字元數 16（Beej §11.1.3）。
  4. 這個函式需要修改字串，所以參數是 char *s，不能加 const。

動手改改看

  • 用補充範例 4-1 的 countChar 計算一句話裡有幾個字母 a。
  • 在補充範例 4-2 的 replaceSpaces 參數加上 const，讀讀看編譯器怎麼說。

本講義未涵蓋的內容

  • 「陣列退化為指標」（decay）這個名詞：本講義在引用的教材中沒有找到這個說法，這是課程講義與練習使用的術語。
  • %td 與 ptrdiff_t：引用的教材中沒有說明，本講義只依編譯器的要求使用。
  • 判斷一個字元是不是英文字母的方法：屬於練習的學習任務，本講義不提供解法。
