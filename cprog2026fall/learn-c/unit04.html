1. 比較運算與 if、if-else

用白話說

到目前為止，程式都是從第一行一路執行到最後一行。但生活中常常要「看情況」做事：分數及格就恭喜，不及格就提醒。if 讓程式先檢查一個條件，再決定要執行哪一段程式碼。

教材怎麼說

比較運算子

運算子 意思
== 等於
!= 不等於
<、> 小於、大於
<=、>= 小於或等於、大於或等於
  • 比較的結果是一個數字：條件成立時是 1（真），不成立時是 0（假）。出處：GNU C 手冊 §6.6 Numeric Comparisons。
  • 「等於」要寫兩個等號 ==，因為一個等號 = 是「存入」。Beej 特別提醒不要把兩者搞混。出處：GNU C 手冊 §6.6；Beej §3.2.5 Conditional Operators。

if 與 if-else

  • if 先計算小括號裡的條件。條件為真（不是 0）才執行後面的敘述；條件為假（0）就跳過。出處：GNU C 手冊 §19.2 if Statement。
  • if-else 在條件為真時執行第一段，為假時執行 else 後面那一段，兩段之中一定會執行其中一段。出處：GNU C 手冊 §19.3 if-else Statement。
  • if 和 else 後面只能接一個敘述。想放好幾行，要用大括號 { } 把它們包成一個區塊。出處：GNU C 手冊 §19.2、§19.3；Beej §3.3.1。

對照練習

練習「單元一」的基本範例用 % 判斷一個整數是不是偶數：餘數等於 0 就是偶數。下面的補充範例把 if 用在另外兩個地方：判斷及格，以及上週學過的「檢查 scanf 有沒有讀到資料」。

補充範例 1-1：及格判斷

檔名 pass.c：

#include <stdio.h>

int main(void)
{
    int score;

    printf("請輸入分數：");
    scanf("%d", &score);

    if (score >= 60) {
        printf("及格\n");
    } else {
        printf("不及格，差 %d 分\n", 60 - score);
    }

    printf("判斷結束\n");
    return 0;
}

執行範例（輸入 72）：

請輸入分數：72
及格
判斷結束

執行範例（輸入 45）：

請輸入分數：45
不及格，差 15 分
判斷結束

一步一步看

輸入 score >= 60 的值 執行哪一段
72 1（真） if 後面的區塊
45 0（假） else 後面的區塊

不論走哪一條路，最後的「判斷結束」都會印出，因為它在整個 if-else 的外面。

補充範例 1-2：輸入錯誤就提早結束

問題：延續第 4 週的補充範例 1-3，這次真的根據 scanf 的回傳值做決定。

檔名 safe_input.c：

#include <stdio.h>

int main(void)
{
    int quantity;

    printf("請輸入數量：");
    if (scanf("%d", &quantity) != 1) {
        printf("輸入的不是整數\n");
        return 1;
    }

    printf("總價：%d 元\n", quantity * 35);
    return 0;
}

執行範例（輸入 4）：

請輸入數量：4
總價：140 元

執行範例（輸入 ten）：

請輸入數量：ten
輸入的不是整數

一步一步看

  1. scanf("%d", &quantity) 讀取成功時回傳 1。
  2. != 1 表示「不等於 1」，也就是讀取失敗。
  3. 失敗時執行 return 1;，main 立刻結束，後面計算總價的那一行不會執行。回傳非 0 的值通常代表程式沒有正常完成。

常見錯誤：把 == 寫成 =

檔名 oops.c：

#include <stdio.h>

int main(void)
{
    int answer = 3;

    if (answer = 5) {
        printf("答案是 5\n");
    }
    return 0;
}

編譯時會看到類似下面的警告：

oops.c:7:16: warning: using the result of an assignment as a condition without parentheses [-Wparentheses]

一步一步看

  1. answer = 5 不是比較，而是把 5 存進 answer。
  2. 這個運算式的值是 5，不是 0，所以條件永遠成立，「答案是 5」一定會印出。
  3. 改成 if (answer == 5)，警告消失，而且因為 answer 是 3，這一行就不會印出。

2. else if 鏈與邏輯運算子

用白話說

有時候不只兩種情況，例如成績要分成 A、B、C 好幾個等級，這時可以把 if-else 串起來。另外，一個條件有時需要同時滿足兩件事（「而且」），或只要滿足其中一件（「或者」），這就要用到邏輯運算子。

教材怎麼說

else if 鏈

  • if-else 可以一路串接成 else if，依序測試多個條件；最後的 else 負責處理前面都不成立的情況。出處：Beej §3.3.1 The if-else statement。

邏輯運算子

運算子 意思 什麼時候為真
&& 而且 左右兩邊都為真
\|\| 或者 左右至少一邊為真
! 不是 原本為假時

出處：GNU C 手冊 §8.1 Logical Operators；Beej §3.2.6 Boolean Operators。

  • 在 C 中，0 代表假，其他任何值都代表真；邏輯運算子的結果一定是 1 或 0。出處：GNU C 手冊 §8.1。
  • 提早決定結果：&& 左邊已經是假時，右邊就不再計算；|| 左邊已經是真時，右邊也不再計算。出處：GNU C 手冊 §8.1。
  • ! 比比較運算子先算，所以要否定一整個比較時要加括號，例如 !(x < 12)。出處：Beej §3.2.6。
  • && 和 || 一起使用時，GNU C 手冊建議一律加括號標明先後，不要依賴它們之間的優先順序。出處：GNU C 手冊 §8.1。

對照練習

練習「單元二」的基本範例依運動分鐘數分成長、中、短三類：先檢查 >= 60，再檢查 >= 30，其餘歸為短時間。下面的補充範例說明「為什麼一定要從大的範圍開始檢查」，並示範 &&、|| 的用法。

補充範例 2-1：成績等第

檔名 grade.c：

#include <stdio.h>

int main(void)
{
    int score;

    printf("請輸入分數：");
    scanf("%d", &score);

    if (score >= 90) {
        printf("等第 A\n");
    } else if (score >= 80) {
        printf("等第 B\n");
    } else if (score >= 70) {
        printf("等第 C\n");
    } else {
        printf("等第 D\n");
    }
    return 0;
}

執行範例：

請輸入分數：85
等第 B

一步一步看（輸入 85）

檢查順序 條件 結果 動作
1 85 >= 90 假 繼續往下檢查
2 85 >= 80 真 印出「等第 B」，整個鏈結束
3 85 >= 70 不會檢查 已經有一個分支成立

如果順序寫反了會怎樣？ 假設第一個條件是 score >= 70，輸入 95 時第一個條件就成立，會印出「等第 C」，後面的 >= 90 永遠沒有機會被檢查。所以範圍條件要從最嚴格的開始寫。

補充範例 2-2：&& 與 ||

問題：遊樂園票價規則：未滿 12 歲或 65 歲以上享半價；12 到 17 歲而且持有學生證，打八折；其他人全票 500 元。

檔名 ticket.c：

#include <stdio.h>

int main(void)
{
    int age;
    int hasStudentCard;

    printf("請輸入年齡：");
    scanf("%d", &age);
    printf("有學生證嗎？（有請輸入 1，沒有請輸入 0）：");
    scanf("%d", &hasStudentCard);

    if (age < 12 || age >= 65) {
        printf("半價：250 元\n");
    } else if ((age >= 12 && age <= 17) && hasStudentCard) {
        printf("學生優惠：400 元\n");
    } else {
        printf("全票：500 元\n");
    }
    return 0;
}

執行範例：

請輸入年齡：15
有學生證嗎？（有請輸入 1，沒有請輸入 0）：1
學生優惠：400 元

一步一步看（年齡 15、有學生證）

  1. age < 12 是假、age >= 65 也是假，|| 兩邊都假，第一個條件不成立。
  2. age >= 12 真、age <= 17 真，括號內 && 的結果為真；hasStudentCard 是 1，也是真。整個條件成立，印出學生優惠。
  3. hasStudentCard 直接當條件使用：它的值是 1 就是真，是 0 就是假（GNU C 手冊 §8.1）。

補充範例 2-3：利用「提早決定結果」避免除以 0

檔名 average.c：

#include <stdio.h>

int main(void)
{
    int total;
    int count;

    printf("請輸入總分與人數：");
    scanf("%d %d", &total, &count);

    if (count != 0 && total / count >= 60) {
        printf("平均及格\n");
    } else {
        printf("沒有資料或平均不及格\n");
    }
    return 0;
}

執行範例（人數為 0）：

請輸入總分與人數：300 0
沒有資料或平均不及格

一步一步看（人數為 0）

  1. && 先算左邊：count != 0 是假。
  2. 左邊已經是假，整個 && 一定是假，所以右邊的 total / count 不會被計算，也就不會發生除以 0。
  3. 如果把兩邊對調，寫成 total / count >= 60 && count != 0，就會先做除以 0 的計算。

動手改改看

  • 用 55、70、90、100 測試補充範例 2-1，並先在紙上寫下預期等第。
  • 補充範例 2-2 中，輸入年齡 15、沒有學生證，會得到哪一種票價？為什麼？

3. switch 敘述

用白話說

當你要根據一個整數代碼做不同的事，例如「輸入 1 查詢、輸入 2 修改、輸入 3 離開」，用 switch 會比一長串 else if 更清楚。

教材怎麼說

  • switch 計算小括號裡的整數值，跳到對應的 case 開始執行；遇到 break 就離開整個 switch。出處：Beej §3.3.5 The switch Statement；GNU C 手冊 §19.7 switch Statement。
  • case 後面的值必須是編譯時就能確定的整數常數，而且不能有兩個 case 是同一個值。出處：GNU C 手冊 §19.7。
  • default 處理所有沒有對應 case 的值；如果沒有 default，而值又對不上任何 case，switch 就什麼都不做。出處：GNU C 手冊 §19.7；Beej §3.3.5。
  • 一個 case 結尾如果沒有 break，會繼續執行下一個 case 的程式碼（稱為貫穿，fall through）。GNU C 手冊指出這通常是不小心造成的；若是刻意的，應該加上註解說明。出處：GNU C 手冊 §19.7。
  • 連續寫好幾個 case 標籤、共用同一段程式碼，是清楚且常見的寫法。出處同上。

對照練習

練習「單元三」的基本範例把季節代碼 1 到 4 轉成中文名稱。下面的補充範例示範「多個 case 共用一段程式」，以及忘記 break 會發生什麼事。

補充範例 3-1：平日還是週末

檔名 weekday.c：

#include <stdio.h>

int main(void)
{
    int day;

    printf("請輸入星期幾（1 到 7）：");
    scanf("%d", &day);

    switch (day) {
        case 1:
        case 2:
        case 3:
        case 4:
        case 5:
            printf("平日，圖書館開到 22:00\n");
            break;
        case 6:
        case 7:
            printf("週末，圖書館開到 17:00\n");
            break;
        default:
            printf("沒有星期 %d\n", day);
            break;
    }
    return 0;
}

執行範例：

請輸入星期幾（1 到 7）：6
週末，圖書館開到 17:00

一步一步看（輸入 6）

  1. switch 直接跳到 case 6:。
  2. case 6: 下面緊接著 case 7:，沒有任何程式碼，繼續往下走，執行「週末」那一行。
  3. 遇到 break，離開 switch。
  4. 如果輸入 9，沒有對應的 case，就執行 default。

補充範例 3-2：忘記 break 的後果

檔名 nobreak.c：

#include <stdio.h>

int main(void)
{
    int level = 2;

    switch (level) {
        case 1:
            printf("解鎖：基本題\n");
        case 2:
            printf("解鎖：進階題\n");
        case 3:
            printf("解鎖：挑戰題\n");
            break;
        default:
            printf("等級不存在\n");
            break;
    }
    return 0;
}

預期輸出：

解鎖：進階題
解鎖：挑戰題

一步一步看

  1. level 是 2，跳到 case 2:，印出「進階題」。
  2. case 2: 結尾沒有 break，所以繼續執行 case 3: 的程式碼，印出「挑戰題」。
  3. 到了 case 3: 結尾的 break 才離開。
  4. 如果原本的意思是「每個等級只印自己那一行」，就要在每個 case 結尾都加上 break。

switch 和 else if 怎麼選

case 只能比對「是否等於某個整數常數」（GNU C 手冊 §19.7）。因此：

情況 適合的寫法
選單代碼、星期、月份這類固定整數 switch
分數在某個範圍、身高超過某個值 else if 鏈
需要比較有小數的數值 else if 鏈

GNU C 手冊有提到一種寫出範圍的 case 寫法，但那是 GNU C 的擴充功能，不是標準 C，本課程不使用。

動手改改看

  • 在補充範例 3-2 的 case 1: 和 case 2: 結尾各加上 break，把 level 分別改成 1、2、3 執行看看。
  • 把補充範例 3-1 的 default 整段刪掉，輸入 9 會印出什麼？
