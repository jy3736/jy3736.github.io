1. 變數：替資料取一個名字

用白話說

程式常常需要記住一些數字，例如存款金額、上課人數。變數就是替這些資料取一個名字，之後用名字就能讀出或改寫它。每個變數都要先說清楚它存放哪一種資料，這就是它的型別。

教材怎麼說

  • 宣告變數的基本寫法是「型別 變數名稱」，後面可以加上 = 初始值。例如 int foo; 宣告一個 int 型別、名叫 foo 的變數。出處：GNU C 手冊 §20.1 Variable Declarations。
  • 變數名稱可以使用英文字母、數字 0-9 和底線 _，但有三條限制：不能以數字開頭、不能以兩個底線開頭、不能以「底線加大寫字母」開頭。出處：Beej's Guide §3.1.1 Variable Names。

對照練習

練習「單元一」的基本範例宣告了一個變數存放存款金額，再把它印出來。下面的補充範例延續這個情境，多做一步「改變變數的值」。

補充範例 1-1：變數的值可以改變

檔名 deposit.c：

#include <stdio.h>

int main(void)
{
    int balance = 500;

    printf("一開始的存款：%d\n", balance);

    balance = balance + 300;
    printf("存入 300 之後：%d\n", balance);

    balance = balance - 150;
    printf("領出 150 之後：%d\n", balance);

    return 0;
}

預期輸出：

一開始的存款：500
存入 300 之後：800
領出 150 之後：650

一步一步看

執行到的敘述 balance 的值
int balance = 500; 500
balance = balance + 300; 800
balance = balance - 150; 650

balance = balance + 300; 的讀法是：先算出右邊「目前的 balance 加 300」，再把結果存回 balance。這裡的 = 是「存入」，不是數學上的「相等」。

printf 中的 %d 表示「在這裡印出一個整數」，要印的變數寫在逗號後面。格式的完整規則在第 4 週介紹。

補充範例 1-2：哪些名字可以用

檔名 names.c：

#include <stdio.h>

int main(void)
{
    int studentCount = 42;     /* 可以：字母開頭 */
    int class_2 = 38;          /* 可以：數字不在開頭 */
    /* int 2ndClass = 40;         不行：以數字開頭，編譯會失敗 */

    printf("%d %d\n", studentCount, class_2);
    return 0;
}

預期輸出：

42 38

動手改改看

  • 把補充範例 1-2 中被註解掉的那一行恢復（刪掉 /* 和 */），重新編譯，讀讀看編譯器怎麼說。
  • 在補充範例 1-1 再加一次「存入 1000」，先在紙上算出結果，再執行驗證。

2. 基本資料型別

用白話說

不同的資料需要不同大小的「容器」。整數用整數型別，有小數點的數字用浮點數型別。容器越大，能存的數值範圍越大。

教材怎麼說

整數型別

  • 整數型別分成「有號」（signed，可存正數和負數）與「無號」（unsigned，只能存 0 和正數）。型別佔用的位元組數決定能存放的數值範圍。出處：GNU C 手冊 §11.1.1 Basic Integers。
  • 在大多數電腦上，各型別的大小如下。出處同上。
型別 大多數電腦上的大小
signed char 1 位元組（8 位元）
short 2 位元組（16 位元）
int 4 位元組（32 位元）
long 4 或 8 位元組，依平台而定
long long 8 位元組（64 位元）

浮點數型別

  • 浮點數是「二進位版本的科學記號」，用來表示有小數的數值。出處：GNU C 手冊 §11.2 Floating-Point Data Types。
  • double 使用 64 位元，是一般情況下應該使用的浮點數型別；float 使用 32 位元，主要用在需要節省空間的場合。出處同上。

sizeof 運算子

  • sizeof 會告訴你某個型別或變數佔幾個位元組，結果的型別是 size_t，用 %zu 印出。出處：Beej 函式庫參考 §2.2.9 The sizeof Operator。

對照練習

練習「單元二」要你為不同的資料選擇合適的型別。下面的補充範例讓你親眼看到每種型別在自己電腦上佔多少空間。

補充範例 2-1：查看型別的大小

檔名 sizes.c：

#include <stdio.h>

int main(void)
{
    printf("char      佔 %zu 位元組\n", sizeof(char));
    printf("int       佔 %zu 位元組\n", sizeof(int));
    printf("long long 佔 %zu 位元組\n", sizeof(long long));
    printf("float     佔 %zu 位元組\n", sizeof(float));
    printf("double    佔 %zu 位元組\n", sizeof(double));
    return 0;
}

在本講義測試的電腦上，輸出如下（long 等型別的大小會因電腦而不同，所以沒有列入）：

char      佔 1 位元組
int       佔 4 位元組
long long 佔 8 位元組
float     佔 4 位元組
double    佔 8 位元組

補充範例 2-2：整數和浮點數存同一個數值

檔名 height.c：

#include <stdio.h>

int main(void)
{
    double heightCm = 172.5;
    int heightInt = 172;

    printf("用 double 存：%f\n", heightCm);
    printf("用 int 存：%d\n", heightInt);
    return 0;
}

預期輸出：

用 double 存：172.500000
用 int 存：172

%f 用來印浮點數，預設會印出小數點後 6 位；%d 用來印整數。

3. 運算式與型別轉換

用白話說

運算式就是「會算出一個值」的算式，例如 price * 3。C 的算術大致和數學相同，但有兩個一定要記住的差異：整數相除會把小數去掉，以及型別不同的數值放在一起計算時，會先被轉成同一種型別。

教材怎麼說

運算順序

  • 乘、除會比加、減先算；同一級的運算由左到右；可以加小括號指定先算哪一部分。出處：GNU C 手冊 §6.1 Basic Arithmetic。

整數除法與餘數

  • 兩個整數相除，結果仍然是整數，小數部分朝 0 的方向捨去。例如 16 / 3 是 5，-16 / 3 是 -5。出處：GNU C 手冊 §6.5 Division and Remainder。
  • 要取得餘數，使用 %。% 只能用在整數上。出處同上。
  • 只要 / 的其中一邊是浮點數，另一邊也會被轉成浮點數，結果就會保留小數。出處同上。

共同型別與強制轉型

  • 算術運算前，兩邊的數值會先轉成「共同型別」：一邊是浮點數、一邊是整數時，整數會被轉成浮點數。出處：GNU C 手冊 §24.5 Common Type。
  • 在數值前面寫 (double) 這種「小括號加型別名稱」，可以明確把它轉成該型別，稱為強制轉型（cast）。想讓兩個整數相除時保留小數，只要把其中一個先轉成 double 就夠了。出處：GNU C 手冊 §24.1 Explicit Type Conversion。
  • 用 %d 去印一個 double 值是錯的，印出來的會是沒有意義的結果。出處同上。

對照練習

練習「單元三」的基本範例把 100 分鐘平均分給 3 堂課，比較了整數除法（33）與轉型後（33.33）的差異。下面的補充範例用同樣的規則處理另外兩種常見情況。

補充範例 3-1：用 / 和 % 換算時間

問題：把總分鐘數換算成「幾小時幾分鐘」。

檔名 minutes.c：

#include <stdio.h>

int main(void)
{
    int totalMinutes = 135;

    int hours = totalMinutes / 60;
    int minutes = totalMinutes % 60;

    printf("%d 分鐘 = %d 小時 %d 分鐘\n", totalMinutes, hours, minutes);
    return 0;
}

預期輸出：

135 分鐘 = 2 小時 15 分鐘

一步一步看

  1. 135 / 60：數學上是 2.25，但兩邊都是整數，小數被捨去，得到 2。
  2. 135 % 60：135 除以 60 的餘數是 15。
  3. 驗算：2 * 60 + 15 等於 135。GNU C 手冊 §6.5 也用「除數乘商再加餘數，可以還原被除數」來說明 / 和 % 的關係。

補充範例 3-2：轉型要放在哪裡

問題：練習「單元三」的概念回顧提到 (double)(a / b) 和 (double)a / b 結果不同。實際跑一次看看。

檔名 castpos.c：

#include <stdio.h>

int main(void)
{
    int total = 7;
    int people = 2;

    double wrong = (double)(total / people);
    double right = (double)total / people;

    printf("先除再轉型：%.2f\n", wrong);
    printf("先轉型再除：%.2f\n", right);
    return 0;
}

預期輸出：

先除再轉型：3.00
先轉型再除：3.50

一步一步看

寫法 計算過程 結果
(double)(total / people) 小括號先算：7 / 2 是整數除法，得 3；再把 3 轉成 3.0 3.00
(double)total / people total 先轉成 7.0；7.0 / 2 中有一邊是浮點數，所以 2 也轉成浮點數 3.50

小數已經在整數除法時被捨去，事後再轉型也救不回來。

補充範例 3-3：運算順序

檔名 order.c：

#include <stdio.h>

int main(void)
{
    int a = 2 + 3 * 4;
    int b = (2 + 3) * 4;
    int c = 20 - 6 - 4;

    printf("a = %d\n", a);
    printf("b = %d\n", b);
    printf("c = %d\n", c);
    return 0;
}

預期輸出：

a = 14
b = 20
c = 10
  • a：乘法先算，3 * 4 是 12，再加 2。
  • b：小括號先算，2 + 3 是 5，再乘 4。
  • c：同一級由左到右，20 - 6 是 14，再減 4。

動手改改看

  • 把補充範例 3-1 的 totalMinutes 改成 59、60、61，先預測結果再執行。
  • 把補充範例 3-2 的 total 改成 8，兩種寫法的結果還會不同嗎？為什麼？

4. 用 const 宣告不會改變的值

教材怎麼說

  • 在宣告前面加上 const，這個變數就不能再被指定新的值，程式中任何改寫它的敘述都會被當成錯誤。出處：GNU C 手冊 §21.1 const Variables and Fields。

對照練習

練習「本週 C 迷你專案：簡易庫存與定價計算程式」需要處理價格計算。像稅率、折扣這種在程式執行中不應該被改動的數值，適合用 const 宣告。

補充範例 4-1：含稅價格

檔名 tax.c：

#include <stdio.h>

int main(void)
{
    const double TAX_RATE = 0.05;
    int price = 240;

    double tax = price * TAX_RATE;
    double total = price + tax;

    printf("售價：%d\n", price);
    printf("稅金：%.1f\n", tax);
    printf("含稅：%.1f\n", total);
    return 0;
}

預期輸出：

售價：240
稅金：12.0
含稅：252.0

一步一步看

  1. price * TAX_RATE：price 是整數、TAX_RATE 是 double，依照共同型別規則，整數先轉成浮點數再相乘，得到 12.0。
  2. 如果在程式中加上 TAX_RATE = 0.1;，編譯會失敗，因為 const 變數不能被修改。

補充知識：整數也有容量上限

  • 計算結果超出型別能表示的範圍，稱為溢位（overflow）。出處：GNU C 手冊 §6.3 Integer Overflow。
  • 有號整數（例如 int）溢位時，結果在原則上是「未定義的」，也就是什麼事都可能發生。出處：GNU C 手冊 §6.3.2。
  • 所以預估數值可能很大時，要選擇夠大的型別。
