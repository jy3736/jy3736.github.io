# 活動值班表自動排班工具

這是一個幫你快速安排活動值班人員的小工具。

你只要設定活動時段、人員可以值班的時間與基本規則，系統就會自動產生一份合理的班表。

## 最簡單的使用方式

1. 填寫活動名稱與日期。
2. 使用「常用值班時段」，或自行新增時段。
3. 新增人員，設定誰是組長，以及每個人可以值班的時段。
4. 設定每人最多值班幾個時段，以及每個時段是否需要組長。
5. 點擊「產生班表」。

完成後可以查看：

- 每個時段安排了哪些人
- 哪些人是組長
- 每個人的值班次數

## 快速測試

想快速看看效果，可以：

1. 點擊「載入範例資料」。
2. 點擊「產生班表」。

系統會自動建立範例活動、時段與 8 位工作人員。

## CSV 匯入

人員較多時，可以使用 CSV 一次匯入。

先建立值班時段，再到「人員管理」點擊「匯入 CSV」。匯入視窗內可以直接填入範例內容。

CSV 格式如下：

```csv
姓名,是否為組長,可值班時段
Alice,是,1|2
Bob,否,2|3
```

`1|2` 代表這位人員可以參加第 1 與第 2 個時段。

## 排班規則

系統會確保：

- 人員只會被排到可以值班的時段
- 每個時段達到需要的人數
- 每人不超過最大值班數
- 開啟組長需求時，每個時段至少有一位組長
- 在符合以上規則的情況下，儘量平均分配工作

如果條件無法滿足，系統會顯示原因，不會產生違反規則的班表。

## 儲存與匯出

- 目前資料會保存在瀏覽器中，重新整理後仍會保留。
- 可以將最終班表下載為 CSV。
- 可以使用「列印班表」取得適合列印的版面。

## 開啟工具

直接用瀏覽器開啟 `index.html` 即可使用，不需要安裝其他軟體。
